- kernel family: Quantized linear (on-the-fly dequantization of low-bit weights)
- concise summary: The forward Triton matmul tiles the activation matrix, unpacks grouped low-bit weights via per-group scale/zero tensors, reconstructs them to FP16, and accumulates the dense product into the output tile.
- detailed summary: `matmul_248_kernel` is autotuned over multiple block shapes; each program handles a BLOCK_SIZE_M×BLOCK_SIZE_N tile and advances along K in BLOCK_SIZE_K steps. Within the loop it loads the group indices `g_idx`, gathers the relevant `scales` and `zeros`, extracts packed integers from `qweight` via bit shifts determined by `bits`, recenters them (`b = b * scales - scales * zeros`) to undo quantization, and performs FP32 `tl.dot` multiplies with the FP16 activation tile. After iterating across all K blocks the accumulator is cast to FP16 and stored under the usual bounds mask. The Python helper `matmul248` sets the launch grid, enforces contiguous quantized weights, and returns the dense output; `_QuantLinearFunction_forward` wraps this helper under AMP casting and simply returns the linear result.
