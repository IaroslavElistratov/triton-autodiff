- kernel family: rotary position embedding (general tensor rotation with optional varlen + inplace)
- concise summary: Shared Triton rotary kernel rotates each BLOCK_M×BLOCK_K slice of the input using per-position sin/cos tables, enabling in-place or out-of-place updates for fixed or variable-length batches.
- detailed summary: The forward wrapper validates tensor layouts, copies non-rotary channels when needed, selects kernel tile shapes from the rotary dimension, and dispatches across `(token-block, batch, head)` grids while optionally reading `cu_seqlens` to span packed sequences. Within the kernel each program offsets pointers based on either scalar or per-batch offsets, gathers sin/cos vectors, handles split or interleaved storage, applies optional conjugation, and writes rotated values back—preserving untouched tail dimensions when operating out of place.
