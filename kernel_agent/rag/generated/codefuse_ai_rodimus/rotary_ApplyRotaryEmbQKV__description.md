- kernel family: rotary position embedding (QKV in-place block rotation with optional variable seqlen)
- concise summary: Triton rotary kernel tiles queries/keys by BLOCK_M tokens and BLOCK_K feature pairs, loading sin/cos tables per token offset to rotate the first rotary_dim channels while leaving any tail untouched.
- detailed summary: Each grid instance spans one batch-head pair and sweeps over token blocks; for fixed sequences it offsets pointers by contiguous strides, while variable-length mode derives per-batch start/length from `cu_seqlens`. Within a block it loads interleaved or split real/imag halves, applies conjugation if requested, multiplies by broadcast sin/cos vectors to produce rotated components, and writes back in-place while preserving non-rotary dimensions. The Python launcher picks BLOCK_K and BLOCK_M based on rotary_dim and interleaving, handles optional per-batch seqlen offsets, and dispatches the same kernel to update Q/K pairs efficiently whether the tensors come in stacked QKV or separate Q/K views.
