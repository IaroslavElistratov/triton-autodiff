- kernel family: gated layer normalization (grouped LN with optional SiLU gate)
- concise summary: A 2D Triton launch normalizes each group-sized slice per batch row, optionally multiplying by `z * sigmoid(z)` either before or after normalization and applying affine scale/bias.
- detailed summary: The kernel iterates over BLOCK_N features within each `(row, group)` tile, mixing an auxiliary modulation tensor if `Z` is present; when `norm_before_gate` is false it gates the raw inputs before computing mean/variance, otherwise it normalizes first then applies the gate to the affine output. Mean/rstd buffers are written to per-group arrays, weight/bias vectors are loaded with contiguous strides, and the surrounding Python wrapper reshapes inputs, enforces contiguous storage, chooses tile sizes under a 64KB limit, and dispatches with the correct num_warps heuristics for group size.
