- kernel family: layer normalization + linear projection (residual-aware LN feeding dense layer)
- concise summary: A Triton row kernel fuses residual add, LN/RMS statistics, and affine scaling before the Python wrapper reshapes back and applies an `F.linear` with autocast-aware weights.
- detailed summary: `_layer_norm_fwd_1pass_kernel` assigns one program per row, loading BLOCK_N features in FP32, optionally summing a residual stream, writing the combined input to an auxiliary buffer, computing mean/variance (or RMS), and applying weight/bias vectors under masks while saving per-row mean/rstd. The launcher enforces contiguous last-dimension access, chooses a power-of-two tile under 64KB, and prepares residual storage so the post-kernel step can cast the normalized tensor into the desired dtype and run the linear projection, caching residual_out, affine weights, and statistics for reuse.
