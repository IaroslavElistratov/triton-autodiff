- kernel family: layer normalization (residual-supporting LN/RMS on contiguous rows)
- concise summary: A single-pass Triton kernel loads each row, adds an optional residual stream, computes mean/variance (or RMS), applies affine parameters, and optionally stores the combined residual for prenorm pipelines.
- detailed summary: The forward wrapper flattens the batch dimension, enforces contiguous storage, and selects BLOCK_N as the next power of two under 64KB before launching `_layer_norm_fwd_1pass_kernel` over the row count. Inside the kernel FP32 accumulators hold the residual-augmented activations, mean/rstd are written to buffers, and weight/bias vectors (if present) modulate the normalized data; the result is reshaped back and, when `prenorm` is enabled, returned alongside the saved residual snapshot.
