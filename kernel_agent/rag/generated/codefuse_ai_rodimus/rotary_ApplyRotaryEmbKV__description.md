- kernel family: rotary position embedding (K/V pair rotation with optional offsets and varlen)
- concise summary: Uses the shared Triton `rotary_kernel` to rotate the key sub-tensor in-place, honoring per-batch sequence offsets and interleaved layouts while leaving the value slice untouched.
- detailed summary: The launcher views the stacked KV tensor as `(B, T, 2, H, D)`, pulls out the key view `kv[..., 0, :, :]`, ensures sin/cos tables are contiguous, selects BLOCK_K/BLOCK_M from `rotary_dim`, and invokes `rotary_kernel` across `(token-block, batch, head)` grids. Inside the kernel each program loads a token stripe, derives absolute rotary indices from scalar or tensor offsets (optionally via `cu_seqlens`), gathers sin/cos entries, and rotates the key feature pairs (split or interleaved) with optional conjugation while preserving non-rotary tails. The value slice is never modified, so downstream code continues to read the original V data.
