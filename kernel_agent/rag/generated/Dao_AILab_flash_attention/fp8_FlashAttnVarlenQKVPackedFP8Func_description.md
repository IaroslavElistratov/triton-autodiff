- kernel family: attention (flash-style, FP8, variable-length QKV packed)
- concise summary: Works on a packed `(total_seqlen, 3, heads, dim)` tensor with cumulative offsets, converts each slice to FP8 using per-sequence max tracking, and runs the FP8 flash-attention kernel tailored for ragged batches with options for causal windows, dropout, softcap, and ALiBi before writing outputs and auxiliary masks.
- detailed summary: `FlashAttnVarlenQKVPackedFP8Func.forward` untangles the shared Q/K/V axis, applies `_cast_varlen_to_fp8_kernel_2d` to obtain FP8 tensors plus head-wise descale factors (reusing supplied factors when available), and builds metadata from `cu_seqlens` and `max_seqlen` to describe each sequence segment. It then configures the autotuned `attn_fwd` kernel in varlen mode: each program id maps to a query block and head, loads the appropriate FP8 slices based on the per-sequence offsets, and iterates over key tiles while applying sliding-window or causal masks, optional ALiBi terms, and Philox-driven dropout/score capture. The kernel keeps accumulators in fp32, handles grouped head mappings, and can optionally convert the final context back to FP8. By keeping Q/K/V packed, this variant minimizes memory movement while still supporting the full feature set of the FP8 flash-attention pipeline for variable-length batches.
