- kernel family: attention (AMP-prefill FlashAttention using external fp8 kernels)
- concise summary: The forward path casts dense `(batch, seqlen, heads, dim)` Q/K/V tensors to fp8 with per-head descale factors, then invokes the fused `flash_attn_gpu.fwd` routine—which supports dropout, alibi bias, softcap clipping, and causal/window masks—to produce the attention output alongside optional softmax statistics and RNG state.
- detailed summary: Helper routines such as `cast_to_fp8` and `_cast_varlen_to_fp8_kernel_2d` quantize each head independently: they sweep the sequence in 128-element stripes, accumulate the maximum absolute activation, compute scaling/descale factors, and write the fp8 representation plus a fp32 descale tensor. `_FlashAttnFP8Func_forward` pads head dimensions to multiples of eight, generates fp8 versions of Q/K/V (unless the caller provided fp8 buffers plus descales), prepares an fp32 output workspace, and calls `flash_attn_gpu.fwd` with the requested hyperparameters (`softmax_scale`, dropout probability, causal/window sizes, optional ALiBi slopes, softcap). The GPU kernel returns the logits’ log-sum-exp (`softmax_lse`), any saved score/dropout masks, and Philox RNG state when dropout is active. If gradients are needed, the function stashes the fp8 tensors, descale factors, RNG state, and configuration in the autograd context; otherwise it simply slices away the head padding and returns the fp32 output (plus optional statistics) to the caller.
