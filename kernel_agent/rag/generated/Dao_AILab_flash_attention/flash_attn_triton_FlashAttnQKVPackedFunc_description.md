- kernel family: attention (FlashAttention forward with packed Q/K/V tensor)
- concise summary: This wrapper expects a single tensor of shape `(batch, seqlen, 3, heads, dim)`; it slices Q, K, and V out of the third dimension and invokes the standard FlashAttention kernel, preserving all bias/causal handling while returning the attention output and log-sum-exp buffer.
- detailed summary: Internally it reuses the same `_fwd_kernel` as the base implementation, so each program still tiles over `BLOCK_M` queries and `BLOCK_N` keys, applies optional vector or matrix bias, keeps the running `m_i`/`lse_i` softmax state, stores temporary scaling factors in `TMP`, and accumulates value contributions before normalizing and writing the output tile with masks for ragged edges. The `_flash_attn_forward` helper is called with `qkv[...,0,:,:]`, `qkv[...,1,:,:]`, and `qkv[...,2,:,:]`, and therefore all preprocessing—bias expansion, head-dimension power-of-two padding, scratch allocation, tile-size selection—matches the non-packed path. `_FlashAttnQKVPackedFunc_forward` only makes the packed tensor contiguous if needed, launches the shared forward routine, saves `(qkv, output, lse, bias)` for backward, and returns the attention result, enabling efficient execution when Q, K, and V are materialized together.
