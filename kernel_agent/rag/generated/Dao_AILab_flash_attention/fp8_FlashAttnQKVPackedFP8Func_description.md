- kernel family: attention (fp8 FlashAttention with packed Q/K/V tensor)
- concise summary: The forward wrapper extracts Q, K, and V from a packed `(batch, seqlen, 3, heads, dim)` buffer, casts them to fp8 with per-head scaling, and calls the fused `flash_attn_gpu.fwd` kernel to compute dropout-aware, bias-aware attention while returning the fp32 output and optional softmax statistics.
- detailed summary: After padding the head dimension to a multiple of eight when necessary, `_FlashAttnQKVPackedFP8Func_forward` runs the fp8 quantization path (`cast_to_fp8` + `_cast_varlen_to_fp8_kernel_2d`) for each component, producing fp8 tensors along with fp32 descale factors. It then hands those buffers to `flash_attn_gpu.fwd`, supplying parameters such as `softmax_scale`, Bernoulli dropout probability, causal/window limits, softcap, and optional ALiBi slopes, and requests score masks when dropout is active. The GPU kernel returns the fp32 output workspace (with head padding still present), the log-sum-exp vector, stored dropout mask, and Philox RNG state; if gradients are required the function saves all of these plus the per-head descale factors in the context. Finally, it slices off the head padding and returns either the output alone or `(output, softmax_lse, softmax_mask)` depending on `return_softmax`, mirroring the non-packed fp8 path while accommodating packed QKV inputs.
