- kernel family: attention (FlashAttention-style forward with fp8 inputs, dropout, masks, optional logging)
- concise summary: The fp8 forward kernel tiles queries over `(BLOCK_M, head)` blocks, streams key/value tiles via `_attn_fwd_inner`, applies alibi/casual masking, tracks log-sum-exp statistics in base-2 space, optionally materializes dropout or score masks, and writes the normalized output back after rescaling by per-head descale factors.
- detailed summary: `_attn_fwd` derives sequence lengths from either fixed sizes or `cu_seqlens_*`, selects the matching K/V head group, and loads the fp8 tiles (promoted via `descale_{q,k,v}`) for each iteration. It splits the loop into full tiles and a masked tail to handle padding/causal windows, invoking `_attn_fwd_inner` which performs the core FlashAttention recurrence: compute `q·kᵀ` (honoring fp8 scaling), add alibi biases, enforce causal offsets, exponentiate with base-2 math, and update the running max `m_i` and normalization `l_i`. When dropout or softmax matrices are requested, it writes the Bernoulli mask and/or raw probabilities while accumulating a Philox offset per block. After processing all tiles it normalizes the accumulator, applies inverted-dropout scaling if enabled, stores optional softmax log-sum-exp in natural log units, and masks off padded heads/tokens before writing the output tensor. The launcher `_flash_attn_forward` prepares strides for either dense or variable-length batch layouts, allocates optional buffers (softmax LSE, score masks, dropout mask), seeds Philox RNG when needed, and dispatches `_attn_fwd` with a fixed `(BLOCK_M=128, BLOCK_N=32)` configuration. `_FlashAttnFP8Func_forward` first pads head dimensions to multiples of 8, converts Q/K/V to fp8 with per-group scaling (`cast_to_fp8`), runs the forward kernel, records fp8 tensors and RNG state if gradients are required, and slices the padded head dimension back to the original size before returning the output (plus optional statistics).
