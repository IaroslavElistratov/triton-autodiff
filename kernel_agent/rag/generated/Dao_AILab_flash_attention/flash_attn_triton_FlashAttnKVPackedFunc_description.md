- kernel family: attention (FlashAttention forward with packed K/V tensor)
- concise summary: This variant reuses the standard FlashAttention kernel but expects keys and values to be stored together as `kv[..., 2, nheads, headdim]`, slicing them before launch so the Triton kernel can operate on the same tiling/bias/causal logic while returning the packed-output and log-sum-exp buffers.
- detailed summary: `_fwd_kernel` in this file is identical to the base implementation: per `(BLOCK_M, head)` tile it loads query vectors, iterates over key/value tiles, applies optional broadcast or full bias tensors and causal masks, maintains the running `m_i`/`lse_i` state, stores temporary scaling in `TMP`, and accumulates the value-weighted outputs before writing the normalized tile and fp32 log-sum-exp to `Lse`. The helper `_flash_attn_forward` now unwraps a packed tensor `kv` of shape `(batch, seqlen_k, 2, nheads, headdim)`, handing `kv[...,0,:,:]` to the kernel as keys and `kv[...,1,:,:]` as values, while retaining all other launch behavior (bias expansion, head-dimension power-of-two padding, buffer allocation, tile sizes). `_FlashAttnKVPackedFunc_forward` merely ensures contiguity, calls the shared launcher, saves `(q, kv, o, lse, bias)` for backward, and returns the attention output, making it convenient to work with fused K/V representations without altering the underlying FlashAttention computation.
