- kernel family: attention (FlashAttention forward for fp16/bf16 inputs with optional dropout/alibi)
- concise summary: The Triton forward kernel mirrors the flash-attention recurrence, tiling over query blocks and heads, streaming key/value tiles while applying causal/window masks, optional alibi bias, and dropout bookkeeping, then writing normalized outputs and log-sum-exp summaries when requested.
- detailed summary: `_attn_fwd` computes per-program offsets from either fixed sequence lengths or `cu_seqlens_*`, selects the matching key head index (supporting grouped Q/K heads), and loads the query tile into registers. It iterates over full key blocks and a masked tail, calling `_attn_fwd_inner` to form `q·kᵀ`, add alibi corrections, enforce causal constraints, and incrementally maintain the base-2 max/sum state (`m_i`, `l_i`). The helper also materializes dropout masks or score dumps when enabled, advances Philox offsets, and accumulates value contributions into a fp32 accumulator before moving to the next tile. After the sweep it divides by `l_i`, applies inverted-dropout scaling, optionally stores `softmax_lse`, and writes the output tile with padding-aware masks. The `_flash_attn_forward` launcher prepares strides for dense or variable-length layouts, allocates optional buffers (LSE, softmax/dmask, dropout mask), seeds Philox if dropout is active, and dispatches `_attn_fwd` with fixed tile sizes `(BLOCK_M=128, BLOCK_N=32)`. `_FlashAttnFunc_forward` pads head dimensions to multiples of 8 so the kernel assumptions hold, invokes the launcher with the caller’s dropout scale/causal/window/alibi settings, saves tensors/RNG state when gradients are needed, and slices the padded head dimension back before returning the output plus any requested statistics.
