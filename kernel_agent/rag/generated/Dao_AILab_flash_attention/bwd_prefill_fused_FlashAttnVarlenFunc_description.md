- kernel family: attention (FlashAttention forward on variable-length batches, fp16/bf16)
- concise summary: For variable-length sequences described by `cu_seqlens`, the kernel tiles queries and heads, gathers the appropriate key/value segments per sample, runs the FlashAttention recurrence with causal/dropout/alibi options, and emits normalized outputs plus optional softmax statistics.
- detailed summary: `_attn_fwd` computes each program’s local `seqlen_q`/`seqlen_k` from cumulative offsets, selects the matching key head, and loads the query tile (optionally scaled if the inputs are fp8). It partitions the key sweep into full blocks and a masked tail, repeatedly calling `_attn_fwd_inner` to evaluate `q·kᵀ`, add alibi penalties, enforce causal windows, and manage dropout masks using Philox RNG. The running max/sum state is maintained in base-2 form so the kernel can write stable log-sum-exp vectors when requested; after normalizing and applying inverted dropout it stores the output tile with masks for both padded tokens and head padding. The `_flash_attn_forward` helper sets up strides for packed variable-length tensors, allocates optional buffers (log-sum-exp, score/dmask, dropout mask), seeds Philox when needed, and launches the kernel with `(BLOCK_M=128, BLOCK_N=32)` over `(ceil_div(max_seqlen_q, BLOCK_M), num_heads, batch)`. `_FlashAttnVarlenFunc_forward` pads head dimensions to multiples of eight, calls the launcher with the caller’s scaling/causal/alibi configuration, records RNG state and inputs if gradients are required, and slices away any head padding before returning the attention output and requested diagnostics.
