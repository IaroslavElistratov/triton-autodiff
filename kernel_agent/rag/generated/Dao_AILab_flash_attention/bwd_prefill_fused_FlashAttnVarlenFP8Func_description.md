- kernel family: attention (FlashAttention forward on variable-length batches with fp8 storage)
- concise summary: Queries, keys, and values are converted to fp8 per sample using `cu_seqlens`, then the FlashAttention kernel processes one `(BLOCK_M, head)` tile at a time, pulling the correct sequence slice for each batch element, applying causal/alibi/dropout logic, and emitting normalized outputs plus optional log-sum-exp statistics.
- detailed summary: `_attn_fwd` accepts cumulative sequence offsets so each program can recover its local `seqlen_q`/`seqlen_k` before loading Q/K/V tiles. Using the fp8 descale factors computed by `cast_varlen_to_fp8`, it iterates over full and masked key blocks, invoking `_attn_fwd_inner` to compute `q·kᵀ`, add alibi biases, enforce per-query causal windows, and manage dropout/score masks with Philox RNG. The running max/sum state (`m_i`, `l_i`) is updated in base-2 form so the kernel can store numerically stable softmax log-sum-exp values when requested, and after normalization (plus inverted-dropout scaling) the accumulator is written back with padding guards for both the head dimension and per-sample sequence length. `_FlashAttnVarlenFP8Func_forward` pads head dimensions to multiples of eight, casts the packed `[total_tokens, heads, dim]` buffers to fp8 via `cast_varlen_to_fp8`, and launches `_attn_fwd` with grid `(ceil_div(max_seqlen_q, 128), num_heads, batch)` while passing the `cu_seqlens` arrays so each program touches only its sample’s slice. Optional dropout masks and softmax dumps are allocated when needed, RNG state is recorded if gradients are requested, and the padded heads are trimmed from the returned tensor.
