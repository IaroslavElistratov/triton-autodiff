- kernel family: attention (FlashAttention v1 forward with optional bias/casual masking)
- concise summary: For each `(BLOCK_M, head)` tile, the Triton kernel streams key/value blocks, applies scale-and-bias adjustments, updates a running log-sum-exp, and accumulates the weighted value projections while caching intermediate scaling factors to avoid register pressure, producing both the attention output and per-row log partition.
- detailed summary: `_fwd_kernel` maps program ids to query tiles and head/batch indices, loads the query block (masking ragged tails), and iterates over key tiles up to the causal boundary if enabled. Depending on `BIAS_TYPE`, it either adds broadcast vector biases or full attention masks after scaling by `softmax_scale`. The kernel maintains `m_i` and `lse_i` (log-sum-exp) in fp32, writes temporary rescaling factors into `TMP` to shrink register usage, and multiplies the running accumulator `acc_o` by those factors before adding the current tile’s contribution (`p = exp(qk)` converted to the value dtype). It handles uneven sequence lengths and head dimensions via masks, supports both even and odd cases, and stores the final LSE per tile into the `Lse` buffer while writing the normalized output tile with appropriate row/head masking. The `_flash_attn_forward` launcher validates tensor shapes/dtypes (fp16/bf16, head dim ≤128), prepares contiguous strides, expands optional bias (vector or matrix) to `(batch, nheads, seqlen_q, seqlen_k)`, allocates fp32 `lse` and `tmp` scratch buffers (rounding sequence length to multiples of 128), selects tile sizes (`BLOCK_M = BLOCK_N = 128`, `BLOCK_HEADDIM = max(pow2(d), 16)`), and dispatches `_fwd_kernel` with `num_warps` chosen by head width before returning the attention output and log-sum-exp needed for backward.
