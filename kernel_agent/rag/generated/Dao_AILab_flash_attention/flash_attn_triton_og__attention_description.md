- kernel family: attention (original FlashAttention v0 causal kernel)
- concise summary: This older kernel assumes causal masking and iterates over key tiles up to the current query block, maintaining running max/sum values in fp32, using a temporary buffer to rescale the accumulator, and writing both the attention output and the per-row normalization stats (`L`, `M`) needed for backward.
- detailed summary: `_fwd_kernel` assigns each program to a `BLOCK_M × head_dim` slice of queries, preloads the query tile, and for each key tile with index `< (start_m+1)*BLOCK_M` computes `q·kᵀ`, applies the causal mask (`offs_m >= start_n + offs_n`), and multiplies by `sm_scale`. It updates `m_i`/`l_i` through the flash recurrence, converts the probabilities `p` to the value dtype, and accumulates `acc` with the current value tile after scaling the prior accumulator by factors stored in the `TMP` buffer (avoiding extra registers). After the loop it normalizes `acc` by `exp(m_i - l_i)` (again retrieved from `TMP`), stores the resulting head output tile, and writes the `l_i` and `m_i` vectors into fp32 workspaces (`L`, `M`). The Python launcher enforces head dim ≤128, allocates the temporary buffers, configures a grid `(ceil_div(seqlen_q, BLOCK), batch*heads)` with `BLOCK=128`, selects `num_warps` based on head size, and dispatches the kernel with the given softmax scale while caching Q/K/V, outputs, and the saved statistics for backward.
