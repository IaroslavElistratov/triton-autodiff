- kernel family: gated GLU activation (GELU gate times value half)
- concise summary: The forward kernel splits the inputs into paired tensors `a` and `b`, applies the tanh-based GELU approximation to `a`, and multiplies the result with `b`, all within `_geglu_tanh_forward_kernel` tiled over the last dimension.
- detailed summary: `geglu_forward` flattens the batch, picks a power-of-two tile size via `calculate_settings`, and launches `_geglu_tanh_forward_kernel` per row. Each program loads the `a` and `b` slices, computes `0.5·a·(1+tanh(√(2/π)(a+0.044715·a³)))` in fp32, casts back to the activation dtype, multiplies by `b`, and stores the GEGLU output. The autograd wrapper caches the flattened buffers so `_geglu_tanh_backward_kernel` can reuse them to form gradients with respect to both inputs; only the forward behavior is summarized here.
