- kernel family: divergence loss (generalized JSD between student and teacher log-probs)
- concise summary: The forward Triton kernel iterates over vocabulary tiles to compute the generalized Jensen–Shannon loss and its input gradient buffer simultaneously, considering optional label masking and the beta coefficient.
- detailed summary: `jsd_forward` views logits/targets as a 2-D `(BT, V)` matrix, allocates per-token loss and gradient buffers, and launches `_jsd_kernel` once per sample. Inside the kernel each BLOCK_SIZE slice is loaded from student (`X`) and teacher (`Y`) logit vectors, exponentiated in a numerically-stable fashion, and combined according to `beta`: β=0 recovers forward KL, β=1 gives reverse KL, otherwise it forms the mixture `M = β·P + (1-β)·Q` and accumulates `β·P·Y + (1-β)·Q·X - M·log M`. The same loop stores the scaled gradient contribution into `dX`. Label indices can mark rows to skip, and the total loss is reduced on the host. Backward simply multiplies the saved `dX` by the upstream gradient, so all heavy work occurs in the forward kernel.
