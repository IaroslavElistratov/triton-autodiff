- kernel family: group normalization (per-block accumulation with affine weights)
- concise summary: Forward reshapes the input to [batch, groups, hidden], launches `_group_norm_forward_kernel` to accumulate mean/variance per group, applies scale/bias, and stores the groupwise statistics for backward reuse.
- detailed summary: `group_norm_forward` flattens each group, selects a power-of-two BLOCK_SIZE, and for every (batch, group) tile the kernel sums chunks of the hidden dimension to compute the group mean and variance. It then iterates over the channels in the group, normalizes `(x-m)*rstd`, multiplies by the per-channel weight, adds bias, and writes the result back to the original layout; the same pass fills `Mean` and `RSTD` tensors. These cached stats feed the backward kernel (not covered here) that reuses the stored values to propagate gradients efficiently.
