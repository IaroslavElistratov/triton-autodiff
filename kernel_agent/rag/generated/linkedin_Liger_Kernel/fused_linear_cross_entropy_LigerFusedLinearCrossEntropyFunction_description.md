- kernel family: fused linear + loss (matmul logits plus cross-entropy with optional enhancements)
- concise summary: Chunks the batch, computes logits via input×weightᵀ (with optional bias), optionally rescales tokens, and for each chunk invokes the fused cross-entropy kernel to obtain numerically stable losses (and, when gradients are requested, in-place logits derivatives) while accumulating optional z-loss and class-weighted smoothing terms.
- detailed summary: The forward path reshapes the batch into manageable chunks sized by the vocabulary-to-hidden ratio, performs dense matmuls on each chunk, and optionally clamps logits through `softcap` and/ or computes per-token scaling factors from detached softmax probabilities. It then launches `liger_cross_entropy_kernel` per chunk, which executes log-sum-exp normalization, applies label smoothing, z-loss, class weights, and writes gradients back into the logits buffer when training. Post-kernel, the code applies token scaling to both loss and stored gradients, accumulates input gradients via `grad_logits @ weight`, and, if required, reduces chunked contributions into weight and bias gradients. The final losses are reduced according to the requested mode (`mean`, `sum`, or `none`), making this a fully fused linear+cross-entropy pipeline.
