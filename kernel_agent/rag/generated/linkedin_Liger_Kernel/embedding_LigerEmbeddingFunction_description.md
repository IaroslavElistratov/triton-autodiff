- kernel family: embedding lookup (gather rows from embedding matrix)
- concise summary: Reshapes the index tensor, batches rows into `BLOCK_SIZE_M × BLOCK_SIZE_N` tiles, gathers the corresponding embedding rows, and writes the results into a flattened output buffer before restoring the original shape.
- detailed summary: The kernel uses a 2D launch where `pid_m` enumerates batches of indices and `pid_n` walks the embedding dimension. For each tile it loads a vector of indices, forms the row/column offsets via `indices[:, None] * embedding_dim + column`, loads the selected embedding values with joint row/column masks, and stores them into the output buffer using the same flattened addressing. This tile-wise gather enables coalesced loads across the embedding dimension while supporting non-contiguous index shapes.
