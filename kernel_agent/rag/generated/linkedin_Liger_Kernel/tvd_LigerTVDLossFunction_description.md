- kernel family: divergence loss (total variation distance with optional masking)
- concise summary: The forward Triton kernel marches over vocabulary blocks, computes ½‖p−q‖₁ per row, and stores both the per-row loss (respecting the chosen reduction) and the sign-based gradients for use in backward.
- detailed summary: `tv_distance_forward_triton` flattens distributions `(BT,V)`, allocates loss and gradient buffers, and invokes `_tv_distance_kernel`. The kernel loads `p`/`q` tiles, writes `0.5·|p−q|` to the loss buffer (or accumulates the sum for batch/sum modes), and records gradient signs (`+½` if `p>q` else `−½`) into `grads`. Label masks (optional) skip ignored rows entirely. Host code handles the final reduction (batchmean, mean, sum, or none) and scales `grads` accordingly. The backward pass simply multiplies the saved gradient buffer by the upstream scalar; thus all heavy forward computation happens in `_tv_distance_kernel`.
