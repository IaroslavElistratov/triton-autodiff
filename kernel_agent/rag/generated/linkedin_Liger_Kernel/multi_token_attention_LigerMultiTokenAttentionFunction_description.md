- kernel family: masked multi-token attention (causal mask + activation + spatial conv)
- concise summary: Forward applies a causal mask to the score tensor, normalizes with either softmax or sparsemax, runs a 2D convolution over the resulting probabilities, and post-masks the convolution output—using Triton kernels for efficient triangular masking.
- detailed summary: `_LigerMultiTokenAttentionFunction_forward` first calls `_mask_inf_forward`, whose Triton kernel tiles the (L×L) score matrices and fills future positions with −1e9 to enforce causality while copying valid entries. Depending on the `sparse` flag it then computes either sparsemax (returning a flattened sparse representation) or softmax probabilities across the last axis. These probabilities are convolved with the provided kernel via `F.conv2d`, producing a context tensor that is remasked with `_mask_zero_forward` (same kernel but using zero fill) so upper-triangular elements remain zero. Intermediate tensors (scores, activation map, optional sparse indices, and conv weights/bias) are saved for the custom backward.
