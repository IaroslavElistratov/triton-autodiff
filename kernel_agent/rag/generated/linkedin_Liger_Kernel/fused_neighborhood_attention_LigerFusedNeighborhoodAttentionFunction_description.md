- kernel family: neighborhood attention (two-stage fused QK + AV with optional mask generation)
- concise summary: Forward first forms local attention scores with `_fused_neighborhood_attention_qk_kernel`, applying scaling and a precomputed neighborhood mask, then launches `_fused_neighborhood_attention_av_kernel` to multiply the normalized attention weights by the value tensor and produce the output tiles.
- detailed summary: `_fused_neighborhood_attention_qk_kernel` tiles the query/key matrices across sequence blocks, loads the relevant neighborhood window using the mask (optionally generated by `_neighborhood_mask_kernel`), performs the scaled dot product, and writes inf-masked logits into the attention buffer. The second stage `_fused_neighborhood_attention_av_kernel` iterates over the same tiles, loads the attention slice and value blocks, and accumulates `Attn·V` in fp32 before casting back to the output dtype. Both kernels support arbitrary head counts, dilation, and kernel sizes by using programmable strides and block sizes, enabling a fused neighborhood attention execution without leaving device memory.
