- kernel family: polynomial normalization (PolyNorm activation)
- concise summary: The forward kernel computes normalized powers of each feature row (`x`, `x²`, `x³`) using RMS normalization and combines them with learnable weights `[w₂,w₁,w₀]` plus bias to produce the output.
- detailed summary: `poly_norm_forward` flattens the input, allocates space for three reciprocal-std values per row, and launches `_poly_norm_forward_kernel`. For each row the kernel loads the input slice, forms `x³`, `x²`, and `x`, computes their mean-square values in fp32 to obtain `rstd₃`, `rstd₂`, `rstd₁`, and normalizes each power. It then writes the weighted sum `w₀·norm(x³) + w₁·norm(x²) + w₂·norm(x)` plus bias into `Y`, while saving the reciprocal stds for the backward pass. This realizes the PolyNorm transformation without leaving GPU memory.
