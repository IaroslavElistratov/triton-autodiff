- kernel family: policy optimization loss (GRPO per-token clipping with optional KL term)
- concise summary: The forward kernel scans logits to compute log-sum-exp, reads the chosen token probability, applies importance-sampling clipping (with optional KL penalty), and writes the per-token loss, log-normalizer, and clipping state for downstream aggregation.
- detailed summary: `_grpo_loss_fwd_kernel` iterates over vocabulary tiles (BLOCK_N) to accumulate the temperature-scaled log-sum-exp for each (batch, position) while honoring completion masks. Once the normalization is known it loads the selected token logit, forms the new log-prob, evaluates the ratio against `old_logp`, applies clip bounds `(1±eps)` to produce the clipped surrogate loss, and, if `beta` is non-zero, adds the generalized KL penalty using `ref_logp`. The kernel emits per-token losses, cached LSE values, per-token KLs (optional), and a flag indicating whether the unclipped surrogate stayed below the clipped one (so clipping was inactive). Reduction across tokens happens outside the kernel; backward uses these saved tensors to propagate gradients.
