- kernel family: rotary positional embedding (standard RoPE for Q/K)
- concise summary: The forward routine transposes Q/K for contiguous head-major layout, pads head counts/dimensions to powers of two, and applies `_triton_rope` to rotate each even/odd feature pair using the supplied cosine/sine tables (shared across batches or per batch).
- detailed summary: `rope_forward` ensures Q/K and the cos/sin tables are contiguous, infers whether the frequency tensors are broadcast (`cos_bs==1`), and launches `_triton_rope` on a grid over `(batch×seq, head)`. The Triton kernel loads the appropriate cosine/sine pair for the current position, rotates the first and second halves of the head dimension for both Q and K (`new_real = real*cos − imag*sin`, `new_imag = real*sin + imag*cos`), and writes the results in place. Backward reuses the same kernel with `BACKWARD_PASS=True` to invert the rotation using the cached tables.
