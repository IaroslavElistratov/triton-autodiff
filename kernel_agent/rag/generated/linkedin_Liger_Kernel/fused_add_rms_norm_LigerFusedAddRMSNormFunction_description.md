- kernel family: normalization (fused residual add + RMSNorm with scaling offset)
- concise summary: For each row it sums the residual and activation tensors, caches the summed vector, computes its RMS-based normalization (respecting casting modes and epsilon), scales by `(offset + weight)` per feature, and emits the normalized output alongside per-row inverse stds.
- detailed summary: The kernel maps one program id to each sequence row. It loads corresponding slices of `X`, `R`, and `W`, forms `S = X + R`, and stores this residual-updated state for reuse. Depending on the selected casting mode (none, llama-style fp32 accumulation, or gemma-style fp32 weight casting), it upcasts `S` and/or `W` before accumulating the mean square, computes `rstd = 1 / sqrt(mean(S²) + eps)`, and writes the fp32 rstd back to a separate buffer. The normalized vector `S * rstd` is then multiplied elementwise by `(offset + W)` and cast back if required before writing the row to the output tensor. This single pass fuses residual addition, RMSNorm, and scaling to reduce memory traffic in decoder blocks.
