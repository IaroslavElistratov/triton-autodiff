- kernel family: sparsemax activation (projection onto simplex)
- concise summary: The forward pass sorts each row, finds the support via cumulative sums, and writes `max(x-τ,0)` using `_sparsemax_forward_kernel`, while caching the flattened output for backward.
- detailed summary: `_sparsemax_forward` transposes the target dimension to the end, precomputes sorted scores for every row, and launches `_sparsemax_forward_kernel`. The kernel loads the sorted values tile-wise, computes the running cumulative sum, determines the largest k satisfying `z_k > (cssv_k−1)/k`, and derives τ accordingly; it then loads the original unsorted values and stores `max(x−τ,0)` back to the output buffer. The backward kernel reuses the saved activations to sum the gradient over the support and subtract the mean from supported entries, leaving zeros elsewhere. Thus, all forward logic lives in the single Triton kernel.
