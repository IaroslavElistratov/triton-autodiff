- kernel family: multimodal rotary embedding (Qwen2-VL M-RoPE)
- concise summary: The forward routine transposes Q/K for coalesced memory, pads head counts/dimensions to powers of two, and runs `_triton_qwen2vl_mrope` to rotate each head’s first/second halves with section-specific cosine/sine tables.
- detailed summary: `qwen2vl_mrope_forward` prepares contiguous buffers, derives padded strides (`pad_n_qh`, `pad_n_kh`, `pad_hd`), and selects a BLOCK_SIZE. The Triton kernel `_triton_qwen2vl_mrope` iterates over `(batch×seq, head)` tiles, loads the temporal, spatial, and width-specific rotation coefficients from the stacked `cos/sin` tensors (split into three sections), and applies the complex rotation to Q/K halves in place. The backward pass reuses the same kernel with `BACKWARD_PASS=True` to apply the inverse rotation, so the forward path is purely in-place M-RoPE transformation for both query and key streams.
