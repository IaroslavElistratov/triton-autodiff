- kernel family: fused linear + divergence loss (student/teacher projection with generalized JSD)
- concise summary: Processes the batch in chunks, forms student and teacher logits via linear projections, temperature-scales them, computes log-probabilities, and invokes a Triton kernel that evaluates the generalized Jensen–Shannon divergence (covering forward/reverse KL at β∈{1,0}) while writing scaled gradients back into the student log-prob buffer.
- detailed summary: Each chunk performs two matmuls (`student_input @ student_weightᵀ`, `teacher_input @ teacher_weightᵀ`), converts them to fp32, divides by the temperature, and applies `log_softmax` to obtain log-probs. The `_jsd_kernel` iterates over the vocabulary in `BLOCK_SIZE` tiles, optionally skipping ignore-index rows, reconstructs probability masses from the log-probs, and, depending on β, computes either asymmetric KL limits or the mixed-JSD form `β·P log(P/M) + (1-β)·Q log(Q/M)` while accumulating per-class losses scaled by `1/n_non_ignore`. It simultaneously writes the gradient contributions for the student distribution back into the tiled buffer. After the kernel, the host converts those per-class gradients into logits-space updates (accounting for the softmax Jacobian / temperature), accumulates them into input and weight gradients, and finally sums the per-class losses to produce the scalar JSD objective.
