- kernel family: loss (fused cross-entropy with optional label smoothing, class weights, softcap, and z-loss)
- concise summary: Each row of logits is processed independently to compute a numerically stable log-sum-exp, form the cross-entropy loss (including optional weight, label smoothing, and z-loss terms), and optionally overwrite the logits buffer with gradients when the fused path is enabled.
- detailed summary: The kernel binds one program id to a `(batch, position)` row, loads the target index, and early-exits by zeroing gradients when it equals `ignore_index`. It streams across the vocabulary in `BLOCK_SIZE` tiles, applying soft-capping (`softcap * tanh`) when requested, updating a running max/sum exponent accumulator for stable `logsumexp`, and accumulating auxiliary terms needed for label smoothing. After the first sweep it finalizes `lse`, replays the tiles if gradient fusing is active to write class-wise derivatives (respecting class weights, smoothing, reduction=mean, and the z-loss scaling), and finally stores the per-row loss plus optional z-loss into the output buffers. Host code aggregates these row losses according to the requested reduction.
