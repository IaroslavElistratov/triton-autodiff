- kernel family: rms normalization (supports llama/gemma casting modes and row/block kernels)
- concise summary: The forward call reshapes the input, chooses between per-row and block-tiled kernels, computes the RMS of each feature row, and scales by `(offset + weight)` while caching the reciprocal standard deviations for backward.
- detailed summary: `rms_norm_forward` enforces dtype/casting policies (LLAMA, GEMMA, or none), flattens `(B×T, H)`, and selects a power-of-two tile. `_rms_norm_forward_kernel` handles most cases by loading one row, accumulating the mean of squared activations, computing `rstd = 1/√(mean_sq+eps)`, and writing `x*rstd*(offset+W)`; when there are many rows it can switch to `_block_rms_norm_forward_kernel`, which processes multiple rows per launch for better occupancy. Both paths store the per-row `rstd` (in fp32 when needed) for the backward kernel (not covered here). Offset handling enables Gemma-style RMSNorm variants without extra passes.
