- kernel family: activation (DyT: elementwise scaled tanh with per-channel gains and optional bias)
- concise summary: Reshapes the input to 2D, loads a global scalar `alpha` and per-channel `gamma` (plus optional `beta`), applies `tanh(alpha * x)` per element, scales by `gamma`, adds `beta` if present, and writes the transformed output.
- detailed summary: The kernel assigns `(column block, row)` program ids, with each instance loading a contiguous column slice guarded by a `mask` for tails. After promoting to fp32, it multiplies each input by the scalar `alpha`, evaluates the hyperbolic tangent, and multiplies by the column-specific `gamma`. When `beta` is provided it adds that column bias before storing the tile back to `Y`. This simple tile-wise mapping enables high throughput for DyT activations over large feature dimensions.
