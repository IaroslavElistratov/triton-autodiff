- kernel family: divergence loss (KL divergence with configurable reductions)
- concise summary: The forward Triton kernel streams through logits and targets tile-by-tile to accumulate the KL divergence in the requested reduction mode, supporting both probability and log-prob targets and writing per-batch outputs for later reduction.
- detailed summary: `kldiv_forward_triton` flattens `(BT,V)`, selects a power-of-two tile, and calls `_kldiv_kernel_forward` for each sample. Inside the kernel each BLOCK_SIZE chunk loads student logits `y` and targets `y_true`, evaluates either `y_true*(log y_true - y)` (prob targets) or `exp(y_true)*(y_true - y)` (log targets), and either stores the elementwise loss (`reduction='none'`) or accumulates a running sum for other reductions. The host then performs the final scalar reduction (`batchmean`, `sum`, `mean`). The backward path reuses `_kldiv_kernel_backward` to produce gradients with respect to the logits; only the forward behavior is summarized here.
