- kernel family: rotary positional embedding (LLama 4 variant, supports heterogeneous head counts)
- concise summary: Forward prepares real/imag frequency tables, casts Q/K to a common compute dtype, and launches `_llama4_rope_kernel` which rotates each head’s even/odd pairs in place using the provided complex frequencies.
- detailed summary: `llama4_rope_forward` reshapes `freqs_cis` to separate real/imag halves, ensures contiguity and dtype alignment, selects a BLOCK_SIZE via `_select_kernel_meta`, and calls `_llama4_rope_kernel` on a grid over `(batch*seq, head)`. The kernel iterates across half-head dimensions in BLOCK_SIZE steps, loads the cosine (`freqs_real`) and sine (`freqs_imag`) factors, and applies the rotation to both Q and K: `q' = q_real·cos − q_imag·sin`, `q'' = q_real·sin + q_imag·cos` (and similarly for K). Backward reuses the same kernel with `imag_sign = -1` to invert the rotation, so the forward computation is a pure in-place RoPE transform.
