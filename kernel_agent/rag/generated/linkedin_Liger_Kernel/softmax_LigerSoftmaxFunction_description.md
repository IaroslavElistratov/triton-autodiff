- kernel family: softmax (row-wise normalization with single/multi-block tiling)
- concise summary: Forward reshapes the tensor to 2D, chooses between single-block and multi-block Triton kernels based on width, and computes numerically stable softmax values per row while caching the output for backward.
- detailed summary: `_softmax_forward` flattens the batch to `(rows, cols)`, selects a power-of-two BLOCK_SIZE and warp count, and launches either `_softmax_single_block_forward_kernel` (when the row fits in one tile) or `_softmax_multi_block_forward_kernel` (which performs a two-pass log-sum-exp accumulation across tiles). Both variants subtract the row max, exponentiate, and normalize in fp32 before writing the softmax probabilities back to the original layout. The backward path reuses the saved output to compute gradients, so the entire forward computation is contained within these Triton kernels.
