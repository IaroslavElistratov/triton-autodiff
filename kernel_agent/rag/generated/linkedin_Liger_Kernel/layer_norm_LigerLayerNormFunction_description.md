- kernel family: layer normalization (rowwise stats with affine transform)
- concise summary: Forward flattens the batch, uses `_layer_norm_forward_kernel` to compute per-row mean/variance, and writes the normalized output multiplied by weight and bias while caching mean and rstd for backward.
- detailed summary: `layer_norm_forward` reshapes the last dimension to `(n_rows,n_cols)`, picks a power-of-two tile (respecting the 64 KB limit), and launches the Triton kernel once per row. The kernel loads the weight/bias vectors, accumulates the row sum and sum of squares in fp32, stores mean and reciprocal std in dedicated buffers, and emits `(x-mean)*rstd*W + B` back to the output tensor. These cached statistics feed the backward kernel (not covered here), which recomputes `x̂` and uses fused reductions to produce gradients for inputs and affine parameters. Forward behaviour is fully contained in `_layer_norm_forward_kernel`.
