- kernel family: cross-entropy loss (logits fused softmax + masking)
- concise summary: Processes each row of logits entirely inside a Triton kernel, handling optional class weights, label smoothing, logit soft-capping, and an auxiliary z-loss while overwriting the input buffer with dL/dlogits and emitting per-sample loss values.
- detailed summary: For every row the kernel skips ignored targets, scans the vocabulary in BLOCK_SIZE tiles applying an optional tanh softcap, tracks the running max/sum to build a numerically stable logsumexp, and accumulates label-smoothing corrections and weight statistics. A second pass converts the logits to probabilities, injects the lse_square regularizer, subtracts the one-hot target (or its weighted variant), rescales for mean reduction, and writes the gradients back into the original tensor. The launcher pre-computes counts and weight sums, allocates per-row loss (and optional z-loss) scratch space, ensures contiguous memory when needed, and chooses a tile size capped by the 64 KiB limit before launching one program per row.
