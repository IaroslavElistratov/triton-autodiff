- kernel family: matrix multiplication (partition-K buffered GEMM)
- concise summary: Splits the K dimension across partitionK slices so each Triton tile accumulates into a per-partition buffer, enabling a reduction over K either via a Triton reduction kernel or a compiled torch einsum-like fallback.
- detailed summary: The kernel maps program IDs to (m,n,partition) tiles using GROUP_SIZE_M scheduling, loads BLOCK_K panels of A and B, and accumulates fp32 products into accumulator[:,:,None] for the assigned partition index before storing the partial tile into `c_buf[m,n,pk]`. The host driver selects the partition count, allocates the (M,N,partitionK) buffer plus destination tensor, launches `_matmul_partition_k`, and then either performs the provided Triton `_reduce` kernel or the high-level compiled reduction to sum across the partition dimension and form the final output.
