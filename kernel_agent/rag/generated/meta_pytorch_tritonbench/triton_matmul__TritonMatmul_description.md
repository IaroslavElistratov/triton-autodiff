- kernel family: matrix multiplication (tiled GEMM with optional activation)
- concise summary: Performs a standard tiled matmul where each program reduces along K in BLOCK_K chunks, accumulates into fp32, and optionally applies a leaky-ReLU before storing the tile to C.
- detailed summary: The kernel maps program IDs to (m,n) tiles using GROUP_M scheduling, loads BLOCK_M×BLOCK_K and BLOCK_K×BLOCK_N blocks of A and B (padding tails with zeros), accumulates tl.dot results in fp32, conditionally runs a leaky_relu on the accumulator, then casts back to the output dtype and writes the masked tile to memory. The forward wrapper allocates C, enforces contiguity when strides are strided in both dimensions, builds the grid via cdiv(M,BLOCK_M)*cdiv(N,BLOCK_N), and launches the autotuned kernel with the chosen activation flag.
