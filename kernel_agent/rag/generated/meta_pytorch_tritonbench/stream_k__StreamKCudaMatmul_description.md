- kernel family: matrix multiplication (Stream-K on CUDA with TMA descriptors)
- concise summary: Wraps NVIDIA’s stream-K matmul strategy by preparing Tensor Core descriptors, splitting tiles between a deterministic DDP-style phase and a streamed remainder phase, and using dot products into fp32 accumulators before storing (or atomically adding) slices of C.
- detailed summary: The host builds TensorDescriptor objects for A, B, and C, derives the tile grid relative to the SM count, and launches `streamk_cuda_gemm`; inside the kernel program IDs below the DDP threshold own entire tiles (computing tl.dot loops across BLOCK_K and writing the result), whereas the remaining programs iterate over portions of the unresolved tiles by slicing the work_units_per_tile along K, loading blocks via the descriptors (with optional smaller SK_BLOCK_K) and atomically accumulating partial results. FP8 outputs are cast appropriately, buffer-op assumptions guard stride validity, and the workload remaps program IDs when streamK splits across SMs.
