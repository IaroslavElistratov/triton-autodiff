- kernel family: matrix multiplication (split-K tiled GEMM)
- concise summary: Autotuned Triton Split-K GEMM that tiles the M×N output, optionally upcasts inputs, and accumulates partial tiles across multiple pipeline stages before writing or atomically adding into C.
- detailed summary: Each program maps to an (m,n) tile determined by GROUP_M scheduling, walks the K dimension in BLOCK_K×SPLIT_K chunks, loads A/B sub-blocks (zero-masking the tail when K is not evenly divisible), optionally converts them to the requested ab_dtype, and performs fp16/bf16/fp8-aware dot products into an fp32 accumulator (or fp8-fast-accum path). After the loop the tile is cast to the destination dtype and either stored directly or reduced via atomic_add when SPLIT_K>1. The python wrapper inspects the operand dtypes to choose an accumulation type, enforces contiguity when necessary, allocates the output tensor, and launches the autotuned kernel grid sized by cdiv(M,BLOCK_M)×cdiv(N,BLOCK_N) with the split-K depth as the z dimension.
