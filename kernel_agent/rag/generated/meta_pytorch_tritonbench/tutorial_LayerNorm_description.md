- kernel family: layer normalization (tutorial fused implementation)
- concise summary: Runs a three-pass row kernel that scans the feature dimension to compute mean and variance, stores the per-row statistics, and writes the affine-normalized outputs.
- detailed summary: The kernel iterates over the row in BLOCK_SIZE steps: the first loop sums activations to estimate the mean, the second loop accumulates squared deviations to compute rstd, and the final loop loads gamma/beta, normalizes `(x-mean)*rstd`, and stores the affine result. The forward wrapper reshapes the input to 2-D, allocates fp32 mean/rstd buffers and the output, selects a power-of-two tile capped by 64 KiB, derives an appropriate warp count, and launches one program per row before caching the statistics for backward.
