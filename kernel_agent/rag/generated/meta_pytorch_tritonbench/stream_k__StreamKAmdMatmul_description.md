- kernel family: matrix multiplication (Stream-K on AMD)
- concise summary: Uses Triton’s stream-K scheduling to distribute matmul tiles across AMD GPUs, first assigning full tiles per shader array and then streaming the leftover K work with atomic accumulation while optionally adding a bias tensor.
- detailed summary: The launcher picks BLOCK_M/BLOCK_N based on aspect ratio, computes tile counts versus SM availability, handles bias layout (row or column), and invokes `streamk_amd_gemm` with flags describing SMS, streamk tail, and optional Mi300 cross-chip duplicated scheduling. Inside the kernel each program iterates over a sequence of tiles: full tiles load BLOCK_K chunks of A and B (with vectorized loads when possible), accumulate fp32 products, and write or bias-add directly; remaining tiles are processed via a while-loop over K iterations where partial strides and masking handle uneven sizes before atomically accumulating into C. The kernel also adapts for bias broadcasting and softens assumptions via tl.assume only when strides are non-negative.
