- kernel family: layer normalization (RMSNorm forward reference implementation)
- concise summary: Computes root-mean-square normalization per row by materializing an output tensor matching the input shape, using a Python reference routine that divides each feature vector by its RMS and applies an elementwise weight parameter with epsilon stabilization.
- detailed summary: The forward path reshapes nothing and calls `rmsnorm_ref`, which evaluates the mean of squared activations along the last dimension, adds `eps`, and takes an inverse square root to obtain a per-row scaling factor; the intermediate RMS tensor is kept for the autograd context. Each lane of the original activation is multiplied by both the RMS-derived gain and the learned weight, with results cast back to the input dtype and written into the preallocated output buffer. No Triton kernel is launched for forward; the compute remains on the PyTorch side, so parallelism is whatever torch dispatch supplies while the saved tensors (`x`, `weight`, `rms`) capture all state needed later without additional workspace.
