- kernel family: normalization (layer norm without bias, fused row reduction)
- concise summary: Reshapes the input to `[rows, hidden]`, streams through the feature dimension in BLOCK_SIZE chunks to accumulate the row mean and variance, stores mean/rstd for reuse, and writes normalized outputs scaled by the learned weight vector.
- detailed summary: `_layer_norm_fwd_fused_no_bias` iterates twice over the feature dimension: the first pass accumulates the sum to compute the mean, the second pass accumulates squared deviations to obtain `rstd = 1/√(var + eps)`. A final pass reloads each tile, subtracts the mean, multiplies by `rstd`, scales by the per-feature weight, and stores the result. The driver handles reshaping, workspace allocation for mean/rstd tensors, and launches the kernel with an autotuned block size and warp count appropriate for the hidden dimension.
