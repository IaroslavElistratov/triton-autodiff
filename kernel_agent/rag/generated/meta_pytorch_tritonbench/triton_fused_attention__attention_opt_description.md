- kernel family: attention (FlashAttention-style fused QKᵀV)
- concise summary: Implements a suite of autotuned Triton attention kernels that stream a block of queries over key/value tiles, apply log-sum-exp softmax with causal masking when requested, and write the normalized QKᵀV result while tracking row maxima in an auxiliary buffer.
- detailed summary: For each batch–head pair the forward kernel selects between base, TMA, and warp-specialized variants; it loads BLOCK_M queries (optionally via Tensor Memory Accelerator descriptors), iterates over N_CTX in BLOCK_N steps, forms qk tiles, rescales by `sm_scale`, maintains running `m_i`/`l_i` for numerical stability, exponentiates to probabilities, and accumulates weighted value tiles (with fp8-aware paths). Stage flags choose prefill/causal ranges, and warp specialization variants pipeline loads, matrix multiplies, and softmax reductions via AsyncTaskContext. The Python wrapper inspects head dimensions, causal flag, hardware capabilities (TMA availability, Blackwell DP), prepares descriptors, and dispatches the appropriate kernel/grid before saving the per-row log-sum-exp output `M` for backward.
