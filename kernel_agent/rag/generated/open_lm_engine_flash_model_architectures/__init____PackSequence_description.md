- kernel family: sequence packing (variable-length token compaction)
- concise summary: The forward path compacts padded batch sequences into a contiguous packed buffer by copying only the valid timesteps indicated by cumulative sequence lengths, honoring left- or right-padding policies.
- detailed summary: `pack_unpack_sequence_triton_kernel` launches a 2D grid over `(S, B)`; each program fetches the `[start, end)` range for batch `b` from `cu_seqlens`, derives the actual sequence length, and determines whether the current timestep `s` maps to a real token (taking into account left-padding offsets). When packing, valid `(b, s)` pairs call `_copy_array`, which iterates over the feature dimension `N` in `BLOCK_SIZE` chunks, loading from the original padded layout and storing into the packed buffer at the computed contiguous index `t = start + offset`. The Python wrapper selects either the Triton or CUDA backend, allocates the packed output of shape `output_shape`, and invokes the kernel so padded timesteps are skipped while real tokens are laid out tightly for downstream compute.
