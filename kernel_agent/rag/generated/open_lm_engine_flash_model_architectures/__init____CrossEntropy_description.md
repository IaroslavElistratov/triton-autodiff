- kernel family: fused cross-entropy (loss + softmax gradient)
- concise summary: A single Triton kernel streams over the vocabulary dimension to compute log-sum-exp normalizers, accumulate the cross-entropy loss, and write the softmax-gradient residuals for each batch row.
- detailed summary: `cross_entropy_forward_backward_triton_kernel` tiles the batch dimension in blocks of `BLOCK_SIZE_B` rows while iterating across vocabulary chunks of width `BLOCK_SIZE_V`. The first pass maintains running row maxima `M` and partition functions `Z`, optionally scaling logits by `logits_multiplier`, so the numeric range stays stable via the classic online max trick (`Z = Z * exp(prev_m - M) + sum(exp(x - M))`). After reading labels, a second sweep reloads the logits tile, re-applies the scaling, reuses the stored `M`/`Z` to produce normalized probabilities, subtracts the one-hot target, and writes the result into the gradient buffer—dividing by `B` if `reduction == 'mean'`. Finally, it fetches the labeled logit, combines it with `M + log(Z)` to yield the per-row loss contribution, and atomically accumulates the reduction output. The host wrapper configures autotuned block sizes (power-of-two capped), flattens strides, and launches the kernel so the forward call returns the scalar loss while caching the gradient tensor for the backward hook.
