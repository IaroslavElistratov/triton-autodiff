- kernel family: recurrent neural network cell (per-head matrix multiply + tanh)
- concise summary: The forward Triton kernel iterates through each timestep of possibly variable-length sequences, applying a weight-projected recurrence and tanh activation to update hidden states while writing outputs in place.
- detailed summary: `rnn_forward_triton_kernel` tiles the batch axis (`BLOCK_SIZE_B`) and hidden width (`BLOCK_SIZE_H`) so each CTA loads a slice of the square recurrent weight matrix `W`. For variable-length batches it reads per-sample `start/end` offsets from `cu_seqlens`, adjusts the input/output pointers accordingly, and skips positions beyond the actual sequence length. At every timestep it streams the current hidden vector `h` (initialized from `h0` or zeros), adds the bias-free matmul against `W` and the input slice via the fused `matmul` helper (which handles vector and matrix special cases), applies a fast inline `tanh`, and stores the updated state back to the output buffer. Pointer arithmetic increments along the time dimension per iteration, while masks prevent out-of-range token or feature accesses. The Python dispatcher picks power-of-two hidden tiles, configures the 2D launch grid `(ceil_divide(B, BLOCK_SIZE_B), N)`, and calls the kernel to produce the RNN outputs.
