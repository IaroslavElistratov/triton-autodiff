- kernel family: recurrent cell (tiled GRU forward)
- concise summary: Runs a Triton GRU forward pass that tiles over batches and hidden units, streams through the time dimension (variable-length aware), computes reset/update gates via small matmuls, and writes both the gate tensors and the updated hidden state sequence.
- detailed summary: Each kernel instance selects a block of batch rows and hidden columns, loads the relevant weight submatrices (W, Wf, Wr), initializes the hidden state (using h₀ if provided), and, for each timestep, optionally consults `cu_seqlens` to skip padding. It multiplies the previous hidden state by gate weights (`Wr`, `W`, `Wf`) using helper matmul routines, applies sigmoid/tanh activations, stores the intermediate gate outputs (r, z, f), updates the hidden state via `h = f*h + (1-f)*z`, and writes the result to the output buffer before advancing pointers. Support for capped sequence lengths, interleaved targets, and multiple block sizes allows the kernel to handle both fixed- and variable-length batches efficiently.
