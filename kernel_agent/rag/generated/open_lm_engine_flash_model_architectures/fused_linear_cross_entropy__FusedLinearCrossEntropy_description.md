- kernel family: fused linear projection + cross-entropy (chunked logits evaluation)
- concise summary: The forward routine multiplies activations by the vocabulary weight matrix in manageable chunks, feeds each chunk through the Triton cross-entropy kernel to accumulate loss and softmax gradients, and immediately propagates those gradients back to the input and weight buffers.
- detailed summary: `__FusedLinearCrossEntropy_forward` tiles the batch dimension so that each chunk’s logits fit in memory (`chunk_size = next_power_of_2(ceil(B / ceil(V/H)))`). For every chunk it computes `_logits = X_chunk @ Wᵀ`, allocates a temporary `_logits_grad`, and calls `cross_entropy_forward_backward_triton_kernel`, which streams over the vocabulary to perform numerically stable log-sum-exp reduction, subtract the one-hot labels, and write the gradient residuals while atomically adding the partial loss. The residuals are immediately recycled: `X` gradients are obtained via `_logits_grad @ W`, and weight gradients accumulate through `addmm(weight_grad, _logits_grad.T, X_chunk)`. After processing all chunks, the code applies optional mean reduction before caching `x_grad` and `weight_grad` for autograd. This design fuses the linear projection, softmax, and gradient formation while avoiding ever materializing the full `(B, V)` tensor at once.
