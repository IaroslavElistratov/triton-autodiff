- kernel family: fused residual add + RMSNorm (optional scaling and weight)
- concise summary: The kernel adds an optional residual, optionally scales the sum, computes an RMS normalization factor per activation row, applies it, and multiplies by a learned weight vector—all within a single Triton launch that can also stash intermediates for backward reuse.
- detailed summary: `fused_residual_add_rmsnorm_forward_triton_kernel` tiles the flattened `[B, H]` matrix with `BLOCK_SIZE_B × BLOCK_SIZE_H` blocks, loading each tile into fp32 registers. It conditionally scales the activations by `multiplier`, adds the residual if provided, and optionally writes this intermediate to `xr_ptr`. The kernel then computes the row-wise denominator `r = rsqrt(sum(x²)/H + eps)` (storing it to `s_ptr` when requested), normalizes the tile (`x *= r[:, None]`), and applies the elementwise weight `W` if supplied before writing the final values back to `y_ptr`. The host wrapper prepares contiguous buffers, picks the block size via a power-of-two hidden dimension, and launches the kernel while deciding whether to cache the combined input or the normalization factors for the backward path.
