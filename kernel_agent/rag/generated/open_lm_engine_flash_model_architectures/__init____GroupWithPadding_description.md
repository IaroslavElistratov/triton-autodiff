- kernel family: MoE token grouping (top-k duplication with optional padding)
- concise summary: This kernel copies token hidden states into expert-specific buffers according to precomputed scatter indices, optionally inserting zero-padding gaps so each expert’s region aligns to a requested multiple.
- detailed summary: `group_with_padding_triton_kernel` tiles the `B = T·K` token–expert assignments along blocks of `BLOCK_SIZE_B`, loading the destination indices and, when padding is enabled, the sorted order to pull an `expert_padding_offset` that shifts the write pointer past reserved padding slots. Depending on `NEEDS_DUPLICATION`, it either gathers from the original token row directly or from a pre-expanded view (`scattered_idxs // K`) so each token can be repeated across its `top_k` experts. The inner loop streams the hidden dimension in `BLOCK_SIZE_H` chunks, using masked loads/stores for edge tiles, and writes activations into the grouped output buffer at the computed offsets. The Python launcher computes optional padding frequencies, allocates outputs of either tight `(T·K, H)` shape or padded layout, and dispatches the kernel with autotuned tile sizes keyed on the hidden width.
