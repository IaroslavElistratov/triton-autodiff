- kernel family: MoE token ungrouping (padded layout → per-token slots)
- concise summary: The forward kernel gathers expert outputs stored in padded, expert-ordered buffers and scatters them back into a `[T, K, H]` tensor aligned with each token’s top‑k assignments.
- detailed summary: `ungroup_with_padding_triton_kernel` iterates over `B = T·K` assignments in blocks, loading the padded output slice for each assignment and computing the destination pointer either via `(scattered_idx // K)` (when atomic accumulation is needed) or the direct scattered index. If padding offsets were inserted earlier, it adds each slot’s expert-specific offset before reading. The hidden dimension is handled in `BLOCK_SIZE_H` tiles; for full tiles it performs contiguous masked loads/stores, and for the tail it combines row and column masks. The Python wrapper allocates the `[T, K, H]` result, feeds in the sorted/scattered index maps and optional padding metadata, and launches the kernel with autotuned shapes so the grouped MoE buffer is converted back into token-major form.
