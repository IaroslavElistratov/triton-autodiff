- kernel family: sequence unpacking (contiguous tokens → padded batches)
- concise summary: The forward operation takes a tightly packed token buffer and scatters tokens back into padded `[B, S, ...]` sequences using cumulative start indices and the specified padding side.
- detailed summary: `_UnpackSequence_forward` invokes `pack_unpack_sequence_triton` with `PACK=False`, which launches a 2D grid over timesteps and batch elements. Each program reads the `[start, end)` window for batch `b`, computes how many leading pads are required for left-padding (or none for right-padding), and when the current timestep corresponds to a real token it calls `_copy_array` to transfer the `N`-wide feature slice from the packed offset `t` into the padded location `(b, s)`. `_copy_array` itself iterates through the feature dimension in 4096-element chunks, performing masked loads and stores so partial tails are handled gracefully. The wrapper zeros the padded output, selects the desired backend (Triton here), and dispatches the kernel so tokens land in their original padded positions ready for downstream layers.
