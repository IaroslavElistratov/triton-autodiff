- kernel family: activation fusion (Swiglu gating)
- concise summary: The Triton kernel computes the SwiGLU activation by multiplying the “up” projection with a gate and its sigmoid, operating on tiled blocks of the flattened batch×hidden tensor.
- detailed summary: `swiglu_forward_triton_kernel` launches a 2D grid over batches (`BLOCK_SIZE_B`) and hidden features (`BLOCK_SIZE_H`), forming pointer offsets that treat the input as `[B, H]`. Each CTA loads the matching tiles from the gate and up tensors, converts the gate slice to fp32, evaluates a fast sigmoid via the inline `tanh` helper, and forms `up * gate * sigmoid(gate)` before storing the result back to the output tile under combined masks. The wrapper computes `B`/`H` from strides, allocates the output, and invokes either this Triton kernel or a CUDA variant depending on the configured backend.
