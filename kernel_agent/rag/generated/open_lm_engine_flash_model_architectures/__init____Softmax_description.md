- kernel family: row-wise softmax (streaming, optional logit scaling)
- concise summary: The kernel streams over the hidden dimension to compute numerically stable softmax probabilities while optionally scaling logits, writing the normalized outputs into a contiguous buffer.
- detailed summary: `softmax_forward_triton_kernel` covers the flattened `[B, H]` tensor with `BLOCK_SIZE_B` rows per CTA and steps through the feature dimension in `BLOCK_SIZE_H` chunks. In the first sweep it maintains running maxima `M` and partition sums `Z`, multiplying logits by `logits_multiplier` when provided and using `Z = Z * exp(prev_m - M) + sum(exp(x - M))` to stay stable. A second sweep reloads each tile, re-applies the multiplier, subtracts the stored `M`, exponentiates, divides by `Z`, and writes the probabilities back under the appropriate masks. The host wrapper determines the number of elements, allocates the output, picks a power-of-two hidden tile size (capped at 4K/8K depending on dtype), and launches one kernel invocation per row block.
