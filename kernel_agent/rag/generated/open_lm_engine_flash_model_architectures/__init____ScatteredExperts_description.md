- kernel family: mixture-of-experts projection (scatter → per-expert matmul)
- concise summary: The forward Triton kernel streams through sorted token assignments, gathers the corresponding hidden states, and multiplies them with each expert’s weight tile to produce expert outputs in a single fused scatter–matmul pass.
- detailed summary: `scatter2scatter_triton_kernel` partitions the `FAN_OUT · M` assignments into `BLOCK_M × BLOCK_N` tiles, loading expert indices and grouped token offsets for the current block. It iterates over the contiguous range of experts present, building a mask `E_mask` that selects the rows owned by each expert and, depending on `x_grouped`, mapping to either grouped or original token positions. For the active expert it calls `_compute_expert_block`, which walks the feature dimension in `BLOCK_K` chunks: each step loads the token slice (`X`) and the expert’s weight slice (`W`) with appropriate masking and increments the accumulator with a dot product. After all experts in the tile are processed, the kernel writes the accumulated outputs either to grouped slots or to the scattered order (`y_grouped` flag), respecting masks for partial tiles. The Python driver prepares the output buffer, configures a 1D grid over combined `(M_blocks × N_blocks)`, and launches the kernel with autotuned tile sizes keyed on output and reduction dimensions.
