- kernel family: activation fusion (packed SwiGLU with coupled projections)
- concise summary: The packed variant splits an `[*, 2H]` tensor into “up” and “gate” halves, then applies the Triton SwiGLU kernel to produce an `H`-wide activation where each element is `up * gate * sigmoid(gate)`.
- detailed summary: `_SwigluPacked_forward` reshapes the input so the last dimension is halved into `(up, gate)` blocks, delegates to `swiglu_forward_triton`, and writes the fused activation. Inside the kernel, CTAs tile batches and feature indices, compute pointer offsets using the original strides, load corresponding up and gate slices, convert the gates to fp32 for stability, evaluate the fast sigmoid helper (built from an inline `tanh`), and emit the product `up * gate * sigmoid(gate)` back to the output tile under masks for partial edges. The packing logic ensures memory accesses remain coalesced even though the source tensor interleaves gate and up values.
