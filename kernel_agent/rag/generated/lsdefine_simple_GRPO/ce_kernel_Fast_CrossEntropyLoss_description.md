- kernel family: cross entropy (log-sum-exp with optional chunking for huge vocabularies)
- concise summary: Forward selects between a single-pass log-sum-exp kernel and a chunked variant that splits vocab rows into 64k tiles, accumulating per-chunk log-sum-exp values and combining them to compute the per-example loss.
- detailed summary: `_Fast_CrossEntropyLoss_forward` inspects the vocab size, choosing `_cross_entropy_forward` when it fits in one block or `_chunked_cross_entropy_forward` otherwise. Both kernels load each row of logits in fp32, compute a numerically-stable log-sum-exp, subtract the target logit, and write the per-row negative log-likelihood (masking ignored labels). The chunked kernel also writes each chunk’s log-sum-exp so the host can perform a final `logsumexp` reduction across chunks before adding to the stored loss. Gradients are handled by separate kernels (not covered here), so the forward computation consists solely of these Triton kernels plus a small host reduction.
