- kernel family: elementwise activation (SiLU followed by gated multiply)
- concise summary: The forward kernel applies SiLU to `e` and multiplies the result with `g` in a single Triton pass; the paired backward kernel derives gradients for both inputs using the saved activations.
- detailed summary: `silu_mul_forward` asserts contiguity, allocates an output buffer, and launches `_silu_mul_forward_kernel`, which loads a BLOCK_SIZE chunk of `e`/`g`, computes `f = e * sigmoid(e)` in fp32 for stability, casts back to the tensor dtype, and writes `f * g`. The autograd function caches `e` and `g`. During backward, `_silu_mul_backward_kernel` reloads the inputs, replays the SiLU intermediate (`sigmoid`, `e·sigmoid(e)`), and emits `de = dh*g*d(SiLU)/de` and `dg = dh*f`, returning the two gradients.
