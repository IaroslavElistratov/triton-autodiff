- kernel family: jagged tensor manipulation (concat with optional dense inputs)
- concise summary: Concatenates two sequences per batch—each potentially dense (padded) or jagged—into a single jagged tensor by stitching rows based on offsets or max lengths and an optional prefix pulled from tensor B.
- detailed summary: The forward helper determines batching metadata from offsets or dense lengths, allocates the destination buffer, and calls `_concat_2D_jagged` (or its multi-row variant) which maps program IDs to batches and row tiles. The kernel computes per-batch sequence lengths, identifies whether the current row should be copied from A’s tail or B’s head/suffix (respecting `n_prefix_from_B`), and loads/stores BLOCK_D-wide feature slices accordingly. The implementation supports combinations of dense and jagged inputs, enabling fast concat without converting to dense formats.
