- kernel family: jagged tensor manipulation (multirow split)
- concise summary: Splits a concatenated jagged tensor into left/right outputs using a multirow Triton kernel that copies BLOCK_N rows per launch, supporting combinations of dense and jagged targets without intermediate padding.
- detailed summary: The forward helper infers total lengths from offsets or max lengths, allocates destination buffers, and dispatches `split_2D_jagged_multirow` with a grid proportional to (max_seq_len, batch). Inside the kernel each program loads BLOCK_D feature slices for a row block, determines whether each row falls into the left span or right span, and writes the data into the corresponding output (reshaping back to dense if required). The multirow tiling boosts throughput on long sequences while preserving jagged semantics.
