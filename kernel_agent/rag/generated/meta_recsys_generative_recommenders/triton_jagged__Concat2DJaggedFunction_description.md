- kernel family: jagged tensor manipulation (row-wise concatenation)
- concise summary: Concatenates two variable-length 2D sequences per batch element—handling dense or jagged inputs, optional prefixes, and replacement mode—by reading row offsets and copying D-wide slices into the output buffer tile by tile.
- detailed summary: The `concat_2D_jagged_w_prefix` family computes each batch row’s source ranges from the provided offsets (or dense sizes), determines whether the current row belongs to tensor A or B (respecting prefix length and replace mode), and loads BLOCK_D features into registers before storing them at the appropriate output index. Multi-row variants process BLOCK_N rows per launch to amortize Weights, while specialized entry points cover jagged→dense, dense→jagged, and jagged→jagged cases. The forward helpers choose the correct kernel, configure strides, and launch a 2-D grid over (row, batch) to materialize the concatenated representation.
