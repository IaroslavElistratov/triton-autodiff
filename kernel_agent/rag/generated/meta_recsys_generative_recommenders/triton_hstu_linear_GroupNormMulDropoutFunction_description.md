- kernel family: grouped layer normalization with modulation and dropout
- concise summary: Applies per-head group norm over linear_dim channels, rescales with learned weights/biases, multiplies by an auxiliary tensor U (optionally passed through SiLU), and emits either the gated activations or a concatenation of U, X, and the gated result with optional dropout.
- detailed summary: For each token-sized row the kernel loads the head×channel tile, computes the mean and variance across the D channels per head, stores the statistics, normalizes `(x-mean)*rstd`, applies per-head scale/bias, and multiplies by the matching U slice (with optional SiLU). In training it generates dropout masks via `tl.rand`—either three independent streams for concatenated [U,X,Y] or a single mask otherwise—and rescales the kept elements. Depending on `concat_ux`, it writes U/X/Y into disjoint output bands or just the gated activations. The wrapper ensures contiguous inputs, decides tile sizes within the 64 KiB bound, seeds the RNG (unless provided), and launches one program per batch element while returning the output plus saved mean/rstd for backward.
