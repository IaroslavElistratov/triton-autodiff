- kernel family: jagged × dense batched matmul with bias
- concise summary: Multiplies a jagged matrix (packed rows with offsets) by a per-batch dense [K×N] tensor, optionally adds a row-wise or batch-wise bias, and writes the jagged output in tiles sized for the maximum sequence length.
- detailed summary: The `jagged_dense_bmm_broadcast_add_kernel` computes per-batch offsets, advances the Jagged and Dense pointers to the correct tile, and loops over BLOCK_K chunks to accumulate `tl.dot` products into fp32 registers, guarding the ragged tails with masks. After the reduction it optionally adds either an elementwise bias (aligned with jagged rows) or a broadcast bias (one vector per batch) before casting back to the output dtype and storing the tile. The Python wrapper ensures contiguous inputs, allocates the output shaped (sum seq_lens, N), derives the autotuning key via `autotune_max_seq_len`, and launches a 3-D grid over (N tiles, sequence tiles, batch) to cover all rows.
