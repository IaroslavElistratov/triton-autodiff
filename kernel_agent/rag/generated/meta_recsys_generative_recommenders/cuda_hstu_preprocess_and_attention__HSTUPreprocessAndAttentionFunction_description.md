- kernel family: sequence attention preprocessing (layernorm + fused addmm + MHA launch)
- concise summary: Normalizes the input with a weighted layer norm (optionally emitting FP8-quantized activations), projects it into concatenated U/V/Q/K blocks via a Triton addmm, optionally applies rotary embeddings, and then dispatches a hardware-specific HSTU multi-head attention kernel.
- detailed summary: The forward path calls `triton_weighted_layer_norm_quantization_fwd` to obtain normalized activations, their mean/rstd, and (if FP8 is enabled) per-row scaling plus FP8 copies. It then materializes `uvqk = addmm(normed_x, uvqk_weight) + bias`, splitting the result into U,V,Q,K shards, applies rotary position encoding and SiLU gating on U when requested, reshapes Q/K/V to `[tokens, heads, dim]`, and routes them into the fused attention primitive (`bw_hstu_mha_fwd` on SM100 or `hstu_mha_fwd` elsewhere) with all auxiliary metadata (sequence offsets, scaling, target masks). The function caches the tensors and flags needed for backward, optionally storing the precomputed normed_x and uvqk outputs or recomputing them later to trade memory for compute.
