- kernel family: positional/timestamp embedding addition
- concise summary: For each sequence element, fetches its positional index and time bucket, sums the corresponding position and timestamp embeddings, and adds them to the sequence embedding in-place while recording the chosen indices for backward.
- detailed summary: The Triton kernel tiles by batch and sequence block, loads the relevant offsets and sequence length, derives position indices that respect contextual windows, target interleaving, and prefix truncation, and writes them to `PosInds` when training. It then time-differences timestamps against the query event, buckets them via either log or sqrt scaling, clamps to the embedding table range, stores the bucket ids, and streams BLOCK_D-wide slices to add `PosEmb[pos_ind] + TsEmb[ts_bucket]` to each sequence vector. The wrapper ensures contiguous inputs, prepares scratch buffers for stored indices, chooses tile sizes, and launches a grid shaped by (batch, ceil(max_seq_len/BLOCK_N)).
