- kernel family: fused sequence modeling (Triton-based HSTU preprocessing + attention pipeline)
- concise summary: Runs a weighted layer norm on the input sequence, projects it via a Triton/Torch `addmm` to produce U/V/Q/K blocks, reshapes them into head-major layouts, applies a SiLU gate to U, and invokes the Triton HSTU attention kernel with optional sequence sorting, windowing, and TMA acceleration.
- detailed summary: The forward begins by calling `triton_weighted_layer_norm_fwd`, which streams over rows to compute per-token mean/variance and applies learned scale/bias, returning both the normalized activations and cached statistics. It then executes `maybe_triton_addmm_fwd` to multiply by the packed projection weights and add bias, producing a concatenated tensor that is split into hidden and attention components for each head. After reshaping Q/K/V into `(sequence, heads, dim)` form and applying `F.silu` to the U branch (used later in the decoder), the function optionally sorts sequences by length and launches `triton_hstu_attention_fwd`. That kernel (described separately) streams over allowable key ranges with SiLU-gated logits, honors multiple-target and contextual-length constraints, and writes the attention outputs; the forward returns both the gated U tensor and the attention result while saving all normalization stats, projections, and configuration flags for backward recomputation control.
