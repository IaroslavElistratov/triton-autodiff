- kernel family: layer normalization with modulation and dropout
- concise summary: Normalizes each row across D features, rescales with affine parameters, multiplies by an auxiliary tensor U (with optional SiLU), and writes either the gated activations or concatenated [U,X,Y] while applying dropout driven by reproducible Triton RNG.
- detailed summary: `_ln_mul_dropout_fwd` handles the single-row case by scanning BLOCK_D elements to compute mean/variance, storing per-row statistics, forming the normalized output, loading gamma/beta, multiplying by U (optionally SiLU), and generating up to three dropout masks (one per concatenated component). A multi-row variant `_ln_mul_dropout_fwd_rng` streams BLOCK_N rows at a time, optionally reuses a precomputed mask buffer, and supports FAST_DROPOUT to reuse rand3x results. Depending on `concat_ux`, the kernel writes U, the pre-dropout X, and the gated Y into designated segments or just the gated activations. The wrapper ensures contiguity, chooses tile sizes respecting the 64 KiB bound, seeds the RNG if needed, and launches one program per batch row while returning the normalized stats for backward.
