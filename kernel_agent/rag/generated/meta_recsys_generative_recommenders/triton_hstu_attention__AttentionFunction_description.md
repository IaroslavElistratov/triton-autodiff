- kernel family: attention (hierarchical sparse target updates)
- concise summary: Executes the HSTU forward attention pass by tiling each sequence chunk, computing query–key dot products over a dynamically determined window, transforming those scores with a SiLU-style gating rule (rather than softmax), and accumulating the gated values into the output buffer.
- detailed summary: The autotuned `_hstu_attn_fwd` kernel maps program IDs to batch/head slices, optionally remaps sequences via `sort_by_length_indices`, and selects either the TLX path or the workspace-backed `_hstu_attn_fwd_compute`. For each BLOCK_M of queries it loads the associated Q rows (supporting delta-query layouts), determines the valid key range from `contextual_seq_len`, `max_attn_len`, and per-target counts, and streams over BLOCK_N keys. Inside `_hstu_attn_fwd_one_block` the code forms q·k panels, applies masking, then feeds the scores through `fast_dividef(qk, 1 + fast_expf(-qk))`—a SiLU gate—to obtain weights that are multiplied with the corresponding V tiles before accumulating into fp32 outputs. The launcher derives the tuning key (Z, head count, sequence length), allocates temporary workspace, and dispatches the Triton kernel with the appropriate masking flags and descriptors so the fused attention matches the HSTU scheduling requirements.
