- kernel family: jagged tensor manipulation (multirow concat)
- concise summary: Concatenates two jagged/dense inputs into an output jagged tensor using a multirow kernel that processes BLOCK_N rows at a time, improving cache reuse when max_seq_len is large.
- detailed summary: The forward function normalizes layouts, infers batch sizes from offsets or dense lengths, allocates the combined buffer, and dispatches `concat_2D_jagged_multirow`. Each kernel instance maps to (row-block, batch), loads up to BLOCK_N rows from the left and right inputs according to their offsets or dense strides, decides whether each row should come from the right prefix, left segment, or right suffix (accounting for `n_prefix_from_right`), and writes BLOCK_D-wide slices into the destination. Autotuning over BLOCK_D/BLOCK_N balances feature and sequence tiling for high-throughput concatenation.
