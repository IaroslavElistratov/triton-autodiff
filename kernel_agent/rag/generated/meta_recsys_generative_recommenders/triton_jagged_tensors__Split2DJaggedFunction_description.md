- kernel family: jagged tensor manipulation (split with optional dense sections)
- concise summary: Splits a concatenated jagged tensor into two components—each possibly dense—by copying rows into the appropriate output buffer according to per-batch offsets and a configurable prefix length drawn from the right side.
- detailed summary: The forward helper normalizes strides, infers sequence lengths (or max lengths for dense segments), allocates outputs, and launches `_split_2D_jagged` (or its multirow variant) that maps program IDs to batches and row indices. The kernel loads BLOCK_D features from the input sequence, decides whether the current position belongs to the right prefix, the left body, or the right suffix (relative to `n_prefix_to_B`), and stores the slice into OutA or OutB with stride-aware addressing. Multirow implementations increase throughput on SM100 targets by processing BLOCK_N rows per launch, while fallback kernels handle general GPUs.
