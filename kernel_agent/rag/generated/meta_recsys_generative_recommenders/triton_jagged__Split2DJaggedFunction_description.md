- kernel family: jagged tensor manipulation (row-wise split)
- concise summary: Partitions a packed 2D jagged tensor into two outputs—supporting dense–jagged and jagged–jagged combinations—based on per-batch offsets, optional dense sizes, and prefix lengths.
- detailed summary: The forward helper determines whether each target is dense or jagged, allocates the output buffers (reshaping dense outputs to [B, dense_size, D] when necessary), and launches `split_2D_jagged_w_prefix` variants that map program IDs to batches and row indices. Each kernel consults the offsets to locate the source rows, copies BLOCK_D features into either OutA or OutB depending on whether the current row falls before or after the split boundary (adjusted by `n_prefix_to_right` and replace mode), and supports multi-row tiles for better occupancy. The function records offsets and layout flags for backward, where the complementary concat kernels reassemble gradients.
