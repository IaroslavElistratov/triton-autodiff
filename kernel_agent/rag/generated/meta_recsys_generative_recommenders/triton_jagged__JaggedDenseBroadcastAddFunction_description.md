- kernel family: jagged tensor broadcasting (row-wise bias add)
- concise summary: Adds a per-batch dense vector to each row of a jagged tensor by tiling the jagged rows, reusing the row offsets, and streaming over the feature dimension in BLOCK_D chunks.
- detailed summary: The kernel computes sequence start/end from `seq_offsets`, advances Jagged, Dense, and Out pointers to the batch segment, and for each BLOCK_N block of rows loads BLOCK_D columns of the jagged data, broadcasts the corresponding dense vector slice, and stores the summed results. It handles variable D by iterating over the feature dimension when BLOCK_D < D. The host wrapper ensures contiguous inputs, allocates an output clone, selects BLOCK_D (power-of-two ≤64), and launches a 2-D grid over (batch, row-tiles) sized by the maximum sequence length hint.
