- kernel family: jagged × dense batched matmul
- concise summary: Multiplies a ragged batch of sequences by per-batch dense projection matrices, producing a jagged output with no bias by streaming through the packed offsets and tiling the K dimension.
- detailed summary: The forward wrapper enforces contiguous layouts, allocates an output of shape (sum seq_lens, K_out), and launches `jagged_dense_bmm_broadcast_add_kernel` with HAS_BIAS=False. Inside the kernel each program maps to a batch, sequence-tile, and output-column tile, loads BLOCK_K panels of the jagged rows and dense weights (masking ragged tails), accumulates fp32 dot products, and writes the tile back to the jagged output buffer. Autotuning uses the runtime maximum sequence length to balance BLOCK_M/BLOCK_N so long sequences and high batch counts are handled efficiently.
