- kernel family: post-attention projection (norm → modulation → addmm)
- concise summary: Normalizes the attention activations (either per-head group norm or global layer norm), multiplies the result by an auxiliary gating tensor with optional SiLU and dropout, and finishes with a Triton addmm that mixes in the residual input.
- detailed summary: The forward helper chooses between `triton_group_norm_mul_dropout_fwd` and `triton_layer_norm_mul_dropout_fwd`, each of which tiles the row, computes mean/variance, applies scale/bias, gates with U (optionally concatenating [U,X,Y] for downstream reuse), and applies dropout via seeded `tl.rand`. The resulting matrix `y` is then fed into `maybe_triton_addmm_fwd` to produce `out = y @ output_weight + x`. The function caches the statistics, layout flags, and optionally the intermediate `y` for backward, while tracking block sizes, RNG seeds, and feature dimensions to reuse during gradient computation.
