- kernel family: layer normalization (optional affine weights)
- concise summary: Processes rows in BLOCK_N batches, computing mean and variance on-the-fly, normalizing the activations, and optionally applying learnable scale/bias to emit the layer-normed tensor.
- detailed summary: The autotuned `_layer_norm_fwd` loads BLOCK_N×BLOCK_D tiles, accumulates per-row means (writing them if training), subtracts them to get `x_mean`, computes the variance and reciprocal std, and multiplies the centered activations by `rstd`. When weights/biases are provided the `_weighted_layer_norm_fwd` variant broadcasts them, applies the affine transform (with an option for swish gating in other code paths), and writes the result—all while masking ragged tails. The helper prepares mean/rstd buffers as needed, ensures contiguity, selects BLOCK_D within the 64 KiB cap, and launches a grid over the row dimension, caching the statistics for backward.
