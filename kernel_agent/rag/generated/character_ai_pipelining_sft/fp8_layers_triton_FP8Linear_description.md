- kernel family: linear layer (FP8 quantized GEMM with Triton casting)
- concise summary: Quantizes bf16 activations per token chunk and weights per 128×128 block into FP8, feeds those tensors plus their scaling metadata into a fused FP8 GEMM, and returns a bf16 output shaped like the original input—without applying any bias inside the kernel.
- detailed summary: `_FP8Linear_forward` flattens the minibatch, calls `per_token_cast_to_fp8_triton` so each row of `x` is split into 128-column tiles whose maxima set the row×chunk scales, and calls `per_block_cast_to_fp8_triton` to quantize the weights with independent scales per 128×128 block. The underlying Triton kernels (`_fp8_cast_kernel` and `_fp8_per_block_cast_kernel`) stream through the tensor tiles, compute max-abs values with a small epsilon, emit FP8 e4m3 payloads, and store the corresponding scale factors. After casting, the code rearranges the scale tensors into the column-major layout required by the custom `deep_gemm.gemm_fp8_fp8_bf16_nt` routine, allocates a bf16 output buffer, and invokes the FP8 GEMM to multiply activations by weights; the optional bias argument is ignored, leaving bias addition to upstream code. Finally, it reshapes the result back to the original batch/time dimensions and saves the unquantized `x` and `weight` for gradient computation.
