- kernel family: attention (FlashAttention v2 baseline)
- concise summary: Autotunes Triton tile sizes, then marches each query block across the full context (or causal prefix), updating running softmax statistics and writing normalized outputs while caching per-row maxima for backward.
- detailed summary: `__attention_forward` enforces matching head widths, chooses `stage = 3` for causal mode (prefix-only) or `stage = 1` for bidirectional, allocates the output tensor and log-sum-exp buffer `M`, and launches `_attn_fwd` over `(BLOCK_M × heads×batch)` with autotuned configs. Inside `_attn_fwd` a query tile is loaded and the helper `_attn_fwd_inner` sweeps over `BLOCK_N` key/value tiles; in stage 1 it covers the entire sequence, while stage 2 applies a triangular mask by clamping scores outside the causal window. At each step it forms scaled q·k in float32, maintains running maxima/exponent sums, optionally casts probabilities to FP8 to match V, and accumulates the weighted values. After finishing the sweep it normalizes by `l_i`, stores the tile into `Out`, and records the per-token log-sum-exp values in `M` for reuse during gradient computation.
