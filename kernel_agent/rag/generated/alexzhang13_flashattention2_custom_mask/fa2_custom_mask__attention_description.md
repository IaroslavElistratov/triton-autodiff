- kernel family: attention (FlashAttention v2 with optional dense mask and FP8 values)
- concise summary: Autotunes tile shapes, then launches a Triton kernel that streams query tiles across the full context, applies optional boolean masks, maintains log-sum-exp statistics, and writes normalized outputs while caching per-tile maxima.
- detailed summary: `__attention_forward` verifies consistent head dims, chooses stage count based on whether a custom mask tensor is supplied, allocates the output `o` and max buffer `M`, and configures the launch grid over `(BLOCK_M × heads×batch)`. The autotuned `_attn_fwd` kernel constructs block pointers for Q/K/V (and the mask if needed), loads a `BLOCK_M×HEAD_DIM` query slab, and iterates across `BLOCK_N` key/value tiles. Inside `_attn_fwd_inner` it forms scaled dot-products, injects mask penalties (when `USE_MASK`), tracks running maxima/softmax denominators in float32, optionally casts probabilities to FP8 to match the V dtype, and accumulates the value tiles. After the loop it normalizes by the aggregate `l_i`, stores the result tile into `Out`, and writes the per-row log-sum-exp values into `M` for backward reuse.
