- kernel family: gated GELU (split-channel GeLU + elementwise product)
- concise summary: The forward splits the last dimension into value and gate halves, applies GeLU to the gate using a Triton kernel that works for both contiguous and transposed layouts, and multiplies it with the value half; separate kernels handle the corresponding gradients.
- detailed summary: `_gelu_glu_forward` inspects the stride of the last dimension. For contiguous-last layouts it launches `_gelu_glu_fwd_kernel`, which loads the first half (`x`) and second half (`gate`) of each row/page, evaluates the tanh-based GeLU approximation (`0.5·gate·(1+tanh(β(g+k·g³)))`), and writes the product back into an output tensor of half the channel width. For non-contiguous cases it reshapes and invokes `_gelu_glu_fwd_kernel_`, which iterates down columns instead. The backward path mirrors this split: `_gelu_glu_bwd_kernel` / `_gelu_glu_bwd_kernel_` pull both halves from the saved input, recompute the GeLU derivative, and return gradients for the value and gate slices separately. This Triton implementation provides a fused GeLU-GLU primitive for 2x channel splitting workloads.
