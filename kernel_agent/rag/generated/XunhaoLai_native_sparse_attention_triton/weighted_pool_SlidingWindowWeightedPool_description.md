- kernel family: sequence pooling (sliding window, optional learned weights)
- concise summary: Computes compressed sequences by sweeping fixed-width windows over ragged inputs, applying either average pooling or learned per-head weights, and emitting the pooled activations plus updated prefix sums.
- detailed summary: `_SlidingWindowWeightedPool_forward` checks dtypes, validates optional weights, calls `get_compressed_seqlens` to derive the output lengths, and zeros the destination tensor using the same device as the inputs. It selects power-of-two block sizes for the kernel span and feature dimension, then runs `sliding_pool_fwd_kernel` with a grid of (batch × head × output index). Each kernel instance gathers a `kernel_size × head_dim` slice via block pointers, multiplies by per-head weights when supplied (otherwise averages), and writes the resulting head_dim vector into the compressed sequence. The function returns both the pooled tensor and `y_cu_seqlens`, which downstream sparse attention kernels reuse to interpret the shortened layout.
