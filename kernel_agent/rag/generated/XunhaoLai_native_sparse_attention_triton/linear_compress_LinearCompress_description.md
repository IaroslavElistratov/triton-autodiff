- kernel family: sequence compression (strided linear projection per head)
- concise summary: Uses prefix sums to slice each head’s sequence into overlapping windows, reshapes the head-specific weights to `[kernel_size, head_dim, head_dim]`, and launches a Triton kernel that linearly projects each window into a shorter sequence plus updated `cu_seqlens`.
- detailed summary: `_LinearCompress_forward` validates shapes, ensures CUDA device context, computes the compressed lengths `y_seqlens`, and allocates the destination tensor and prefix sums. It reshapes `w` for head-local matrix blocks, configures block sizes (`block_output_seq_size=64`, `block_kernel_size` as pow2, etc.), and dispatches `linear_compress_fwd_kernel` over `(batch×head, output-tile, head_dim tile)`. Inside the kernel, each program gathers the relevant `kernel_size × head_dim` slice using the stride, reshapes it, multiplies by the corresponding weight block in float32 (iterating across the head dimension in `BLOCK_HEADd_DIM` chunks), accumulates the results, and stores the compressed vectors to `Y`. The function returns both the compressed tensor and its new `cu_seqlens`, ready for sparse attention stages.
