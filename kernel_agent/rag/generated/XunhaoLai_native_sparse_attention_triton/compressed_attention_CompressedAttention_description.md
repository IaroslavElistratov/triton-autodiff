- kernel family: attention (compressed windowed attention)
- concise summary: Applies attention over strided sliding windows: each BLOCK_SIZE_Q query tile attends only to nearby keys spaced by `kernel_stride`, using an online softmax to accumulate outputs and per-row log-sum-exp values.
- detailed summary: `_compressed_attention_fwd` validates dtypes, derives sharing between query and KV heads, zero-initializes the output `o` and `lse`, and dispatches `forward_kernel` on a grid of (batch × q-head × query-block). The Triton kernel loads a window of queries starting at `kernel_size-1`, then loops over admissible key blocks defined by the stride; each iteration forms scaled q·k (with causal masking that clips future keys), updates the running max and normalization terms, converts the probabilities to the value dtype, and accumulates the weighted V tile in float32. After visiting all reachable keys it rescales by `exp2(m_i - lse_i)`, writes the normalized tile back to `o`, and stores the log-sum-exp rows so downstream code can reuse the softmax statistics without recomputing the full score matrix.
