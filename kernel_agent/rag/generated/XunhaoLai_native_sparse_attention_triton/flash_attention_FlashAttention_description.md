- kernel family: attention (flash attention, variable-length sequences with optional GQA interleave)
- concise summary: Dispatches a Triton kernel that tiles queries in 128-row blocks, streams 64-key chunks per block, applies causal or dense masking, and maintains online softmax statistics before writing the mixed values and log-sum-exp outputs.
- detailed summary: `_flash_attention_fwd` checks head counts and dtypes, allocates the output and LSE buffers, and selects tile shapes (`BLOCK_SIZE_Q=128`, `BLOCK_SIZE_K=64`, powers-of-two for qk/v head dims) plus warp/stage counts via `get_num_warps_stages`. The `forward_kernel` grid spans `(batch × q_heads × query_tile)`; each program maps query heads to KV heads (respecting `gqa_interleave`), fetches the ragged Q/K/V slices via prefix sums, and iterates over admissible key tiles. Within the loop it forms scaled q·k in float32, injects causal blocking when requested, updates the running max/log-sum terms for stability, accumulates the weighted V tiles, and advances the block pointers. After finishing the key loop it rescales the tile by `exp2(m_i - lse_i)`, stores the normalized output, and records the per-token log-sum-exp values for reuse in backward or checkpointing flows.
