- kernel family: attention (top-k block sparse)
- concise summary: For each query tile it reads the precomputed block indices, gathers only those key/value blocks allowed by the causal constraint, runs an online softmax, and scatters the accumulated outputs plus log-sum-exp statistics.
- detailed summary: `_topk_sparse_attention_fwd` prepares dense output/LSE tensors, determines tiling parameters (`num_q_loop` chunks, power-of-two block sizes for K/D/H/T), and launches `forward_kernel` across `(batch × kv_head × query_chunk)`. Inside the kernel each program iterates over the `real_q_loop` queries in its chunk, loads the associated TOPK block indices, filters them so only past blocks contribute (for causal ordering), and for each surviving block loads the matching K/V tiles. It computes scaled q·k in float32, updates running maxima and exponentials to keep the softmax stable, accumulates the weighted values, and finally rescales by `exp2(m_i - lse_i)` before storing the compressed outputs. Per-query log-sum-exp rows are written alongside the activations so later stages can reuse the normalization factors.
