- kernel family: mixture-of-experts token routing (top-k gating, histogram-based tiling)
- concise summary: The forward pass builds per-expert token histograms, prefix sums, and gather/scatter maps so that top-k gate selections can be packed contiguously for expert dispatch.
- detailed summary: `_combined_routing_memset` multiplexes several tiny tasks across program IDs—prefix-scanning token counts, deriving per-expert tile offsets, zeroing metadata buffers, and stamping sentinel values—while `_expt_data_memset` and `_expt_data_compute` expand histogram counts into tile-level start indices. A second launch `_combined_routing_compute` fills expert tile maps for subsequent kernels and invokes `_routing_compute_indx`, which loads each tile of top-k expert assignments, radix-sorts them by expert ID via `tl.sort`, runs an associative scan to obtain run lengths, and finally writes scatter offsets, inverse gathers, and renormalized gate scales. The launch grid slices across blocks of experts (`BLOCK_M`, `SIZES`) so every program instance owns a manageable chunk of gating entries and loops over its tile span to keep data resident in registers during accumulation.
