- kernel family: Top-K selection (streaming bitonic merge with bitmask output)
- concise summary: The forward kernel optionally reuses provided indices; otherwise it streams the row through BLOCK_N chunks, maintaining a bitonic top-K structure, and writes both the top values/indices and a packed bitmask indicating selected experts.
- detailed summary: `_topk_forward` assigns each program a BLOCK_M batch of rows. If `USE_PROVIDED_INDX` is false it calls `streaming_topk`, which bitcasts the latest BLOCK_N slice into unsigned keys combining quantized values and indices, maintains the current top-K via `tl.topk` and bitonic merges as it walks backward across the row, and finally decodes the winning keys back into indices and fp values. Optional softmax normalization is applied in FP32 before storing. The kernel writes values and (when newly computed) indices into the output tensors, then iterates across the padded expert dimension to construct 32-wide bitfields marking which experts were selected, storing them into the `Bits` matrix for routing. Host utilities such as `topk_forward` manage tensor wrappers, block sizes, and configuration flags before launching the kernel.
