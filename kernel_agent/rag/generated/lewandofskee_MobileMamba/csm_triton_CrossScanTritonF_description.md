- kernel family: Cross-state scan (producing directional feature maps over 2D grids)
- concise summary: The forward path tiles the input activation map and for each block writes four directional scan buffers—top-to-bottom, left-to-right, and their reversed counterparts—into an output tensor shaped for downstream cross-state modules.
- detailed summary: `_CrossScanTritonF_forward` normalizes tensor layout options, computes tiling parameters (`BC=1`, `BH=BW=32`), allocates an output buffer with a leading dimension of size 4 (one per scan), and dispatches `triton_cross_scan_flex` with `operation=0`. In that kernel, every program handles one `(BH×BW)` spatial tile for a channel chunk and batch entry, builds index routes (`HWRoute0-3`) corresponding to the desired traversal orders, and masks boundary elements so partial tiles near the image edges are safe. For the non-`one_by_one` case used here, it walks through each channel in the tile, loads the source activations according to the requested memory layout, and writes them into the four directional buffers inside `y`, effectively materializing the scan state for each orientation while respecting channel-first or channel-last layouts specified by the flags.
