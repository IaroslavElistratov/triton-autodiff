- kernel family: Cross-state scan (2-direction variant emitting paired traversals)
- concise summary: The forward pass partitions the feature map into Triton tiles and writes two directional scan buffers—forward and reverse—per tile into an output tensor sized for downstream MobileMamba blocks.
- detailed summary: `_CrossScanTritonFk2_forward` resolves layout flags, computes the `(NH*NW, NC, B)` grid with tiles (`BH=BW=32`, `BC=1`), allocates an output tensor whose leading dimension enumerates the two scan directions, and launches `triton_cross_scan_flex_k2` with `operation=0`. In the kernel each program derives the tile-specific index routes, masking boundary elements when the final tile is ragged, then iterates across its channel chunk to copy the source activation block into both forward (`HWRoute0`) and reverse (`HWRoute2`) buffers, collapsing to a single route when `scans==1`. Layout-dependent pointer math lets it support channel-first vs channel-last tensors as well as the optional `one_by_one` decomposition where four-direction storage is interleaved in the channel dimension.
