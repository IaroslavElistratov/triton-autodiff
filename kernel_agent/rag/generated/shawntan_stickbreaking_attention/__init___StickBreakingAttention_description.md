- kernel family: attention (stick-breaking monotonic attention, Triton block streaming)
- concise summary: Implements the stick-breaking attention forward pass by sweeping backward over key blocks, computing logistic gates, and accumulating probabilities and remainders per query chunk.
- detailed summary: Each Triton program handles one head and BLOCK_M queries, loading their Q, then iterating over prior BLOCK_N keys (and optionally the diagonal) while calling `compute_block`, which applies a custom softplus-based stick-breaking transform to obtain log-probabilities and updates per-row negative log residual mass. The kernel streams K/V blocks through shared helpers that respect dimensional masking, multiplies the stabilized probabilities with V in fp32, optionally records attention weights, and writes both the attention output and the remaining mass/neg-log-accumulator tensors used later for normalization. Launch helpers map the grid to `(batch, heads, ceil(seq/BLOCK_M))`, precompute lower-triangular coefficients for cumulative sums, and support `attend_current` toggles without touching backward code.
