- kernel family: distributed cross-entropy (block-split logits with smoothing/z-loss)
- concise summary: The forward kernel scans each row’s logits in column blocks, computing log-sum-exp values, partial losses, and optional z-loss terms while handling label smoothing and sharded vocabularies.
- detailed summary: `cross_entropy_fwd_kernel` launches over `(row, block)` pairs; it loads a `BLOCK_SIZE` slice of logits, rescales by `logit_scale`, and updates a running max/partition (`lse`) to maintain numerical stability before writing `lse` into a buffer that can later be reduced across blocks or ranks. Depending on whether the target class resides in the current block, it subtracts either the true logit or the smoothed expectation, and if `SPLIT` is false it also adds the `z_loss = lse_square_scale·lse²`. For column-sharded or oversized vocabularies the host accumulates blockwise losses, performs inter-chunk reductions and optional `all_gather`/`all_reduce` across process groups, and finally adds the aggregated `lse` (and z-loss) back into the per-sample loss while masking ignored labels. This fused approach avoids materializing the full probability vector yet still supports smoothing, global vocab size, and optional z-regularization.
