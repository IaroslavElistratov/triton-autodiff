- kernel family: fused layer/RMS norm (optional residual capture)
- concise summary: The kernel combines residual addition, mean/variance computation, normalization, and affine scaling into a single pass over the feature dimension, optionally caching the summed residual stream.
- detailed summary: `_layer_norm_fwd_1pass_kernel` processes one row per program: it loads the activation slice, adds an optional residual vector (and, if requested, writes the combined value to a residual-out buffer), then either subtracts the row mean (LayerNorm) or skips centering (RMSNorm) while accumulating the second moment. It stores the per-row reciprocal stddev `rstd` (and mean if needed), multiplies the normalized features by gamma when provided, adds beta when present, and writes the fused result back under column masks. The host helper flattens batch dimensions, ensures contiguous layout, allocates mean/rstd/residual buffers in the desired dtypes, selects a power-of-two tile (`BLOCK_N ≤ 64 KB` worth of elements), and launches one kernel instance per row with autotuned warp counts keyed on hidden width and feature flags.
