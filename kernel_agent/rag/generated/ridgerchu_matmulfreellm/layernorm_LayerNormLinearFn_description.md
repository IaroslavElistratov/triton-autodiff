- kernel family: normalization + linear (quantized layernorm + linear projection)
- concise summary: Reshapes the input to 2D, applies a single-pass Triton layer/RMS norm that can fold in residual connections, quantizes the normalized activations, and finishes with a quantized-weight linear projection (returning the prenorm residual if requested).
- detailed summary: `_layer_norm_fwd_1pass_kernel` streams through each row to compute mean/variance (or RMS), optionally adds and stores a residual buffer, and applies affine weight/bias before emitting the normalized tensor. The Python wrapper then quantizes both activations and weights (`activation_quant`, `weight_quant`) and calls `F.linear` with the quantized weights to produce the final projection, reshaping outputs back to the original batch shape and optionally returning the saved residual for prenorm pipelines.
