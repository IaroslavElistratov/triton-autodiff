- kernel family: L2 normalization (row-wise)
- concise summary: The Triton kernel normalizes each row by its L2 norm, computing the squared magnitude and scaling the vector so its norm becomes one, with epsilon for stability.
- detailed summary: `_l2_norm_fwd_1pass_kernel` binds one program to each flattened row, loads a `BLOCK_N` chunk of activations into fp32, squares and sums the elements to obtain `var = ‖x‖₂²`, and forms the reciprocal `rstd = 1 / sqrt(var + eps)`. It then multiplies the original values by `rstd` under a column mask and writes the normalized row back in place. The wrapper reshapes arbitrary batch dimensions to 2D, ensures contiguous layout, picks a power-of-two feature tile (capped by 64 KB of elements), and launches the kernel across all rows before restoring the original shape.
