- kernel family: fused layer/RMS norm with per-row symmetric quantization
- concise summary: The forward kernel normalizes each row (optionally adding a residual), applies gamma/beta, and then quantizes the result to int8 by computing a per-row scale based on the maximum absolute activation, enabling BitNet-style low-bit linear layers.
- detailed summary: `_layer_norm_fwd_quant_kernel` shares the residual-handling and mean/variance logic of the standard fused layer norm: it optionally adds a residual stream, stores it back out, and computes either LayerNorm or RMSNorm statistics before multiplying by the weight and adding bias. After producing the normalized vector, it derives a scale factor `scale = 127 / max(|y|, 1e-5)` for the current row, rounds `y * scale` to the nearest integer, clamps to `[-128, 127]`, and divides by `scale` so the stored activations mimic int8 quantization while remaining in floating-point form. The wrapper reshapes the tensor, enforces contiguity, and launches one kernel per row with autotuned block sizes, then passes the quantized activations into a BitNet-aware linear layer whose weights are quantized separately via `weight_quant`.
