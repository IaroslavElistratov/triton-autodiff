- kernel family: recurrent gating (HGRN chunked scan across time)
- concise summary: The forward pass processes the sequence in fixed-size chunks, updating hidden states with exponential gates, writing intermediate accumulators, and then stitching adjacent chunks so the recurrence spans the entire timeline.
- detailed summary: `chunk_hgrn_fwd_kernel_h` assigns each CTA a `(batch×head, chunk, feature)` tile, optionally seeds `b_h` from `h0`, and walks `BT` timesteps inside the chunk. At each step it loads the input `x` and log-gate `g`, forms `b_h = exp(g) * b_h + x`, accumulates the gate prefix sum `b_gc`, and stores both the running hidden state and gate cache back to memory. A second kernel `chunk_hgrn_fwd_kernel_o` then iterates over chunk boundaries: it reloads the cached gate sums and chunk outputs, pulls the last hidden state from the previous chunk, and performs `o += exp(gc) * h_prev` so the exponential recurrence carries across chunk seams. The driver chooses tile sizes (`BT=128`, `BD≤64`), launches the intra-chunk kernel on a 3D grid `(D_tiles, T_tiles, B·H)`, follows with the chunk-stitch kernel over `(D_tiles, B·H)`, and optionally copies the last timestep as the final state before casting results back to the input dtype.
