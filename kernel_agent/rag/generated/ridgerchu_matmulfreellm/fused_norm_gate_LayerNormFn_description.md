- kernel family: fused layer/RMS norm with residual capture and gating
- concise summary: The forward kernel optionally adds a residual stream, computes either LayerNorm or RMSNorm statistics, normalizes and scales by gamma/beta, and finally gates the result by multiplying with a learned modulation tensor `o * sigmoid(o)`.
- detailed summary: `_layer_norm_fwd_1pass_kernel` processes one row per program: it loads the activation tile, adds an optional residual, and writes it back out if a residual buffer needs to be preserved. Depending on `IS_RMS_NORM`, it either subtracts the mean before accumulating the variance or treats the raw activations as the RMS numerator; in both cases it stores the row’s `rstd` (and `mean` when required) for backward use. After normalizing, it multiplies by the weight vector, adds bias when present, and retrieves the corresponding gate values `O`, applying the elementwise modulation `y *= o * sigmoid(o)` so the normalized features are gated in one pass. The host wrapper ensures contiguous layout, materializes any residual-out buffer in the desired dtype, chooses a power-of-two feature tile (up to 64 KB), and launches the kernel with autotuned warp counts keyed on hidden width and feature flags.
