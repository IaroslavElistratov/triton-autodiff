- kernel family: mixture-of-experts (grouped GEMM + scatter/gather gating)
- concise summary: Buckets tokens by expert, scatters them into contiguous blocks, runs two grouped matmuls with SiLU-and-gate fusion and a second projection, then re-gathers the weighted outputs back to the original order.
- detailed summary: The forward call builds expert histograms to obtain prefix sums, uses `moe_scatter` and a stable sort-based index to pack tokens per expert, and launches `group_gemm_same_nk` twice to compute the paired feed-forward projections (with a Silu×linear activation). Gate probabilities are scattered to match the rearranged tokens, multiplied into the activations, and sent through a third grouped GEMM. Finally `moe_gather` restores the original token order so the fused MoE layer returns a tensor shaped like `hidden_states`.
