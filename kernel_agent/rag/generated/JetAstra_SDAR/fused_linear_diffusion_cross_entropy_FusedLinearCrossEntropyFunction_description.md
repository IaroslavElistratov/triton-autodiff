- kernel family: linear projection + cross-entropy (staged Triton logits/LSE + loss kernel)
- concise summary: Each batch chunk first runs a dense `F.linear` to form logits, then a Triton log-sum-exp kernel and a separate cross-entropy kernel normalize those logits, write per-sample losses, and overwrite the logits buffer with gradients for the backward accumulation.
- detailed summary: The Python driver splits the batch into configurable chunks, applies `torch.nn.functional.linear` to obtain the logits, and invokes `logsumexp_fwd_kernel` so each `(row, vocab tile)` program computes local maxima and partial log-sum-exp values before collapsing them into a per-row `lse`. It then launches `cross_entropy_kernel`, which iterates over the vocabulary in `BV`-sized tiles, skips ignored targets, applies optional label smoothing and scaling, stores the per-row loss, and writes the normalized gradient back into the logits buffer. After these two kernels finish, the host multiplies the gradient-filled logits by the inputs to accumulate `dx`, optionally reduces `dw`/`db` in fp32, and performs the requested reduction (`mean`, `sum`, or `none`). The linear projection and loss evaluation are therefore staged but coordinated within the same forward routine.
