- kernel family: dropout (elementwise inverted-dropout mask)
- concise summary: The forward path flattens the tensor, draws a Philox-style random mask per element inside a Triton kernel, zeros elements with probability `drop_p`, rescales the survivors by `1/(1-drop_p)`, and reshapes the result back.
- detailed summary: `_DropoutAutoGrad_forward` short-circuits when dropout is disabled, otherwise allocates a flattened output buffer and chooses a random seed saved for backward. `dropout_forward_kernel` tiles the 1-D array in `BLOCK_SIZE` chunks; each lane loads one element, uses `tl.rand(seed, offset)` to produce reproducible Bernoulli decisions, and writes either zero or the scaled activation to `output_pointer`. Special cases for `drop_p == 1` return an all-zero tensor without launching Triton. The kernel launch size `ceil_div(size, BLOCK_SIZE)` ensures full coverage before the tensor is restored to its original shape.
