- kernel family: pointwise losses (smooth L1 / L1 / squared L2 / Huber)
- concise summary: The forward launch flattens the tensors, evaluates the chosen p-loss per element in fp32, and either writes the elementwise errors or accumulates block-level partial sums that the host finishes reducing.
- detailed summary: `p_loss_forward_kernel` assigns each program a `BLOCK_SIZE` slice, loads the aligned input/target values, and computes `diff = input - target`. Depending on `p_loss`, it branches to smooth-L1 (`diff` thresholded by `param`), absolute value, squared L2, or Huber formulas, all executed elementwise. When `reduction='none'` it stores the error vector back to the same offsets; for `mean` or `sum` it collapses the block into a single scalar (dividing by `size` for the mean) so the host can sum the partials. The Python forward wrapper records the loss type/parameter, flattens arbitrary shapes, allocates the appropriate output buffer, dispatches the autotuned elementwise kernel with `ceil_div(size, BLOCK_SIZE)` programs, and—if a reduction was requested—truncates the temporary array to the actual number of launched blocks before finishing the scalar reduction on the CPU.
