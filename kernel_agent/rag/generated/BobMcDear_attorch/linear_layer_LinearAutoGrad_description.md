- kernel family: linear projection (matrix multiply with optional bias + fused activation)
- concise summary: The forward kernel tiles the batch and output-channel axes, streams the input-feature dimension in blocks to accumulate fp32 dot products (with fp16/tf32 options), adds an optional bias, and can immediately pass the pre-activation through a chosen nonlinear before storing results.
- detailed summary: `linear_forward_kernel` assigns each program to a `(BLOCK_SIZE_BATCH × BLOCK_SIZE_OUT_FEAT)` tile, groups multiple batch tiles together for L2 reuse, and iterates over the input features in `BLOCK_SIZE_IN_FEAT` slices. For each slice it loads the activation submatrix and corresponding weight panel, optionally casts to fp16, and performs a `tl.dot` into a fp32 accumulator (`allow_tf32=tf32` when enabled). After the reduction the kernel adds a broadcast bias if requested, optionally stores the accumulator into `pre_act` for backward, and, when `act_func` is specified, invokes `apply_act_func` on the fp32 tile before writing to the output buffer with boundary masks. The Python launcher flattens leading dimensions into a 2-D matrix, parses any activation parameter suffix, allocates output (and pre-activation) tensors in the autocast-selected dtype, and dispatches the autotuned kernel with one program per `(batch tile × output tile)` combination.
