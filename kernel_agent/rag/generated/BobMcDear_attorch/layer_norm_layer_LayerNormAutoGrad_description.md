- kernel family: layer normalization (per-row normalization with optional affine)
- concise summary: The forward kernel processes `BLOCK_SIZE_BATCH` rows at a time, computes their mean and variance in fp32, normalizes each feature, optionally applies learned scale/bias, and can emit row statistics for reuse in backward.
- detailed summary: `layer_norm_forward_kernel` maps each `batch_pid` to a tile of rows and loads the corresponding logits into registers, promoting them to fp32 for the reductions. It forms the row mean, constructs centered deviations, evaluates the inverse standard deviation `1/sqrt(var + eps)`, and writes `mean`/`inv_std` to global memory when gradients will be needed. The normalized output is optionally scaled by `weight` and shifted by `bias` (if provided), with masking to tolerate partial tiles along the feature axis. The Python forward wrapper reshapes arbitrary inputs into a 2-D `[batch_dim, feat_dim]` view, allocates the output in either fp32 or the input dtype per autocast policy, dispatches one Triton program per batch tile via the autotuned `BLOCK_SIZE_BATCH`, and reshapes the normalized tensor back to the original form while stashing the saved statistics in the context.
