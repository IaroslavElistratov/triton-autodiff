- kernel family: attention (flash-style softmax attention with Triton block pointers)
- concise summary: Each program owns a tile of `BLOCK_M` queries for one `(batch, head)` pair, streams through key/value blocks with block pointers, performs log-sum-exp updates in base-2 space for numerical stability, and accumulates the normalized attention output while writing the per-row logits/lse summary.
- detailed summary: `_fwd_kernel` indexes `(start_m, off_hz)` to select the current query tile and constructs block pointers over K and V laid out as contiguous `BLOCK_DMODEL × BLOCK_N` panels. It loads the query tile, scales by `sm_scale * log2(e)`, and iterates over key blocks from `lo` to `hi` (respecting causal limits). For each block it computes `qk = tl.dot(q, k)` in fp32, applies a causal mask when needed, and updates running maxima `m_i` and normalization terms `l_i` via the flash-attention recurrence (`alpha = exp2(m_i - m_i_new)`). The value accumulator `acc` is rescaled by `alpha`, receives the contribution from `p = exp2(qk - m_i_new)`, and advances the block pointers to the next chunk. After the loop it divides `acc` by `l_i`, stores the log-sum-exp summary `m_i + log2(l_i)` into `L`, and writes the output tile back through another block pointer. The launcher validates head dimension support (16–128), allocates the logits buffer `L`, configures a grid of `(ceil_div(N_CTX, BLOCK_M), batch*heads, 1)` with `num_warps` tuned for head size, and dispatches the kernel to produce the attention result tensor `o`.
