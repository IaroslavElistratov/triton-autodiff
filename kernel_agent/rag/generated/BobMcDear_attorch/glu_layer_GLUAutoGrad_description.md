- kernel family: gated linear unit (configurable activation gate)
- concise summary: The forward pass splits the chosen dimension into two contiguous halves, launches an elementwise kernel that multiplies the first half by the activation-transformed second half, and writes the gated output back in a flattened view.
- detailed summary: `_GLUAutoGrad_forward` parses any activation parameter from the `act_func` string, chunks the tensor into `input1` and `input2`, flattens them, and dispatches `glu_forward_kernel` with one Triton program per `BLOCK_SIZE` slice. Inside the kernel each lane loads matching offsets from both halves, applies the requested activation via `apply_act_func` (using fp32 math for nonlinearities that need it and no dropout), and forms `output = input1 * gate`. The result buffer is reshaped implicitly when returned, while the contiguous halves are cached in the context when gradients are required.
