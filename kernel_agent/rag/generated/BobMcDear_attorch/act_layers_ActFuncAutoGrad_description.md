- kernel family: elementwise activation (wide catalog with optional fused dropout)
- concise summary: The forward path flattens the tensor, launches a single elementwise Triton kernel that branches on the requested activation (ReLU/GELU/Sigmoid/etc.), optionally applies parameterized variants, and can fuse inverted-dropout using a Philox-style RNG seeded per launch.
- detailed summary: `act_func_forward_kernel` tiles the flattened array in `BLOCK_SIZE` stripes; each thread loads one element, forwards it through `apply_act_func`, and stores the result. `apply_act_func` switches on `act_func` to invoke jit-compiled helpers (GELU, SiLU, SELU, shrink ops, etc.), casting to fp32 when necessary for stability and honoring per-activation parameters parsed on the host (`leaky_relu_α`, `elu_α`, `hardshrink_λ`, …). When `dropout` is enabled, it generates a reproducible mask via `tl.rand(seed, offset)` and rescales kept activations by `1/(1-drop_p)` so the mean remains unchanged. The Python launcher extracts any parameter suffix from `act_func`, saves context (including the RNG seed), flattens the input, and dispatches the autotuned kernel with a grid sized by `ceil_div(size, BLOCK_SIZE)` before reshaping the result back.
