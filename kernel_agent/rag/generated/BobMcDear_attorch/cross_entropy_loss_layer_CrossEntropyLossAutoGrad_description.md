- kernel family: cross-entropy loss (batched log-sum-exp reduction with optional class weighting)
- concise summary: Each program owns a block of examples, streams their logits in power-of-two feature tiles to compute numerically-stable log-sum-exp, subtracts the true-class logit, and either rescales by per-class weights or averages by the batch size before writing partial reductions.
- detailed summary: `cross_entropy_loss_forward_kernel` maps `batch_pid` to `BLOCK_SIZE_BATCH` contiguous indices and forms pointers to both the entire row and the true-class column (`pred_pointer`). It loads the row into fp32, subtracts the row max, exponentiates/sums to obtain `logsumexp`, and forms `loss = logsumexp - logit[target] + max`. When `weighted` it fetches the per-class weight, applies it to each sample, and records the weight sum for later normalization; otherwise it divides by the global batch count inside the kernel. The partial losses are accumulated into `output_pointer[batch_pid]`. The Python forward wrapper chooses a batch tile heuristic, allocates buffers for the partial losses (and optional weight sums), dispatches the autotuned kernel with one program per batch tile, and performs the final scalar reduction/normalization on the host while caching the logits/targets for backward.
