- kernel family: negative log-likelihood loss (gather-based loss with optional class weights)
- concise summary: The forward kernel tiles the batch and spatial axes, gathers the log-probability for each target label, negates it, optionally multiplies by class weights, and either writes per-element losses or reduces to block partials depending on the requested reduction.
- detailed summary: `nll_loss_forward_kernel` maps `batch_pid`→`BLOCK_SIZE_BATCH` samples and iterates over `BLOCK_SIZE_SPATIAL` positions; it advances the input pointer to the appropriate class column using the target indices, loads the selected logits in fp32, and computes `-logit`. If `weighted`, it fetches the per-class weight and scales the contribution, recording the weight sum when `reduction='mean'`. For `reduction='none'` the tile is written directly to the output tensor at the matching coordinates; otherwise each program accumulates its block sum (and optional weight sum) into per-program buffers that the host later aggregates. The launcher flattens arbitrary spatial dimensions to `[batch, spatial]`, chooses block sizes heuristically, allocates the output/weight-sum buffers, dispatches one program per batch tile, and performs the final host-side reduction and normalization before reshaping the result if needed.
