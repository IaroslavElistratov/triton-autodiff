- kernel family: softmax / softmin (row-wise normalization with optional log)
- concise summary: The forward kernel tiles the batch axis, loads each row into fp32, optionally negates it, subtracts the per-row maximum for stability, and writes either the normalized probabilities or their log depending on configuration.
- detailed summary: `softmax_forward_kernel` assigns each program a `BLOCK_SIZE_BATCH × BLOCK_SIZE_FEAT` slice, fetching the input row with broadcasted masks. If `neg` it flips the sign to implement softmin, then applies the log-sum-exp trick by subtracting the row maximum, exponentiating, summing, and producing either `exp / sum` or `input - log(sum)` when `log=True`. The kernel writes the resulting tile back to the output buffer, tolerating partial tiles along the feature axis via masking. The host wrapper reshapes arbitrary inputs into `[batch_dim, feat_dim]`, allocates the output in the chosen autocast dtype, configures a grid with one program per batch tile via heuristically selected block sizes, and records the output for backward when gradients are required before reshaping to the original layout.
