- kernel family: rms normalization (per-row normalization with optional scale)
- concise summary: The forward kernel processes `BLOCK_SIZE_BATCH` rows at a time, computes each row’s inverse root-mean-square in fp32, multiplies the activations by it, optionally scales by a learned weight, and can stash the inverse RMS for backward reuse.
- detailed summary: `rms_norm_forward_kernel` tiles the input matrix `[batch_dim, feat_dim]`, loading each tile into fp32 registers, evaluating `inv_rms = 1 / sqrt(mean(x^2) + eps)`, and applying it elementwise to yield the normalized row. When gradients are requested it stores the per-row `inv_rms` buffer, and if `scale_by_weight` is enabled it loads the per-feature weight vector and multiplies the normalized tile before writing out with appropriate masks for partial tiles. The AMP-decorated forward wrapper flattens arbitrary shapes to 2-D, allocates the output (and optional stats buffer), dispatches one program per batch tile using heuristics for the block sizes, and reshapes the normalized tensor back to the original view while caching the tensors needed for backward.
