- kernel family: quantized linear dequantization (2/4/8-bit weight unpacking for matmul)
- concise summary: Forward execution dequantizes packed QKV weights into fp16/fp32 tiles with Triton, then runs a dense matrix multiply between the input activation and the reconstructed weight matrix.
- detailed summary: `dequant_kernel_248` assigns each program instance a vector of output coordinates, infers the source group via `g_idx`, and extracts packed values by shifting and masking the row and column bitfields; companion loads pull per-group scales and zero-points, which are converted to float and applied before writing the linearized output tile. `dequant248_core` orchestrates buffer allocation, grid sizing (`X_BLOCK` autotuned), and launches the kernel so the entire quantized weight tensor is inflated to full precision. The launcher `quant_matmul_248` then performs a standard matrix product—optionally transposed for backward reuse—against the dequantized weight tensor on the weight’s device, returning the result in the caller’s original dtype.
