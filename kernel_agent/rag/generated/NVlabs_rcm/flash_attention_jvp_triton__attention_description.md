- kernel family: attention (flash-style forward with Jacobian-vector product tracking)
- concise summary: A block-streaming Triton kernel computes softmax(QKᵀ)V while simultaneously propagating tangent inputs (tQ, tK, tV) to a tangent output, using online log-sum-exp buffers and optional causal staging.
- detailed summary: `_attn_fwd` tiles queries by BLOCK_M rows and iterates over BLOCK_N key/value tiles via `_attn_fwd_inner`, which maintains running maxima `m_i`, sums `l_i`, and accumulators for the primal output (`acc`) and two auxiliary terms (`acc_A`, `acc_B`) that capture contributions from tangents. Each iteration loads Q/K/V and their tangent counterparts, forms qk scores with scaling and causal masking when needed, exponentiates in base-2 for stability, updates the running softmax weights, and contracts with V/tV to update both primal and tangent accumulators. After streaming through all tiles it writes log-sum-exp values `M`, normalized outputs, and the final tangent combination `(acc_A + acc_B - r_i * acc) / l_i` to global memory. The Python wrapper prepares output/tangent tensors, selects stage=3 for causal mode to split pre- and post-diagonal passes, and autotunes configs over head dimensions and sequence lengths.
