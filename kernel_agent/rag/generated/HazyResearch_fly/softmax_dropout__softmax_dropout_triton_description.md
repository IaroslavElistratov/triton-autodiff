- kernel family: attention activation (masked softmax with fused dropout)
- concise summary: Reshapes attention logits to a 3D contiguous buffer, runs the Triton softmax kernel with optional causal/additive masking, and immediately applies `torch._fused_dropout` to produce sampled probabilities and the dropout mask.
- detailed summary: The forward helper flattens `(batch, head, query, key)` into `(batch*heads, query, key)` tiles, prepares additive masks (broadcasting block-k masks across heads when needed), and feeds them to `_softmax`, which subtracts per-row maxima, exponentiates in fp32 when inputs are fp16, and normalizes across the key dimension under optional causal masking. Once the probabilities `y` are materialized, the kernel path never leaves Triton; instead, the Python launcher calls `torch._fused_dropout` with keep probability `p`, yielding both the dropped logits and the Bernoulli mask. These tensors are reshaped back to the original layout while the forward context caches the full softmax output and the mask for reuse. This design fuses masking, normalization, and stochastic dropout in one data pass, so logits are read once, transformed into probabilities, and sparsified without creating intermediate dense copies.
