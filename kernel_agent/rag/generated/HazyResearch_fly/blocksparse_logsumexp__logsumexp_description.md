- kernel family: attention reduction (block-sparse log-sum-exp over layout LUT tiles)
- concise summary: Traverses the sparsity LUT for each block row, gathers dense `BLOCK x BLOCK` tiles from `x`, and computes a numerically stable log-sum-exp that is written into a compact `(batch, head, row)` tensor.
- detailed summary: The forward launcher builds a grid over `(sparse_heads * sparse_rows * BLOCK, batch)` so every program owns one row within a block and walks the LUT header to learn how many nonzero column blocks to process. Inside `_forward`, each thread block loads the referenced dense tiles via masked `tl.load`, casts to fp32, subtracts the per-row maximum, and evaluates `log(sum(exp(x - max))) + max` to avoid overflow before storing the result to the packed output strides `(batch, head, row)`. The LUT layout encodes `(blockid, column, row, head)` so the kernel can remap sparse attention structure without additional branching, and the heuristics configure `TN` and `num_warps` from the metadata to keep the reduction power-of-two aligned. Forward execution emits zeros-initialized outputs ahead of time, saves `x`, the reduced tensor, and the LUT for reuse, and never materializes dense attention—everything streams tile-by-tile through shared registers.
