- kernel family: attention reduction (block-sparse row summation with LUT-driven tiling)
- concise summary: Streams block-sparse tiles of `x` according to the LUT layout, accumulates BLOCK-wide sums per attended row, and writes the reduced values into a dense `(batch, head, row)` tensor.
- detailed summary: The forward path launches `_forward` over a grid shaped `(sparse_heads * sparse_rows * BLOCK, batch)` so each program handles one row of a block; it pulls the active column indices and head/row metadata from the LUT header, then masked-loads the `BLOCK x BLOCK` subtensors belonging to that sparse column set. After casting to fp32, each kernel instance performs a horizontal sum across the column dimension (TN lanes) and stores the result at the packed output stride derived from `(batch, head, row)`. Zeros are used for inactive columns, so sparsity never materializes dense memory, and `force_nc_cache` plus heuristics tune warp count and `TN` to align with the number of participating blocks. Forward execution saves `x`, the LUT, and the Boolean layout for downstream use, but the dataflow in this stage is a single-pass accumulation over block tiles with no intermediate reductions outside registers.
