- kernel family: activation / normalization (fused masked softmax or log-softmax over sequence axis)
- concise summary: Flattens the tensor to `(batch*heads, query, key)`, launches an autotuned Triton kernel that applies additive masks, optional causality, and computes either softmax or log-softmax in fp32, writing the normalized scores back in the original layout.
- detailed summary: The forward entry reshapes potentially 2D or 4D inputs into a 3D contiguous buffer and prepares the optional mask—broadcasting block (`bk`) masks across heads—before launching `_softmax` on a 2D grid `(batch*heads, queries)`. Each program iterates over the key dimension in vector chunks sized by the `DEPTH` heuristic (next power-of-two ≥ K), masks out invalid positions (length, causal triangle, or LUT-provided additive mask), subtracts the row maximum for stability, and accumulates `exp(z)` in fp32. Depending on the `LOG` flag it either normalizes via `num/denom` or returns `log_softmax` by subtracting `log(denom)`, then stores the results with the original stride-1 key axis. Autotuning sweeps `num_warps` and switches to fp32 math when inputs are fp16 to avoid precision loss, allowing forward execution to cover standard attention logits, log-softmax, and causal/batched masking without additional kernels.
