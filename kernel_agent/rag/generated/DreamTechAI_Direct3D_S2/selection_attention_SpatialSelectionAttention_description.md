- kernel family: sparse attention (top-k block selection with variable-length sequences)
- concise summary: The Triton forward kernel loops over each query head and its selected block indices, performs blockwise QK dot products with log-sum-exp normalization, and accumulates V contributions only for the kept blocks, producing both the output activations and per-head log-sum-exp terms.
- detailed summary: For each `(batch, kv-head, query-chunk)` program, the kernel reads prefix-sum tables (`cu_seqlens_*`, `cu_seqblocks`, `cu_block_include_tokens`) to locate the active query tokens and the candidate key blocks retrieved from `topk_idx`. It loads the query tile once, iterates through its real `TOPK` blocks, streams K/V tiles using `tl.make_block_ptr`, and maintains running maxima and sums (`m_i`, `lse_i`) to stabilize softmax. Each tile update multiplies normalized attention weights by the corresponding V slice and accumulates in FP32 before scaling by `exp(m_i - lse_i)` and storing to the output buffer; matching log-sum-exp values are written to `lse_ptr`. The Python launcher derives grid dimensions from cumulative sequence lengths, chooses warp/stage counts based on head dimension, and allocates zero-initialized outputs prior to dispatch.
