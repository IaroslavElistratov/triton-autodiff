- kernel family: Row-wise softmax (optional causal masking)
- concise summary: Each program normalizes one flattened row by subtracting the row max for stability, applying a causal mask when requested, and storing the resulting probabilities.
- detailed summary: `softmax_kernel_forward` operates on a BLOCK_SIZE-wide tile of a row; it loads the logits with -inf padding for out-of-range columns, and if `causal` is true it nulls entries whose column index exceeds the row’s effective position (derived from `row_idx`). The kernel subtracts the per-row maximum to avoid overflow, exponentiates the centered logits, sums them to obtain the denominator, and divides to produce normalized probabilities before writing them back under the usual tail mask. The Python wrapper flattens the leading dimensions, chooses BLOCK_SIZE as the next power of two of the row length, computes an appropriate warp count via `calc_num_warps`, and launches the kernel, caching the result for the backward pass when gradients are needed.
