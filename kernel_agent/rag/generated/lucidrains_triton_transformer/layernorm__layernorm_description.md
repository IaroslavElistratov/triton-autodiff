- kernel family: Layer normalization (optional stable mode with affine weights)
- concise summary: One program per row computes mean/variance (optionally after scaling by the row max for stability), normalizes the row, multiplies by `gamma`, and, in training mode, materializes the centered inputs and normalized activations for reuse.
- detailed summary: The forward kernels flatten the last dimension so each program indexes a single row with a BLOCK_SIZE equal to the next power of two of `n_cols`. They load the row and expanded `gamma`, optionally divide by the row maximum to improve numerical stability, compute the mean and variance using masked partial sums across the tile, and form the normalized values via `inv_var = 1/sqrt(var+eps)`. `layernorm_kernel_forward_inference` writes only the scaled output, whereas `layernorm_kernel_forward_training` additionally stores the mean-centered row and normalized activations into auxiliary buffers. The Python wrapper broadcasts `gamma` across rows, selects training vs inference kernels depending on `requires_grad`, chooses warp counts with `calc_num_warps`, and reshapes the result back to the original tensor shape.
