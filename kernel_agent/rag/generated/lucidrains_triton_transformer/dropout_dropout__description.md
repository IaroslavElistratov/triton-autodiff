- kernel family: Dropout (seeded RNG with scaling)
- concise summary: The forward kernel walks the flattened tensor in 4×BLOCK_SIZE chunks, generates four independent uniform samples per lane from a given seed, and writes scaled activations for the retained elements while zeroing dropped positions.
- detailed summary: `_seeded_dropout` assigns one program per contiguous block of `BLOCK_SIZE*4` elements; it computes four index vectors, loads the corresponding values with tail masking, and invokes `tl.random.rand4x(seed, off0)` to obtain reproducible random numbers tied to the global seed and element offsets. Each random draw is compared to the dropout probability `p` to form keep masks, and surviving values are scaled by `1/(1-p)` before being stored back. The `seeded_dropout` helper allocates the output tensor, determines the launch grid via `cdiv(n_elements, BLOCK_SIZE*4)`, and dispatches the kernel, while `_dropout__forward` chooses a fresh integer seed, caches it on the autograd context alongside `p`, and returns the masked tensor.
