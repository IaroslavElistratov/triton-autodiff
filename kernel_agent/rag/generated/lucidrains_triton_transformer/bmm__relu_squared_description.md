- kernel family: Batched matmul with fused activation (ReLU-squared projector)
- concise summary: An autotuned Triton kernel performs batched matrix multiplications with swizzled tiling over M×N, optionally applying a custom activation (here ReLU-squared) before storing the output.
- detailed summary: `bmm_kernel` is autotuned across several `(BLOCK_M, BLOCK_N, BLOCK_K)` configurations; for each launch `pid_batch` selects the batch element while `pid` traverses a GROUP_SIZE_M-swizzled grid of output tiles, helping balance work when M is large. Each program loads BLOCK_K-wide slices of the input matrices `x` and `y` (with strides derived from layout), accumulates FP32 dot products across the reduction dimension, and, if the meta argument `ACTIVATION` is provided, applies it to the tile before writing back under a bounds mask. `triton_bmm` prepares compatible shapes (expanding `y` to B×K×N when needed), enforces `K % 32`, allocates the `(B,M,N)` output, and dispatches the autotuned kernel with an activation callback of `relu_squared_activation` in the ReLU-squared module. The forward entry point simply wraps this helper and caches inputs/outputs when gradients are required.
