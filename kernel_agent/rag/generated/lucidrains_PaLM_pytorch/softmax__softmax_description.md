- kernel family: row-wise softmax (optional causal masking)
- concise summary: The forward kernel computes a numerically stable softmax across each row of a flattened tensor, applying a per-row causal mask before exponentiating and normalizing the logits.
- detailed summary: `softmax_kernel_forward` binds each `tl.program_id(0)` to one row of the reshaped `[n_rows, n_cols]` matrix, loads a power-of-two tile of logits with masking, and conditionally subtracts `inf` for columns that violate a simple causal rule (`col > row_idx % n_cols`). It then subtracts the row maximum for stability, exponentiates, and divides by the summed numerator to obtain probabilities, finally writing the tile back to global memory. The launcher reshapes the input, picks `BLOCK_SIZE = next_power_of_2(n_cols)`, selects an appropriate warp count, and dispatches one kernel instance per row while caching the output for reuse in the backward pass if gradients are required.
