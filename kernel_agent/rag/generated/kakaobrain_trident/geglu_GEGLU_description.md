- kernel family: gated activations (GEGLU feedforward linear + GELU gating)
- concise summary: Performs a fused matmul that yields paired state and gate vectors, applies GELU to the gate half, multiplies it elementwise with the state half, and writes both the activated output and the saved intermediates.
- detailed summary: Each program id iterates over a batch tile (`m_block_size`) and feature tile (`x_block_size`) produced by the shared linear helper, reusing the same weight/bias to materialize two contiguous output slices: the first `x_size` elements as the linear state and the next `x_size` as the gate. The kernel invokes `language.Linear.forward` twice with different column offsets to fill those slices in fp32, then applies `language.math.GELU.forward` to the gate tile and multiplies by the state tile to form the GEGLU activation. Results are stored back with boundary guards, and the concatenated state/gate buffer is preserved for reuse during backward factorization.
