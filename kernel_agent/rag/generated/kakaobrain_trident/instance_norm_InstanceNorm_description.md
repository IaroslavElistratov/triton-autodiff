- kernel family: normalization (instance normalization with optional running stats)
- concise summary: Iterates over batch-channel pairs, optionally recomputes mean/variance across spatial positions, normalizes and affine-transforms the slice, and persists the per-instance statistics for later use.
- detailed summary: Each program handles a single `(batch, channel)` row, loading up to `x_block_size` spatial elements with boundary padding. When `use_input_stats` is true it forms the channel mean by averaging across the spatial extent, stores it, and similarly accumulates the variance from centered values; otherwise it loads the running mean/var tensors supplied by the caller. The centered activations are multiplied by `rsqrt(var + eps)` to obtain normalized outputs, then per-channel `weight`/`bias` scalars are fetched (if provided) and applied. The kernel writes the normalized activations back to the original dtype and, in training mode, records the computed means/variances so the auxiliary pass can blend them into running estimates.
