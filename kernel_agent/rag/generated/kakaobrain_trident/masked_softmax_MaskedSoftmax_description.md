- kernel family: softmax (masked softmax over arbitrary dimension)
- concise summary: Processes one logical row at a time, applies an additive mask that turns masked positions into -inf, performs a max-shifted exponential reduction for stability, and returns the normalized probabilities.
- detailed summary: Each program id corresponds to a row along the chosen softmax axis; block pointers stride across that row with `x_block_size` elements and optionally guard partial tiles. The kernel loads both logits and mask, replaces masked entries with `-inf`, computes the row maximum, and evaluates `fast_expf(logit - max)` to avoid overflow. After accumulating the sum of exponentials, it divides the numerator tile by the scalar sum, writing the resulting probabilities back in the source dtype. This forward pass also caches the outputs so backward can reuse them without recomputing the normalization.
