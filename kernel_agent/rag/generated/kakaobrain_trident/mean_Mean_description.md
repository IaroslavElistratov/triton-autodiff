- kernel family: reduction (mean over specified dimension)
- concise summary: Delegates each reduction row to a helper that streams across the target axis, accumulates the sum in fp32, divides by the element count, and writes the scalar mean result.
- detailed summary: Program ids iterate over the non-reduced indices (`y_offset`), from which `language.Mean.forward` constructs block pointers over the row using the supplied strides. The helper loops through the row in `x_block_size` fragments, handling non-multiple tails via boundary predicates, accumulates the running total, multiplies by `1 / x_size`, and returns the final scalar. The kernel simply stores that scalar into the output vector, yielding an efficient row-wise mean computation ready for reuse by backward expansion.
