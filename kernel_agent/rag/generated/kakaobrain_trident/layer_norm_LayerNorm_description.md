- kernel family: normalization (layer norm with affine parameters)
- concise summary: For each row over the normalized shape, it computes the mean and variance across features, rescales the centered values with an rsqrt normalizer, and optionally applies shared weight/bias vectors before writing outputs and cached stats.
- detailed summary: Launch assigns one program id per logical row (`y_offset`) of the flattened batch × leading dimensions. The kernel loads up to `x_block_size` contiguous elements (with zero-padding when shapes are not multiples), builds the mean by averaging over `x_size`, and subtracts it to obtain centered values. Variance is accumulated on the same tile, followed by `rsqrt(var + eps)` to produce the inverse std `rstd`. The normalized activations are multiplied by the per-feature weight and shifted by the bias if those tensors exist, then written out in the original dtype. The per-row `mean` and `rstd` are stored separately for reuse in the backward path.
