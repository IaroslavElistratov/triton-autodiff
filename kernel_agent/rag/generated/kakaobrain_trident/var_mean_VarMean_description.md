- kernel family: reduction (simultaneous variance and mean)
- concise summary: For each row it streams through the elements once, accumulating both the mean and squared deviations with the requested correction, then writes the variance and the accompanying mean buffers.
- detailed summary: The kernel assigns one program id to each non-reduced index, invokes `language.VarMean.forward` to iterate over the row in `x_block_size` chunks with boundary predicates, and collects running totals for the sum and sum of squares in fp32. After computing the mean and applying the `(N - correction)` denominator to the centered second moment, it stores the resulting variance scalar as well as the mean for reuse in backward. This fused pass eliminates redundant memory traffic between the mean and variance computations.
