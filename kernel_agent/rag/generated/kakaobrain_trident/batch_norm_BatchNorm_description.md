- kernel family: normalization (per-channel batch norm with fused statistics update)
- concise summary: For each feature channel, the kernel reads all batch×spatial elements, computes mean and variance in a streaming tile, normalizes the tile, applies affine weight/bias when provided, and updates running statistics.
- detailed summary: Launch binds one program id to a channel `pid`, creating block pointers that cover the full batch and feature extent with `batch_block_size` × `x_block_size` tiles. The kernel loads the tile with boundary guards, derives the mean and variance by dividing sums over `num_batches * x_size`, and normalizes inputs in-place using a shared `std = sqrt(var + eps)`. Optional weight and bias vectors are fetched per channel and fused into the normalization. Final normalized values are written back alongside per-channel mean/variance, and running_mean/running_var are updated in global memory using the provided momentum and an unbiased factor.
