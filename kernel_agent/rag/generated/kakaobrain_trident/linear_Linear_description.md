- kernel family: linear algebra (batched dense matmul + bias)
- concise summary: Tiles the batched `m × n` output matrix, invokes a fused `language.Linear.forward` helper to multiply input by weight, optionally adds bias, and writes each tile back in the target dtype.
- detailed summary: Program ids are partitioned into `(batch, m_block, n_block)` indices using autotuned `m_block_size`, `n_block_size`, and `k_block_size`. For each tile the kernel forwards the appropriate offsets and strides into `language.Linear.forward`, which streams through the K dimension (optionally on accelerator hardware) to accumulate the block in fp32 while handling boundary predicates. The resulting tile—bias-adjusted if `bias_ptr` is provided—is then stored into the output matrix with or without boundary checks depending on divisibility. This yields a fully fused batched GEMM and bias add tailored to the problem sizes.
