- kernel family: similarity (cosine similarity over arbitrary dimension with fused norm products)
- concise summary: Tiling along the reduction dimension, each program computes cosine similarity between two slices by accumulating dot products and squared norms, then emitting both the cosine value and its numerator/denominator.
- detailed summary: The launch maps each program id to a single output coordinate outside the reduced axis and constructs block pointers that stride along the selected dimension in `block_size` chunks. Within the loop the kernel loads matched tiles from `x1` and `x2` (with optional boundary zero-padding), accumulates partial sums for ‖x₁‖², ‖x₂‖², and x₁·x₂ in fp32, and advances the pointers until the entire slice is consumed. After reduction it takes square roots, forms the denominator product, divides the dot product by `max(denominator, eps)` for numerical safety, and writes the cosine value while also storing the raw numerator and denominator tensors for reuse downstream.
