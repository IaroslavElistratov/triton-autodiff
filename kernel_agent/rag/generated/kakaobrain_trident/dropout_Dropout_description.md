- kernel family: dropout (elementwise Bernoulli mask with scaling)
- concise summary: Flattens the input, generates per-element RNG using the passed seed, zeros out samples below the keep probability, and rescales kept values to maintain expectation.
- detailed summary: Each program covers a contiguous `x_block_size` slice of the flattened tensor, loading the block with optional boundary checks. A uniform random variate is produced for each element with `tl.rand(seed, idx)`, and the kernel forms a boolean keep mask by comparing against `p`. Surviving values are divided by `(1 - p + eps)` to compensate for the dropped mass, while zeros are written for dropped elements. The kernel stores the scaled outputs back to global memory using the original dtype, enabling reuse of the mask during backward.
