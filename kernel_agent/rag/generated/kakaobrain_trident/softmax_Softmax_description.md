- kernel family: softmax (unmasked row-wise softmax with streaming log-sum-exp)
- concise summary: Streams across each row in tiles, maintains running maxima and exponentials to build a numerically stable normalization, and then replays the row to emit the normalized probabilities.
- detailed summary: Each program id owns a row along the reduction axis and loops over it in `x_block_size` chunks. During the first pass it loads a tile, applies boundary predicates when required, updates the running `max` and `sum` using `fast_expf(input - peak)` so both values stay well-conditioned, and advances the block pointer. After a final reduction combines per-tile stats into a single row-wide `(max, sum)`, the kernel restarts the pointer and performs a second pass that exponentiates `input - max`, divides by the global `sum`, and stores the probabilities back in the source dtype. This two-phase streaming avoids materializing temporary buffers while preserving numerical stability.
