- kernel family: attention (streaming scaled dot-product with optional causal or additive masks, base-2 log-sum-exp normalization, dropout support)
- concise summary: Processes each batch/head by tiling query rows and iterating across key/value tiles, accumulating numerically stable attention scores and outputs in registers before normalizing and optionally applying dropout.
- detailed summary: Each program id binds to a specific head and contiguous band of query positions (`y_block_size` × `x_block_size`). The kernel loads a query tile once, rescales it by the softmax factor in log2 space, and loops over key/value tiles (`y_block_size` chunks of the sequence) either respecting causal ordering or adding a precomputed mask. Within the loop it forms block dot products via `language.dot`, maintains running maxima and exponentiated sums (`alpha`/`beta`) to implement streaming log-sum-exp, and accumulates the weighted value contributions in a private tile. After the final iteration it divides by the accumulated sum, applies dropout by generating tile-wise RNG, and writes normalized attention outputs alongside the log2 normalization factors for reuse by backward.
