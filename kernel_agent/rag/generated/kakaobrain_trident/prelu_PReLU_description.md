- kernel family: activation (parametric leaky ReLU with per-channel slopes)
- concise summary: Tiles the batch×channel×spatial tensor, loads the corresponding channel weight, and applies an elementwise leaky ReLU using that slope before writing the tile back.
- detailed summary: The kernel factors program ids into batch, channel (`y_block_size`), and spatial (`x_block_size`) indices so each launch covers a contiguous tile. Within the tile it fetches the appropriate per-channel `weight` scalar, loads the activation values (with boundary guards when shapes are not multiples), and feeds them into `language.math.LeakyReLU.forward`, which selects `x` for positive inputs and `weight * x` otherwise. The results are stored in the original dtype, enabling the backward pass to reuse both the input and the learned slopes when forming gradients.
