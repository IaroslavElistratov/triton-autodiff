- kernel family: normalization (group norm with affine scale/shift)
- concise summary: For every batch/group tile, it accumulates mean and variance across the `group_size × x_size` elements, rescales them with rsqrt for numerical stability, applies optional per-channel weights/biases, and emits normalized activations alongside the saved statistics.
- detailed summary: The grid assigns each program to one `(batch, group)` pair and constructs block pointers that cover that group’s contiguous chunk of channels and spatial extent. The kernel loads the tile (with optional boundary padding), computes the group mean by summing all elements divided by `num_elements`, then subtracts it to form centered values. Variance is obtained by summing squared centered values over the tile, and an `rsqrt(var + eps)` yields the group-wise inverse standard deviation `rstd`. Outputs are generated by multiplying the centered values with `rstd`, and if provided the kernel fetches group-aligned `weight` and `bias` vectors to apply affine transforms. The normalized tile is written back together with per-group mean and rstd buffers for reuse in the backward pass.
