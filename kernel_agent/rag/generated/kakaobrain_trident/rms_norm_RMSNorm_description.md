- kernel family: normalization (RMSNorm with optional partial window and affine scale/shift)
- concise summary: For each row it computes a root-mean-square over either the full feature width or a `p`-scaled subset, divides activations by that magnitude, and applies learned weights (and bias) before writing the normalized output together with the per-row RMS cache.
- detailed summary: The kernel binds a program id to one row of the flattened tensor, loads `x_block_size` elements with optional tail padding, and—when the requested partial size is smaller than the tile—zeros out the unused tail so that only the leading `partial_size` values contribute. It then forms `rms = sqrt(sum(x²)/partial_size)`, normalizes the original inputs via `(rms + eps)⁻¹`, fetches the per-feature weight vector and multiplies elementwise, optionally adds a broadcasted bias, and stores both the normalized row and the scalar RMS in global memory for reuse during the backward pass.
