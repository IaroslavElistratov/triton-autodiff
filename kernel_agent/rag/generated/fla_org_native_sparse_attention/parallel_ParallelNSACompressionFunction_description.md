- kernel family: block-sparse attention (parallel native sparse compression with grouped heads)
- concise summary: The forward compression kernel walks over block-sparse key/value tiles for each query token, performs stable grouped dot-products with running softmax normalization, and writes both the normalized value aggregation and per-group log-sum-exp scalars while honoring optional segment offsets.
- detailed summary: `parallel_nsa_compression_fwd` derives the head-group factor G, selects key/value tile widths from device capability, builds chunk offsets/token indices when variable-length segments are present, and launches `parallel_nsa_compression_fwd_kernel` across token positions, value tiles, and batch-head pairs. Each program loads a G×BK slice of the query, scales it, and iterates over contiguous chunk blocks (size `BC==BS==block_size`) limited by the causal window `NC=(i_t+1)//BS`; within each loop it fetches the corresponding key and value submatrices referenced by the compressed chunk indices, accumulates logits with running maxima to maintain numerical stability, and updates both the weighted value sum and the softmax denominator in FP32. After the loop it normalizes the G×BV output tile, stores it, and emits the log-sum-exp for the first value tile so downstream stages can reconstruct probabilities. Helpers such as `prepare_token_indices` and `prepare_chunk_offsets` supply the tensor-index mapping from variable-length offsets without altering the forward math.
