- kernel family: activation (sigmoid)
- concise summary: The pointwise Triton forward kernel casts elements to fp32, evaluates `1 / (1 + exp(-x))` via base-2 exponentiation for speed, and returns the result in the original dtype, caching the output when gradients are needed.
- detailed summary: `sigmoid_forward` is wrapped in `pointwise_dynamic`, so runtime tiling maps each element to a lightweight Triton program; inside it multiplies the fp32 input by `log2(e)` and uses `exp2` to compute the sigmoid efficiently before reciprocating. The Python forward detects whether gradients are required: if yes it promotes the arguments, runs the kernel, stores the fp32 output for backward, and casts back to the source dtype; otherwise it executes straight on the tensor, ensuring the forward evaluation is a single fused pass.
