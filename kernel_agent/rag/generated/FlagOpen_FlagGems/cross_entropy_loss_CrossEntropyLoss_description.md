- kernel family: cross-entropy loss (logits vs indices/probabilities, optional class weights and label smoothing)
- concise summary: Forward kernels tile over sequence positions, build numerically stable log-sum-exp values for each sample, subtract the gathered target logits, apply optional label smoothing and class weights, and optionally reduce the result with Triton-based mean/sum helpers.
- detailed summary: The index-based kernels (`celoss_indices_kernel` and `celoss_indices_smooth_kernel`) assign each program a block of positions (`BLOCK_D`) for one batch item, stream through the class dimension in `BLOCK_C` chunks while maintaining running maxima and exponent sums, and finally compute cross-entropy terms by combining the log-partition with the gathered target logit; the smoothed variant performs an additional sweep to mix in label-smoothing priors and per-class weights. The probability-target kernel instead multiplies each class log-loss contribution by the provided soft labels before accumulation. All variants write per-position weights into an auxiliary buffer so the higher-level `sum_and_scale` kernel can average either by element count or by the weight total, depending on the requested reduction. The Python launcher flattens leading dimensions into batch (`N`) and residual positions (`D`), dispatches the appropriate Triton kernel based on target format and smoothing settings, and then invokes the reduction helper to emit either no reduction, a weighted mean, or a pure sum while caching shape metadata for backward.
