- kernel family: activation (in-place GELU with exact and tanh approximation paths)
- concise summary: The in-place forward clones the original tensor for backward, marks the input dirty, and invokes the selected Triton pointwise GELU kernel with `out0` pointing to the input buffer so results overwrite the source tensor.
- detailed summary: Both `gelu_none` and `gelu_tanh` reuse the same fp32-evaluated formulas as the out-of-place variant, but when called with `out0=A` they emit their outputs directly into the provided storage; the Triton `pointwise_dynamic` decorator sizes and schedules the elementwise work at runtime. The Python forward path preserves a copy of the pre-activation values, tracks which approximation is in use, and simply dispatches the appropriate kernel—ensuring the forward pass performs a one-pass, in-place GELU transformation without allocating a new tensor.
