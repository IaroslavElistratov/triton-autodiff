- kernel family: normalization (root mean square norm with learnable weights)
- concise summary: The kernel assigns one Triton program per normalized row, loads the feature vector, accumulates its mean square to form the reciprocal RMS, scales and weights the vector in fp32, and stores both the normalized output and the inverse RMS scalars.
- detailed summary: `rms_norm_kernel` computes `M = ∏ leading dims` and tiles only along rows, so each program walks one row with `BLOCK_SIZE` threads, masking tails when `N` is not a power of two. It loads the row into fp32, evaluates the variance (`sum(x²)/N`), forms `rrms = 1/√(var + eps)`, multiplies each element by both `rrms` and the matching weight parameter, and writes the result back at the original strides while also recording `rrms` in a per-row buffer for reuse. The Python forward path flattens the outer dimensions, allocates the output and inverse-RMS tensors, chooses a power-of-two block width, and launches the kernel under the current device context without invoking any backward functionality.
