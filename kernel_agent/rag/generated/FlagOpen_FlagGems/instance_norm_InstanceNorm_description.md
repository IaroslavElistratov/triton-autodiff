- kernel family: normalization (instance norm with optional affine parameters and running-stat updates)
- concise summary: Depending on whether fresh statistics are required, the forward path either streams over each instance/channel slice to compute mean/variance on the fly or reuses running stats, normalizes the slice, applies optional weight/bias, and emits mean/rstd buffers for later use.
- detailed summary: `instance_norm_loop_kernel` assigns each program a flattened instance-channel row (`pid` spans `M=B*C`), walks the spatial dimension in `TILE_N` chunks using a Welford-style running mean/variance update to avoid precision loss, stores the final mean and reciprocal std, and then rewinds through the row to normalize and optionally affine-transform the original elements before writing them back. When external stats are supplied, `instance_norm_use_running_stats_kernel` simply loads the provided mean/variance for that channel, applies the normalization, and writes the outputs in one pass. The Python forward path determines shapes, materializes mean/rstd tensors, chooses the proper kernel based on `use_input_stats`, and—if new stats were computed—launches `update_running_stats_kernel` to momentum-update the running buffers, all while keeping backward-only logic separate.
