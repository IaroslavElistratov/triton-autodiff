- kernel family: normalization (group norm over channels × spatial positions with optional affine)
- concise summary: Each Triton program owns one sample/group pair, loads its `group_size × HW` tile, computes mean and variance in fp32, normalizes the tile, applies optional weight/bias, and writes both the normalized output and the per-group mean/rstd buffers.
- detailed summary: `group_norm_kernel` derives the batch/group index from the flattened program id, materializes channel and spatial offsets via `BLOCK_GROUP_SIZE` and `BLOCK_HW_SIZE`, and uses masked loads so partial channel groups or tail spatial positions are handled safely. It sums all elements to get the mean, centers the data, accumulates the squared norm to obtain the variance, and forms `rstd = rsqrt(var + eps)` before rescaling the centered values. Optional affine parameters are broadcast across the spatial dimension, applied in-register, and the final tensor plus the mean and inverse std are written back for reuse. The Python forward sets up contiguous tensors, allocates outputs, launches the kernel with `N * num_groups` programs, and saves normalization metadata for backward without touching the derivative kernels.
