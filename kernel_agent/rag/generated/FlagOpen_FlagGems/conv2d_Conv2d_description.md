- kernel family: spatial convolution (dense 2D, grouped with stride/padding/dilation support)
- concise summary: The forward kernel maps a 3D Triton grid over (batch×spatial tiles, output-channel tiles, groups), streams filter tiles across input channels, applies padding/dilation/stride indexing, fuses bias addition, and writes the per-position convolution result.
- detailed summary: `conv2d_forward_kernel` derives per-program batch, height, and width coordinates from the flattened pid, offsets the input and weight pointers by group, and iterates over every filter height/width position while chunking input channels in BLOCK_CI slices. For each slice it builds masked loads that honor spatial bounds and channel counts, performs a dot product accumulating in fp32, and finally adds a per-group bias vector before storing into the output tensor with guards for partial tiles. The Python launcher computes output geometry via `conv2d_output_size`, allocates an output tensor, supplies either the real bias or a zero buffer, and dispatches the autotuned grid defined by logical tiles of NI×HO×WO, output-channel blocks, and groups; it also records convolution metadata for the backward path without touching the backward kernels themselves.
