- kernel family: activation (hyperbolic tangent on MetaX pointwise runtime)
- concise summary: Launches a Triton pointwise kernel that evaluates tanh in fp32 and returns the result in the input dtype, caching the forward output when gradients are needed.
- detailed summary: The forward path invokes `tanh_forward`, which promotes each element (and any integer inputs) to fp32 and applies the runtime's intrinsic `_tanh`, ensuring numerical stability regardless of the original precision. When autograd tracking is active, `_Tanh_forward` materializes the fp32 output, stores it for reuse, then casts back to the caller's dtype to avoid extra kernels; otherwise it uses the same kernel without saving state. Execution is fully elementwise—each program instance handles a shard of activations—with the `@pointwise_dynamic` decorator configuring automatic dtype promotion so the fused tanh handles mixed-precision tensors without manual branching.
