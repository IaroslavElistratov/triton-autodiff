- kernel family: fused activation-and-gate (GELU(x) * y) with selectable approximation
- concise summary: Each pointwise Triton kernel promotes the activand to fp32, evaluates either the exact fast-erf or the tanh-based GELU polynomial, and multiplies the result with the companion tensor `y`, producing the gated output in one pass.
- detailed summary: The `gelu_none_and_mul_kernel` and `gelu_tanh_and_mul_kernel` run under `pointwise_dynamic`, so program tiles are chosen at runtime while inputs are vectorized; inside the kernel the GELU value is computed in registers—either via `fast_erf` with the 1/√2 scaling or via `fast_tanh` with the 0.044715 cubic term—before returning the product with `y`. The forward wrapper simply captures both operands for backward, records which approximation is active, and dispatches the matching kernel, yielding a fused GEGLU-style transform without allocating intermediate tensors.
