- kernel family: activation (Gaussian Error Linear Unit, exact and tanh approximation)
- concise summary: The forward path selects between two Triton pointwise kernels that upcast inputs to fp32, evaluate either the erf-based GELU or its tanh approximation, and return the results in the original dtype.
- detailed summary: `gelu_none` and `gelu_tanh` are decorated with `pointwise_dynamic`, so each execution maps elementwise work to Triton programs sized at run time; within the kernel the value is promoted to fp32 for numerical stability, the chosen closed-form expression (erf with `scale=1/√2` or the tanh polynomial approximation) is evaluated, and the output is cast back to the incoming precision. The Python forward simply dispatches the appropriate variant based on the `approximate` flag, logs the call, and stashes the raw input tensor for backward without involving any other computation.
