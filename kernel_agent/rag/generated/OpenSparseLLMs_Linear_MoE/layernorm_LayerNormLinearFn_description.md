- kernel family: layer normalization + linear projection (grouped LN with optional residual capture)
- concise summary: A one-pass Triton row kernel normalizes each token slice, optionally adds/stores a residual branch, applies scale/bias (or RMS variant), and hands the result to a fused Python-side `F.linear`.
- detailed summary: Each program handles one logical row, loading BLOCK_N features, fusing optional residual addition and residual-out writeback before computing mean/variance (or RMS norm) in FP32, writing per-row mean/rstd buffers, and multiplying by per-group affine weights/bias when provided. The launcher reshapes grouped channels, chooses BLOCK_N as the next power of two under 64KB, materializes residual/mean/rstd workspaces, and returns the normalized tensor (reshaped back) so the forward path can cast weights to the active autocast dtype and execute the dense projection, caching all intermediates for later use.
