- kernel family: LASP2 attention (causal masked variant with context-parallel prefix sums)
- concise summary: Forward execution splits work into an intra-block causal kernel that accumulates Q·Kᵀ·V within each BLOCK tile and an inter-block kernel that adds prefix-summed cross-block contributions precomputed from K/V products.
- detailed summary: `prepare_m` tiles K/V into CBLOCK chunks, runs `_fwd_m_calculate` to form KᵀV tiles, and `_fwd_m_cumsum` to prefix-sum them; after cross-rank all-gather, `_fwd_m_update` injects upstream totals. `lasp2_forward` first calls `_fwd_intra_kernel` across `(batch×head×block, cblock)` grids, where each program enforces causality by iterating only over previous CBLOCK segments, accumulating QK and then QKV in FP32. `_fwd_inter_kernel` then launches over `(batch×head, block×chunk, e-slice)` to load the aggregated KV tiles and add their contributions to the partially filled output buffer. Together these kernels produce masked LASP2 attention outputs using blockwise prefix sums without explicitly forming attention weights.
