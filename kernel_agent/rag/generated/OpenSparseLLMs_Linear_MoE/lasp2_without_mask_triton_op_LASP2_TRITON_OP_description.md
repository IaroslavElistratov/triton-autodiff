- kernel family: LASP2 attention (context-parallel prefix-summed KV without masking)
- concise summary: Forward path first tiles K/V into CBLOCK chunks to build cumulative K·V products per sequence block, then applies Q·(∑K·V) multiplications to emit blockwise outputs while stitching in cross-partition prefix sums for context-parallel ranks.
- detailed summary: `_fwd_m_calculate` sweeps each `(block, d-slice, e-slice)` tile to accumulate local KᵀV matrices in FP32, `_fwd_m_cumsum` prefix-sums those along the block axis, and `_fwd_m_update` injects any upstream suffix from earlier ranks into the workspace `kv`. The main `_fwd_kernel` launches over `(batch×head, block×chunk, e-slice)` grids, loading CBLOCK rows of Q and the matching aggregated KV tile to perform dot products into the output tensor. `prepare_m` and `lasp2_forward` orchestrate these phases, choosing BLOCK/CBLOCK based on sequence length, and the top-level forward copies the all-gathered prefix totals so each rank’s Q sees the appropriate accumulated KV mass.
