- kernel family: MSA attention mixing (softmax-weighted averaging with sigmoid gating)
- concise summary: For each batch/head tile, normalizes pairwise logits with a running log-sum-exp, forms weighted sequence features, and applies a per-channel sigmoid gate to emit fused MSA representations.
- detailed summary: A program indexed by `(batch, head, residue-block)` iterates over residue columns in `BLOCK_SIZE_COL` chunks, loads the bias tensor `b`, and updates per-row maxima and sums so weights `w` are exponentiated in base 2 without overflow. Within each residue pair chunk it loops across sequence tokens and hidden channels, accumulating `w @ v` into the output buffer while rescaling previous partial sums by the new max. After all columns, it revisits the sequence/channel grid to apply the sigmoid gate `g`, divides by the accumulated weight sum `l`, and stores both the gated output and the ungated normalized values `vw`; the kernel also writes the final `logsumexp` statistics for later reuse.
