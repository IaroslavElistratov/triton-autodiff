- kernel family: chunked delta-rule attention (state-updated values with linear attention readout)
- concise summary: Iteratively applies a delta-rule update to per-head key–value states within BT-length chunks—subtracting predicted contributions via `d`, updating the state `h`, writing the corrected values `v_new`, and then performing a chunked linear-attention readout to produce the final output.
- detailed summary: The forward runner chooses tile sizes (`BK` from next power-of-two of K, `BV` capped at 64) and grid (NK, NV, B·H), allocates an fp32 state buffer `h`, and launches `chunk_delta_rule_fwd_kernel_h`. Each program processes one block of keys and values, optionally seeds `h` from `initial_state`, and for every timestep chunk loads key slices, the delta tensor `d`, and value tiles. It subtracts the projection of the current state from `v`, applies `k⊗v` to update `h`, and stores the corrected values into `v_new`, writing the instantaneous state snapshot into `h` (and the final state if requested). A second kernel `chunk_linear_attn_fwd_kernel_o` runs over value tiles, collecting chunked dot products between queries and the stored states as well as an intra-chunk causal score matrix; it combines those with `v_new` and scales by `scale` (fixed to 1 here) to produce the output `o`. Together these kernels realize a fused “predict–correct–readout” pipeline for delta-rule attention while keeping all reductions within a chunk-local BT×BK tile.
