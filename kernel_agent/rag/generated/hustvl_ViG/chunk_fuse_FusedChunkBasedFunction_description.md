- kernel family: polynomial-based attention (chunked fused "based" approximation with running moments)
- concise summary: A single Triton kernel streams over 16-token chunks, updates zeroth/first/second-order statistics of the key/value tiles, and uses a second-order Taylor expansion of the similarity scores to emit both the numerator tiles and their normalization scalars before the host sums across key partitions.
- detailed summary: `_FusedChunkBasedFunction_forward` picks compact tile sizes (BT=16, BK/BV≤32), allocates per-key-slice scratch tensors `o` and `z`, and launches `fused_chunk_based_fwd_kernel` over value tiles × key tiles × batch-heads. Inside the kernel each program keeps three accumulators (`b_h_0o`, `b_h_1o`, `b_h_2o`) capturing running sums of V, KᵀV, and (K⊗K)ᵀV, alongside corresponding key moment buffers (`k_0o`, `k_1o`, `k_2o`). For every chunk it loads a BT×BK query block (scaled), the matching key/value tiles, applies a causal mask, and evaluates the series `1 + s + ½s²` for local scores `s = q·k`. The partial numerator tile is the sum of: the stored lower-order moments, a quadratic form combining current queries with the accumulators, and the masked chunk contribution `b_s·v`; the kernel also integrates the same expansion into `z` for later normalization. After looping over all chunks it updates the running moments for the next iteration, advances the block pointers, and writes the BT×BV tile plus the updated `z` slice. The host sums the per-key-slice outputs over `NK` and returns the dtype-cast result; no additional forward kernels are invoked.
