- kernel family: normalization + projection fusion (Layer/RMS norm followed by dense linear)
- concise summary: The forward pass normalizes each token with the same Triton RMS/LayerNorm kernel as above—respecting optional residual paths and dtype overrides—and immediately feeds the normalized output into a PyTorch linear projection with autocast-aware weights.
- detailed summary: `_LayerNormLinearFn_forward` reshapes `x` to 2D, prepares contiguous copies of `norm_weight`, optional `norm_bias`, and `residual`, and calls `_layer_norm_fwd` with `is_rms_norm` toggled by the caller. That helper launches `_layer_norm_fwd_1pass_kernel`, which streams one row per program, optionally adds/stores a residual, computes either full mean/variance or RMS-only stats, writes `(x̂·γ + β)` into `y`, and emits the fp32 reciprocal std (and residual_out when needed). Back on the host, the normalized tensor is reshaped to the original layout and cast to the active autocast dtype before applying `F.linear` with the provided projection weights/bias. The function caches the residual/scale tensors and flags for backward, but there are no other forward kernels beyond this one-pass norm followed by the fused linear matmul.
