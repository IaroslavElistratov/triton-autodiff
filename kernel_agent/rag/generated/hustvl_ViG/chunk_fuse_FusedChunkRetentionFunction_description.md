- kernel family: fused chunked retention attention (single-pass with head-specific decays)
- concise summary: Processes the sequence in BT=64 chunks, maintaining an exponentially decayed state per head, combining decay-scaled query–key scores with local values, and optionally saving/returning the recurrent state.
- detailed summary: The host selects tile sizes (`BK`,`BV`≤64) and launches `fused_chunk_retention_fwd_kernel` across (NV, NK, B·H). Inside the kernel a head-dependent decay factor `b_b = log2(1 - 2^{-5-h})` produces chunk-scale (`d_b`) and intra-chunk (`d_o`, `d_h`, `d_s`) multipliers. Each iteration loads a chunk of q/k/v, scales queries by `scale`, computes decay-weighted scores `b_s = (q·k) * d_s`, and forms the chunk output from two parts: `b_s·v` plus the decay-scaled projection of the running state (`q·h * d_o`). The state `b_h` is simultaneously updated via `b_h = d_b·b_h + k·(v * d_h)`, with an optional initial seed and final snapshot; when `CHECK` is set (for Triton < 2.2) the first chunk uses a guarded update sequence. After all NK tiles finish, their fp32 outputs are summed and cast back to the original dtype. Saved tensors (`q`, `k`, `v`, `initial_state`) and the `CHECK` flag feed the backward pass, but the forward computation is entirely this fused decay-aware kernel.
