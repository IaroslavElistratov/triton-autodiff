- kernel family: recurrent generalized linear attention (single-direction fused state update)
- concise summary: Iterates through the sequence per head, maintaining a fp32 key–value state matrix (optionally initialized, gated, or reversed), and emits query-weighted outputs while optionally returning the final state.
- detailed summary: The forward wrapper selects compact Triton tiles (`BK`,`BV`≤32), allocates an output buffer expanded along the key-tile axis (NK), and launches `fused_recurrent_gla_fwd_kernel` with grid (NV, NK, B·H). Each program loads its query/key/value slices (plus optional exp-transformed gates `gk`, `gv`), keeps an fp32 accumulator `h`, and—if an initial state exists—pre-populates `h` from the provided tensor. For every timestep it multiplies keys and values to update `h`, applies multiplicative decay from the gates, scales the current query, and contracts `h` with the query to form the tile’s contribution; the result is written to `p_o`, which advances forward or backward depending on `reverse`. Pointer arithmetic decreases or increases addresses to follow the scan direction, and the loop continues for all T tokens before optionally snapshotting the ending `h` matrix into `final_state`. After the kernel completes the host sums across NK to combine key tiles and casts the accumulated fp32 output back to the input dtype.
