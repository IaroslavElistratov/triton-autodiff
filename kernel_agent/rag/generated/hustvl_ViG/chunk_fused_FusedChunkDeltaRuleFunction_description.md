- kernel family: fused chunked delta-rule attention (single-kernel predict–correct–readout)
- concise summary: Within each BT-sized chunk, subtracts the state-predicted value (`d·h`) from `v`, updates the recurrent key–value state, writes the corrected values to `v_new`, and accumulates both the causal score contribution and the state contribution to the output—all inside one Triton launch.
- detailed summary: The host enforces NK=1, selects `BK`=next_pow2(K) and `BV`≤32, allocates an NK-expanded output plus a scratch `v_new`, and dispatches `fused_chunk_delta_rule_fwd_kernel` with grid (NV, NK, B·H). Each iteration loads chunked q/k/v/d tiles, scales queries, forms the causal score matrix (`b_s = q·k` with intra-chunk mask), and computes the delta prediction `b_v_prime = d·h`. It subtracts that from the raw values (storing the corrected tile in `v_new`), adds the masked value term (`b_s·v`) to the output, and also accumulates `q·h`. The recurrent state `h` is updated by adding `k⊗v` (optionally seeded from `initial_state`), with an optional first-iteration guard (`CHECK`) for older Triton. After all NK tiles finish, the host sums across the tile dimension and returns the fp32 output cast back to the input dtype alongside an optional final-state snapshot. Saved tensors (`q`, `k`, `v_new`, `d`, `initial_state`) support the backward implementation, but the forward computation is fully captured by this fused kernel.
