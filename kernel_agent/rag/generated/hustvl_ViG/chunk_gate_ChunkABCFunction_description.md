- kernel family: gated chunked ABC attention (exponentiated gate modulation)
- concise summary: Augments the chunked ABC pipeline by exponentiating a gate tensor `g`, using it to rescale intermediate logits/values, and otherwise following the staged log-cumsum → state build → block assembly → softmax → value projection workflow.
- detailed summary: The forward entry first runs `chunk_abc_fwd_kernel_cum` to convert the raw gate `g` into cumulative sums (later exponentiated), then invokes the shared helper `chunk_abc_fwd_kernel_h` to populate chunk states `hk`. `chunk_abc_fwd_kernel_K` contracts queries against those states, records triangular attention blocks `A`, and scales the resulting logits with `exp(g)` before writing them. Additional kernels (`chunk_abc_fwd_kernel_intra_K`, `chunk_abc_fwd_kernel_intra_M`, etc.) reuse the gated tensors to accumulate intra-chunk contributions, yielding gated logits `ok` that are softmaxed to produce probabilities `p`. A second state build with the probabilities drives `chunk_abc_fwd_kernel_V`, which combines gated states/values to form the final output; throughout, gating factors appear as `exp(g)` multipliers on queries, values, and stored states as appropriate. Tile sizes mirror the ungated ABC variant (BT=64, BC=16, power-of-two BK/BV/BM), and all intermediate tensors (`g`, `hk`, `hv`, `A`, `ok`, `p`) are cached for backward, but the forward computation differs by consistently applying the learned gate to modulate state updates and readouts.
