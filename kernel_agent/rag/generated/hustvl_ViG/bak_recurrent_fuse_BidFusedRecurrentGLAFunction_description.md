- kernel family: bidirectional recurrent generalized linear attention (fused state update)
- concise summary: Streams through a sequence per head, maintains forward and reverse key–value state matrices (optionally initialized and gated), and accumulates query-weighted outputs for both directions into a shared buffer—optionally returning the terminal state.
- detailed summary: The launcher chooses modest tile sizes (`BK`,`BV`≤32), expands the output tensor across key tiles (NK) and value tiles (NV), and dispatches a grid (NV, NK, B·H). Each kernel instance pulls the relevant query/key/value slices plus optional exponential gates `gk`, `gv`, and keeps two fp32 accumulators: `h` for the forward scan and `inv_h` for the reverse scan (using mirrored pointers `inv_p_*`). On every timestep it multiplies keys and values to update the state, applies multiplicative decay when gates are present, and contracts the state with the current (scaled) query to form output tiles. Forward and reverse contributions are written into the same temporaries—forward via `p_o`, reverse via `inv_p_o`—so the bidirectional result is built in one pass; existing contents are read back to accumulate across key tiles. Pointer arithmetic flips direction when `reverse=True`, and the loop optionally seeds from `initial_state` and writes out `final_state` snapshots when requested. After the kernel finishes, the host sums across NK to collapse the tile dimension and casts the fp32 buffer back to the input dtype.
