- kernel family: recurrent delta-rule update (fused bidirectional-free variant with beta gating)
- concise summary: The forward kernel streams through the sequence per head, subtracts the state-predicted value from each token, scales the residual by a learned `beta`, and updates a K×V state whose projection against the current query yields the output tile; optional initial/final states let the recurrence persist across calls.
- detailed summary: `_FusedRecurrentFunction_forward` fixes 1D tiling (BT implicit, BK is the next power-of-two ≥ d_head_qk, BV ≤ 8/32) and launches `fused_recurrent_fwd_kernel` over value tiles × key tiles × batch-heads while keeping `NK=1` to avoid synchronization hazards. Inside the kernel each program maintains an fp32 state `h` of shape BV×BK, optionally seeded from `initial_state`. At every timestep it loads the K and V slices (applying the causal mask via the tile index), computes the predicted value `v_minus = h·k`, writes the residual back to `v`, rescales it by the scalar `beta[t]`, and performs an outer product to refresh `h`. The query tile (scaled by `scale = d_head_qk^-0.5`) is then dotted with the updated state to produce the BV-length output vector, which is stored before the loop advances the pointers; the loop continues until all T positions are processed, and the kernel optionally snapshots the final `h` to `final_state`. Backward-only kernels are ignored here, as the forward work is fully captured by this recurrent delta-rule update.
