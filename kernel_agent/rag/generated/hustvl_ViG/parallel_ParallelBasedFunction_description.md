- kernel family: parallel BASED attention (chunked second-order kernel approximation)
- concise summary: Splits the sequence into 128-length tiles, streams previous tiles using a quadratic Taylor kernel (`1 + s + 0.5s²`) to accumulate normalization and value outputs, and handles the current tile with an additional causal mask before writing chunk outputs and log-normalizers.
- detailed summary: The launcher enforces NK=1, sets chunk sizes BTL=128 and BTS=32, and dispatches `parallel_based_fwd_kernel` with grid (NV·NK, ceil_div(T,BTL), B·H). Each program loads a BTL×BK query tile (scaled by `scale`) and iterates over earlier BTS blocks without masking, repeatedly loading key/value tiles to accumulate `b_z` (the truncated exponential kernel sum) and `b_o` (its product with values). After processing past blocks it recomputes key/value tiles for the current chunk, applies an in-chunk causal mask (`o_q ≥ o_k`), and continues accumulating. At the end it stores the output tile into an NK-expanded buffer and writes the per-token normalizer `z`. The host sums across NK to collapse the tile dimension and casts to the original dtype, returning both `o` and `z` while caching (`q`, `k`, `v`) and `scale` for backward computations.
