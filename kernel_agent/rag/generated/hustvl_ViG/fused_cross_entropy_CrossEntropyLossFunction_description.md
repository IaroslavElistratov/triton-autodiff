- kernel family: fused cross-entropy loss (block-partitioned log-sum-exp with optional label smoothing and z-loss)
- concise summary: Processes logits row by row in BLOCK_SIZE shards, computing log-sum-exp, per-block losses, and optional z-loss terms in Triton before aggregating across shards (and across ranks) to produce the final masked loss tensor.
- detailed summary: The forward launcher flattens logits to [N_rows, N_cols], chooses a power-of-two block size, and runs `cross_entropy_fwd_kernel` with grid (rows, splits). Each program loads a column block, rescales logits by `logit_scale`, evaluates the block’s max and log-sum-exp, and—depending on `smoothing` and whether this block contains the true class—accumulates the cross-entropy contribution plus an optional quadratic penalty (`lse_square_scale * lse²`). Blocks operating on very large vocabularies set `SPLIT=True`, so the kernel emits partial losses and log-sum-exp terms that the host later merges (using `logsumexp` locally and optionally `all_gather`/`all_reduce` for distributed sharding). Ignored indices get zeroed, and the final loss tensor retains dtype float32 alongside a separate z-loss buffer. The backward path reuses the stored logits/LSE to launch `cross_entropy_bwd_kernel`, which reconstructs probabilities within each block, applies label smoothing adjustments, and writes gradient chunks scaled by `grad_loss * logit_scale`—thereby completing the fused per-block softmax/CE pipeline while keeping all reductions numerically stable.
