- kernel family: chunked ABC attention (gated log-cumsum softmax with blockwise recurrences)
- concise summary: Runs a staged pipeline that (1) log-cumsum-normalizes the state tensor `s`, (2) builds chunk-level key–value accumulators `h`, (3) assembles triangular attention blocks `A`, (4) applies a chunkwise softmax, and (5) projects the resulting probabilities onto `v`, all with fused Triton kernels tuned to 64-token/16-feature tiles.
- detailed summary: The forward driver fixes chunk widths (`BT=64`, `BC=16`) and powers-of-two feature tiles (`BK`,`BV`) before launching several kernels in sequence. `logcumsumexp_fwd_kernel` produces normalization terms `z` for the gating tensor `s`. `chunk_abc_fwd_kernel_h` then scans through the sequence chunk by chunk, optionally seeding from `initial_state`, to accumulate per-chunk key–value states `h` in fp32, with branches for key- or value-normalized scaling. Using those states, `chunk_abc_fwd_kernel_K` contracts queries against `h` to form one contribution (`ok1`) while simultaneously emitting a casual block matrix `A`; `chunk_abc_fwd_kernel_intra_K` adds intra-chunk contributions (`ok0`) by multiplying previously stored blocks after reweighting with exp-normalized `s`. The summed logits `ok` are passed to a Triton softmax that respects the chunk tiling, and the resulting probabilities `p` (cast to the query dtype) feed a second round of state building (`hv`) via `chunk_abc_fwd_kernel_h` with `s` as keys. Finally, `chunk_abc_fwd_kernel_intra_V` aggregates cross-chunk value terms into `Av`, and `chunk_abc_fwd_kernel_V` combines `hv`, `Av`, and the original values `v` to materialize the chunked attention output `ov`. Intermediates (`z`, `ok`, `p`, `h`, `hv`, `Av`) are cached for backward but the forward path remains entirely composed of these fused blockwise kernels.
