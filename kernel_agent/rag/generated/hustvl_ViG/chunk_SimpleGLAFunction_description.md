- kernel family: simple generalized linear attention (chunked with precomputed exp decays)
- concise summary: Converts the gating signal `g` into cumulative log-decays, scans each chunk to update a key–value state with those decays, and produces outputs by combining decay-weighted queries, keys, and stored states.
- detailed summary: Forward reshapes `g` into BT=64 blocks, accumulates it via cumsum·log2 so every step has an exp2-based decay, and enforces that T is divisible by BT. With tile sizes (`BK`,`BV`≤64), `chunk_simple_gla_fwd_kernel_h` iterates over chunks: it optionally seeds `h` from `initial_state`, writes the current state snapshot, multiplies the state by exp2 of the chunk’s final log-decay, and adds the exp-adjusted `k⊗v` contribution (values scaled by exp2 of per-step deltas). `chunk_simple_gla_fwd_kernel_o` then walks over each chunk/value tile, accumulating `q·h` and `q·k` terms, multiplies them by the appropriate exp factors pulled from `g`, applies the causal mask, and mixes with the local values before scaling by `K^{-1/2}`. The resulting tensor is cast back to the input dtype; optional final states are emitted if requested, and the forward pass caches (`q`, `k`, `v`, `h`, `g`) for gradients.
