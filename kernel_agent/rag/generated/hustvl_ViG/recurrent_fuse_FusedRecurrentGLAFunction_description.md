- kernel family: gated linear attention (single-direction recurrent fusion with optional gating and reverse pass)
- concise summary: The forward Triton kernel walks through the sequence in either forward or reverse order, multiplies the running K×V state by optional gate factors `gk`/`gv`, accumulates the current rank-one update, and projects it with the scaled query to produce the output tile; final states can be emitted for cache handoff.
- detailed summary: `_FusedRecurrentGLAFunction_forward` converts `gk`/`gv` to exponential form, chooses 32-wide tiling for key/value dimensions (so `NK,NV = ceil(d_head/32)`), allocates an fp32 output buffer, and launches `fused_recurrent_gla_fwd_kernel` over value tiles × key tiles × batch-heads. Each program keeps an fp32 state `h` (BV×BK), optional seeded from `initial_state`; at every timestep it loads the K and V blocks (starting from the end if `reverse=True`), scales `h` entrywise by the per-token gate vectors (if present), adds the new outer product `k⊗v`, and evaluates `q·h` (with `scale = d_head_qk^-0.5`) to fill the BV-length output slice. Pointer arithmetic handles forward vs. reverse traversal, and if requested the terminal `h` snapshot is stored into `final_state`. After the kernel the host sums across `NK` slices and casts back to the request dtype; no other forward kernels participate.
