- kernel family: chunked linear attention (prefix-accumulated KV state with optional recurrent cache)
- concise summary: Forward execution first builds per-chunk key–value accumulators and then reuses them to assemble causally masked linear-attention outputs, optionally seeding from an initial state and returning the final cache tile.
- detailed summary: `_ChunkLinearAttentionFunction_forward` picks 64-token query blocks and power-of-two key/value tile widths, materializes an `NT×K×V` state tensor `h`, and launches `chunk_linear_attn_fwd_kernel_h` across key/value tile pairs and batch-heads; that kernel streams through the sequence, adding each chunk’s `K×BT` keys dotted with its `BT×V` values to the running state (starting from `initial_state` when provided and optionally persisting the last tile). A second launch of `chunk_linear_attn_fwd_kernel_o` iterates over query chunks and value tiles: it loads the precomputed `h`, recomputes the local `q·k` correlations for the chunk (enforcing causal masking within the block), adds the corresponding `q·h` contribution, multiplies by the scaled block of values, and writes the resulting `BT×BV` block into the output tensor. These two kernels constitute the entire forward path; all backward-specific Triton routines are unused here.
