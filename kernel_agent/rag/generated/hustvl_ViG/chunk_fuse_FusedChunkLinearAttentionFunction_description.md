- kernel family: fused chunked linear attention (single-pass state accumulation)
- concise summary: Uses a single Triton kernel to step through BT=64 chunks, maintain the key–value state, form causal dot products, and write the attention output—optionally seeding/returning the state and guarding the first iteration for older Triton builds.
- detailed summary: The forward path picks powers-of-two tiles (`BK`,`BV`≤64), allocates an NK-expanded buffer for the output, and launches `fused_chunk_linear_attn_fwd_kernel` with grid (NV, NK, B·H). Each program loads chunked q/k/v tiles, scales the queries by `scale`, computes the causal score matrix `b_s = q·k`, and multiplies it with the values to form the chunk’s contribution. Simultaneously it keeps an fp32 state `b_h` that aggregates `k⊗v`; the current chunk output adds `q·b_h`, and when `CHECK` is set (for Triton < 2.2) the first iteration uses a slightly different update order to avoid precision loss. After writing the chunk’s output and advancing pointers, the state persists into the next chunk; final states are stored if requested. Once all NK tiles finish, the host sums over the tile dimension and casts the fp32 result back to the activation dtype, caching (`q`, `k`, `v`, `initial_state`) and the `CHECK` flag for backward.
