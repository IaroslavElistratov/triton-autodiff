- kernel family: parallel retention attention (chunked exponential decay kernel)
- concise summary: Streams through 128-length tiles while maintaining per-head exponential decay factors, applying them to past contributions, and composing decay-scaled query–key scores with values to produce the output.
- detailed summary: The forward driver uses chunk sizes BTL=128 and BTS=32, builds a grid (NV·NK, ceil_div(T,BTL), B·H), and calls `parallel_retention_fwd_kernel`. Each program computes a head-specific decay rate `b_b`, loads a BTL×BK query tile scaled by `K^{-1/2}`, and iterates over preceding BTS blocks: it loads key/value tiles, weights the scores with precomputed decays (`d_h`, `d_b`), exponentially damps the running output `b_o`, and adds decay-adjusted contributions. When processing the current chunk it applies a causal mask and uses `d_s = exp2((i-j)*b_b)` to weight intra-chunk scores before mixing with the local values. The tile result is written into an NK-expanded buffer; afterwards the host sums across NK and returns the output in the original dtype. Saved tensors (`q`, `k`, `v`) feed the backward kernels, but all forward work lies in this fused decay-aware sweep.
