- kernel family: chunked retention attention (head-specific exponential decay)
- concise summary: Maintains per-head states that decay geometrically across timesteps, updates them with chunked key⊗value contributions, and produces outputs by mixing decayed queries with both the stored state and same-chunk values.
- detailed summary: The forward wrapper fixes chunk size BT=64, picks tile powers (`BK`,`BV` ≤64), computes `NT`, and dispatches `chunk_retention_fwd_kernel_h` over (NK, NV, B·H). Each kernel derives a head-specific log-decay `b_b`, precomputes per-step factors `d_b` (chunk-to-chunk) and `d_i` (within-chunk), optionally loads an initial state, and for every chunk stores the previous state snapshot to `h` before applying `h = d_b·h + k·(v·d_i)` in fp32. A second kernel `chunk_retention_fwd_kernel_o` visits each (value tile, chunk, batch·head) combination, reuses `b_b` to scale queries (`d_i`) and in-chunk pairwise scores (`d_s`), loads the stored state, and combines `q·h` plus a decayed `q·k` term multiplied by the current values; the result is scaled by `K^{-1/2}` and written to the output. Optional final states are emitted when requested, and the forward path saves (`q`, `k`, `v`, `h`) for backward.
