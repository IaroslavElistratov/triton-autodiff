- kernel family: fused chunked GLA (decay-adjusted recurrent state plus block corrections)
- concise summary: Precomputes decay-scaled queries/keys, runs a fused chunk kernel that updates a recurrent key–value state while emitting per-chunk outputs, and adds a secondary blockwise correction built from decay-aware query–key products.
- detailed summary: The driver first upgrades `g` to fp32, applies `fwd_decay_cumsum` to accumulate log-decays over BT=16 windows, and calls `prepare_qg_kg` to create decay-adjusted tensors `q_g`/`k_g`. With tile sizes (`BK`,`BV`≤64), `fused_chunk_gla_fwd_kernel` iterates over the sequence: it optionally seeds the fp32 state from `initial_state`, loads chunked q/k/v tiles, multiplies the state by `exp2` of the chunk decay, accumulates `k⊗v` into the state, and writes the current `q·state` contribution to the output buffer; a guard (`CHECK`) tweaks the first iteration for older Triton builds. Outputs are stored in an NK-expanded tensor that is summed across key tiles and optionally accompanied by a final-state snapshot. To capture non-recurrent interactions, `fwd_inner_chunk` constructs a triangular matrix `A` of decay-reweighted dot products between raw `q`/`k`; reshaped values `v2` are multiplied by `A` and added to the recurrent output. The forward pass returns this combined tensor (cast to the input dtype) and any requested final states, caching (`q`, `k`, `v`, original `g`, `A`, `initial_state`) for gradients.
