- kernel family: recurrent retention (per-head exponential decay with K⊗V updates)
- concise summary: Each head maintains a decaying K×V state scaled by a fixed per-head retention factor and updates it with the current outer product before projecting through the scaled query to emit the output; optional initial/final states allow chunk-to-chunk continuity.
- detailed summary: `_FusedRecurrentRetentionFunction_forward` selects 32-wide tiles for queries/values, allocates an fp32 output buffer, and launches `fused_recurrent_retention_fwd_kernel` across value tiles × key tiles × batch-heads. Within the kernel, the fp32 state `h` (BV×BK) is optionally seeded from `initial_state`, then iteratively updated as `h = b_b * h + k⊗v`, where `b_b = 1 - 2^{-(5 + head_idx)}` gives each head a fixed decay constant. The scaled query block multiplies the updated state to form the BV-length output, which is written while pointers advance to the next timestep; after T steps the kernel can snapshot the terminal `h` to `final_state`. No other forward kernels participate—the entire recurrent retention computation resides in this Triton loop, with the host merely summing across NK slices and casting back to the input dtype.
