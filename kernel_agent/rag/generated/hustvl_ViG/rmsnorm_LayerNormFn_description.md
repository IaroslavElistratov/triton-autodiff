- kernel family: normalization (layer/RMS norm with optional fused residual capture)
- concise summary: The forward path flattens the input to row-major batches, optionally adds a residual branch, and launches a single Triton kernel that computes either layer-norm or RMS-norm statistics, applies scale/bias, and can materialize the residual in an alternate dtype for prenorm pipelines.
- detailed summary: `_LayerNormFn_forward` reshapes `x` to `(M,N)`, makes contiguous copies of `x`, `weight`, `bias`, and (if provided) `residual`, then picks a power-of-two tile (`BLOCK_N` ≤ 64 KB / elem_size). It calls `_layer_norm_fwd` which allocates fp32 buffers for the per-row mean (if `is_rms_norm=False`) and reciprocal std, selects an output buffer dtype, and invokes `_layer_norm_fwd_1pass_kernel`. That kernel processes one row per program id: it loads the row (adding the residual when requested), optionally stores a residual-out copy, computes either the full mean/variance or only the second moment (for RMS norm), forms the `rstd`, and finally writes `(x̂ * weight + bias)` back to `Y`. The kernel supports label-smoothing style residual storage and bias toggles via compile-time flags. After reshaping the result back to the original layout (or pairing it with the saved residual-out when `prenorm=True`), the caller saves only the tensors needed for backward; no other forward kernels participate.
