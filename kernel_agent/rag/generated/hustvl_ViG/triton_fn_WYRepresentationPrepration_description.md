- kernel family: delta-rule precomputation (W-Y representation preparation over chunked attention weights)
- concise summary: For each (batch, head, chunk) tile the Triton kernel iteratively applies the lower-triangular attention block `A` to the running feature tensor `x` and the decay tensor `k`, peeling off previously accumulated contributions so it can emit per-token cumulative sums (`o_cumsum`) and decay-adjusted sums (`o_cumdecay`).
- detailed summary: `_WYRepresentationPrepration_forward` reshapes the 5D inputs `(b,h,n,c,d_k)` into contiguous chunk tiles, sets `BT=c`, `BK=d_k`, and launches `fwd_prepare_wy_repr` across key-tiles × chunks × batch-heads. Inside the kernel each program loads a `BT×BK` slice of `x` and the matching `k`, then walks `i=0…BT-1`: it fetches the current row of `A`, masks out columns ≥ i to respect causality, computes how much of the already-accumulated state should be removed (`new`, `new_cumdecay`), subtracts those from the running matrices `S` and `S_cumdecay`, and advances the pointer. After processing the block it stores the updated tensors into `o_cumsum` and `o_cumdecay` at the appropriate positions. The host merely allocates the outputs, calls the kernel, and caches the results for the backward pass—no other forward kernels are involved.
