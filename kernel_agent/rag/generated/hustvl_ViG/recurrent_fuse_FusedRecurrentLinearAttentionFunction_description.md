- kernel family: recurrent linear attention (stateful K⊗V accumulator)
- concise summary: The forward kernel incrementally builds a K×V state by adding each chunk’s outer product, then projects that state with the scaled query vector to emit causal linear-attention outputs, optionally warm-starting from and checkpointing a persistent state tensor.
- detailed summary: `_FusedRecurrentLinearAttentionFunction_forward` fixes 32-wide tiles for key/value dimensions (`NK = ceil(d_head_qk/32)`, `NV = ceil(d_head_v/32)`), allocates an fp32 output buffer, and launches `fused_recurrent_linear_attn_fwd_kernel` across value tiles × key tiles × batch-heads. Each program keeps an fp32 matrix `h` (BV×BK) seeded from `initial_state` when provided; for every timestep it loads the current key/value tiles, updates `h += k⊗v`, and multiplies the updated state by the scaled query block (`scale = d_head_qk^-0.5`) to produce the BV-length output slice, which is stored before advancing pointers. After all T steps, the kernel writes the final state to `final_state` if requested. Because only this Triton kernel participates in the forward path (followed by a sum over NK slices), the implementation provides a compact recurrent linear-attention primitive without any auxiliary forward kernels.
