- kernel family: chunked generalized linear attention (decay-gated recurrent state with block refinement)
- concise summary: Precomputes exponential decay factors from `g`, updates per-head key–value states chunk by chunk via a recurrent kernel, forms both direct query×state products and blockwise low-rank corrections, and combines them to produce the final attention output.
- detailed summary: The forward path first promotes `g` to fp32, runs `fwd_decay_cumsum` to accumulate chunked decay exponents, and `prepare_qg_kg` to build decay-adjusted query/ key tensors (`q_g`, `k_g`). With chunk size BT=64 and tiles (`BK`,`BV`≤64), `chunk_gla_fwd_kernel` traverses the sequence per batch/head tile: it optionally seeds the fp32 state from `initial_state`, writes intermediate snapshots `h`, multiplies the state by exp2(decay) each step, and adds the current `k⊗v` contribution; final states are stored if requested. The first output contribution reshapes `q_g` and `h` with `einops` and contracts them directly. To capture interactions between queries beyond the recurrent summary, the code builds a block matrix `A` via `fwd_inner_chunk`, which walks over chunk pairs (size BC=16) computing decay-aware dot products in fp32 and accumulating into an NK-tiled buffer before summing across key tiles. This triangular `A` multiplies the chunked value tensor (reshaped as `v2`) to yield `o2`; adding the direct `q_g @ h` term gives the final output, cast back to the original dtype. Saved tensors (`q`, `k`, `v`, `g`, `A`, `h`, optional states) support the backward pass but the forward work is entirely in these fused Triton kernels and small reshape matmuls.
