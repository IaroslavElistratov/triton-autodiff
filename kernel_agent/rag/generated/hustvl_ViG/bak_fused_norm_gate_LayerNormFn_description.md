- kernel family: fused layernorm + gated activation (BAK variant with residual support)
- concise summary: Applies a one-pass LayerNorm/RMSNorm over each row, multiplies the normalized output by an auxiliary gate `o·sigmoid(o)`, and optionally fuses residual addition/buffering before returning the prenorm tensor.
- detailed summary: The host reshapes inputs to 2-D, aligns residuals, and launches a Triton kernel per row that loads both the feature slice `x` and matching gate vector `o`. Residual values can be added in fp32 and stored to a side buffer if needed. The kernel performs standard LayerNorm stats (mean/variance or RMS), writes per-row `mean`/`rstd`, and applies affine `weight`/`bias`. Before storing, it fetches the gate, applies the nonlinearity `gate = o * sigmoid(o)`, and scales the normalized activations elementwise, so each program emits a gated LayerNorm result while writing residual_out when requested. Autotune selects warp counts and the host enforces the usual 64 KB tile limit; the wrapper preserves original shapes (incl. prenorm output pairs) and stashes tensors for backward.
