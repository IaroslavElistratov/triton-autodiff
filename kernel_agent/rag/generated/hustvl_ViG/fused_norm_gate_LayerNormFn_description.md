- kernel family: fused layernorm + gating (residual-aware, RMSNorm option)
- concise summary: Performs LayerNorm or RMSNorm in one Triton pass, multiplies the normalized output by an auxiliary gate `o·sigmoid(o)`, and optionally fuses residual add/return semantics before reshaping back to the original layout.
- detailed summary: The forward wrapper flattens the input to (M,N), ensures contiguous strides, prepares residual buffers as needed, and launches `_layer_norm_fwd_1pass_kernel`. That kernel loads the row, adds any residual slice, computes mean/variance (or RMS), stores per-row statistics, applies the affine weight/bias, and finally loads the gate tensor `o` to scale the normalized activations by `o·σ(o)` before writing to `Y` (with optional residual_out). Autotuning sweeps warp counts to cover different N. Saved tensors include the post-residual activations, gate, affine params, and stats so the backward kernel can recompute `y` and propagate through both the normalization and gating factors. No additional forward work beyond this fused normalization plus gating is performed.
