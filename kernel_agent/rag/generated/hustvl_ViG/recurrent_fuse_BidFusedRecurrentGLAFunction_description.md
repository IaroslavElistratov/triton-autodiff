- kernel family: bidirectional fused recurrent GLA (dual state scan with optional gating)
- concise summary: Runs a single kernel that maintains forward and reverse key–value states (with optional exponential gates), accumulates query-weighted outputs for both directions into distinct buffers, and averages them to form the final result, optionally tracking the terminal state.
- detailed summary: The forward launcher derives tile sizes (`BK`,`BV`≤32), allocates an fp32 output buffer with 2·NK slices, and exponentiates gating tensors `gk`/`gv` if present. `bid_fused_recurrent_gla_fwd_kernel` then executes with grid (NV, NK, B·H): each program keeps two fp32 state matrices (`h` and `inv_h`), loads forward and backward pointers to q/k/v tiles, and iterates over T steps. At each step it applies multiplicative gates when supplied, updates both forward and reverse states with `k⊗v`, and projects them onto the scaled query to produce forward and backward contributions written to separate halves of `o`. Pointer arithmetic walks forward for the normal pass and backward for the reverse pass; optional initial states seed `h`, and final states can be stored. After the kernel finishes, the host sums the NK dimension, averages the two directional outputs, casts back to the input dtype, and returns the result along with an optional final-state snapshot while caching tensors for backward.
