- kernel family: bidirectional scan duplication (sequence + time-reversed copy)
- concise summary: Tiles a [B, H, T, D] tensor, writes the original token order into the first half of the output, and simultaneously writes a time-reversed copy into the second half, yielding shape [2B, H, T, D].
- detailed summary: The host picks tile widths (`BC` along feature, `BT` along sequence), ensures the input is contiguous, allocates `y` with doubled batch size, and launches `triton_bid_scan` using grid (NC, NT, B·H). Each program derives its batch/head, sequence block, and depth block, applies masks for boundary tiles, and loads a BT×BC slice from the source. The slice is stored verbatim into the “forward” half of `y`, and also stored into a mirrored location where the sequence index is flipped (`seq_len - seq_idx - 1`) and the batch offset is shifted by B·H·seq_len·d_head to target the reverse half. No reductions occur; the kernel just copies blocks into both layouts. The forward wrapper records tiling metadata for the inverse merge used in backward.
