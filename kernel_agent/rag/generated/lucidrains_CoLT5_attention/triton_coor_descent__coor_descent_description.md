- kernel family: Coordinate descent routing (iterative projection with entropy regularization)
- concise summary: Each row of logits is iteratively updated in a Triton kernel that enforces masking, decays an epsilon schedule, and accumulates dual variables `a` and `b`; the host stitches multiple kernel segments to produce the final soft assignment via exponentiation.
- detailed summary: `coor_descent_kernel_forward` launches with one program per row and a BLOCK_SIZE-wide vector of columns determined by the next power of two of `n_cols`. It loads the row’s mask, current dual variables, logits `s`, and target mass `k`, then performs `n_iters` iterations: compute `a = (s + b)/eps`, apply the mask, stabilize with a max subtraction, exponentiate and sum to form `log_sum_exp`, update `a` from `logk - log_sum_exp`, clip `b = -(s + a)` when positive, and decay `eps` by `eps_decay` but never below `eps`. After the loop it writes updated `a` and `b` to the next checkpoint slice. The Python driver (`__coor_descent_forward`) flattens potentially high-rank inputs via `pack_one`, materializes boolean masks as ints, seeds checkpoint buffers for `a` and `b`, and splits the total iteration budget into `checkpoint_segments` groups—launching the kernel for each segment while keeping track of the evolving epsilon. Once the final segment completes, it reconstructs the solution `y = exp((a + b + x)/eps)` and returns it in the original tensor shape, saving intermediate states for backward when gradients are required.
