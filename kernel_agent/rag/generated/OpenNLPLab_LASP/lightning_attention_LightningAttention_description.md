- kernel family: lightning attention (blockwise decay-based attention without cache sharing)
- concise summary: Processes sequence blocks in order, applying exponential decay to both intra-block logits and accumulated cross-block KV products, and writes the attended values directly into the output tensor.
- detailed summary: `_fwd_kernel` iterates over `NUM_BLOCK` chunks for each `(batch×head, model-block)` tile: it loads `BLOCK` positions of Q/K/V, forms the decayed self-attention scores via `diag_decay`, adds the contribution from the running `kv` accumulator multiplied by `q_decay`, and writes the sum to the corresponding slice of `Out`. After each chunk it updates `kv` by applying the block decay and adding the decayed K⊗V term. The host forward wrapper chooses `BLOCK=64`, sets the number of model tiles (`BLOCK_MODEL`), launches the Triton kernel across `(b·h, ceil(e/BLOCK_MODEL))`, and saves the inputs for the backward pass.
