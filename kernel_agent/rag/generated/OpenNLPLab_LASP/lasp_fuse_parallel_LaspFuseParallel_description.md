- kernel family: LASP fused attention (parallel decomposition across sequence and feature tiles)
- concise summary: Splits the LASP attention update into diagonal, KV-precompute, and off-diagonal phases, each launched over distinct grids so that outputs and cache updates can be assembled efficiently before exchanging the refreshed cache across sequence-parallel ranks.
- detailed summary: `lasp_forward` first runs `_fwd_diag_kernel` to handle the intra-block (j≤i) interactions, tiling the sequence into `BLOCK` chunks subdivided into `CBLOCK` stripes. It then invokes `_fwd_kv_parallel` to accumulate future-facing KV tiles per block/feature tile, `_fwd_kv_reduce` to propagate those tiles with the block decay, and `_fwd_none_diag_kernel` to combine the precomputed KV slices plus the global cache `KV`/`GKV` with the current Q stripes, applying the appropriate exponential decays. After finishing, it decays and updates the shared cache (`KV = exp(-s·n)·KV + kv[:, :, -1]`). The outer `_LaspFuseParallel_forward` manages sequence-parallel send/receive of the cache, clones the incoming `KV` for saved tensors, and launches the staged pipeline, returning the fused attention output while streaming the updated cache to the next rank.
