- kernel family: LASP attention (naïve per-call blockwise computation with sequence cache)
- concise summary: Iterates through sequence blocks to form decayed dot products, writes outputs, and accumulates a per-head KV tensor that is forwarded between sequence-parallel ranks, but recomputes everything locally instead of fusing cache tiles.
- detailed summary: `_fwd_kernel` handles `(batch×head, model-block)` tiles: it loops over `NUM_BLOCK` sequence chunks, loading Q/K/V blocks, applying intra-block decay (`diag_decay`) and inter-block decay via a running `kv` accumulator, and emits the block’s contribution to `Out`. After processing all chunks it writes the final `kv` to the provided buffer. The host `_LaspNaive_forward` allocates a fresh `KV`, receives the upstream cache if needed, calls `lasp_forward` to obtain both the blockwise output and per-block `kv`, adds the residual term `matmul(q * q_decay, KV)`, updates the cache `KV = exp(-s·n)·KV + kv`, and sends it downstream, yielding the simplest (non-fused) LASP forward path.
