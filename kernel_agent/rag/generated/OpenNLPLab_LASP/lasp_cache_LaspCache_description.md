- kernel family: LASP cache attention (blockwise decayed attention with sequence-parallel cache passing)
- concise summary: Processes sequence blocks of Q/K/V to accumulate decayed key-value products, writes tile outputs, and updates a running KV cache that is pipelined across sequence-parallel ranks.
- detailed summary: `_fwd_kernel` assigns each program a `(batch×head, model-block)` pair, precomputes exponential decay factors from the per-head slope `s`, and iterates over `NUM_BLOCK` chunks of length `BLOCK`. In each step it loads the local Q/K/V tiles, multiplies the prior `kv` accumulator by `block_decay`, adds the decay-weighted self-term `tl.dot(q,k)`·`v`, and writes the resulting slice to `Out`; the final `kv` state is merged into the persistent cache tensor `KV` with a global decay of `exp(-s·n)`. The Python `_LaspCache_forward` routine receives the previously accumulated `KV` from the upstream sequence-parallel rank, runs `lasp_forward`, adds the cross-chunk residual via `matmul(q * q_decay, KV)`, applies the decay/update rule to `KV`, and forwards it to the next rank before returning the fp16 output. This yields a streaming attention cache that can be shared across partitions without re-reading the entire history.
