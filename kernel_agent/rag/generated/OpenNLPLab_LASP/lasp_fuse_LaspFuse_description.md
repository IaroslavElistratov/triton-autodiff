- kernel family: LASP fused attention (multi-slice decayed attention with distributed cache)
- concise summary: Tiles both the feature (`d`) and output (`e`) dimensions, mixes the existing KV cache with newly computed block contributions under exponential decay, and streams results while coordinating cache exchanges across sequence-parallel ranks.
- detailed summary: `_fwd_kernel` is launched over `(d-block, e-block, batch×head)`; it preloads the current KV slice, derives decay factors from the slope `s`, and iterates over `NUM_BLOCK` sequence chunks. Each iteration loads local Q/K/V blocks, adds two contributions—one from the rolling `kv` accumulator and one from the decayed cached KV—then updates both the output tile and the local accumulator before advancing the block pointers. After finishing the chunk loop it writes the refreshed KV slice back with a global decay factor `exp(-s·n)`. The Python `_LaspFuse_forward` zeroes KV (or receives it from an upstream rank), runs `lasp_forward` to obtain the fused attention output, and hands off the updated KV to the next rank, enabling a fused kernel that handles both in-chunk computation and inter-chunk cache evolution without revisiting earlier sequence data.
