- kernel family: Linear attention (bidirectional, kernelized normalization)
- concise summary: The forward pass first fuses a KᵀV contraction with per-key running means, then streams Q against the cached S and KM tensors to normalize attention outputs tile by tile.
- detailed summary: `fused_fwd_kernel_s_km` launches over (value tiles × key tiles × batch·head); each program loads a BK×BL chunk of keys and an aligned BL×BV chunk of values, multiplies them (after scaling V) to accumulate the contribution to S=KᵀV, and simultaneously sums the key rows to form KM (the average key features). It iterates across the sequence length by advancing block pointers, finally storing its BK×BV slice of S and the matching KM segment. After those tensors are materialized, `fused_fwd_kernel_o` iterates over (value tiles × query tiles × batch·head), loads a BL×BK slab of queries plus the precomputed S tile and KM slice, accumulates Q·KM to build the normalization denominator z, performs the Q·S matmul in FP32, and divides each BL×BV tile by (z+eps) before writing to the output. The Python wrapper orchestrates both kernels with autotuned block shapes, allocating S and KM buffers so the second phase can avoid recomputing these statistics.
