- kernel family: Linear attention (factorized KᵀV precompute + Q·S apply)
- concise summary: The forward phase first computes S = KᵀV by tiling keys and values, then multiplies queries against S to form the attention output without explicit softmax normalisation.
- detailed summary: `_fwd_kv_kernel` iterates over (value tiles × key tiles × batch·head); each program loads a BK×BL chunk of keys and an aligned BL×BV tile of values, rescales V by `scale`, and accumulates their dot product into a BK×BV slice of S using FP32 accumulation before storing to global memory. Once S is materialized, `_fwd_qs_kernel` launches over (value tiles × query tiles × batch·head), streams through the K dimension in BK steps, multiplies the current BL×BK slice of queries with the BK×BV slice of S, and accumulates results into an FP32 buffer that is finally written to the output tensor. The Python wrapper selects autotuned block sizes based on sequence length and head dimension, allocates the intermediate S tensor, and orchestrates the two kernel launches to produce the linear-attention output.
