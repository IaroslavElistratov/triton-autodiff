- kernel family: sequence modeling (parallel retention with exponential decay factors)
- concise summary: Partitions queries, keys, and values into tiles, uses a Triton kernel to accumulate exponentially weighted retention features across time (with per-head decay), and stores the per-head outputs for later reduction.
- detailed summary: `_ParallelRetentionFunction_forward` fixes tile sizes (`BTL=128`, `BTS=32`), computes per-head decay coefficients `b_b`, and launches `parallel_retention_fwd_kernel` over `(NV*NK, ceil(T/BTL), B*H)` where `NK/NV` tile the QK and value dimensions. Inside the kernel, the first loop processes past segments, repeatedly multiplying the running output by the decay factor and adding the contribution `q·k` times `v`. The second loop handles the current window, applying a causal mask via position comparisons and exponential distance factors. Results are accumulated in FP32 and stored into a staging tensor `o`, which the host sums over the NK dimension to return a `(B, H, T, DV)` output. The decay buffers (`L`, etc.) saved on the context allow the backward kernels to reconstruct gradients efficiently.
