- kernel family: sequence retention (fused recurrent update with LoRA-style state)
- concise summary: For each head, iterates over time steps updating a decay-weighted outer product state `h`, forms outputs by contracting `h` with the current query and value vectors, and optionally reads/writes persistent state tensors.
- detailed summary: `_FusedRecurrentRetentionFunction_forward` tiles the head dimensions (`BK`, `BV`), sets a grid `(NV, NK, B*H)`, and initializes the hidden state `h` from `initial_state` when provided. In `fused_recurrent_retention_fwd_kernel`, each step loads the current K/V tiles, updates `h = decay*h + k⊗v`, multiplies by the scaled query to produce the output slice, and advances the pointers through the sequence. When `output_final_state` is true, the terminal `h` is stored for reuse. The forward sums the tiled outputs across `NK` to return a `(B,H,T,Dv)` tensor and saves inputs (and initial_state) for the backward kernel, which replays the recurrence to accumulate gradients.
