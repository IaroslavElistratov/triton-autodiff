- kernel family: activation (general N-dimensional softmax with Triton autotuning)
- concise summary: Flattens the input along the target dimension, launches either an “inner” or “non-inner” Triton softmax kernel depending on remaining strides, and writes the exponentiated, normalized probabilities to an output tensor of the requested dtype.
- detailed summary: `_Softmax_forward` computes `M` (product of sizes before the softmax axis) and `N` (length of the axis), then calls `softmax_kernel_inner` when the remaining trailing dimensions collapse to one, otherwise it dispatches `softmax_kernel_non_inner` over both `M` and the trailing size `K`. Both kernels iterate over tiles determined by autotuned heuristics, maintain running maxima to stabilize the exponentials, and emit normalized values via vectorized loads/stores (handling ragged tails with masking). The function stores the forward result so the backward Triton kernel can reuse the probabilities when forming gradients.
