- kernel family: normalization (Liger Triton layer norm with row blocking)
- concise summary: Flattens the input to `(rows, cols)`, selects a power-of-two block size, and runs `_layer_norm_forward_kernel`, where each row tile computes its mean/variance and applies the affine weights/bias before returning the reshaped result.
- detailed summary: `layer_norm_forward` rescales the batch to 2D, uses `calculate_settings` to pick `BLOCK_SIZE`/warp count, and allocates output plus `Mean`/`RSTD` buffers. The Triton kernel loads an entire row in tiles, accumulates the sum and sum-of-squares to compute mean/variance, stores these statistics, and finally normalizes and affine-transforms the elements using `W` and `B`. The forward wrapper record keeps `X`, `W`, `B`, and the computed stats for reuse by the backward routine, which launches another Triton kernel to compute gradients.
