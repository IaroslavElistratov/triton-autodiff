- kernel family: attention (FlashAttention-style causal forward for TritonBench)
- concise summary: Validates query/key/value head dimensions, allocates output plus FP32 buffers for running sums and maxes, and runs a Triton kernel that marches over key blocks to accumulate softmax-normalized value tiles under a causal mask.
- detailed summary: `__attention_forward` preallocates `L` and `M` buffers to store the per-row softmax denominator and running max, configures a grid `(ceil(seqlen/BLOCK_M), batch*heads)`, and launches `_fwd_kernel`. Inside the kernel, each program loads a query block, iterates over key blocks up to the causal frontier, computes Q·K products, applies the scaling factor, and updates the running max/log-sum-exp values (`m_prev`, `l_prev`) to maintain numerical stability. Probabilities are formed in FP16, multiplied with the corresponding V block, and accumulated in FP32 before being stored back in the original dtype. The final `L` and `M` tensors capture the normalization statistics required by the backward pass to recompute gradients.
