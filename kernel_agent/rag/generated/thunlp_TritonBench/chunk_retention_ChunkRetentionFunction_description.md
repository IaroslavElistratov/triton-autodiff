- kernel family: sequence retention (chunked recurrent accumulation with exponential decay)
- concise summary: Splits the sequence into 64-step blocks, first accumulates a head-specific decayed state `h` tile by tile (with optional initial/final states), then uses that state plus masked within-block interactions to produce the retained output.
- detailed summary: `_ChunkRetentionFunction_forward` chooses block sizes (`BT=64`, `BK/BV` up to 64), allocates the intermediate buffer `h`, and launches `chunk_retention_fwd_kernel_h` over `(ceil(K/BK), ceil(V/BV), B·H)` programs. This kernel loads per-block K/V tiles, applies per-head decay factors `b_b`, and updates `h = decay*h + K·(V * decay_offsets)`, storing the state for each chunk and optionally writing the final state tensor. A second launch `chunk_retention_fwd_kernel_o` (grid `(ceil(V/BV), ceil(T/BT), B·H)`) loads queries, keys, and the stored state to compute outputs: it multiplies the state contribution, adds masked intra-block QK scores scaled by decay factors, and contracts with V to form the block output scaled by `scale`. The forward caches `(q, k, v, h)` so the backward kernels can reconstruct gradients with respect to all inputs and states.
