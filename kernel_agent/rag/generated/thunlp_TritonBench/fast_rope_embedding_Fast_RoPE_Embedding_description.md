- kernel family: rotary positional encoding (RoPE rotation applied per attention head, Triton fused implementation)
- concise summary: Flattens the `[batch, seq, head, dim]` queries and launches a two-dimensional kernel over sequence rows and groups of four heads to rotate each head’s half-dimension pair by the provided sin/cos tables.
- detailed summary: The launcher squeezes the broadcasted sin/cos inputs, reshapes queries to `(batch·seq, heads·dim)`, and chooses a `BLOCK_SIZE` as the next power-of-two of `head_dim/2` along with an appropriate warp count. In the Triton kernel, `program_id(0)` indexes rows while `program_id(1)` iterates head groups of size four; within each program the column offsets span the first half of the head dimension, guarded by a mask for odd tails. The kernel pulls the sin and cos values for the current sequence position, optionally flips the sign when reused for backward, and loops over the heads in the group, loading corresponding halves (`Q1`, `Q2`) and overwriting them with the complex rotation `Q1·cos − Q2·sin` and `Q2·cos + Q1·sin`. After the launch the tensor is reshaped back to the original rank, carrying the rotated embeddings forward.
