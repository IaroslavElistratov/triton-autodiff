- kernel family: attention variant (Lightning Attention without decay)
- concise summary: Tiles queries, keys, and values into time blocks, performs blockwise dot products with causal masking, accumulates both intra-block and cross-block contributions, and writes the aggregated outputs to `(b, h, n, e)`.
- detailed summary: `_LightningAttention2NoDecay_forward` ensures contiguous Q/K/V, allocates an output tensor, and sets `BLOCK=64` with `NUM_BLOCK = ceil(n/BLOCK)` and `BLOCK_MODEL = min(pow2(e), 32)`. The Triton `_fwd_kernel` launches over `(batch*heads, ceil(e/BLOCK_MODEL))`. Within each block iteration it loads Q/K/V tiles, forms the block attention scores, applies a causal mask via relative offsets, and keeps a running `kv` accumulator so later blocks can reuse past contributions. After computing both intra-block (`qk·v`) and accumulated inter-block terms, it stores the combined result back to the proper slice of `Out`. The kernel operates entirely in FP32 accumulators before casting to the output dtype; all tensors needed for the backward phase are saved on the autograd context.
