- kernel family: sequence retention (modular chunked retention with optional checkpointing)
- concise summary: Separates the retention forward pass into two stages—first building chunk states `h` via `chunk_retention_fwd_kernel_h`, then emitting outputs with `chunk_retention_fwd_kernel_o`—with helpers that allow checkpoint-level control over whether the intermediate state is kept for backward.
- detailed summary: `_ChunkRetentionFunction_forward` calls `chunk_fwd_h_fn` to allocate `h` and invoke the state kernel over `(ceil(K/BK), ceil(V/BV), B·H)`, accumulating decayed key/value outer products into `h` while optionally storing a final state tensor. It then computes outputs via `chunk_fwd_o_fn`, which launches `chunk_retention_fwd_kernel_o` across `(ceil(V/BV), ceil(T/BT), B·H)`. Both kernels reuse the same decay factors as the combined version, but the ops wrapper exposes knobs for checkpointing (`checkpoint_level`), scale parameter injection, and optional state reuse. Saved tensors (`q, k, v, h, initial_state`) allow backward kernels to recompute gradients; when checkpointing is enabled, the intermediate `h` can be dropped to save memory and recomputed on demand.
