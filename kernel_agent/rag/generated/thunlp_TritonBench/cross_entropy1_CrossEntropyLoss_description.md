- kernel family: classification loss (baseline cross-entropy with optional smoothing and distributed splits)
- concise summary: Launches a Triton kernel per block of vocabulary columns to compute log-sum-exp and negative log-likelihood contributions (respecting label smoothing, class splits, and z-loss), then consolidates partial results across blocks and ranks to produce per-example losses.
- detailed summary: `_CrossEntropyLoss_forward` reshapes logits to contiguous, determines whether the vocab must be chunked (`BLOCK_SIZE` up to 64K) or sharded across ranks, and allocates per-block loss/LSE buffers. `cross_entropy_fwd_kernel` processes each row/block: it loads the logits, subtracts their max for stability, computes the block LSE, subtracts the true logit (with smoothing adjustments), and optionally adds the quadratic `lse_square_scale` term. When the vocabulary is split, the host reduces the chunk losses, performs all-gather + logsumexp across ranks, and finalizes the per-row loss tensor. The forward saves logits/LSE/labels so the backward kernel can compute gradients via softmax probabilities adjusted for smoothing and z-loss.
