- kernel family: normalization (RMSNorm with optional Gemma shift, row-wise Triton implementation)
- concise summary: Flattens the input to rows, autotunes a row kernel, and applies either standard RMS normalization or a Gemma-flavored variant that scales by `W+1`, caching the inverse RMS factors for reuse.
- detailed summary: The launcher reshapes `[*, dim]` activations to `(rows, dim)`, picks `BLOCK_SIZE = next_power_of_2(dim)` capped by `MAX_FUSED_SIZE`, allocates the normalized output plus an FP32 buffer `r` for the inverse RMS, and dispatches `_rms_layernorm_forward` (or `_gemma_rms_layernorm_forward` when `gemma=True`). Each Triton program handles one row: it loads the row and weight tiles with masking, accumulates the mean of `x²` in FP32, forms `inv_var = 1/sqrt(mean + eps)`, stores that scalar in `r`, multiplies the normalized row by the weight vector (adding 1.0 to the weights in the Gemma path), and writes the result back to global memory. Saved tensors (`X`, `W`, `r`) along with the chosen launch parameters are retained for the backward pass so the statistics need not be recomputed.
