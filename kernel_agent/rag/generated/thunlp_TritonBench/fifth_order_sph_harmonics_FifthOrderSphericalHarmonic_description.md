- kernel family: geometric feature expansion (fifth-order real spherical harmonics over 3D coordinates)
- concise summary: Evaluates the 11 nonredundant fifth-order spherical harmonic polynomials for batched xyz inputs, writing them to an output tensor with matching leading dimensions.
- detailed summary: The helper first derives how many row blocks to launch along the last dimension given a `block_size`, then each Triton program (indexed only by that block id) walks a contiguous chunk of coordinate triplets. It loads `x`, `y`, and `z` components with stride-3 addressing, applies masking for ragged tails, computes a sequence of reused power terms (x²…x⁵, etc.), and combines them with baked-in coefficients to realize the harmonic basis `Y00..Y10`. The kernel stores the 11 results per point into the output using the provided stride (typically stepping by 11), adding an optional column offset, and the forward launcher materializes the output tensor if needed before invoking the kernel with the computed grid size.
