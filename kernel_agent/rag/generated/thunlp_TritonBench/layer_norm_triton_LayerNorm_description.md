- kernel family: normalization (row-wise layer norm with Triton fused statistics)
- concise summary: Reshapes the input to `(M,N)`, allocates mean/rstd buffers, and runs `_layer_norm_fwd_fused`, where each Triton program accumulates per-row mean and variance in FP32 and writes normalized, affine-transformed outputs back to the preallocated tensor.
- detailed summary: `_LayerNorm_forward` reshapes the activations, selects `BLOCK_SIZE` up to the 64 KB feature limit, and launches a 1D grid of Triton programs. Inside `_layer_norm_fwd_fused`, each program streams across the feature dimension in `BLOCK_SIZE` chunks, first summing to compute the mean, then the squared deviations to compute the variance. After storing the row mean and inverse std, it performs a final pass that loads weight/bias, normalizes `(x-mean)*rstd`, applies the affine parameters, and stores the results—all under masks for tail columns. The context caches the reshaped input, parameters, and computed statistics for reuse by the backward kernels.
