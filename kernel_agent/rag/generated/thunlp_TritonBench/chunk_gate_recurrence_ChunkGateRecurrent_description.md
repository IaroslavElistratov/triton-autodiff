- kernel family: sequence retention (chunked gated recurrence over K/V tiles)
- concise summary: Tiles `(D_k, D_v)` into fixed blocks, iterates across the time chunks multiplying the previous state by a per-chunk decay and adding the current `kv` contributions, optionally seeding from `last_kv`, and stores the evolving state for every chunk.
- detailed summary: `_ChunkGateRecurrent_forward` enforces contiguous layout, picks block sizes (`BLOCK_MODEL_K=64`, `BLOCK_MODEL_V=16`), and launches `_fwd_recurrence` over `(B·H, D_k/64, D_v/16)` programs. Each kernel program maps to a specific head and `(k,v)` tile, initializing an accumulator `acc` either from zeros or `last_kv`. For each chunk, it loads the decay scalar `d_i` and the chunk slice `S_i` from `kv`, updates `acc = acc * d_i + S_i`, writes the result to the output tensor, and advances the pointers. This produces a per-chunk running retention state that the backward kernel later differentiates through using the saved outputs and decays.
