- kernel family: recurrent (HGRN-style fused gating recurrence)
- concise summary: Slices the hidden dimension into Triton tiles, iterates over time updating the hidden state `h = g * h + x`, and writes both the per-step outputs and optional final state, with support for initializing from a previous state tensor.
- detailed summary: `_FusedRecurrentHGRNFunction_forward` launches `fused_recurrent_hgrn_fwd_kernel` on a grid `(ceil(D/BD), B*H)` where `BD` is autotuned. Inside the kernel, each program loads a block of the input `x` and gate `g`, optionally seeds `h` from `initial_state`, and for each timestep multiplies `h` by the gate then adds the new input block. The updated block is stored to the output tensor using masked stores to handle tail dimensions. When `output_final_state=True`, the last `h` is saved into `final_state`. Forward saves the gate, full outputs, and initial state for use by the backward kernel, which replays the recurrence in reverse to accumulate gradients.
