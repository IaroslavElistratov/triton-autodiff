- kernel family: state-space model (diagonal SSM forward) 
- concise summary: Advances a diagonal state-space recurrence `s = λ·s + x` across `length` steps—supporting both real and complex diagonals—while materializing the sequence of states as the output tensor.
- detailed summary: `__ssm_forward_forward` ensures contiguous buffers, inspects `Lambda`’s dtype, and launches either `diag_ssm_forward_kernel` (real) or `diag_ssm_forward_kernel_complex` (complex) over `(ceil(batch·dim / BLOCK_SIZE),)` programs. Each program updates a column-aligned slice of the state vector: it loads the initial `s`, multiplies by the diagonal `λ`, adds the current input `x`, stores the new state in `y`, and repeats for every timestep. For complex diagonals, the kernel maintains separate real/imag parts and performs fused complex multiplies. The forward saves the initial state, full state trajectory, and diagonal so the backward kernels can propagate gradients through the recurrence.
