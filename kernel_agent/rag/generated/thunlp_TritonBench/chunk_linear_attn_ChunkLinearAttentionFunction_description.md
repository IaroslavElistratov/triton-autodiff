- kernel family: attention variant (chunked linear attention with running state)
- concise summary: Splits the sequence into blocks of 64, first accumulates chunk-level key/value products into an intermediate state tensor `h` (optionally initialized from a previous state), then launches a second kernel that forms outputs by combining `h` with current queries and within-chunk QK scores under a causal mask.
- detailed summary: `_ChunkLinearAttentionFunction_forward` chooses block sizes (`BT=64`) and head tiling (`BK`, `BV`), allocates the intermediate buffer `h`, and dispatches `chunk_linear_attn_fwd_kernel_h` over `(ceil(K/BK), ceil(V/BV), B·H)`. That kernel loads block-row slices of `k` and `v`, accumulates their outer product into `h`, and stores the running state per block; it also writes the final state if requested. A second launch `chunk_linear_attn_fwd_kernel_o` iterates over keys to load matching tiles of `q`, `k`, and the stored state, computes both state-driven and within-block contributions, applies the lower-triangular mask, multiplies by `scale`, and writes the result into the output tensor (matching `v`’s layout). Saved tensors (`q, k, v, h`) allow the backward kernels to recover gradients for queries, keys, values, and states without redoing the forward accumulation.
