- kernel family: classification loss (scaled cross-entropy with z-loss output and optional smoothing)
- concise summary: Similar to the baseline kernel but includes logit scaling and returns both the primary loss and a separate z-loss tensor; the Triton kernel handles block-wise processing and optional distributed splitting like the fused variant.
- detailed summary: `_CrossEntropyLoss_forward` ensures contiguous logits, determines whether to chunk or shard the vocabulary, and allocates per-block buffers for the loss, log-sum-exp, and z-loss. `cross_entropy_fwd_kernel` loads each logits block, applies the provided `logit_scale`, evaluates the stable log-sum-exp, subtracts the labeled logit (incorporating smoothing terms), and, when not split, accumulates `lse_square_scale * LSE^2` into both the main loss and z-loss tensors. Post-kernel reductions merge chunked blocks and, if in distributed mode, all-gather LSE values before adding z-loss back in. The backward kernel mirrors this setup, computing gradients via scaled probabilities adjusted for both smoothing and the z-loss contribution.
