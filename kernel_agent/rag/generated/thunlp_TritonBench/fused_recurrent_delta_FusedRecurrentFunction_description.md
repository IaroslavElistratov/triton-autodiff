- kernel family: recurrent delta attention-style state update (head-wise outer-product memory with optional persistent state)
- concise summary: Maintains a V×K state per head that is iteratively updated by subtracting prior contributions, scaling value deltas by beta, and projecting the refreshed state with the current query tile to emit the output sequence.
- detailed summary: Each Triton program instance is indexed by (value tile, key tile, batch×head) and processes full time steps for that slice, with BK set to the next power-of-two of K (asserting NK==1) and BV capped at 8 via next_power_of_2(V). The kernel optionally seeds its state `h` from an initial tensor, then for every timestep loads the local q/k/v tiles, subtracts `h @ k` from `v` to remove prior memory, writes the residual back for reuse, multiplies by a beta factor that can be per-value or per-step, and accumulates the outer product `k ⊗ (beta·v)` into the state. It immediately projects the refreshed state with the scaled query (`scale·q`) to produce the output tile, strides all pointers by the sequence pitch, and after the loop optionally materializes the final state. The forward launcher builds an `(NV, NK, B·H)` grid with single warp/stage, allocates transient output shaped `(T, V)` (after squeezing NK), and passes flags for initial/final state storage and beta layout.
