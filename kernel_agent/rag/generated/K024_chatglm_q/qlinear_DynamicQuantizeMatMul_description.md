- kernel family: quantized matmul (float activations × int8 weights with per-column scale)
- concise summary: The Triton tile kernel multiplies FP activations against quantized int8 weight blocks, rescales each BLOCK_N column by its stored float scale, and accumulates FP32 dot products into the output with optional split-K reductions.
- detailed summary: Launch geometry maps program ids into `(BLOCK_M, BLOCK_N)` tiles grouped along M for better L2 reuse; within each loop iteration the kernel loads a BLOCK_K slice of A and the corresponding int8 slice of B, applies the broadcasted `B_scale` factors, and accumulates via `tl.dot` (using TF32 if allowed). Boundary masks gate partial tiles when K is not a multiple of BLOCK_K, and if `SPLIT_K>1` the partial results are atomically added. The Python wrapper flattens batching, enforces contiguous strides, allocates the output tensor, selects grid dims from M/N, and dispatches `_dynamic_quant_matmul_kernel` (or falls back to PyTorch when tensors are on CPU).
