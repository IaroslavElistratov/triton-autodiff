- kernel family: Gated linear attention (chunked exponential moving state)
- concise summary: The fused forward kernel iterates through BT-length chunks, updates a head-specific hidden state with gated Q/K/V factors (optionally seeded and persisted), accumulates chunk outputs, and then adds a secondary semiring contraction computed on reshaped tensors.
- detailed summary: `fused_chunk_gla_fwd_kernel` launches over (value tiles × key tiles × batch·head). Each step loads BT×BK slices of Q, K, the gating tensor G, and BT×BV values; it converts the cumulative gates to base-2 exponent space, rescales Q and K accordingly, applies the decay from the tail gate sample, and forms the chunk output via `dot(Q, state)`. The running state `b_h` is multiplied by the decay, updated with `Kᵀ·V`, and optionally initialized from `initial_state` and stored into `final_state` after the last chunk. After summing these chunk outputs across key tiles, the Python wrapper reshapes (b,h,seq) into chunked form, computes an additional global term `A = semiring_cal_A.forward(q2,k2,g2)` capturing interactions within each chunk, multiplies by `V` to obtain `o2`, and adds it to the kernel output. The wrapper manages gating reshapes, cumulative sums, launch parameters (BT=16, BK/BV up to 64), and final aggregation, returning both the output and optional final state.
