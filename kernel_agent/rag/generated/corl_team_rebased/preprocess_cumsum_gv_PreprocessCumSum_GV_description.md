- kernel family: gated linear attention precompute (value gate cumulative sums)
- concise summary: Scans value-side gate logits inside each chunk to produce cumulative sums, exponentials, and decay-adjusted value tensors consumed later by inter-chunk kernels.
- detailed summary: For every batch×head pair, the Triton kernel iterates through the `CHUNK_SIZE` timesteps of a chunk, accumulating the running sum of `gv`, writing that prefix to `gv_cumsum`, and caching `exp(cumsum)` both per-step (in `gv_cumsum_exp`) and at the chunk tail (in `gv_last_exp`). After completing the scan it replays the chunk, this time multiplying each value vector by `exp(final_cumsum − gv_cumsum[t])` so `v_reduce` carries decay-adjusted values aligned with the key-side preprocessing. The forward wrapper allocates the four auxiliary tensors, launches the kernel across (batch×head, chunk) grid points, and returns the precomputed buffers so downstream Triton attention kernels no longer need to recompute the cumulative value gates.
