- kernel family: retention attention (fused recurrent outer-product update)
- concise summary: The forward kernel maintains a BV×BK retention matrix per head, decaying it with a fixed head-dependent factor each step, injecting the new key⊗value outer product, and projecting with scaled queries to emit the causal output while optionally tracking persistent state.
- detailed summary: For every `(NV, NK, B·H)` launch the kernel builds block pointers into the current key/value/query tiles. It zeros an fp32 accumulator `h` (or loads the supplied initial state slice) and iterates across the T timesteps: each iteration loads the BK-sized key, BV-sized value, and scaled query vectors, multiplies the accumulator by the head-specific decay `b_b = 1 - 2^{-5-i_h}`, adds the rank-1 update `_k⊗_v`, and then contracts `h` with the query to generate a BV-length output vector stored to the staging tensor. After the scan completes it optionally writes the final accumulator tile back for use in subsequent segments. The Python wrapper configures block sizes (≤32), launches the grid, collapses the key-split dimension by summing, and returns the resulting retention outputs together with the final state if requested.
