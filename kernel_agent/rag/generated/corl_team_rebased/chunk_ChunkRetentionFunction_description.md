- kernel family: Retention attention (chunked state update and query emission)
- concise summary: The forward pass first sweeps through keys/values in BT-length chunks to build exponentially decaying hidden states, optionally seeding from an initial state and writing the final state, then reuses those cached states to transform each query block into outputs with intra-chunk correlations.
- detailed summary: `chunk_retention_fwd_kernel_h` launches over (key tiles × value tiles × batch·head). For each block it loads a BK×BT slab of keys and the matching BT×BV values, applies a head-specific decay factor `b_b`, and iteratively updates a BK×BV state matrix `b_h` (initialized from `initial_state` when provided) by decaying the previous state and adding `Kᵀ·(V * decay_vector)`. The updated state is stored into the chunk buffer `h`, and, if requested, the final iteration writes the concluding state tile into `final_state`. Next, `chunk_retention_fwd_kernel_o` iterates over (time chunks × batch·head); it streams through BK slices of queries and keys, applies scaling and per-position decay matrices (`d_i`, `d_s`), accumulates contributions from the precomputed states `h`, and adds an extra term from the local K/V chunk to produce a BT×BV output tile that is stored back to `o`. The Python wrapper configures tile sizes (BT=64, BK/BV power-of-two ceilings), allocates the intermediate state tensor, runs the state-building kernel (optionally capturing final states), and then runs the output kernel to emit the retained sequence.
