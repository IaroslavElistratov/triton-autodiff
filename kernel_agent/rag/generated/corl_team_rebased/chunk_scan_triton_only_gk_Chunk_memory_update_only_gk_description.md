- kernel family: block-parallel gated linear attention memory update (key-decay only)
- concise summary: Performs a tilewise prefix recurrence that multiplies the running state by key decay scalars before adding new contributions, while leaving value channels untouched.
- detailed summary: Each Triton program operates on a 32×32 tile over the key/value feature grid with batch and head fused into the first launch axis. After writing the initial tile from `to_add`, it iterates forward across the chunk dimension: loads the next decay vector from `decay_key_last`, scales the accumulator row-wise, adds the incoming tile, and emits the refreshed memory tile to `output` before advancing pointers. The accumulator stays resident in registers for all `NUM_BLOCK-2` steps, and the Python wrapper zeros the first temporal block so subsequent kernels see a clean scan seeded by the decayed key state only.
