- kernel family: block-parallel retention attention with per-head exponential decay
- concise summary: Processes Q/K/V tiles in 128-step chunks, applying head-dependent exponential decay to accumulate a causal retention response before writing the chunked output.
- detailed summary: Each Triton program selects a key/value tile `(i_k, i_v)` and sequence block `i_c`, scales its 128×BK query tile by `scale = d_k^{-0.5}`, and streams over earlier blocks in 32-step increments. For context blocks it loads K/V, multiplies the dot products by precomputed decay weights `d_h` and decays the running output accumulator `b_o` by `exp2(b_b * BTS)` to respect the retention forgetting curve tied to the head index. It then reinitializes block pointers over the current chunk, applies a lower-triangular mask with distance-based decay `exp2((q_idx−k_idx)*b_b)`, and adds the gated contribution from V to `b_o`. The launcher tiles the feature dimensions (≤128 features per tile), fuses batch×head onto the grid, and sums key-slice temporaries so the forward path yields the retention output tensor already incorporating geometric decay across and within blocks.
