- kernel family: Chunked ABC attention (fused cumulative stats + slot weighting)
- concise summary: The forward pass precomputes cumulative normalization factors for the K/V slot logits, builds per-chunk slot scores and attention probabilities, applies a softmax across slots, and finally combines V with those probabilities to produce chunked outputs.
- detailed summary: `chunk_abc_fwd_kernel_cum` walks through the sequence in BT steps for each (slot tile, head), recursively maintaining running maxima and partition sums so it can write the cumulative values `c`, `p`, and decay factors `r` needed for numerical stability. With those prefactors, `chunk_abc_fwd_kernel_s` traverses query/key blocks: it loads a BT×BK strip of queries and the matching BK×BT keys, computes both inter-chunk (via the decayed history `rk`) and intra-chunk correlations (via masked dot products), and multiplies by the cached `pk` to fill a BT×BM slice of the slot score tensor `s`. After summing `s` across key tiles and applying a softmax along the slot dimension, `chunk_abc_fwd_kernel_o` mirrors the process for values: it consumes `p`, the value chunks, and the cumulative factors for V (`rv`, `cv`, `pv`) to accumulate both inter- and intra-chunk contributions into the BT×BV output tile, updating an internal running state `b_hv` as it advances. The Python wrapper sets tile sizes (BT=16 with BK/BV/BM up to 64), launches the cumulative kernels for K and V, materializes `s`, performs the softmax, and finally launches the output kernel before reducing across chunk axes.
