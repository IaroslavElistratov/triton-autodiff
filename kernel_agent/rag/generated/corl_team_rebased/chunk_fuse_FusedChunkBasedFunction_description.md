- kernel family: Chunk-based quadratic attention approximation (series expansion A/B/C = 1 + S + ½S²)
- concise summary: The forward kernel iterates over BT-length chunks, tracking running sums of V, K·V, and (K⊗K)·V to evaluate the truncated series for each query block, yielding both the output and a normalization term `z` per chunk.
- detailed summary: `fused_chunk_based_fwd_kernel` launches with grid `(value tiles × key tiles × batch·head)`; it keeps three state buffers (`b_h_0o`, `b_h_1o`, `b_h_2o`) representing the 0th, 1st, and 2nd order moments accumulated from previous chunks. For each block it loads BT×BK queries (scaled), BK×BT keys, and BT×BV values, forms dot products to compute the truncated exponential kernel `b_s = 1 + QK + ½(QK)²` with causal masking, and combines it with the states to update both the output tile and the scalar normalization `z` (which tracks the same series for the partition function). After processing, it stores the updated states for use by later chunks and advances pointers. The Python wrapper selects chunk sizes (BT=16 with BK/BV aligned to head dims), allocates per-key-tile accumulators `o` and `z`, dispatches the kernel, and then sums across key tiles to produce the final outputs and normalization terms.
