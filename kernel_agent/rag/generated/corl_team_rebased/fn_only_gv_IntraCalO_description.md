- kernel family: intra-chunk gated linear attention output synthesis (value-gating variant)
- concise summary: Accumulates chunkwise attention outputs by applying exponential value gates to V tiles before multiplying by the precomputed intra-chunk attention blocks `A`.
- detailed summary: The Triton kernel tiles the chunk length into 16×16 blocks and the value dimension into slices up to 128 features, with batch×head collapsed onto a grid axis. For each query tile beyond the causal diagonal it loads the corresponding attention block from `A`, rescales the contributing value tiles using gate logits from `gv`, and accumulates the dot product into an output register array before writing it back. It then handles the diagonal tile separately: retrieves the stored partial sum, applies the gated value transform and a final row-wise gate to enforce causality, and stores the gated result. The Python launcher simply instantiates an `o` buffer of the same shape as `v` and runs the kernel, producing per-chunk outputs that respect the value-only gating schedule.
