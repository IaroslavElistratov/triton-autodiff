- kernel family: normalization + projection (RMS-aware fused norm-plus-linear)
- concise summary: The forward wrapper reshapes the tensor, runs the single-pass Triton layer/RMS norm kernel with residual fusion, then casts to the active autocast dtype and performs a dense projection, optionally returning the cached residual buffer for prenorm flows.
- detailed summary: After ensuring contiguous row-major views, `_LayerNormLinearFn_forward` calls `_layer_norm_fwd`, which assigns one Triton program per row to accumulate the squared activations, produce the inverse root-mean-square, and apply the scale/bias in fp32 (residual add and caching are conditional). The normalized output is reshaped back, converted to either the autocast dtype or the input dtype, and multiplied by the supplied linear weight (and optional bias) via `F.linear`. The context records the residual cache, norm parameters, and inferred dtypes so backward can reuse them, while callers that set `prenorm=True` receive both the projected activations and the saved residual snapshot.
