- kernel family: block-parallel BASED attention approximation (Taylor-softmax scan)
- concise summary: Tiles the sequence into 128-long blocks and computes causal attention outputs by evaluating a second-order Taylor expansion of the exponential kernel while streaming K/V tiles in Triton.
- detailed summary: Each program instance picks a key/value tile index `(i_k, i_v)` and a sequence block `i_c`, then loads a 128×BK slice of Q (scaled once up front) and iterates over earlier context blocks in steps of `BTS=32`. For past blocks it forms Q·K products, applies the approximation `1 + s + 0.5 s²` to mimic `exp(s)`, accumulates the resulting weights into a running normalization vector `b_z`, and multiplies by the matching V tile to update the output accumulator `b_o`. It then processes the current block with a lower-triangular mask to enforce causality before writing the 128×BV output tile and its normalization row into temporaries `o` and `z`. The Python launcher configures block sizes (up to 128 features per tile), enforces `NK=1` to avoid sync hazards, and returns the sum over key-slice temporaries so the forward pass provides both the approximated attention output and its normalizer for downstream corrections.
