- kernel family: gated linear attention (fused recurrent outer-product update)
- concise summary: The forward kernel advances a BV×BK memory tile across the sequence, optionally seeding it with an initial state, decaying it with exponentiated gates, injecting the current K⊗V outer product, and projecting with scaled Q to emit the chunk’s value output (and an optional final state).
- detailed summary: Each launch over `(NV, NK, B·H)` picks a value tile (`BV≤32`) and key tile (`BK≤32`) for one batch-head stream. It initializes an fp32 accumulator `h`; if an initial state tensor is supplied it loads the matching slice. For every timestep it loads the current key, value, and scaled query tiles (walking backwards when `reverse=True`), multiplies `h` by the per-column key gate and per-row value gate when provided, adds the rank-1 update `_k⊗_v`, and then multiplies by the query tile to produce a length-`BV` output vector that is stored to the staging buffer. Pointer arithmetic marches forward or backward depending on scan direction. After processing all T steps, the kernel optionally writes the ending state tile. The wrapper exponentiates the log-gates, configures the grid and block sizes, allocates the staging tensors, and returns the summed outputs (plus the detached final state when requested).
