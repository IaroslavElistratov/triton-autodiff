- kernel family: block-parallel gated linear attention memory update (value-decay only)
- concise summary: Implements a tilewise recurrence that scales each accumulator column by the provided value decay factors before incorporating new contributions.
- detailed summary: The forward Triton kernel maps batch×head to `program_id(0)` and breaks key/value features into 32×32 tiles. It loads the first slice from `to_add`, writes it out, and then loops over the remaining temporal blocks: fetches the decay vector from `decay_value_last`, scales the running accumulator column-wise, adds the next tile from `to_add`, and stores the refreshed memory tile. The accumulator lives in registers throughout `NUM_BLOCK-2` iterations, minimizing memory traffic, and the wrapper zeros the leading time block so later stages receive a decay-only scan in the value dimension.
