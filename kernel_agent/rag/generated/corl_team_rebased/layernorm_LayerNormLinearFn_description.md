- kernel family: fused layer normalization followed by linear projection
- concise summary: Normalizes each sequence row with the same single-pass Triton layernorm kernel (supporting RMSNorm and residual fusion) and immediately applies a dense linear transform in PyTorch.
- detailed summary: The forward path reshapes the input to 2-D, makes the optional residual contiguous, and invokes `_layer_norm_fwd_1pass_kernel` to add the residual, compute mean/variance (or RMS statistics), and scale by `norm_weight`/`norm_bias`, storing mean and reciprocal std for reuse. The normalized activations are reshaped back to the original layout, cast to the target dtype, and multiplied by `linear_weight` (plus optional `linear_bias`) via `F.linear`, yielding the projected output; prenorm callers can also receive the stored residual buffer. Because the layernorm is fully fused inside Triton, the only additional work versus the plain variant is the final GEMM-style linear layer executed on the CPU API but operating on GPU tensors.
