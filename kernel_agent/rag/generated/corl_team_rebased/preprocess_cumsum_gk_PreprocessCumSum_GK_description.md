- kernel family: gated linear attention precompute (key gate cumulative sums)
- concise summary: Walks each chunk of key-gate logits to build running exponentials, producing cumulative GK buffers plus rescaled Q and K tensors used by downstream inter-chunk kernels.
- detailed summary: For every batch×head tile and 32-channel slice, the Triton kernel sweeps through `CHUNK_SIZE` positions, maintaining a register `cumsum` of gate logits pulled from `gk`. At each step it writes the cumulative sum into `gk_cumsum`, multiplies the matching query slice by `exp(cumsum)` to populate `q_exp`, and advances to the next timestep; once the chunk is done it stores `exp(cumsum)` as the chunk’s terminal factor in `gk_last_exp`. A second streaming pass reuses the stored cumulative sums to scale each key vector by `exp(final_cumsum - gk_cumsum[t])`, filling `k_reduce`. The Python wrapper allocates the four output tensors, configures the grid over (batch×head, chunk, key-dimension tiles), and launches the kernel so later stages can reuse these precomputed exponentials without recomputing per-position gate scans.
