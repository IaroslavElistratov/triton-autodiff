- kernel family: intra-chunk gated linear attention accumulator (key-gating variant)
- concise summary: Builds the causal chunkwise attention matrix by applying exponential key gating to Q/K tiles before forming lower-triangular dot products inside each chunk.
- detailed summary: The Triton kernel maps (chunk index, batch×head, feature-slice) onto its grid and operates on 16×16 micro-tiles drawn from Q, K, and the precomputed `gk` normalizers. For every tile it loads the matching gate logits, exponentiates them against a shared normalizer, rescales Q row-wise and K column-wise, and then forms dot products for all strictly lower-triangular pairs before separately handling the diagonal tile with a triangular mask. Partial results accumulate into a scratch tensor `A` that is later summed across feature slices, so the forward pass returns the intra-chunk contribution weighted purely by key gating with numerical stabilization baked into the per-tile exponentials.
