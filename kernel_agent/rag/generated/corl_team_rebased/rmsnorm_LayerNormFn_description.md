- kernel family: normalization (layer/RMS norm helper reused by RMSNorm module)
- concise summary: The forward path reshapes the input to 2-D, invokes the single-pass Triton normalization kernel with `is_rms_norm` toggled by the caller, and optionally returns both the normalized activations and a cached residual buffer.
- detailed summary: `_layer_norm_fwd_1pass_kernel` launches one program per row, adds an optional residual, computes either the mean/variance or second moment depending on `IS_RMS_NORM`, stores the per-row inverse std, and applies the affine weights (plus bias when provided) in fp32 before writing the result. The Python wrapper prepares contiguous views, selects residual dtypes, and calls `_layer_norm_fwd`, reshaping the output back to the original batch layout; when `prenorm=True` it also returns the residual cache so upstream layers can reuse it. This file exports the same functionality under `LayerNormFn`, ready for RMSNorm configurations that simply set `is_rms_norm=True` at call time.
