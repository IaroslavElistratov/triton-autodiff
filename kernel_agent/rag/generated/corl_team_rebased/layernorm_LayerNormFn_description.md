- kernel family: fused layer normalization / RMSNorm with optional residual path
- concise summary: Launches one Triton program per row to add an optional residual, compute mean and variance (or just variance for RMSNorm), and emit the gamma/beta-scaled normalized activation in a single pass.
- detailed summary: `_layer_norm_fwd_1pass_kernel` autotunes the warp count and loads the feature block for one sequence position, optionally accumulates a residual buffer, and—if requested—stores the merged residual for later use. It computes either `(x-mean)` statistics or pure RMS statistics depending on the `is_rms_norm` flag, writes the per-row mean and reciprocal standard deviation to side buffers, then multiplies by `weight` and optionally adds `bias` before storing the normalized output slice. The Python wrapper reshapes inputs to 2-D, ensures contiguity, materializes a residual-out buffer when dtype conversion is needed, and chooses a power-of-two `BLOCK_N` no larger than 64 KB so the entire row is processed in-register during the single Triton launch.
