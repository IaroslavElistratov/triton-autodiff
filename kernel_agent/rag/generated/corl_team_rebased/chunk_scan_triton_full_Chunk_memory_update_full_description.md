- kernel family: block-parallel gated linear attention memory update (32x32 chunk scan)
- concise summary: Each kernel instance walks a chunked key/value memory buffer, applying per-position decay factors while accumulating the running state tiles that will seed subsequent chunks.
- detailed summary: Within a tile of size 32×32 across key and value dimensions, the Triton kernel loads the initial contribution for the current chunk pair, stores it, and then advances through the sequence dimension one block at a time. At every step it multiplies the running accumulator by the corresponding key and value decay scalars, adds the tile from `to_add`, and immediately writes the refreshed memory tile back to the output buffer. The launch grid packs batch and head into `program_id(0)` and stripes the d_k and d_v axes across the other dimensions, keeping the accumulator resident in registers so repeated decayed updates over `NUM_BLOCK` iterations avoid extra global reads; the Python wrapper later zeroes the first temporal block, preserving the scan structure for downstream kernels.
