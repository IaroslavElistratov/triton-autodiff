- kernel family: attention (FlashAttention-style streaming SDPA with optional causal masking)
- concise summary: Tiles queries over `BLOCK_M × D` chunks, loops across key/value blocks with causal-aware masking, and maintains running log-sum-exp statistics to stream normalized attention outputs without materializing the full score matrix.
- detailed summary: Program ids split into `(block of query positions, batch×head)` so each instance loads a contiguous query tile, rescales it by the softmax factor, and iterates `start_n` over key/value tiles of width `BLOCK_N`. Inside the loop it loads the key/value blocks, applies the causal predicate when requested, forms fp32 dot products, and updates per-row maxima `m_i` and normalization sums `l_i` via base-2 exponentiation (`exp2`). The running accumulator `acc` is scaled by the ratio of old/new exponent factors and incremented with the current `p·V` contribution, yielding a numerically stable streaming softmax. After traversing all tiles, the kernel divides by `l_i`, writes the attention output tile, and stores `log2(l_i)` for the backward pass.
