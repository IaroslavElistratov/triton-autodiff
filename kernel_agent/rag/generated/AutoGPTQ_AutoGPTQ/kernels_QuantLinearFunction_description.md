- kernel family: quantized linear matmul (AutoGPTQ fused decompression × GEMM)
- concise summary: The forward kernel tiles the activation matrix and quantized weights, decodes low-bit weight blocks with their per-group scales/zeros on the fly, and accumulates fp32 dot products into an fp16 output tile chosen by Triton autotuning.
- detailed summary: `quant_matmul_248_kernel` launches with program ids over `(M,N)` tiles grouped by `GROUP_SIZE_M`; for each `BLOCK_SIZE_K` slice it loads the activation tile `A`, looks up group indices `g_idx` for those K columns, fetches scale/zero vectors with strided addressing, and bit-unpacks the packed int32 weight block into signed deltas via shifts & masks (`shifter`, `maxq`). After subtracting the zero offsets (plus one) and scaling, it performs a `tl.dot` against the activation tile and accumulates into fp32 registers. The pointer arithmetic advances through the packed layout (`// infearure_per_bits`) so the kernel streams quantized weights without materializing them. The Python launcher chooses tile sizes through `custom_autotune`, allocates an fp16 output, and dispatches a grid sized by `ceil_div(M, BLOCK_SIZE_M) * ceil_div(N, BLOCK_SIZE_N)` using the provided strides, enabling reuse inside the AMP-decorated forward wrapper.
