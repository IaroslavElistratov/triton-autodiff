- kernel family: state-space chunk scan (chunked SSM forward propagation with optional gating)
- concise summary: First forms intra-chunk convolution kernels `CB = C @ B` with a tiled batched matmul, then scans each chunk to combine recurrent states, exponential decays, and input updates—optionally applying diagonal re-scaling `D` and SiLU gates `z`—to produce the streamed activations.
- detailed summary: `_bmm_chunk_fwd_kernel` tiles `(chunk_size × chunk_size)` blocks per batch/chunk (and group) and iterates over the feature dimension to accumulate `C·B`, honoring causal masks and optional `seq_idx` equality checks. `_chunk_scan_fwd_kernel` launches over `(chunk, row-tile, head)`; it loads cumulative decay values `dA_cumsum`, previous state matrices, and the precomputed `CB` tile, builds exponentiated scalers, and loops across the chunk to multiply decay-adjusted `CB` slices by `dt` coefficients and the current inputs `x`. When present, it adds diagonal corrections from `D` and stores the pre-gated activations to `out_x` before modulating by `z*σ(z)` and writing the final output. The Python forward wrapper ensures tensor layouts, computes `CB`, and invokes the two kernels so the state-space model can stream chunked sequences without materializing full-time-step loops on the host.
