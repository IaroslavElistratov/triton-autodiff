- kernel family: state-space chunk state update (chunked accumulation of B·x into latent states)
- concise summary: For every chunk and head, iteratively combines input slices with B kernels scaled by exponential decays `exp(dA)` and step sizes `dt` to produce updated state tensors, optionally masking by sequence ids.
- detailed summary: `_chunk_state_fwd_kernel` tiles the `(headdim × dstate)` output, loads `x` and `B` in `BLOCK_SIZE_K` strips, and multiplies each B panel by `exp(dA_last - dA_k) * dt_k`; sequence-aware runs zero tiles whose `seq_idx` differs from the last element in the chunk. The accumulated state block is stored into the `(batch, chunk, head, headdim, dstate)` buffer, with the grid arranged over `(chunk row tile, chunk index × batch, head)`. The Python forward helper allocates or reuses the state tensor (optionally in fp32), ensures contiguous layouts, and launches the autotuned kernel so chunked SSM layers can materialize the per-chunk carry states needed by later scans.
