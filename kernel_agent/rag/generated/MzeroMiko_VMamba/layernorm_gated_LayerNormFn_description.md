- kernel family: gated layer normalization (grouped LN / RMSNorm with optional SiLU gate)
- concise summary: Normalizes each row in `group_size` slices, optionally multiplies by a learned gate `z*sigmoid(z)` either before or after normalization, and emits affine-scaled outputs with saved statistics.
- detailed summary: The Triton kernel is launched over `(row, group)` so each program handles one contiguous group of features; it loads the slice, applies an optional gate in the pre-norm branch by folding `z*σ(z)` into the activations, computes mean/variance (or skips the mean for RMS mode), and writes the normalized-and-scaled values. If gating is configured post-norm, it instead multiplies the affine output by `z*σ(z)` right before storing. The host wrapper reshapes the tensor to `(M,N)`, enforces divisibility by `group_size`, allocates output/mean/rstd buffers per group, selects a power-of-two `BLOCK_N`, and launches the kernel with the user-specified `norm_before_gate` behavior so downstream stages can reuse the recorded normalization statistics.
