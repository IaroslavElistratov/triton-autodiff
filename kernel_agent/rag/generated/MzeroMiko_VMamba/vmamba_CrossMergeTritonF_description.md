- kernel family: spatial cross merge (directional aggregation with configurable scan patterns)
- concise summary: Processes the directional scan outputs in BH×BW×BC tiles, uses routing tables determined by `scans` to map four directions per pixel, and sums them into the merged representation respecting channel layout choices.
- detailed summary: Within each program the helper `triton_cross_scan_flex` computes routing indices (including the extra bidirectional pattern when `scans==3`), builds pointers that honor channel-first/last layouts and `onebyone` packing, and iterates over the channel subset to either copy inputs to four directional buffers or—when `operation=1` as in forward—load the four directional tensors and accumulate them into the output tile. The host forward wrapper selects tile geometry (`BC=1`, `BH=BW=32`), allocates the destination tensor in the requested layout, and launches the kernel over `(NH*NW, NC, B)` so each tile reduces its four directional paths into the merged VMamba feature map.
