- kernel family: layer normalization + linear projection (single-pass Triton LN feeding fused matmul)
- concise summary: Runs the configurable one-pass LayerNorm kernel to normalize rows with optional residual/dropout handling, then immediately applies a dense projection in the requested dtype to emit the final activations.
- detailed summary: The Triton kernel mirrors the flexible LayerNorm variant—each program processes one row, mixes optional residual or parallel streams, performs dropout via Philox-seeded masks, computes mean/variance (or RMS), and writes normalized outputs plus saved mean/rstd. The forward wrapper reshapes inputs, ensures contiguous strides, invokes the kernel to produce `y`, upsamples weights to the autocast dtype when needed, and finishes by calling `F.linear(y, linear_weight, linear_bias)` so the normalization and projection behave as a fused block; it also saves the normalized buffer and statistics so downstream steps can reuse them without recomputation.
