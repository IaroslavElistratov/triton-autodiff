- kernel family: state propagation (chunk-to-chunk exponential carry update)
- concise summary: Iteratively propagates latent states across chunks by exponentiating per-chunk decay scalars `exp(dA)` and optionally injecting initial states or resetting where sequence ids change, returning both intermediate states and the final carry.
- detailed summary: `_state_passing_fwd_kernel` tiles the state dimension, initializes each threadblock either from `initial_states` or zeros, then loops over `nchunks`: it loads the next chunk’s state contribution, multiplies the running state by `exp(dA_chunk)` (dropping it when `seq_idx` indicates a discontinuity), adds the new chunk state, and writes either the intermediate result or the final carry on the last step. The host helper allocates the `(batch, nchunks, nheads, dim)` output, computes launch dimensions, and dispatches the autotuned kernel, which supplies both the per-chunk propagated states and the terminal `(batch, nheads, dim)` state tensor consumed by downstream scan kernels.
