- kernel family: spatial cross-scan merge (directional feature aggregation)
- concise summary: Traverses the feature map in BH×BW tiles, maps each pixel to up to four directional scan routes, and for the merge configuration used in forward sums the routed values into a consolidated output tensor layout.
- detailed summary: Each program enumerates a `(h,w)` tile and a channel slab, constructs index routes (`HWRoute0-3`) that depend on the requested scan pattern (full criss-cross, shared, or mirrored), and builds per-direction pointers respecting whether tensors are channel-first or last. With `operation=1` and `onebyone=0`, it loads the four directional responses from the input tensor, applies edge masks for incomplete tiles, and writes the sum back to the destination layout; alternative branches support copying without reduction or operating on packed four-way tensors. The host forward configures the tile sizes (BC=1, BH=BW=32), computes grid dimensions from `(B,C,H,W)`, allocates the appropriately ordered output buffer, and launches the kernel to produce the merged representation.
