- kernel family: spatial cross scan (directional feature decomposition)
- concise summary: Launches one program per `(tile, channel-slab, batch)` to gather the input feature map into four directional stacks, with configurable scan patterns covering forward, shared, mirrored, or bidirectional routings.
- detailed summary: `triton_cross_scan_flex` computes tile-level routing indices for the chosen `scans` mode (including the four-way pattern when `scans==3`), builds pointers for channel-first/last layouts and optional `onebyone` packing, then—under `operation=0` for the forward path—copies each source pixel into its four routed destinations while honoring boundary masks. The host wrapper determines tile counts (`BH=BW=32`, `BC=1`), allocates the 4-direction output tensor in the requested layout, and dispatches the kernel so every tile exports its directional features that downstream merge kernels can recombine.
