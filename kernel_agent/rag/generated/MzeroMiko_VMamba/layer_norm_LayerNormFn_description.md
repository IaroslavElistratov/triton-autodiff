- kernel family: layer normalization (configurable Triton single-pass variant with residual/dropout options)
- concise summary: Processes one row per program, optionally mixes in residual streams, applies dropout and row-wise scaling, computes either LN or RMSNorm statistics, and writes up to two affine-projected outputs along with saved mean/rstd buffers.
- detailed summary: The `_layer_norm_fwd_1pass_kernel` loads a `BLOCK_N` slice of the row, scales it by `rowscale`, applies dropout driven by per-row Philox seeds, and sums auxiliary streams (`residual`, optional parallel `x1`). Depending on flags it stores the fused residual, computes the mean/variance (skipping the mean for RMS mode), derives `rstd`, and normalizes to produce the main output and an optional secondary head `(weight1,bias1)` without leaving float32 scope. The host helper reshapes tensors to `(M,N)`, enforces contiguous strides, allocates residual/dropout buffers when needed, seeds RNG state, chooses a power-of-two `BLOCK_N`, and launches the autotuned kernel, returning the normalized outputs plus any requested masks or residual copies for later stages.
