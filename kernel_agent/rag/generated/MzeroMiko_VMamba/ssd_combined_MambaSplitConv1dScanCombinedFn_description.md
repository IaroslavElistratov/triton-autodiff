- kernel family: Mamba split-conv + chunk scan (conv-preprocessed SSM with optional RMS gating)
- concise summary: Splits the packed input into gating, convolutional, and state parameters, runs a causal 1-D convolution to build `B`/`C`/`x`, then feeds the resulting tensors through the chunked SSM pipeline, finishing with either SiLU gating or an RMSNorm gating branch and an optional linear projection.
- detailed summary: The forward pass first unpacks `zxbcdt` into non-SSM features, gates, chunk parameters, and per-head `dt`; it applies `causal_conv1d_cuda.causal_conv1d_fwd` to the `xBC` slice and reshapes the result into head-major tensors `x`, `B`, and `C`. It then invokes `_mamba_chunk_scan_combined_fwd`, which internally computes chunkwise decays `dA_cumsum`, propagates states, forms `CB = C @ B`, and runs the Triton scan to produce both pre-gated activations `out_x` and final outputs. When `rmsnorm_weight` is absent, the model applies SiLU gating directly (possibly concatenating non-SSM channels); otherwise it reuses `out_x` and `z` to execute a grouped RMSNorm/SiLU gating via `_layer_norm_fwd` before recombining the auxiliary channels. An optional output projection (`F.linear`) completes the block, while context saves the intermediate tensors and optionally returns the final recurrent states.
