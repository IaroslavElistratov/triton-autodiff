- kernel family: state-space chunked scan (end-to-end Triton pipeline for Mamba forward pass)
- concise summary: Builds chunked transition kernels, exponentiated decay tables, and propagated states in Triton before streaming each chunk’s inputs through the scan, optionally applying diagonal factors `D` and gating `z`.
- detailed summary: The pipeline starts with `_chunk_cumsum_fwd_kernel`, which tiles `(chunk_size × BLOCK_SIZE_H)` regions to apply bias/softplus to `dt`, clamp it, and accumulate `dA_cumsum` alongside the rescaled `dt_out`. `_state_passing_fwd_kernel` then marches chunk states forward: it multiplies per-chunk states by `exp(dA_chunk)` while integrating optional initial states and sequence-id resets, returning both the chunked state tensor and the final state. Next, `_bmm_chunk_fwd_kernel` forms the intra-chunk convolution blocks `CB = C @ B` with optional causal masking and sequence-id filtering. Finally, `_chunk_scan_fwd_kernel` (shared with the standalone scan) iterates over `(chunk,row-tile,head)` to combine `CB`, the per-step `dt`/`dA` factors, and the propagated states; it accumulates activations, adds diagonal corrections from `D`, caches the pre-gated output in `out_x`, and if `z` is provided multiplies by `z·σ(z)` before writing `out`. The Python forward wrapper orchestrates these stages, handles contiguity, stores saved tensors, and optionally returns the terminal states for recurrent use.
