- kernel family: spatial cross-scan (directional feature extraction)
- concise summary: Tiles the feature map and redistributes each pixel into up to four directional scan buffers, producing the 4-way representation consumed by the cross-merge stage.
- detailed summary: The Triton kernel enumerates `(h,w)` tiles and channel stripes, constructs forward/backward index routes based on the requested `scans` mode, and prepares per-direction pointers that respect channel-first or channel-last layouts. With `operation=0` it copies each source activation into four routed destinations (or a single route when the scan mode collapses them) while honoring `one_by_one` packing and boundary masks for incomplete tiles. The host forward computes tile counts (`BH=BW=32`, `BC=1`), allocates the 4-branch output tensor in the desired layout, and launches the kernel so every program populates its directional slice of the output grid.
