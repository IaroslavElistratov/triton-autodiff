- kernel family: attention (FlashAttention-style block streaming with optional bias, causal masking, and partial accumulation for ring all-reduce)
- concise summary: Processes tiles of queries against key/value blocks, maintains running max/sum statistics for numerical stability, optionally incorporates precomputed bias and soft-clamping, and writes either normalized outputs or accumulated numerators/log-sum-exp so that ring-partitioned stages can merge results.
- detailed summary: `_fwd_kernel` maps each program to a `(block of queries, head)` pair. It loads the query tile, iterates over key/value blocks (bounded by causality when requested), forms `qk` via block matrix multiply, optionally adds bias/softclamp, updates the running maximum `m_i` and denominator `lse_i`, rescales the existing output accumulator, and multiplies by the corresponding value block before adding to `acc_o`. Flags control whether previously accumulated numerators are loaded (`LOAD_ACCUMULATED`), whether to normalize the output immediately or defer by storing `m_i`, and whether to emit a parallel “sliding” pass. After the loop the kernel writes the updated log-sum-exp buffer and either the normalized output or the unnormalized accumulator, enabling the ring-attention algorithm to aggregate contributions across devices.
