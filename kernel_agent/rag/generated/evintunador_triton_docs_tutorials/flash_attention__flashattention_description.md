- kernel family: attention (FlashAttention-style causal softmax)
- concise summary: The forward Triton kernel tiles the query dimension, streams over key/value blocks twice (strictly lower then diagonal), and maintains running log-sum-exp statistics so it can write softmax-normalized outputs and log-sum-exp caches without materializing the full attention matrix.
- detailed summary: `attn_fwd` launches with grid `(ceil(N/BLOCK_SIZE_QO), B·H)` and, for each tile, loads its query block and initializes `M` and `L` (the running max and denominator). The helper `_attn_fwd_inner` loops over key/value panels of size `BLOCK_SIZE_KV`, applying the causal mask when `DIAGONAL=True` so the two passes cover below-diagonal and on-diagonal regions separately. Within the loop the kernel loads Kᵀ and V, forms scaled dot products, updates the running max and denominator using base-2 exponentials (`exp2`), rescales the partial output `O`, and accumulates the weighted V contributions. After both passes it normalizes `O` by `L`, computes the log-sum-exp cache `M + log₂ L`, and stores both the output tile and cache back to memory. The Python wrapper enforces contiguous fp32 tensors with head size ≤128, allocates the output and LSE buffers, and launches the autotuned kernel with the provided scale.
