- kernel family: normalization (tutorial-style layer norm)
- concise summary: A single Triton program handles one row, streaming over the feature dimension three times to compute the mean, variance, and final affine transform using per-element weights and biases.
- detailed summary: `_layernorm_forward` iterates over the row in `BLOCK_SIZE` chunks: the first sweep accumulates the fp32 sum to form the mean, the second recomputes the variance via `(x-mean)²`, and the third loads the weights, bias, and original values to produce `(x-mean)/sqrt(var+eps)` scaled by `w` and shifted by `b`. Mean and inverse std are written to auxiliary buffers for backward. The Python wrapper flattens the leading dimensions, selects a power-of-two block size not exceeding 64KB divided by the element size, launches the kernel with one program per row, and saves the intermediate statistics for the backward pass.
