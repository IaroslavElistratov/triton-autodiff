- kernel family: quantized linear (AWQ 4-bit weight matmul)
- concise summary: The forward path either fully dequantizes the packed 4-bit weights and performs a dense FP16 GEMM, or—when the heuristics favor it—launches the Triton AWQ GEMM that unpacks 4-bit blocks on the fly while applying per-group scales and zero points.
- detailed summary: `WQLinearMMFunction.forward` converts the activation matrix to FP16 and, when the custom CUDA extension is present, chooses between two routes: for large workloads it invokes `dequantize_weights_cuda` (or the Triton `awq_dequantize_triton` fallback) to expand the packed weights to FP16 and calls `torch.matmul`; otherwise it dispatches the fused AWQ GEMM (either via the extension or `awq_gemm_triton`) which keeps the weights in their packed form, unpacks 8 values per byte using the interleaving pattern from `reverse_awq_order_tensor`, applies the per-group zero offsets and scales, and accumulates FP32 partial sums before writing the result. The helper kernels (`awq_dequantize_kernel`, `awq_gemm_kernel`) implement those two pathways, making the wrapper’s decision strictly about performance heuristics rather than correctness differences.
