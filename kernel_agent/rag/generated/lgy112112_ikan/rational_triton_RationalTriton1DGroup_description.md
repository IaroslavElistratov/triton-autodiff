- kernel family: grouped rational activation (1D feature axis)
- concise summary: The kernel applies a 5th-degree numerator over a 4th-degree denominator rational function to every element along the feature dimension, selecting coefficients by channel group before storing the transformed output.
- detailed summary: `rational_fwd_kernel` launches a 1D grid over flattened elements, maps each offset to its channel index `d_index`, and derives the group ID so it can pull the appropriate six numerator (`a_ptr`) and four denominator (`b_ptr`) coefficients. Using Horner-form FMA sequences, it evaluates the numerator `P(x)` and denominator `Q(|x|)`—the latter enforcing non-negativity by taking absolute values of both `x` and the `b` coefficients—then divides and writes the result with masking for partial tiles. The helper `rational_fwd_triton` allocates the destination tensor, computes `BLOCK_SIZE=256` tiling, and dispatches the Triton kernel across the flattened batch×sequence extent.
