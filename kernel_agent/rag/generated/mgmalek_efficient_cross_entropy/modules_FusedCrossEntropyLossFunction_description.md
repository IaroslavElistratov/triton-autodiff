- kernel family: Cross-entropy with fused logit gradient (classification loss)
- concise summary: For each token, the Triton kernel performs a numerically stable log-softmax against the target index, writes the scalar loss (respecting `ignore_index` and reduction divisor), and emits the corresponding gradient with respect to logits.
- detailed summary: `fused_cross_entropy_fwd_bwd_kernel` runs with one program per token; it loads the logit row, subtracts the row maximum, exponentiates to compute the partition function, gathers the ground-truth logit via an equality check against the column offsets, and forms the loss `log_sum_exp - logit_target` divided by the provided `divisor`. When the label matches `ignore_index`, both loss and gradients are zeroed. The kernel simultaneously constructs a one-hot mask for the target, converts the softmax probabilities into logit gradients `(p - y_one_hot) / divisor`, and stores this vector back under a tail mask. On the Python side, `_FusedCrossEntropyLossFunction_forward` splits the input embeddings into batches (`n_loop_iters` chunks), materializes logits via a GEMM with `proj_weight`, and reuses the logits buffer as workspace for gradients so the fused kernel can be invoked chunk by chunk. After each chunk, it optionally accumulates `grad_in_feat` and `grad_proj_weight` via matrix products when those gradients are needed, finally summing the per-token losses to return a scalar.
