- kernel family: classification loss (chunked cross-entropy with optional softcapping and logit scaling)
- concise summary: Chooses between a single-pass or chunked Triton kernel to compute log-sum-exp over the vocabulary, subtracts the target logit (honoring `ignore_index`), and writes per-sample losses while caching the log-sum-exp values for backward use.
- detailed summary: `_Fast_CrossEntropyLoss_forward` inspects the vocabulary size; if it exceeds the `MAX_FUSED_SIZE` or must be split for HIP targets, it launches `_chunked_cross_entropy_forward`, otherwise it uses `_cross_entropy_forward`. Both kernels operate per row: they load a block of logits, optionally apply softcapping (`SOFTCAP * tanh(logit/SOFTCAP)`) and/or scaling, compute a numerically stable log-sum-exp, and write it to a dedicated buffer. The chunked variant emits partial LSEs per chunk, which the host later `logsumexp`s together before finishing the loss reduction. When the true label lies in the processed block, the kernel subtracts the logit (with smoothing/scaling adjustments) to form the negative log-likelihood; rows with `label == -100` are zeroed. The forward returns the loss tensor (and stores logits/LSE/labels for the backward kernel that constructs gradients via softmax probabilities).
