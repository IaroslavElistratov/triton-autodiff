- kernel family: low-rank adaptation (LoRA update fused with optional FP8 weight dequantization)
- concise summary: Flattens the input if needed, optionally dequantizes an FP8 or compressed weight matrix, performs the base matrix multiply, and then adds a rank-`A·B` LoRA update scaled by `S`, returning the combined result in the original shape.
- detailed summary: `_LoRA_W_forward` calls `matmul_lora`, which first reshapes `(batch, seq, hidden)` inputs to 2D batches when necessary. If the main weight `W` is stored in FP8, it routes through `fp8_linear` (either fbgemm-style or block quant) using the supplied `weight_scale`; otherwise it invokes `fast_dequantize` to recover BF16/FP16 weights (or falls back to a direct matmul if already dense). After computing `X @ W`, it checks whether LoRA factors `A` and `B` are provided: if so, it multiplies `X` by `A`, multiplies the result by `B`, and accumulates the scaled update via `out.addmm_(XA, B, alpha=s)`. The function restores the original tensor shape before returning, while caching `W`, quantization metadata, `S`, and the LoRA factors for the backward pass.
