- kernel family: layer normalization (per-row Triton kernel with cached stats)
- concise summary: The forward reshapes the input to 2D, launches a Triton kernel that computes rowwise mean/variance, applies scale and bias, and stores the reciprocal std and mean for reuse in the backward pass.
- detailed summary: `_Fast_Layernorm_forward` flattens the trailing dimension, selects a power-of-two tile size via `calculate_settings`, and allocates fp32 buffers `r` (inverse std) and `mu` (mean). `layernorm_forward` then loads the row, computes the average and variance, writes `inv_var` and `mean` to the side buffers, and emits `(x - mean) * inv_var * W + b`. The backward function simply relaunches `layernorm_backward`, which recomputes the normalized activations from the saved `X`, `mu`, and `r`, multiplies by `W`, and applies the standard layer-norm backward formulas to produce `dX`; gradients for `W` and `b` are not formed in this implementation.
