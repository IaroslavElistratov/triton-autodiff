- kernel family: FP8 block-quantized linear (activation quantization + pre-quantized weight matmul)
- concise summary: Forward quantizes the activation matrix in 1D blocks to FP8 using per-block max-based scales, then dispatches a specialized FP8 block matmul alongside stored weight scales to produce the output in the original dtype.
- detailed summary: `act_quant` enforces contiguity, partitions the last dimension into `BLOCK_SIZE` chunks, and launches `act_quant_kernel`, which records each block’s max-abs value, derives an FP8 scale (`max/448`), rescales the floating activations into the FP8 E4M3 range, and writes both the quantized values and their scale factors. `_FP8BlockQuantLinear_forward` retrieves the `(m,n)` weight shape, infers the 2D block size metadata (swapping the scale matrix if necessary), quantizes the input via `act_quant`, and then calls `fp8_block_matmul` with the quantized activations, FP8 weight tiles, and their respective scales to accumulate FP32 results before casting back to the input dtype. During backward the helper `weight_dequant` (with a Triton `weight_dequant_kernel` for block granularity) reconstructs FP16/BF16 weights so that the gradient w.r.t. inputs can be computed with a standard matrix multiply; gradients w.r.t. weights/scales are not produced in this path.
