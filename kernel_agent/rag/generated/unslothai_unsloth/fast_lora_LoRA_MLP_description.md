- kernel family: low-rank adaptation (LoRA-enabled gated MLP block)
- concise summary: Computes the gating and up-projection branches via `matmul_lora` (handling FP8 or dequantized weights plus optional LoRA updates), applies a supplied nonlinearity on the two results, and sends the activated vector through a LoRA-augmented down projection.
- detailed summary: `_LoRA_MLP_forward` leverages `matmul_lora` three times—first for the gate weights (`gateW`, etc.), then for the up projection (`upW`, …), and finally for the down projection. Each call flattens `(batch, seq, hidden)` inputs if necessary, dequantizes FP8 weights or reconstructs them from NF4 quant states, performs the base matmul, and adds a low-rank `A @ B` update scaled by the corresponding `S`. After generating the gate tensor `e` and the up tensor `g`, the function evaluates `_forward_function(e, g)` (e.g., SiLU or Swish gating), then projects the result with the down branch. Helper utilities such as `torch_matmul`, `fast_dequantize`, and the quantization wrappers are defined elsewhere in the module tree, so the extracted forward kernel assumes those symbols are available at import time. All LoRA weights, quant states, and the backward helper are saved on the context so gradients can reuse the same dequantization logic during backprop.
