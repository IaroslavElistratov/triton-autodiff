- kernel family: low-rank adaptation (LoRA projection for Q/K/V with optional FP8 weights)
- concise summary: Reuses the LoRA matmul helper to generate Q, K, and V projections from the same input—each path optionally dequantizing FP8 weights and adding rank-reduced updates—then returns the three tensors (optionally in-place).
- detailed summary: `_LoRA_QKV_forward` simply calls `matmul_lora` three times, once for each parameter set `(QW, QA, QB, QS)`, `(KW, KA, KB, KS)`, and `(VW, VA, VB, VS)`. Inside `matmul_lora`, the input is reshaped to 2D if necessary, the base weight matrix is either processed through `fp8_linear` (with fbgemm or block quant) or dequantized to BF16/FP16 via `fast_dequantize`, and the core matmul `X @ W` is performed. If LoRA factors are provided, the function multiplies `X` by `A`, then by `B`, accumulating the scaled update with `alpha=s`. Outputs are reshaped back to match the original `(batch, seq, hidden)` layout. The forward caches all weights, quant states, and LoRA scaling factors so the backward pass can recompute gradients without re-dequantizing.
