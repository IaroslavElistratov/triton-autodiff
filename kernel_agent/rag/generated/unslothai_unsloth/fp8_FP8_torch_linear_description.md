- kernel family: FP8 block matmul (PyTorch/FBGEMM path)
- concise summary: The forward path reshapes the input to 2D, quantizes it to FP8 with `triton_quantize_fp8_block`, and calls FBGEMM’s `f8f8bf16_blockwise` kernel with prequantized weights and scales before restoring the original output shape and optional bias.
- detailed summary: `_FP8_torch_linear_forward` derives the FP8 tile sizes from `weight`/`weight_scale` metadata, verifying that the stored scale matrix matches the tiling (and transposing it if needed). It flattens the batch, quantizes the activation matrix via `triton_quantize_fp8_block` (returning quantized activations `xq` and per-block scales `xs`), then invokes `torch.ops.fbgemm.f8f8bf16_blockwise`, which performs the GEMM using the quantized activations, quantized weights, activation scales, and weight scales, accumulating in BF16/FP32 before casting to the input dtype and adding the bias when provided. The output is finally reshaped back to the original batch structure. Gradients reuse the same `weight_dequant` helper as other FP8 modules to reconstruct FP16/BF16 weights so input gradients can be computed with a dense matmul; weight/scales gradients are not produced.
