- kernel family: FP8 linear (rowwise FBGEMM path with optional dequant fallback)
- concise summary: The forward checks whether the provided weight scales align with the FP8 row layout; if so, it quantizes the flattened input per row via `torch.ops.fbgemm.quantize_fp8_per_row` and runs `f8f8bf16_rowwise`, otherwise it dequantizes the weights and falls back to a dense matmul.
- detailed summary: `_FbgemmFp8Linear_forward` first validates the relationship between `weight` and `weight_scale`. When the scale matrix matches the row count, it flattens the batch, quantizes each row of `x` to FP8 along with a per-row scale, ensures the weight/scales are contiguous, and invokes FBGEMM’s rowwise FP8 matmul (accumulating in BF16) before adding the bias, casting to the original dtype, and reshaping to the batch layout. If the scales were stored transposed (or incompatible), it dequantizes the FP8 weight blocks via `weight_dequant`/`weight_dequant_block` and performs a conventional matmul instead. Gradients only reconstruct FP16/BF16 weights for the input-gradient computation; weight and scale gradients are not formed.
