- kernel family: landmark attention (flash kernel with per-block prefix landmarks)
- concise summary: Computes causal landmark attention by mixing local query-key scores with per-block landmark tokens, keeping numerically stable running maxima and sums while accumulating the value-weighted outputs tile by tile.
- detailed summary: Each program handles one (batch, head) pair and a BLOCK-sized query tile, loading contiguous Q/K/V chunks and maintaining log-sum-exp state (`m_prev`, `l_prev`) plus an accumulator for the output tile. It loops over prefix blocks that include a dedicated landmark column, extracting the landmark logits, rescaling historical contributions, and blending normalized non-landmark weights with V to update the accumulator before advancing. The final block executes a standard causal softmax over the active keys, again renormalizing with the stored max/sum vectors, and writes both the BLOCK × d_model output tile and the updated log-normalizer buffers `L` and `M` used downstream.
