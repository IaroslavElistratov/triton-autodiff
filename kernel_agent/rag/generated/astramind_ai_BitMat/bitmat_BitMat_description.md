- kernel family: ternary linear matmul (int8 activations × packed ternary weights)
- concise summary: Unpacks packed ternary weights in 2-bit groups, restores their signed values, and performs a tiled int8×ternary matrix multiply that feeds BitMat’s quantized forward path.
- detailed summary: `_ternary_mm_kernel` assigns each program a `(BLOCK_SIZE_M × BLOCK_SIZE_N)` output tile, walks across the K dimension in `BLOCK_SIZE_K` chunks, and loads contiguous int8 activation tiles alongside packed weight tiles. Within the loop it right-shifts each weight column by the appropriate 2-bit offset, maps the ternary codes `{00,01,10}` back to `{0,1,-1}`, casts to the activation dtype, and accumulates `tl.dot` results in float32. After visiting all K slices it writes the tile to the output matrix (respecting row/col masks), and the Python `bitmat_` wrapper handles reshaping, autotuned launch parameters, and quantization scales so BitMat’s forward pass can reuse the kernel for ternary GEMM.
