- kernel family: RMS normalization (Triton single-pass row kernel with optional Gemma-style gain)
- concise summary: Flattens the input to 2‑D, chooses a power-of-two block size per feature width, and launches a Triton kernel that computes row-wise RMS statistics, applies learned weights (optionally `(w+1)` for Gemma), and records the inverse norms for reuse in backward.
- detailed summary: `_Fast_RMS_Layernorm_forward` reshapes the tensor to `(rows, dim)`, derives an autotuned `BLOCK_SIZE`/`num_warps`, and dispatches either `_rms_layernorm_forward` or `_gemma_rms_layernorm_forward`. Those kernels read a row, accumulate `mean(x²)` in FP32, form `inv_rms = 1/sqrt(mean + eps)`, multiply the normalized values by `W` (or `W+1` in Gemma mode), and write the result to `Y` while storing `inv_rms` in the `r` buffer. The saved `r` is later consumed by the backward kernel to avoid recomputing statistics, enabling a fast RMSNorm implementation tailored to ternary BitMat blocks.
