- kernel family: normalization (layer norm with Welford reduction)
- concise summary: Flattens the normalized axes, chooses a Triton tile size, and launches a fused kernel that computes mean/variance via Welford updates before applying the affine transform, caching statistics for the PyTorch-backed backward path.
- detailed summary: `_LayerNorm_forward` reshapes the input to `(rows, N)`, ensures weight/bias are contiguous, and allocates optional `mean`/`rstd` buffers when gradients are needed. It selects `BLOCK_SIZE = min(64KB limit, next_pow2(N))`, enforces the 64KB feature cap, and dispatches `_layer_norm_fwd_fused` with one program per row. The Triton kernel iterates over the feature dimension in `BLOCK_SIZE` chunks when necessary, using `welford_combine` to maintain streaming mean, second moment, and sample count; once the statistics stabilize it computes `rstd = 1/sqrt(var+eps)`, optionally stores the per-row stats, and replays the same tiles to normalize `(x-mean)*rstd`, multiply by `weight` (if provided), and add `bias`. After reshaping the result back to the original shape, the forward saves `x`, `weight`, `bias`, and the cached statistics so the backward simply delegates to `aten.native_layer_norm_backward`.
