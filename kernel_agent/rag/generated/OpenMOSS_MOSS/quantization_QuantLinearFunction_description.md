- kernel family: quantized linear matmul (dequantize-and-dot for 2/4/8-bit weights)
- concise summary: Tiles the input activations and packed weight rows, unpacks low-bit groups via per-group indices, applies scales/zero points, and accumulates a float32 matmul before writing the fp16 output.
- detailed summary: `matmul_248_kernel` assigns each program a `(BLOCK_SIZE_M × BLOCK_SIZE_N)` tile, iterates over `BLOCK_SIZE_K` slices, and uses `g_idx` to fetch the correct scale and zero-point entries for the current weight sub-block. For each fragment it right-shifts the packed weight integers to extract `bits`-wide values, subtracts the stored zero offsets (plus one), multiplies by the scale, and runs a tensor dot against the fp16 activation tile, accumulating in float32. The host wrapper `matmul248` chooses the autotuned launch grid, executes the kernel, and returns the fp16 result, which the forward path caches alongside the quantization metadata for reuse during the transpose matmul in backward.
