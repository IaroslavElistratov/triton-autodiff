- kernel family: cross-entropy loss (token-wise Triton implementation with optional softcapping, label smoothing, and z-loss)
- concise summary: Each program processes one `(batch,time)` row, performs a log-sum-exp reduction over the vocabulary with optional logit softcapping, incorporates label smoothing and per-class weighting, writes normalized gradients back into the logits buffer, and accumulates the per-row loss and optional z-loss before reducing them on the host.
- detailed summary: The `liger_cross_entropy_kernel` loops over the vocabulary in `BLOCK_SIZE` chunks, first building a numerically-stable running maximum/sum for `logsumexp`, tracking extra terms for label smoothing and class weights. After computing the log-partition, it replays the tiles to form the softmax probabilities, adjusts the true-class probability by `(1 - label_smoothing)`, adds the label-smoothing and `lse_square_scale` penalties, and, if weights are supplied, scales by the class and total weights. The kernel overwrites the input tile with the per-logit loss gradients (including the derivative of the softcap when active), writes the scalar loss (and optionally the z-loss) to row-specific buffers, and honors `ignore_index` by zeroing the gradient tile early. The `cross_entropy_forward` launcher prepares contiguous inputs, obtains per-row statistics such as the count/sum of non-ignored weights, and dispatches one Triton program per row to compute and optionally reduce the losses on the host side.
