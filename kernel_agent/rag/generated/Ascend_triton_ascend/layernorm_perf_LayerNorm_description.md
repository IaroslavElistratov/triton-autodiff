- kernel family: layer normalization (Ascend fused per-row pass on dense activations)
- concise summary: Each program owns a block of rows, streams across the feature dimension twice to accumulate the row mean/variance in fp32, then normalizes and affine-transforms the inputs while writing mean and inverse std buffers for reuse later.
- detailed summary: The `_layer_norm_fwd_fused` Triton kernel launches one program per `RBLOCK_SIZE` rows; within each row tile it strides the feature axis in `XBLOCK_SIZE` chunks. It first sums the loaded fp32 values to form a per-row mean, then replays the same tiling to compute the centered squared sum for the variance. After computing `rstd`, it stores both `mean` and `rstd` to global memory. A third pass streams the row again, loads the affine weights/bias, forms the normalized outputs, and writes them to the output tensor. Shape guards on row/column masks handle partial tiles so the kernel supports arbitrary sequence length, and the forward launcher reshapes the input into 2-D `[M, N]` tiles, configures the grid as `(ceil_div(M, RBLOCK_SIZE),)`, and keeps the kernel handle warmed for repeated launches.
