- kernel family: rotary position embedding
- concise summary: Tiled across tokens and head dimensions, the Triton kernel loads sin/cos tables and rotates the first `rotary_dim` features of each query/key vector, supporting interleaved layouts, variable-length batches, and optional conjugation.
- detailed summary: `rotary_kernel` maps program IDs to `(token-block, batch, head)` slices, computes absolute indices using scalar or tensor offsets (or `cu_seqlens` for packed sequences), and gathers the appropriate sin/cos pairs. Depending on the `interleaved` flag it either works on even/odd pairs or contiguous halves, performing the complex rotation in FP32 before writing the results and leaving any tail channels untouched. The high-level `apply_rotary` helper wraps tensor reshaping, selects BLOCK_K/M from `rotary_dim`, and dispatches the kernel for in-place or out-of-place updates.
