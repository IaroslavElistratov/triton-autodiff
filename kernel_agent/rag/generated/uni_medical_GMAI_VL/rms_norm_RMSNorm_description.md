- kernel family: normalization (RMSNorm)
- concise summary: A fused Triton kernel walks the feature dimension in BLOCK_SIZE tiles, accumulates squared activations to compute the row-wise RMS, and immediately rescales by the learned weights to produce the normalized output.
- detailed summary: `_rms_norm_fwd_fused` assigns one program per row; it loops over BLOCK_SIZE chunks to accumulate `∑x²`, derives `rstd = 1/√(var+eps)`, writes the rstd buffer, and then replays the loop to load both the input and weight tiles, multiply by `rstd`, and store the weighted results. The wrapper reshapes arbitrary batches into 2D, chooses a power-of-two tile not exceeding 64 KB of feature data, allocates the rstd vector, and dispatches the fused kernel to deliver the RMS-normalized tensor.
