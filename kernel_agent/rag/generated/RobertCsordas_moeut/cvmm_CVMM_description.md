- kernel family: sparse matmul routing (conditional VM multiplication)
- concise summary: Wraps a Triton CVMM kernel that multiplies input vectors against expert key matrices according to `sel_index`/`sel`, producing routed outputs in the requested dtype and optionally collapsing grouped results with `reduction_weight`.
- detailed summary: The forward path records all tensors for backward, infers the compute dtype from autocast, materializes a default `out_index = -1` when scatter locations are not provided, then invokes `cvmm_triton_call`—a fused GPU routine that uses the selection indices to gather the appropriate blocks of `keys` and apply them to the flattened input `x`, scattering the products either densely or into the supplied `out_index` layout. After the kernel returns, the wrapper reshapes the per-selection outputs and, when `reduction_weight` is supplied, performs a final weighted reduction over the grouped dimension before handing the result back while keeping the backward metadata.
