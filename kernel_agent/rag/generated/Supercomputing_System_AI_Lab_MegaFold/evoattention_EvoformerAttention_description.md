- kernel family: Evoformer attention (pair-biased residue-aware softmax attention for MSA sequences)
- concise summary: The forward pass tiles Q/K/V along sequence and head dimensions, fusing pair bias and residue mask additions before performing numerically stable softmax to produce transposed attention outputs and per-query log-sum-exp statistics.
- detailed summary: Q, K, and V are first transposed into (batch, msa, head, seq, dim) layout, then `_attn_fwd` launches a 2D grid where each program instance owns a BLOCK_SIZE_Q slice of queries for one (batch, msa, head). Within `_attn_fwd_inner`, the kernel scales queries, streams over key/value tiles of size BLOCK_SIZE_KV, loads pair bias and residue mask tiles with masking for uneven tails, forms QK scores, and applies a log-sum-exp update that tracks running maxima (`m_i`) and sums (`l_i`) to stabilize the exponential weights. Each iteration multiplies the probabilities with the V tile to accumulate an FP32 output buffer that is normalized by `l_i` after the loop and cast back to the output dtype before storing to global memory along with the per-query `m_i`. Launch parameters adapt to HIP targets by tuning waves per EU, and `BLOCK_DIM` is promoted to the next power-of-two so dot products stay vectorized even for ragged dimension tails.
