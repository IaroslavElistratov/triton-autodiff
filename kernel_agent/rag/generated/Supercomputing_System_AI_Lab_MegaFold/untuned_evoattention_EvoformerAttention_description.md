- kernel family: Evoformer attention (autotuned pair-biased softmax attention for MSA)
- concise summary: The forward path autotunes tile sizes while looping over key/value tiles to accumulate numerically stable attention outputs that incorporate pair biases and residue masks.
- detailed summary: `_attn_fwd` is decorated with an autotune sweep across BLOCK_SIZE_Q/BLOCK_SIZE_KV, stage counts, and warp counts; per launch it receives Q/K/V transposed into (batch, msa, head, seq, dim) and carves the grid so each program handles one query tile for a fixed (batch, msa, head). Inside `_attn_fwd_inner`, the kernel scales query vectors, streams over K/V tiles, loads the matching pair-bias and residue-mask panels with tail masking when sequence or head dimensions are uneven, and performs a log-sum-exp reduction that updates running max (`m_i`) and normalization factors (`l_i`) to keep the exponential weights stable. Each iteration uses FP32 accumulation of `P_block @ V_block`, and after all tiles the results are normalized, cast back to the output dtype, and stored alongside the log-sum stats `M`. The host launcher computes `BLOCK_DIM` via a power-of-two ceiling, chooses HIP-specific kernel arguments when needed, and relies on the autotuner to select performant schedules for the given `(SEQ_LEN, DIM)` pair.
