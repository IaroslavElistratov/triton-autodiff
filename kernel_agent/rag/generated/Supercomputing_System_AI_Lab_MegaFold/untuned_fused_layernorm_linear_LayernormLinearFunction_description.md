- kernel family: Fused layernorm + linear projection (autotuned row-wise normalization matmul)
- concise summary: The forward path first computes per-row statistics, then autotunes the matmul schedule to normalize each tile with learned per-channel weights/biases while accumulating the linear transform.
- detailed summary: After flattening inputs to (M×K), `_first_forward_kernel` launches one row-per-program to load the entire feature vector via BLOCK_SIZE strides, reduce its mean/variance, and write reciprocal std deviations for later reuse. `_second_forward_kernel` is autotuned over the candidate configs from `get_autotune_forward_config`, so each winning schedule controls BLOCK_SIZE_M/N/K, grouping, and warp count; the kernel groups program IDs so each instance covers a tile of rows and output columns, streams through the K dimension BLOCK_SIZE_K elements at a time, rescales activations using the previously stored mean/rstd and learned per-feature weights, optionally adds a layernorm bias, and performs FP32 `dot` accumulations against the matching weight tile from `b`. Once all K slices are processed, optional output bias is fused and the tile is cast back to the target dtype and written out. The Python driver supplies the autotuned meta-parameters, ensuring the operation adapts across shapes while preserving the reshaped output layout.
