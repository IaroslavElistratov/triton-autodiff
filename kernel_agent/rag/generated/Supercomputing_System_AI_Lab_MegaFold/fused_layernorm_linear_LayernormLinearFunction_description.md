- kernel family: Fused layernorm + linear projection (row-wise stats fused matmul)
- concise summary: Forward execution first computes per-row mean and variance, then streams normalized activations through a tiled matrix multiply that folds per-channel weights and optional biases before writing the linear output.
- detailed summary: Inputs are reshaped to 2D (M×K) and `_first_forward_kernel` launches one program per row to load a BLOCK_SIZE chunk, accumulate the full-row mean/variance, and write both mean and reciprocal std for reuse. `_second_forward_kernel` organizes the launch over (M,N) tiles via grouped swizzling so each program repeatedly loads BLOCK_SIZE_K slices of the normalized activations and the corresponding weight vectors, applies optional layernorm bias, multiplies by the linear weight tile, and accumulates FP32 products. After looping over K the tile is cast back to the requested dtype, optional linear bias is added, and the tile is stored to the output matrix. Host-side `layernorm_linear_forward` orchestrates the two kernels, choosing tile sizes and warp counts from `calculate_settings`, and handles CUDA vs HIP configuration knobs while preserving the original higher-dimensional layout when reshaping the final tensor.
