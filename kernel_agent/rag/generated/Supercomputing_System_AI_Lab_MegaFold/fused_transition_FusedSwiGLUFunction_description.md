- kernel family: SwiGLU activation (fused SiLU gating across split channels)
- concise summary: The forward Triton kernel slices each row into left/right halves, applies SiLU to the right half, multiplies by the left half, and writes the gated output while retaining the rearranged input for backward reuse.
- detailed summary: `swiglu_forward` flattens the trailing dimension so each program instance in `_swiglu_forward_kernel` handles one logical row with BLOCK_SIZE lane vectors. It computes pointers for the left (`a_ptr`) and right (`b_ptr`) channel halves, loads them with masking for tail elements, promotes the right half to FP32, evaluates `sigmoid(b)` to implement the SiLU `b * sigmoid(b)`, multiplies by the corresponding left-half activation, and stores the dim_out slice back to the output tensor. The driver picks tile size and warp count via `calculate_settings`, enabling the kernel to cover arbitrary batch × sequence shapes while ensuring the contiguous layout required by the decorators.
