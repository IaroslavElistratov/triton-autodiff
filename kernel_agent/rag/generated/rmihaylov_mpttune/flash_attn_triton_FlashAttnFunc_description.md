- kernel family: attention (flash attention, fp16/bf16, optional bias & causal masking)
- concise summary: Fuses QK^T, softmax, and PV in one Triton kernel for separate Q/K/V tensors while keeping numerics stable via running max-log-sum-exp bookkeeping.
- detailed summary: Each program handles one `(BLOCK_M \times head)` tile: it loads a BLOCK_M slice of Q, streams over BLOCK_N key/value tiles, forms QK^T with `tl.dot`, injects optional vector or matrix bias, and enforces causality with triangular masking. The kernel maintains per-row maxima and log-sum-exp terms in fp32 scratch buffers (`TMP`, `Lse`) to normalize probabilities before multiplying by V and accumulating the BLOCK_M×headdim output, which is finally rescaled and written to `Out` alongside the log-sum-exp tensor for later backward use; launch helpers round the sequence length to 128, choose num_warps from the head size, and derive the softmax scale if unset.
