- kernel family: attention (FlashAttention with packed KV staging)
- concise summary: The forward wrapper ensures the packed `(B, S_k, 2, H, D)` tensor is contiguous, slices it into separate K and V views, and then hands Q, K, and V to the generic `_flash_attn_forward` launcher that produces the attention output and log-sum-exp statistics.
- detailed summary: `_FlashAttnKVPackedFunc_forward` first makes `q` and `kv` contiguous along the last stride and extracts `kv[:, :, 0]` and `kv[:, :, 1]` so the downstream FlashAttention implementation receives the standard dense K and V layouts. `_flash_attn_forward` allocates the output tensor, the per-query log-sum-exp buffer, and (when needed) dropout masks, chooses block sizes based on head dimension, and launches the Triton `_attn_fwd` kernel. Each `_attn_fwd` program owns a BLOCK_M slice of queries for a specific (batch, head) pair, walks over BLOCK_N-key tiles, applies optional ALiBi/bias and causal masking, keeps running maxima and exp-sums for numerical stability, and accumulates V contributions in fp32 before writing the normalized tile and log-sum-exp values back to global memory.
