- kernel family: matrix multiplication (dense x quantized 2/4/8-bit weights, Triton)
- concise summary: Dequantizes grouped low-bit weight tiles on the fly and multiplies them with fp16 activations using an autotuned BLOCK_M×BLOCK_N schedule.
- detailed summary: The `matmul_248_kernel` arranges programs over output tiles, loading a BLOCK_M slice of activations and iterating across BLOCK_K chunks; for each chunk it looks up the group index `g_idx`, loads the per-group scale/zero tensors, extracts packed weight values via bitshifts, rescales them back to fp16, and accumulates the product in fp32. Autotune sweeps asymmetric tile shapes to match activation and output aspect ratios, after which the helper reshapes the input to 2D, launches the kernel with `grid=(ceil(M/BLOCK_M)*ceil(N/BLOCK_N),)`, and reshapes the fp16 result back to the original batch dimensions.
