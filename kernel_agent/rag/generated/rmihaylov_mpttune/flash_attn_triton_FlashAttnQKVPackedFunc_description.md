- kernel family: attention (flash attention, fp16/bf16, QKV packed, optional bias)
- concise summary: Works directly on a packed QKV tensor, performing the flash-attention softmax/value accumulation with one pass over key/value tiles per `(head, BLOCK_M)` of the sequence.
- detailed summary: Kernel programs index into the shared QKV buffer to grab the BLOCK_M slice of Q and repeatedly load BLOCK_N tiles of K and V, multiplying to form QK^T, masking for causality, and folding in broadcast biases. They maintain fp32 maxima and log-sum-exp in scratch arrays to normalize probabilities before casting back to the value dtype, accumulate the partial outputs in fp32, and emit both the normalized attention block and the stored log-sum-exp for backward computations; the launcher controls BLOCK sizes, head-dimension padding via `next_power_of_2`, and derives the softmax scale if the caller omits it.
