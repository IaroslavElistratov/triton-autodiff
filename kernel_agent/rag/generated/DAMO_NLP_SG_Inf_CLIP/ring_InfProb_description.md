- kernel family: distributed attention statistics (ring all-gather + flash log-sum-exp)
- concise summary: On each rank the kernel computes the per-query log-sum-exp of local `Q·K` tiles across all heads, while the host orchestrates a ring pass exchanging key shards so every process accumulates the global normalization term without materializing all keys at once.
- detailed summary: `_prob_fwd_kernel` matches the single-node variant: for each `BLOCK_M` chunk of queries it iterates over key tiles, loops over heads to accumulate `qk = q · kᵀ`, applies masks for ragged sequence lengths, and maintains streaming maxima/sums to output `logsumexp` values in fp32. `_InfProb_forward` builds a `RingComm`, iteratively sends its current shard of keys to the next rank while receiving the previous shard, and after each local `_flash_prob_forward` call merges the resulting log-sum-exp vector into the running total via `lse = lse - logσ(lse - block_lse)`, which performs a numerically-stable `logaddexp`. After traversing all `world_size` shards it saves the queries, all observed key shards, and the final log-sum-exp for backward. This yields the same normalization factors as the centralized computation but with ring communication and per-step kernel launches that only ever touch one shard of keys at a time.
