- kernel family: attention statistics (flash-style log-sum-exp of Q·K across heads)
- concise summary: Each program handles a `BLOCK_M` slice of query positions, streams over key tiles, accumulates the head-wise dot products for all attention heads, and maintains running max/sum terms to emit the stabilized log-sum-exp needed for probabilistic normalization.
- detailed summary: `_prob_fwd_kernel` flattens `(heads, head_dim)` into a single contiguous stride `ndims`; with program id `start_m` it gathers the current query rows, then for each key tile and head index it loads the corresponding Q/K blocks, forms `qk += q · kᵀ`, and applies masks so queries beyond `seqlen_q` or keys beyond `seqlen_k` contribute zero. It tracks the streaming maximum `m_i` and partial sums `lse_i` using the flash-attention recurrence (`lse_i = exp(m_old - m_new)*lse_i + sum(exp(qk - m_new))`), ensuring numerical stability even for long sequences. After processing all key tiles it stores `lse_i = m_i + log(lse_i)` to the output buffer, zeroing positions beyond the actual query length. The Python wrapper rounds the sequence length for workspace allocation, selects tile sizes (64×64, head-dim rounded up to a power of two), launches a single-grid kernel over `ceil_div(seqlen_q, BLOCK_M)`, and slices the result back to the true sequence length before returning it.
