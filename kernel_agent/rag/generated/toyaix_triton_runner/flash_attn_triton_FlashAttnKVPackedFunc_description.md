- kernel family: attention (FlashAttention forward with K/V packed inputs)
- concise summary: Follows the same tiled FlashAttention algorithm as the QKV-packed variant but expects separate Q and shared K/V tensors, computing softmax-normalized attention and storing both the output and per-row log-sum-exp for later reuse.
- detailed summary: `_flash_attn_forward` (invoked by the module’s autograd wrapper) validates tensor layouts, expands any bias to match `(batch, nheads, seqlen_q, seqlen_k)`, allocates FP32 scratch for the LSE and temporary scaling factors, and dispatches `_fwd_kernel` with the computed strides. Within the kernel, each program processes a block of queries, iteratively loads K and V tiles, applies optional bias and causal masking, maintains running maxima and log-sum-exp values for numerical stability, and accumulates the weighted V contributions in FP32 before writing the results back in the original dtype. The stored LSE buffer is later consumed by the backward kernel to rebuild gradients without recomputing softmax normalizers.
