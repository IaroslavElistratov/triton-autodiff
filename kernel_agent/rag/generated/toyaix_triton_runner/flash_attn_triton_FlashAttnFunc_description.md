- kernel family: attention (FlashAttention forward with separate Q/K/V tensors)
- concise summary: Calls `_flash_attn_forward` to run the Triton FlashAttention kernel, which streams through key/value tiles while maintaining per-row softmax statistics, applies optional bias/causal masks, and writes both the attention output and log-sum-exp cache.
- detailed summary: The wrapper computes power-of-two block sizes based on the head dimension, allocates FP32 scratch buffers (`lse`, `tmp`), expands bias tensors to `(batch, nheads, seqlen_q, seqlen_k)` if necessary, and launches `_fwd_kernel` over `(ceil(seqlen_q/BLOCK_M), batch*nheads)` programs. Each program loads a query tile once, loops across the key dimension in `BLOCK_N` steps, computes scaled dot products, incorporates causal/bias masks, and updates running max/log-sum-exp values to avoid overflow. Probabilities are evaluated on the fly and multiplied with the corresponding V tile, accumulating the result in FP32 before casting back to the original dtype. The final LSE buffer is stored for the backward phase, enabling gradient computations without recomputing softmax denominators.
