- kernel family: attention (FlashAttention forward with packed Q/K/V tensors and optional bias)
- concise summary: Validates head shapes, prepares scratch buffers, and launches Triton’s `_fwd_kernel`, which tiles over query positions and heads to compute scaled dot-product attention with causal/bias handling—accumulating the softmax-normalized value sum and per-row log-sum-exp.
- detailed summary: `_flash_attn_forward` reshapes or copies bias tensors when provided, determines the appropriate block sizes (`BLOCK_M`, `BLOCK_N`, `BLOCK_HEADDIM`), allocates an output tensor plus FP32 working buffers (`lse`, `tmp`), and calls `_fwd_kernel` with grid `(ceil(seqlen_q/BLOCK_M), batch*nheads)`. Each kernel program loads the local Q tile, streams over K/V tiles (respecting causal masks and bias types), computes Q·K, applies the scaling factor, carries forward running max/log-sum-exp statistics, and accumulates the weighted V contributions in FP32 before casting back to the query dtype. The resulting attention output and LSE buffer are stored for use by the backward pass; other helper functions in the file wrap this logic into an autograd-friendly interface.
