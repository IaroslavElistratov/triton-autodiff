- kernel family: forgetting attention (decayed causal attention with adaptive truncation)
- concise summary: The forward path first computes per-head start indices based on cumulative log-decay (`LOG_LAMBDA`) and a threshold, then runs a Triton attention kernel that restricts each query block to the surviving context, incorporates the decay bias into the logits, and normalizes the result to produce both the output and log-normalizers.
- detailed summary: `_find_start_index_kernel` scans `LOG_LAMBDA` for each (batch, head) pair, advancing a start pointer until the drop in log-cumulative forgetting exceeds the provided `THRESHOLD`; these offsets populate `START_INDEX` when adaptive truncation is enabled. The main `_fwd_kernel` tiles the query dimension (`BLOCK_M`) and, for each chunk, iterates over key tiles (`BLOCK_N`), loading the appropriate `K/V` slices and the decayed log-cumulative values. It adds the decay term (`log_lambda_out - log_lambda_in`) to the scaled dot product, applies causal and sequence-start masks, performs a log-sum-exp accumulation (keeping per-row maxima `m_i` and normalizers `l_i`), and writes both the normalized outputs and the cached log-sum-exp values. Configuration helpers (`get_fwd_config`) pick tile sizes and warps based on model dimensions and causal mode. Backward kernels (not summarized here) reuse the saved tensors to propagate gradients through the forgetting mechanism.
