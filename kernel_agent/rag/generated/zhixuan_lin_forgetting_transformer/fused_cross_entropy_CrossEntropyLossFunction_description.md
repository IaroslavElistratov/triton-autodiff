- kernel family: classification loss (distributed-aware fused cross-entropy with z-loss regularization)
- concise summary: Optionally shards the vocabulary across ranks, launches a Triton kernel that sweeps vocabulary tiles to accumulate log-sum-exp and per-label losses (with label smoothing and z-loss support), and consolidates split results before returning per-sample losses and cached LSE values.
- detailed summary: `fused_cross_entropy_forward` first normalizes layout, selects `BLOCK_SIZE` (capped at 64K), and determines whether the classes are split across ranks or require multiple kernel passes. It allocates intermediate tensors shaped `(n_splits, n_rows)` when needed and dispatches `cross_entropy_fwd_kernel`, which loads a block of logits, scales them, computes a block-local LSE, and—if the true label resides in that block—subtracts the correct logit (plus smoothing offsets). When splitting is active, the host reduces the per-block losses/LSEs, optionally all-gathers across the process group to recover the global softmax normalization, and adds the quadratic `lse_square_scale * LSE^2` term (masked by `ignore_index`). The forward returns `(losses, z_losses)` along with storing logits/LSE/targets for the backward pass.
