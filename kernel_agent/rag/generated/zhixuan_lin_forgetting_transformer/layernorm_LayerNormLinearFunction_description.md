- kernel family: fusion (grouped layer norm followed by linear projection)
- concise summary: Reshapes the input to collapse batch/group dimensions, calls a Triton layer-norm routine that can optionally add a residual and emit the summed activations, then feeds the normalized tensor through a PyTorch `F.linear` with converted weights/bias.
- detailed summary: The forward wrapper enforces group divisibility, reshaping `(…, channels)` into `(T, D)` with `D = channels / num_groups`. It optionally reshapes and accumulates a residual (with optional fp32 precision) before invoking `layer_norm_fwd`, which chooses between `layer_norm_fwd_kernel` (tile-based) or `layer_norm_fwd_kernel1` (scalar loop) depending on `D`. Those Triton kernels compute mean/variance (or RMS), write `mean`/`rstd` when needed, and can store the combined residual into `res_out`. After the normalization, the code restores the original shape, casts weights if autocast is active, and performs the linear projection on the normalized tensor, returning either the projection alone or, in prenorm mode, the projection plus the reshaped residual output for skip connections.
