- kernel family: normalization (grouped layer norm / RMSNorm with optional residual capture)
- concise summary: Reshapes the activations into `(T, D)`, runs a Triton layer-norm kernel that can add a residual and emit the combined tensor, and returns the normalized data (plus the residual output when prenorming).
- detailed summary: `_LayerNormFunction_forward` verifies group divisibility, flattens the grouped channels, and optionally reshapes an incoming residual tensor. It then calls `layer_norm_fwd`, which selects between a block-tiled kernel (`layer_norm_fwd_kernel`) for moderate `D` and a per-row kernel (`layer_norm_fwd_kernel1`) when `D` is large. These kernels support both standard layer norm and RMSNorm modes, accumulating mean/variance (or just RMS), writing `mean`/`rstd` buffers for backward, blending in a residual add, and optionally storing the summed activations into `res_out` (useful for prenorm skips). The normalized result is reshaped back to the original tensor layout; when `prenorm=True`, the function returns a tuple of `(normalized_output, residual_output)` for downstream consumption.
