- kernel family: sequence mixing (token-wise shift blend with learned weights)
- concise summary: Launches a Triton grid over heads, time tiles, and batch items so each program reads the current token vector and its predecessor, multiplies them by per-position weights, and writes the weighted sum back into the output tensor.
- detailed summary: The forward driver ensures the `(B, T, H, D)` activations are contiguous, allocates an output mirror, and picks a grid `(H, ceil(T/BLOCK_T), B)` while autotuning `BLOCK_T` and warp count. Inside `shift_fwd_kernel`, the program computes offsets into the activation and weight strides, loads both the current token chunk and the previous time-step chunk using masked accesses at sequence boundaries, and loads the matching `curr_weight`/`prev_weight` scalars. It forms the weighted blend in FP32 before casting back to the input dtype and storing it to the corresponding output tile, handling ragged tails by masking. No other state is modified; the saved tensors are only for the backward pass.
