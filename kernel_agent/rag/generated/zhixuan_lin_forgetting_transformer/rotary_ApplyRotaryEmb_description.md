- kernel family: positional modulation (rotary embedding application with optional interleaving and variable lengths)
- concise summary: Wraps `apply_rotary`, which selects a Triton kernel that iterates over sequence tiles and heads, loading cosine/sine lookup tables and combining paired head-dim components to rotate each token’s query/key vector in place or into a fresh output buffer.
- detailed summary: The forward helper handles both fixed-length `(batch, seqlen, nheads, headdim)` tensors and packed variable-length layouts driven by `cu_seqlens`/`max_seqlen`, as well as scalar or per-batch `seqlen_offsets`. It computes launch parameters—`BLOCK_M` for the sequence tile, `BLOCK_K` for the rotary sub-dimension—and invokes `rotary_kernel` with flags indicating interleaved storage and conjugation. Inside the kernel, each program locates its batch/head slice, pulls the appropriate cosine/sine rows (offset by the sequence position), and loads even/odd elements of the rotary subspace (handling interleaved layouts by swapping indices). It multiplies the components in FP32 to form the rotated pair and stores them back to the output tensor, leaving any tail dimensions untouched when `rotary_dim < headdim`. Variable-length batches use `cu_seqlens` to bound masking so only valid positions are written.
