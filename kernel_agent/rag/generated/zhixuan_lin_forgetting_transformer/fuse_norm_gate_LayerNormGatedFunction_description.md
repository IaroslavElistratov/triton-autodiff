- kernel family: fused layer norm + gating (supports residuals, groups, and RMS mode)
- concise summary: Forward reshapes the input by groups, runs a Triton layer-norm kernel that optionally adds a residual, normalizes, applies per-group scale/bias, and gates the result with an activation (SiLU/swish/sigmoid) driven by `g`, returning the normalized output plus cached statistics for backward.
- detailed summary: `layer_norm_gated_fwd` prepares optional residual/out buffers, chooses between a block-tiled kernel (`layer_norm_gated_fwd_kernel`) for moderate feature sizes and a simpler per-token kernel (`layer_norm_gated_fwd_kernel1`) for larger widths. Both kernels load the input slice (adding a residual if provided), optionally stash a copy, compute mean/variance (or RMS stats), and store `mean`/`rstd`. They then apply the learned scale/bias per group and combine with the gating tensor `g` through the requested activation (swish/silu/sigmoid) before writing to `y`. The autograd wrapper flattens the batch/group dimensions and saves the tensors needed by the backward kernels (not shown here) to propagate gradients through the fused normalization and gating steps.
