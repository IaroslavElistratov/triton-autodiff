- kernel family: fusion (layer norm + gating + linear projection)
- concise summary: Flattens the input and gating tensors, runs a Triton layer-norm kernel that can add/save a residual and apply a learned scale/bias, multiplies the normalized result by a gating vector with configurable activation, and finally projects it via a PyTorch linear layer.
- detailed summary: `_LayerNormGatedLinearFunction_forward` reshapes `x` and gate `g` to `(T, D)` blocks, optionally reshaping the residual and promoting it to fp32 for the normalization if requested. It calls `layer_norm_gated_fwd`, which picks between a block-tiled (`layer_norm_gated_fwd_kernel`) or scalar (`layer_norm_gated_fwd_kernel1`) Triton implementation depending on `D`. Those kernels compute mean/RMS statistics, optionally add and stash the residual, and apply per-group weight/bias before combining with the gate vector using Swish/Sigmoid-style activations. The fused output is reshaped back to the original layout, cast to the autocast dtype if needed, and fed through `F.linear` with the provided projection weights/bias. When `prenorm=True`, the forward returns both the projected tensor and the saved residual output for downstream skip connections.
