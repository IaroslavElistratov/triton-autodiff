- kernel family: attention (native sparse attention with sliding window + selected blocks)
- concise summary: Tiles queries in `(BLOCK × head_group)` chunks, first attends over a causal sliding window of nearby key blocks, then iterates through a list of preselected remote key/value blocks, maintaining running log-sum-exp statistics and accumulating attention·value outputs for both the dense and sliding streams.
- detailed summary: `native_sparse_attn_forward` enforces contiguous layouts, determines per-head groupings, and launches `forward_kernel` with heuristics describing tile divisibility. Inside `forward_kernel_causal_and_sparse`, each program loads a `BLOCK` of queries (expanded across grouped heads), initializes max/sum trackers (`m_i`, `lse_i`), and—if enabled—scans local causal blocks by stepping backward `SEL_BLOCK` positions to build streaming softmax contributions and aggregate `acc_o`. It then loops over `NUM_SEL_KV_BLOCKS`, using `kv_block_indices` and `kv_block_mask` to fetch disjoint remote blocks; for each, it computes query·key tiles, applies masks, updates softmax statistics, and multiplies by the corresponding value slices before averaging over sub-block shards. The kernel writes both the attention outputs and per-token log-sum-exp to global memory (and optionally a separate sliding-window output), producing the sparse attention result without materializing the full attention matrix.
