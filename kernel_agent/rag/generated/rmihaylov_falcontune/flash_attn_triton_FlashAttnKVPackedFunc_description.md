- kernel family: attention (flash attention, fp16/bf16, KV packed, optional bias & causal masking)
- concise summary: Streams over packed K/V tiles to fuse QK^T, numerically stable softmax, and weighted value aggregation for each head in a single Triton launch.
- detailed summary: The forward kernel assigns each program to a `(BLOCK_M, head)` tile, loading a BLOCK_M slice of queries once and looping over BLOCK_N key/value blocks from the packed `kv` tensor while respecting causal cutoffs and optional vector or matrix bias. For every tile it forms QK^T via `tl.dot`, updates a running max/log-sum-exp held in fp32 scratch (`TMP`, `Lse`) to keep softmax stable, converts the probabilities to the value dtype, and accumulates block outputs in fp32 before the final rescale. After the sweep completes it writes the normalized attention result to `Out`, stores per-query log-sum-exp for backward reuse, and returns the chosen softmax scale computed from the head dimension.
