- kernel family: attention (flash attention, fp16/bf16, QKV packed, optional bias & causal masking)
- concise summary: Unpacks a `(batch, seq, 3, heads, dim)` tensor on the fly and performs fused attention with streamed key/value tiles and log-sum-exp softmax stabilization.
- detailed summary: Launch configuration maps one Triton program to each head and BLOCK_M chunk of the sequence; it slices Q, K, and V out of the packed tensor, computes QK^T block products in fp32, and keeps a running max/log-sum-exp in `TMP`/`Lse` to maintain numerical stability under causal or full attention. After converting the probabilities to the value dtype it accumulates the TILE × dim outputs in fp32, rescales them using the stored normalization factors, and commits both the attention output and per-query log-sum-exp statistics for reuse by the autograd logic.
