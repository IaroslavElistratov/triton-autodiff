- kernel family: selective scan state propagation
- concise summary: Propagates per-chunk state vectors across the sequence using the cumulative dt factors, producing intermediate chunk outputs and final states while optionally seeding from provided initial states.
- detailed summary: For each batch/head/dimension block, the kernel initializes the state with zeros or initial_states, iterates through nchunks, blends the previous state with the incoming chunk state using exp(dA_chunk_cumsum) as a decay factor, zeroing updates when seq_idx reveals a sequence boundary, and writes the intermediate value to the output tensor while keeping the last step as the returned final state. The wrapper ensures contiguous layout, allocates fp32 buffers, launches the kernel with autotuned BLOCK_SIZE over the feature dimension, and exposes both the per-chunk trajectory and the last state.
