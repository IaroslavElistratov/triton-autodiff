- kernel family: layer normalization (minimal fused residual)
- concise summary: A lighter Triton layernorm that optionally adds a residual input, computes mean/variance per row, and applies scale and bias to emit a normalized tensor.
- detailed summary: Each kernel instance owns one row, optionally adds the residual row to the activations, writes the blended value to RESIDUAL_OUT when dtype conversions require it, computes the per-row mean (skipped for RMS mode) and variance in fp32, stores mean and inverse std into dedicated buffers, and writes out the affine-transformed normalized data. The Python entry point reshapes inputs to 2-D, ensures contiguity, allocates the statistic buffers and optional residual copy, and launches the kernel with a tile size bounded by the 64 KiB feature limit.
