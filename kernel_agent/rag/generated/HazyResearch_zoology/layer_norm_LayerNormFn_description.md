- kernel family: layer normalization (residual/dropout/parallel branches)
- concise summary: Single-pass Triton layernorm that fuses optional residual addition, a secondary activation stream, per-row scaling, dropout, and storage of aux buffers while emitting one or two normalized outputs.
- detailed summary: Each program processes one row of the 2-D reshaped activation, loading a BLOCK_N tile, optionally multiplies by row-wise scale factors, applies dropout (recording masks) with per-row RNG seeds, adds an auxiliary input X1 and/or residual buffer, and optionally snapshots the blended activation to RESIDUAL_OUT. It then computes mean/variance (or RMS) in fp32, stores the per-row statistics, forms the normalized vector, multiplies by learned weights/biases (and optionally a second set W1/B1) to produce Y and Y1. The Python wrapper prepares output, residual, mean/rstd, seed, and mask tensors, chooses a power-of-two tile size under 64 KiB, and launches the kernel across M rows with flags describing which fused features are active.
