- kernel family: selective scan / state-space chunked attention
- concise summary: Executes the forward selective scan over chunked sequence blocks by multiplying precomputed chunk transition matrices with input tiles, applying exponential dt scaling, optional residual weights, and SiLU gating to produce per-head outputs.
- detailed summary: A 3-D Triton launch tiles over chunk rows, batch-chunk pairs, and heads; for each tile the kernel marches through the chunk in BLOCK_SIZE_K steps, loading a slice of cb, rescales it with exp(dA_cumsum[row] - dA_cumsum[k]) and the diagonal dt factors, applies causal or sequence-index masks, and accumulates the dot product with the matching slice of X. After the sweep it optionally adds a skip term from D ∘ x, materializes the ungated activations to out_x, and, if a gate tensor Z is present, multiplies by z * sigmoid(z) before storing to the final output. The Python forward path builds CB = _bmm_chunk_fwd(C, B, chunk_size), prepares optional buffers (for gated outputs or dtype changes), and launches the autotuned kernel; sequence-index arrays zero contributions whenever a chunk boundary crosses different sequences.
