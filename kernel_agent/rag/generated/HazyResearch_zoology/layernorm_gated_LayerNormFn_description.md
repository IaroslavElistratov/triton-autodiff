- kernel family: group layer normalization with gating
- concise summary: Performs group-wise normalization over fixed-size feature groups and optionally applies a SiLU gate either before or after normalization using a companion tensor z.
- detailed summary: The kernel launches over rows and groups, slices each group of size group_size, optionally multiplies by a gate z * sigmoid(z) ahead of normalization, computes the group mean/variance (or squared norm for RMS), stores the per-group statistics, normalizes and affine-scales with group-specific weights/biases, and if norm_before_gate is true multiplies the post-affine output by the same SiLU gate. The wrapper reshapes and contiguates inputs, enforces divisibility by group_size, allocates fp32 mean/rstd buffers, and configures the launch grid (M, ngroups) with autotuned block widths.
