- kernel family: selective scan state preparation
- concise summary: Generates per-chunk hidden states by contracting the input activations against the state matrix B with exponential dt scaling, readying the state tensors for downstream scans.
- detailed summary: Each program iterates across the chunk dimension for a given head/group, loading an (headdim × BLOCK_SIZE_K) slice of X and the matching chunk of B, weighting each column by exp(dA_cumsum[last] - dA_cumsum[k]) * dt[k], optionally masking terms when seq_idx marks a reset, and accumulating the contributions into a (headdim × dstate) tile that is written to the state tensor. The wrapper enforces layout/shape constraints, allocates the output in fp32 when requested, chooses an autotuned block configuration, and launches the kernel across (batch × nchunks, heads).
