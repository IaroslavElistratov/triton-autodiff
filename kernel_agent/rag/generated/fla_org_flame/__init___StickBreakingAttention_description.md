- kernel family: stick-breaking attention (block-causal with reversible stick mass tracking)
- concise summary: Blocked Triton kernel processes one batch/head/query tile at a time, iterating backward over key/value tiles to build the stick-breaking mass, apply causal masking, and accumulate attention-weighted values into the output and residual mass buffers.
- detailed summary: Each program instance loads a BLOCK_M slice of queries and maintains a `neg_log_acc` vector representing the remaining stick mass; it walks over preceding key/value tiles in steps of BLOCK_N, using `compute_block` to form scaled dot products, apply the softplus-based stick-breaking transform, update the remaining mass, and optionally store attention weights. Tile loads respect head and dimensional masks via `load_kv`, and partial results are accumulated in FP32 before writing the output tile, the residual mass, and its logarithm. Autotuned launch parameters select block shapes and warps, while the Python launcher prepares scratch buffers for the remainder mass and dispatches `_forward` across `(batch, head, sequence-block)` grids with configurable diagonal attendance.
