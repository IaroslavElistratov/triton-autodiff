- kernel family: Layer normalization (fused mean/var + affine scale/bias)
- concise summary: A single Triton kernel iterates over each row three times to compute mean, variance, and normalized outputs with learned affine parameters, caching mean and reciprocal std for the backward pass.
- detailed summary: `_layer_norm_fwd_fused` assigns one program per row of the flattened input; it computes the row mean by streaming across the feature dimension in BLOCK_SIZE chunks, accumulates variance in a second pass using the stored mean, derives the reciprocal standard deviation, and writes both statistics to auxiliary buffers. A final sweep reloads the same tiles, normalizes activations, multiplies by the per-channel `weight`, adds `bias`, and stores the result. The launcher reshapes the input to (M×N), picks BLOCK_SIZE as a clipped power of two bounded by the hardware maximum and element size, derives an appropriate warp count, and dispatches the fused kernel while stashing the intermediate statistics on the context.
