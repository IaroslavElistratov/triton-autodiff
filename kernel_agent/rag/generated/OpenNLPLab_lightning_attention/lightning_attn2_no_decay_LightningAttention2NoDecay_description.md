- kernel family: lightning attention (no-decay variant)
- concise summary: Performs the same blockwise Lightning scan but without exponential forgetting—each block’s logits and KV accumulator operate with plain causal masking, so the inter-block term is a simple running sum.
- detailed summary: `_fwd_kernel` visits blocks of length `BLOCK`, loads Q/K/V tiles, zeros out strictly future positions via a causal mask (`index >= 0`), computes the intra-block dot products, and adds the contribution from the cumulative `kv` tensor without any decay factor. After writing the output slice it simply updates `kv += Kᵀ·V` and advances to the next block. The forward wrapper keeps the same tiling strategy (`BLOCK=64`, `BLOCK_MODEL≤32`), dispatches the kernel across `(b·h, ceil(e/BLOCK_MODEL))`, and stores Q/K/V for the corresponding backward routines.
