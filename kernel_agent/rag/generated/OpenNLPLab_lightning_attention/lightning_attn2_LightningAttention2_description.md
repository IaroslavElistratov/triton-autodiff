- kernel family: lightning attention (v2 block-decayed attention kernel)
- concise summary: Implements the Lightning Attention recurrence by scanning blocks of queries, mixing decayed self-attention logits with a running KV accumulator, and writing the result tile-by-tile without auxiliary caches.
- detailed summary: The Triton `_fwd_kernel` shares the block structure of the v1 kernel: for each `(batch×head, model-block)` tile it precomputes decay factors from the slope `s`, loads `BLOCK` positions of Q/K/V at a time, forms intra-block contributions using `diag_decay`, adds the inter-block term from the `kv` accumulator multiplied by `q_decay`, then stores the combined output slice. After each chunk it updates `kv = exp(-s·BLOCK)·kv + (K_decay ⊗ V)`. The forward wrapper selects `BLOCK=64` and an `BLOCK_MODEL` up to 32, launches the kernel over the `(b·h, ceil(e/BLOCK_MODEL))` grid, and preserves Q/K/V/S for backward analysis.
