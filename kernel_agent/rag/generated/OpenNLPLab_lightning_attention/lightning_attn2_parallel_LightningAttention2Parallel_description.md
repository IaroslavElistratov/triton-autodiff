- kernel family: lightning attention (parallel block decomposition)
- concise summary: The forward pass decomposes Lightning Attention v2 into three Triton phases—block-diagonal computation, parallel accumulation of decayed KV summaries, and cross-block mixing—so that long sequences can be processed by independent workgroups over time and feature tiles.
- detailed summary: `_fwd_diag_kernel` handles the causal intra-block term by looping over previous CBLOCK segments, applying the slope-dependent decay to K before dotting with Q and V; `_fwd_kv_parallel` runs in parallel over `(block, d-tile, e-tile)` to accumulate per-block KV matrices in float32 (`exp(-s·Δ)` weighted), `_fwd_kv_reduce` performs the recurrence `kv = exp(-s·BLOCK)·kv + kv_current` to propagate history along the block dimension, and `_fwd_none_diag_kernel` finally combines the cached history with the original Q blocks via `dot(q, kv) * exp(-s·offset)` to add the cross-block contribution to the output tensor. The Python wrapper sets `BLOCK=256`, `CBLOCK=64`, allocates the intermediate `kv` tensor, launches these kernels sequentially, and stores `(q, k, v, s, kv)` for the backward pass.
