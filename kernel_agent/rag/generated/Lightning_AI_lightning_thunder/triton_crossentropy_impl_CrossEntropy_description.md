- kernel family: loss (cross-entropy with optional label smoothing and class weights)
- concise summary: The forward Triton kernel streams over logits in BLOCK-sized tiles to build log-sum-exp statistics, writes per-class negative log-probabilities, and reduces to the cross-entropy loss under either index targets or full distributions.
- detailed summary: `_class_indices_forward` keeps running maxima/sums (`m_prev`, `l_prev`) in the chosen buffer dtype, storing log-softmax values to `PROBS` while optionally accumulating class-weight totals and applying label smoothing before sampling the target index (respecting `ignore_index`). `_class_probs_forward` handles dense target distributions similarly, multiplying log-softmax outputs by the provided probability weights and saving the normalization term in `WEIGHT_BUFFER`. The Python wrapper picks FP32 buffers for low-precision logits, allocates temporary tensors, sets launch grids from the flattened row count, and dispatches `_forward`, which selects the appropriate helper via compile-time flags for weights, class-indexed targets, and smoothing.
