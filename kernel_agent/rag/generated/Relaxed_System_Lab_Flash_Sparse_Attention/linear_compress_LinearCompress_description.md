- kernel family: sequence compression (per-head strided linear projection)
- concise summary: Computes a strided sliding-window linear transform that maps each `kernel_size × head_dim` patch into a single head_dim vector using head-specific weights, yielding shorter key/value sequences and updated prefix sums.
- detailed summary: `_LinearCompress_forward` derives the compressed sequence lengths from `cu_seqlens`, reshapes the weights into `[heads, kernel_size, head_dim, head_dim]`, and launches `linear_compress_fwd_kernel` over `(batch×head, output_tile, head_dim_tile)`. Within the Triton kernel each program gathers the necessary kernel window from the ragged input using prefix sums and the configured stride, reshapes the patch into a 2D tile, multiplies it by the corresponding weight block (iterating over head_dim in BLOCK_HEADd_DIM chunks), accumulates float32 results, and writes the compressed output tile; it also records the new `cu_seqlens` for downstream attention stages.
