- kernel family: sequence pooling (sliding window weighted average)
- concise summary: Iterates over ragged sequences with a fixed kernel size/stride, gathers each window, optionally multiplies by per-head weights, and writes the pooled output plus new prefix sums.
- detailed summary: `_SlidingWindowWeightedPool_forward` computes per-batch window counts from `cu_seqlens`, zeros the output tensor, and launches `sliding_pool_fwd_kernel` on a grid of (batch × head × output index). Each kernel instance reads a contiguous `kernel_size × head_dim` slice from the sequence using block pointers, loads head-specific weights if provided, and either sums or averages the window along the kernel axis (keeping computations in float32) before storing the result tile back to the compressed sequence; the companion `y_cu_seqlens` records the shortened layout for downstream modules.
