- kernel family: attention (top-k block sparse, original formulation)
- concise summary: Uses precomputed per-token block indices to visit only the selected key blocks, performing an online softmax over those blocks for each query/head group and accumulating the corresponding value tiles.
- detailed summary: `_topk_sparse_attention_fwd` allocates dense output and LSE buffers, infers tiling parameters (BLOCK_SIZE_K/D/H/T) from the block size and head sharing, and dispatches `forward_kernel_orig` across `(batch × key-head chunk × query tile)`. Within the kernel each program iterates over the real top-k blocks for its query tokens, loads the shared-head query patch, then fetches the indicated K/V block, applies a causal guard to discard future blocks, computes scaled q·k, updates the running max/exp sums, and fuses the weighted V accumulation. After iterating through all selected blocks it writes the normalized outputs back to the dense layout and stores per-token log-sum-exp values for reuse in later stages.
