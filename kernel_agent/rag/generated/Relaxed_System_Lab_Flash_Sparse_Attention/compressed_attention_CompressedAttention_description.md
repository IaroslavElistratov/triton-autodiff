- kernel family: attention (compressed/sliding-window sparse attention)
- concise summary: Iterates over query tiles with a configurable kernel size and stride, evaluates only the reachable key blocks via an online softmax, and accumulates the compressed attention output along with per-row log-sum-exp values.
- detailed summary: `_compressed_attention_fwd` allocates the output and LSE buffers, derives block sizes (BLOCK_SIZE_Q=128, BLOCK_SIZE_K=128, BLOCK_SIZE_D=pow2(head_dim)), selects warp/stage counts from `get_num_warps_stages`, and launches `forward_kernel` across (batch × query-head × query-tile). Each kernel instance gathers a BLOCK_SIZE_Q slice of queries starting at `kernel_size-1`, constructs block pointers into the grouped K/V heads, and scans the admissible key indices spaced by `kernel_stride`. For every key block it forms scaled q·k (with a causal guard that blocks future positions), updates the running max and exp sums for numerical stability, accumulates weighted V contributions in float32, and advances the pointers. After visiting all valid blocks it rescales by `exp2(m_i - lse_i)`, stores the normalized tile into `o`, and writes the corresponding log-sum-exp entries back to the LSE tensor.
