- kernel family: attention (flash attention, variable-length, optional GQA interleave)
- concise summary: Tiles queries in 128-row stripes, streams 64-key blocks per stripe while respecting causal or dense masks, and performs the online softmax with float32 accumulation before writing dense outputs and log-sum-exp buffers.
- detailed summary: `_flash_attention_fwd` allocates output/LSE tensors, derives BLOCK_SIZE_Q=128, BLOCK_SIZE_K=64, BLOCK_SIZE_D=pow2(head_dim), and selects warp/stage counts via `get_num_warps_stages`. It launches `forward_kernel` over `(batch × q_heads × tile)`; each program makes block pointers into the ragged Q/K/V segments determined by `cu_seqlens`, optionally remaps query heads to key heads under `gqa_interleave`, and iterates over admissible key tiles. Inside the loop it forms scaled q·k, applies either causal masking or end-of-sequence guards, updates running maxima and exp sums for numerical stability, accumulates weighted V tiles in float32, and advances the K/V pointers. After the loop it rescales by the final normalization factor, stores the result tile into `o`, and records the per-token log-sum-exp entries for reuse downstream.
