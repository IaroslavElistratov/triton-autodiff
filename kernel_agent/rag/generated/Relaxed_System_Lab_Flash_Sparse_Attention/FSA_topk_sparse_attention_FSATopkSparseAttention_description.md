- kernel family: attention (block-sparse top-k selection with online softmax)
- concise summary: Reorders the per-token top-k block indices into block-centric token lists, streams only those query/key/value tiles through Triton kernels that maintain online softmax statistics, and then reduces the partial tiles back into dense attention outputs with proper normalization.
- detailed summary: The forward driver `_topk_sparse_attention_fwd_opt` walks each sequence slice, counts how many tokens fall into every key block, and materializes Triton-friendly layouts: `build_block_to_token_triton` maps blocks to token IDs, `index_mapping` builds a lookup from token to within-block position, and `online_softmax` precomputes per-block running maxima for numerical stability. For each head group it dispatches `forward_kernel_opt` via `qkv_kernel`, where each program handles a `(block, head)` pair, gathers the active queries from `selected_tokens`, loads the corresponding K/V block, applies scaled q·k using the stored maxima, and accumulates weighted V tiles while writing per-token scaling factors. A final `reduce_output` kernel sweeps the buffered tiles, rescales them with the accumulated exponent factors, and scatters the results into the dense output tensor and log-sum-exp buffer; residual buffers are reset with `fused_fill` before moving to the next head share.
