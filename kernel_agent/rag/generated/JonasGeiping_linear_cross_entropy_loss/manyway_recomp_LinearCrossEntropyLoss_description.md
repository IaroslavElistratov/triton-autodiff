- kernel family: linear cross-entropy (Triton matmul with recomputation-friendly log-sum-exp buffers)
- concise summary: Tiles the class dimension to compute logits, accumulate a numerically stable loss, and persist only the per-token log-sum-exp statistics needed to later recompute softmax values.
- detailed summary: Each program enforces divisibility so it can stream through the entire weight matrix in `H_BLOCK_SIZE` tiles, producing `V_BLOCK_SIZE` logits at a time for `N_BLOCK_SIZE` samples. It tracks the running max `m`, updates the scaled exp-sum `s`, subtracts the ground-truth logit from an accumulator scaled by `1/N`, and after exhausting all class tiles emits the log-sum-exp vector (`lse_ptr`) alongside the partial loss. The forward driver simply dispatches this autotuned kernel over the batch using contiguous inputs, caches `lse_global` for later normalization work, and returns the aggregated loss scalar without storing the full logits matrix.
