- kernel family: linear cross-entropy (Triton fused matmul with multi-tile class reduction)
- concise summary: Computes batched logits and numerically stable log-sum-exp losses in a single Triton pass that sweeps four V tiles per program while caching logits for later reuse.
- detailed summary: Each kernel instance covers `N_BLOCK_SIZE` samples and streams through the weight matrix in `H_BLOCK_SIZE` chunks, folding four successive `V_BLOCK_SIZE` class slices into registers where it performs dot products, tracks the running max `m`, and updates the scaled sum `s`. The program subtracts the true-class logit from a partial loss accumulator, writes the logits to `z_nv_ptr`, and stores log-sum-exp fragments in `lse_ptr`; host code chunk-splits the batch (`N_group`), autotunes the grid, and later aggregates the buffered `lse` tiles to full-row normalizers. When gradients will be needed, the forward pass immediately normalizes the cached logits into softmax probabilities via a secondary kernel so that saved tensors already contain the normalized activations.
