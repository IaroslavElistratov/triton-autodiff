- kernel family: loss (chunked Malek-style fusion with Triton epilogues for both gradients)
- concise summary: Processes the batch in `N_group` slices, writes logits into a reusable `(chunk,V)` buffer, and after each chunk invokes Triton epilogues to compute both `x` and `Aᵀ` gradients before moving to the next slice, logging the chosen autotune configs for forward, dx, and dA.
- detailed summary: Within each loop iteration, `linear_xent_fwd_prep_bwd_kernel_matmul_t` multiplies the current chunk’s activations with `Aᵀ`, stores logits into `z_nv`, and accumulates block losses plus log-sum-exp entries in shared buffers. Because `z_nv` persists for the chunk, the code immediately launches `linear_xent_bwd_kernel_matmul_t_epilogue_dx` to regenerate the chunk’s input gradients directly from `z_nv`, `Aᵀ`, and `lse_global`, and—if weight gradients are needed—runs `linear_xent_bwd_kernel_matmul_t_epilogue_dA` to tile the same logits with activation slices. This keeps peak memory bounded by a single chunk while avoiding recomputation; the function prints the best Triton configurations for all three kernels, stores the assembled `x_grad` and `A_gradᵀ`, and returns the summed loss so that the autograd backward step only scales the precomputed gradients.
