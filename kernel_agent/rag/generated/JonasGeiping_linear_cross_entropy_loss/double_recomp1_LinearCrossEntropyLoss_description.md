- kernel family: chunked cross entropy via matmul^T
- concise summary: Runs a fixed-configuration matmul-based scan over the vocabulary, recording per-block losses and per-row log-sum-exp values for later reuse while avoiding full-logit storage.
- detailed summary: With block sizes fixed at (V,N,H)=(256,64,64), the kernel iteratively multiplies chunks of X by slices of A^T, updates the running m/s statistics for log-sum-exp, subtracts the target logit through a boolean mask, and after the final tile writes the averaged block loss into losses[idx] and each row's lse into lse_global. The Python wrapper enforces divisibility by 64/256, flattens the inputs, launches the kernel across ceiling(N/64) blocks (printing the tuned configuration), stores the minimal tensors needed for later stages, and returns the sum of the block losses.
