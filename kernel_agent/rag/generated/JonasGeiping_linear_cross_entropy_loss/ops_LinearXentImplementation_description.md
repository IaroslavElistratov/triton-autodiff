- kernel family: linear cross-entropy (batched matmul followed by log-sum-exp staging)
- concise summary: Tiled Triton GEMM computes the logits for each `(N, V)` block, emits both logits and per-row log-sum-exp slices, and—when monitoring is enabled—records auxiliary statistics that the Python wrapper later reduces into loss and diagnostic scalars.
- detailed summary: `linear_xent_fwd_kernel_matmul_t` binds each program to a `N_BLOCK_SIZE × V_BLOCK_SIZE` tile, iterates through the hidden dimension in `H_BLOCK_SIZE` chunks, and accumulates `z_j_to_k = x @ Aᵀ` in fp32 before writing the tile back to `z_nv_ptr`. After computing the tile’s maximum it evaluates `lse = log∑exp(z)` for that row subset and stores the partial log-sum-exp values (along with the raw logits) in the auxiliary buffers; when `monitoring=True` it simultaneously accumulates entropy/logit-norm summaries into side buffers used by the epilogue. The host-side forward reshapes the inputs, enforces the required divisibility by the block sizes, loops over `N_chunk_size` groups, launches the kernel, and then collapses the stored log-sum-exp tiles (and, if requested, the monitoring statistics) to obtain the scalar loss and optional diagnostics while the gradient staging happens in subsequent epilogues.
