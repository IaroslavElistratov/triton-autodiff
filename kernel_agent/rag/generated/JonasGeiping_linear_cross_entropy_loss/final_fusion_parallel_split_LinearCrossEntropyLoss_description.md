- kernel family: loss fusion (parallel epilogue with shared N/V split factor)
- concise summary: Executes the usual tiled matmul to stage logits and loss statistics, then uses a dispatcher whose grid splits either the batch or vocab axis by a single `SPLIT_NV` parameter so input and weight gradients can be generated concurrently while the forward pass computes the scalar loss.
- detailed summary: The forward kernel `linear_xent_fwd_prep_bwd_kernel_matmul_t` multiplies activation tiles by slices of `Aᵀ`, stores logits in `logits`, and writes block loss plus log-sum-exp values to `losses` and `lse_local`. After each chunk, the host reduces `lse_local.logsumexp(1)` to contribute to the total loss and, when gradients are requested, launches `linear_xent_bwd_dispatcher`. That dispatcher routes some programs to `_epilogue_dx` (with vocab splitting factor `SPLIT_NV`) and others to `_epilogue_dA` (with batch splitting factor `SPLIT_NV`), enabling both gradient paths to run in parallel without multiple kernel launches per split. The forward function logs the best autotuned configs for traceability, stores the computed gradients, and returns `losses.sum()` plus the accumulated log-sum-exp term, so backward later only rescales the saved tensors. This variant simplifies the parallel fusion interface by tying both split directions to a single knob while keeping the same chunked staging buffers as the other fused implementations.
