- kernel family: linear cross-entropy (Triton row-wise fused softmax + loss)
- concise summary: Tiles the projected logits so each Triton program normalizes one token’s logits with a log-sum-exp path, computes its contribution to the cross-entropy loss, and optionally writes softmax gradients in-place.
- detailed summary: The fused kernel pulls a full row of logits using a `BLOCK_SIZE` that is the next power-of-two over the class count, subtracts the per-row max for stability, exponentiates and reduces to get the log-sum-exp normalization, and subtracts the target logit before scaling by the divisor that encodes mean/sum reduction semantics. When gradients are requested, it also emits the softmax-minus-one-hot residual into a reusable buffer; masking by `ignore_index` nulls both the loss and gradient. The forward host loop splits tokens into `n_loop_iters` chunks, computes logits via a dense matmul against `proj_weight` cast to the execution dtype, runs the fused kernel on each chunk, and accumulates the scalar loss while buffering the optional input and weight gradients for later reuse.
