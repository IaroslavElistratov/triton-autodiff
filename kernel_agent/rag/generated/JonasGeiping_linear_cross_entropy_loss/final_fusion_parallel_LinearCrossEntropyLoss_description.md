- kernel family: loss fusion (parallel epilogue fused linear cross-entropy)
- concise summary: Splits the batch into `N_group` chunks, uses a Triton matmul kernel to stream logits into a staging tensor while accumulating block losses and log-sum-exp, and then launches a dispatcher that computes input and weight gradients in parallel grids within the same forward call.
- detailed summary: `linear_xent_fwd_prep_bwd_kernel_matmul_t` tiles the activations (`N_BLOCK_SIZE × H_BLOCK_SIZE`) and transposed weight matrix (`H_BLOCK_SIZE × V_BLOCK_SIZE`), iteratively forms logits via `tl.dot`, stores them into `logits`, and maintains numerically stable log-sum-exp reductions along with per-block loss contributions. After each chunk, the host reduces `lse_local.logsumexp(1)` to obtain `lse_global` and, if gradients are requested, invokes `linear_xent_bwd_dispatcher`, whose grid is partitioned so some programs execute `_epilogue_dx` (building `softmax(z-lse) - one_hot`, dotting with weight tiles) while the remainder run `_epilogue_dA` (multiplying activation tiles with the staged gradients). This setup lets forward execution produce both loss and gradients without round-tripping through autograd, while the parallel dispatcher ensures the two gradient paths can overlap in-flight, keeping only chunk-sized logits and statistics resident in memory.
