- kernel family: linear cross-entropy (Triton fused matmul + log-sum-exp over variable V tiles)
- concise summary: Fuses the logits matmul, numerically stable log-sum-exp, and per-example loss accumulation for a chunk of the batch, while staging intermediate logits needed later without re-materializing them.
- detailed summary: Each Triton program owns `N_BLOCK_SIZE` examples and iterates over `V_TILES` groups of `V_BLOCK_SIZE` classes, using block pointers to stream through `H_BLOCK_SIZE` fragments of the weight matrix and accumulate `z_j_to_k = x @ A_t` in registers. A running max `m` and scaled sum `s` maintain stable normalization, and the kernel subtracts the true-class logit from the loss before writing logits to `z_nv_ptr` and the partial log-sum-exp slices to `lse_ptr` for the chunk. The host forward pass chunks the batch by `N_chunk_size`, launches the autotuned kernel grid over (N,V), reduces the buffered log-sum-exp tiles to global values, and—when gradients are required—invokes a lightweight normalization kernel to turn the stored logits into softmax probabilities that feed saved tensors for reuse without extra matmuls.
