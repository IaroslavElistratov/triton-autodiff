- kernel family: loss fusion (parallel split-N/V epilogue with ignore-index and z-regularization support)
- concise summary: Enforces power-of-two-aligned shapes, streams logits into chunked buffers, and dispatches a split-N/V gradient kernel that factors in ignore indices, optional z-regularization, and fp32 accumulation toggles while the forward pass computes the loss.
- detailed summary: The forward matmul kernel matches `N_BLOCK_SIZE × H_BLOCK_SIZE` activation tiles with `H_BLOCK_SIZE × V_BLOCK_SIZE` weight tiles, writing logits to a staging tensor and updating both block losses and numerically stable log-sum-exp slices. After each chunk, the host trims `lse_local` to the active `V_BLOCK_SIZE`, accumulates `lse_global`, and applies an optional `z_regularization * ||lse||² / reduction` penalty. When gradients are requested, `linear_xent_bwd_dispatcher` partitions its grid across SPLIT_N and SPLIT_V, assigning some programs to `_epilogue_dx` (which forms `softmax(z-lse)` minus a reduction-scaled one-hot, zeroing ignored labels and optionally accumulating in fp32) and others to `_epilogue_dA` (which multiplies activation tiles with the staged gradients and performs atomic adds if necessary). The forward function runs under `torch.inference_mode()`, so it finishes with precalculated `x_grad`/`At_grad` and exposes the fused loss, while still supporting mixed-precision toggles and more flexible regularization than the raw parallel variant.
