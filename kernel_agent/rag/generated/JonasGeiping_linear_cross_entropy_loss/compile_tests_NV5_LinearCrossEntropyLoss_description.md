- kernel family: chunked cross entropy with staged buffers
- concise summary: Processes the batch in configurable N-sized groups, emitting partial losses and log-sum-exp tiles while caching the full logits for immediate conversion into gradient tiles.
- detailed summary: For each N_group chunk, linear_xent_fwd_prep_bwd_kernel_matmul_t walks vocabulary tiles, computing logits via block matmuls, maintaining per-row maxima/exponent sums, and writing both loss tiles into losses and raw logits into z_nv_and_grad. After the kernel, lse_local is reduced with logsumexp along the tile axis to produce lse_global; when gradient buffers are requested, linear_xent_mini_bwd_prologue_kernel rewrites the cached logits as (softmax - one_hot)/N and stores them back into z_nv_and_grad so torch.addmm can accumulate the weight updates without recomputing the logits. The wrapper iterates over all chunks, optionally remaps ignore_index, keeps per-chunk losses, and finally returns losses.sum() + lse_global.sum() / N.
