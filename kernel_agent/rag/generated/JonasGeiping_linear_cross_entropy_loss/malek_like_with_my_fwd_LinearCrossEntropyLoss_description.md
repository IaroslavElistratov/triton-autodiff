- kernel family: linear cross-entropy (single-tile Triton matmul + log-sum-exp)
- concise summary: Streams the full class dimension in `V_BLOCK_SIZE` slices to jointly compute logits, softmax normalizers, and per-example losses while caching logits for later reuse.
- detailed summary: Each program handles `N_BLOCK_SIZE` samples, advances block pointers over `H_BLOCK_SIZE` fragments of `x` and `A_t`, and accumulates `z_j_to_k = x @ A_t` for one class tile at a time. It keeps a running max `m` and rescaled sum `s` for numerical stability, subtracts the ground-truth logit from a partial loss, then after all class tiles adds the log-sum-exp term and writes both the logits (`z_nv_ptr`) and the row-wise `lse` buffer. The forward host splits the batch into `N_group` chunks, launches the autotuned kernel over the N axis, and, when gradients are needed, immediately normalizes the cached logits via the auxiliary kernel so downstream steps can reuse the saved softmax probabilities.
