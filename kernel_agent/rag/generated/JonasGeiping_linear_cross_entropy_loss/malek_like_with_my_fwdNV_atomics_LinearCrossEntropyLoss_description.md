- kernel family: linear cross-entropy (Triton fused matmul with atomic accumulation)
- concise summary: Performs the batched logits matmul while accumulating numerically stable loss statistics via atomics so multiple V tiles can collaborate on each sample without staging auxiliary buffers.
- detailed summary: Each program handles `N_BLOCK_SIZE` samples and sweeps four `V_BLOCK_SIZE` class tiles, repeatedly loading `H_BLOCK_SIZE` slices of `x` and `A_t` to build logits, maintain a running max `m`, and update an exponentiated sum `s`. After subtracting the ground-truth logit from the loss accumulator, it writes logits to `z_nv_ptr` and atomically adds both the partial loss and exp(log-sum-exp) contributions into per-sample scalars stored in global memory. The forward host loop chunks the batch, launches the autotuned kernel, folds the atomic buffers into the final loss expression, and optionally normalizes the cached logits in-place so saved tensors already contain softmax probabilities for future reuse.
