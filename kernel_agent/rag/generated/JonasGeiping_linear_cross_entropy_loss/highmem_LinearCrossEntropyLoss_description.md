- kernel family: loss (high-memory fused cross-entropy using full logits staging)
- concise summary: Tiles the activation matrix against `Aᵀ`, materializes every vocab tile in registers, accumulates a numerically stable log-sum-exp while atomically adding the loss, and stores per-sample `lse` for a later dense backward that reads the staged logits matrix.
- detailed summary: `linear_xent_fwd_kernel_matmul_t` enforces divisible tile sizes, loads `H_BLOCK_SIZE` stripes of `x` and `Aᵀ` to build `V_BLOCK_SIZE` logits in fp32, and maintains running `m`/`s` values so log-sum-exp can be updated without overflow. After subtracting the gold-class logit per row, it advances pointers to the next vocab tile, looping until the full vocabulary has been processed. The kernel writes the final `lse` vector into global memory and atomically accumulates the block's loss contribution into a single scalar buffer—hence the “highmem” label, as all logits are realized and kept for backward. The Python forward launcher allocates fp32 loss and `lse` tensors, launches the autotuned kernel over `N / N_BLOCK_SIZE`, and saves `(x, y, Aᵀ, lse)` so the backward stage can reconstruct gradients without recomputation. Forward execution therefore favors simplicity—explicitly materializing logits and statistics—at the cost of higher memory traffic compared to the recompute-based variants.
