- kernel family: linear cross-entropy (tiled logits matmul with streaming log-sum-exp)
- concise summary: Triton programs stream the X·At product over V tiles while maintaining per-row maxima and exponent sums so the host can accumulate numerically stable cross-entropy losses by chunking the batch (`N_group`) and caching logits for later gradient use.
- detailed summary: Each forward kernel instance maps to an `N_BLOCK_SIZE` by `V_BLOCK_SIZE` tile, iteratively loading X and At submatrices along H to form logits, updating running row maxima `m` and exp-accumulators `s`, subtracting the ground-truth logit from a local loss buffer, and writing both logits and condensed log-sum-exp terms to workspace tensors before rewinding the block pointers for the next V tile. The Python launcher slices the batch into `N_group`-sized chunks, launches the tuned matmul kernel, reduces the per-tile loss and log-sum-exp buffers into a scalar loss, and—when gradients are needed—invokes a companion Triton prologue that reads the cached logits, normalizes them via the stored log-sum-exp, and overwrites the workspace with `(softmax - one_hot)/N` so standard matrix multiplies can produce dX and dAt without another pass over the activations.
