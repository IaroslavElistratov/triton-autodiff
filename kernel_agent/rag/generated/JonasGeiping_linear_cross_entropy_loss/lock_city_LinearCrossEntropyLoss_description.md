- kernel family: loss (instrumented high-memory cross-entropy with verbose tiling)
- concise summary: Runs the standard tile-wise matmul-and-logsumexp routine, emitting `tl.static_print` diagnostics for the chosen block sizes, atomically accumulates the averaged loss into a scalar buffer, and stores per-row log-sum-exp values for later use.
- detailed summary: The forward kernel demands that `N`, `H`, and `V` divide the selected tile sizes, then loads each `N_BLOCK_SIZE × H_BLOCK_SIZE` slice of `x` and multiplies it by matching slices of `Aᵀ` to build `V_BLOCK_SIZE` logits at a time. It maintains running maxima and exponent sums so log-sum-exp can be computed without numerical blow-up, subtracts the labeled logit scaled by `1/N`, and advances the block pointers across the vocabulary. After the loop, the kernel writes the completed log-sum-exp vector to global memory and uses `tl.atomic_add` to fold the block’s loss into the single scalar output; verbose `tl.static_print` calls expose the active tile configuration for debugging. The Python launcher enforces 16-way divisibility, allocates fp32 buffers for `loss` and `lse_global`, launches the autotuned kernel across `N / N_BLOCK_SIZE`, logs the winning configuration, and saves `(x, y, Aᵀ, lse)` so subsequent stages can consume the cached statistics instead of recomputing logits.
