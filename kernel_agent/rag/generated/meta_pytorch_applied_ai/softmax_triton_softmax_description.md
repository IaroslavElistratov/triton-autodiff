- kernel family: row-wise softmax (training variant)
- concise summary: The Triton kernel computes softmax across each row of a flattened tensor, executing the max subtraction, exponentiation, and normalization in-register for stability and throughput.
- detailed summary: `_softmax_kernel_fwd` launches one program per row, loads a `block_size = next_power_of_2(n_cols)` slice of logits, masks out tail elements, and subtracts the row maximum before exponentiating. It accumulates the denominator via `tl.sum`, divides the numerator to obtain probabilities, and writes the result back to the corresponding row-strided output. The forward wrapper reshapes the input to 2D, picks a warp count keyed on the tile size, allocates the result buffer, and dispatches the kernel while caching the probabilities for the backward step.
