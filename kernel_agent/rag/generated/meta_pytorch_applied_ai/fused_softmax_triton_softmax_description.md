- kernel family: row-wise softmax (fused, numerically stable)
- concise summary: The forward kernel performs a single-pass softmax across each row, subtracting the row maximum for stability, exponentiating, summing, and normalizing within Triton before writing the probabilities.
- detailed summary: `_softmax_kernel_fwd` assigns each `tl.program_id(0)` to one flattened row, loads a `block_size = next_power_of_2(n_cols)` tile of logits with masking, subtracts the maximum to avoid overflow, and evaluates the exponentials and denominator inside registers; the normalized probabilities are then streamed back to contiguous output rows. The Python wrapper reshapes the tensor to 2D, allocates the output, picks a warp count based on `block_size`, and launches one CTA per row while optionally storing the result for the backward pass.
