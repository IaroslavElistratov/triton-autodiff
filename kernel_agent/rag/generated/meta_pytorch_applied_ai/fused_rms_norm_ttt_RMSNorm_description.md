- kernel family: RMS normalization (fused normalization + scale)
- concise summary: The forward kernel normalizes each row to unit root-mean-square using an epsilon-stabilized reciprocal stddev and multiplies by a learnable weight vector, caching the row-wise rstd values for backward.
- detailed summary: `_rms_norm_fwd_kernel` gives every CTA one row of the flattened `[M, N]` activation, loading a power-of-two tile of features into fp32 registers alongside the weight slice. It squares-and-sums the masked tile to compute the mean squared value, derives `rstd = 1 / sqrt(var + eps)`, and stores this scalar to `Rstd` for reuse. The normalized activations `x_hat = x * rstd` are then multiplied elementwise by the weights (`w`), and the result is written back with masking for partial tiles. The launcher flattens the input, ensures contiguous strides, allocates the `rstd` buffer, chooses `block_N = min(64KB/elem, next_power_of_2(N))`, and dispatches one kernel instance per row with autotuned warp count keyed on `N`.
