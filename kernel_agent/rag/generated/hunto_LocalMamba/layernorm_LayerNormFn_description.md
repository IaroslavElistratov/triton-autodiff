- kernel family: layer normalization (optional residual fusion / RMSNorm path)
- concise summary: Normalizes each row of an M×N activation matrix in a single Triton pass, optionally adding a residual input, returning the residual in a requested dtype, and handling both standard LayerNorm and RMSNorm variants with affine weights/biases.
- detailed summary: The launcher reshapes inputs to 2-D (flattening leading dims), ensures contiguous strides, materializes per-row mean/rstd buffers (skipping mean for RMSNorm), and allocates an auxiliary residual tensor when the residual needs a distinct dtype or must be returned for prenorm. The kernel assigns one thread block per row; it loads a BLOCK_N-wide tile of `x`, adds residual contributions if requested, and optionally writes the fused activations into `RESIDUAL_OUT`. For standard LayerNorm it computes the mean and variance across the row, whereas RMSNorm bypasses the mean and just accumulates the squared magnitude. After deriving the reciprocal std with epsilon stabilization, it loads the scale (and bias) parameters, normalizes the row (`(x-mean)*rstd` or `x*rstd`), applies the affine transform, and stores the result. Kernel autotuning sweeps warp counts to cover different widths while the host side enforces `BLOCK_N ≤ 64kB / element_size` to keep the 1-pass implementation valid.
