- kernel family: local patch scan (K×K window to sequential channel reorder)
- concise summary: Pads BCHW inputs to K-aligned dimensions, then sweeps each K×K spatial window and writes it into contiguous channel slots (with optional flipping) to produce a locally scanned representation.
- detailed summary: The forward helper pads ragged shapes via `pad_tensor`, chooses Triton tile sizes for channels (`BC`) and spatial tiles (`BH`,`BW`), and launches `triton_local_scan` with grid (NH·NW, NC, B) so that every program owns one spatial tile and channel block. Within the kernel it builds masks for partial tiles, loads a BH×BW patch, computes per-element offsets by mapping its absolute indices into window coordinates (`DW//K` groups by row/col), and adds an optional flip that reverses the flattened window order. As it iterates through channel blocks it streams the masked patch into the output tensor at `BC`-strided offsets, effectively stacking the window pixels along the channel dimension (or flattening to B×C×(H·W) when requested). A debug barrier ensures writes complete before the kernel exits, and the wrapper returns the padded layout without post-cropping, leaving backward to invert the permutation.
