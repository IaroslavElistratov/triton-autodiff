- kernel family: fused layer normalization + linear projection (optional residual/RMSNorm)
- concise summary: First runs the one-pass Triton layer-norm kernel with optional residual fusion and RMSNorm support, then immediately feeds the normalized activations into a dense linear projection using autocast-aware weights/biases.
- detailed summary: The host reshapes the input to 2-D, prepares contiguous residual/norm parameters, and invokes `_layer_norm_fwd` to launch the same per-row Triton kernel used by the standalone LayerNorm op—computing means/variances (or RMS) in fp32, accumulating residual additions, and storing reciprocal standard deviations plus an optional residual-out tensor. Once the normalized tensor is reshaped back to the original batch form, the code promotes the linear weights (and bias) to the active autocast dtype and applies `F.linear`, yielding the projected output. Context objects stash the normalized activations (or residual-out) and scaling stats for backward while optionally returning both the linear output and residual tensor in prenorm mode. No backward-specific logic leaks into the summary; the forward path is essentially “LayerNorm → affine → linear matmul” executed with the Triton normalization fused ahead of a PyTorch GEMM.
