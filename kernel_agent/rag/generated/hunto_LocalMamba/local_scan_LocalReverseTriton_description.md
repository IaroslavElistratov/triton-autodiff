- kernel family: local patch reversal / permutation (windowed BCHW tensor rearrangement)
- concise summary: Tiles the spatial grid into K×K windows, remaps each window’s pixels into a channel-major layout (optionally reversed), and writes the reordered data back to a padded BCHW tensor that is cropped to the original size.
- detailed summary: The host ensures the height/width are multiples of K by padding if needed, computes Triton tile sizes (`BC`,`BH`,`BW`) and grid counts (`NC`,`NH`,`NW`), and launches `triton_local_reverse` with grid (NH·NW, NC, B) so each kernel instance processes one spatial tile and one block of channels for a batch element. Within the kernel, it creates masks for partial tiles, loads the BH×BW patch from the source tensor, flattens window indices into `K×K` coordinates, and computes the destination offsets either directly or via the flip transformation (`DH·DW - offset - 1`). For each channel block it streams the masked patch into the destination buffer at the computed offsets, thereby reordering local windows into contiguous channel chunks. The forward wrapper then trims any padding and flattens back to B×C×(H·W) if the original input was 3D.
