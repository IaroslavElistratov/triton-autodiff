- kernel family: rotary position embedding (cached sin/cos, S×B×H×D layout)
- concise summary: Tiles sequence blocks per batch/head, indexes precomputed cos/sin tables using absolute or provided positions/offsets, performs GPT-J or NEOX rotations, and writes the mixed output while optionally preserving NOPE segments.
- detailed summary: `_rope_kernel_sbhd_cached_fwd` operates on `(sequence-block, batch, head)` triples; it fetches per-token indices from `positions` (plus optional offsets), maps feature indices depending on whether front-part reuse is enabled, and loads the corresponding cos/sin entries from cached tables. After gathering the source slice it constructs the rotated companion via helper routines, computes `x·cos + x_rot·sin`, and stores the rotated slice back (handling both inplace and out-of-place paths, as well as NOPE-first layouts by copying untouched halves). This kernel supports GPT-J/NEOX rotations over packed `(S, B, H, D)` tensors without needing cumulative sequence metadata.
