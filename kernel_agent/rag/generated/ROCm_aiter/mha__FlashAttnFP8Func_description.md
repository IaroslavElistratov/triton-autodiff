- kernel family: attention (flash attention with FP8 quantized QKV)
- concise summary: Pads heads to multiples of eight, quantizes Q/K/V to FP8 with per-(batch,head) scales, and invokes a Triton flash-attention kernel that streams tiles of the quantized tensors with optional dropout, causal masking, and ALiBi bias, returning float32 accumulations trimmed back to the original head width.
- detailed summary: The forward path first infers or pads the head size, chooses the ROCm FP8 e4m3 format, and `_cast_to_fp8` computes scaling/descaling factors by clamping per-tile maxima before converting the 4D Q/K/V tensors. `_flash_attn_forward` then prepares dense or variable-length strides, zero-initializes outputs, softmax log-sum-exp buffers, and (if needed) dropout masks, and selects launch parameters from device-specific configs. The `_attn_fwd` kernel maps each work item to a query block within a (batch, head) pair, remaps heads across XCDs for load balance, loads BLOCK_M×BLOCK_N tiles of Q and K (respecting optional positional encoding channels), forms scaled dot products in float32 using the descale factors, adds ALiBi bias, applies causal or windowed masks plus dropout, maintains running max/LSE, and finally mixes with V tiles while writing results (and optional score tensors) in the chosen accumulation dtype.
