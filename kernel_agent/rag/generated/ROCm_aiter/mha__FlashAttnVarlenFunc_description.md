- kernel family: attention (flash attention, variable-length sequences, standard dtype)
- concise summary: Pads head dimensions, then drives the varlen flash-attention launcher over ragged Q/K/V using sequence prefix sums to bound each tile while supporting causal masks, dropout, and ALiBi before projecting the trimmed result back.
- detailed summary: The forward wrapper infers the scaling factor (default 1/√d), pads Q/K/V to multiples of eight, and hands the jagged tensors plus `cu_seqlens` to `_flash_attn_forward`, which recognizes varlen mode, constructs batched/head strides, zero-initializes outputs and softmax-LSE buffers, seeds dropout RNG if needed, and picks ROCm-tuned block sizes. The `_attn_fwd` kernel iterates over BLOCK_M query rows per (batch, head), remaps head indices for XCD balancing, loads the permissible key/value tiles bounded by each sequence’s slice, forms scaled q·k in float32, injects ALiBi bias and causal/window masking, maintains running max/exp sums, optionally materializes dropout masks, and fuses the V accumulation into the output tensor that is finally cropped back to the original head width.
