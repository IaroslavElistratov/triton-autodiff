- kernel family: normalization (fused residual add + RMSNorm)
- concise summary: Streams residual additions and RMS normalization together so each row is summed once, accumulates the RMS statistic in float32, and writes both the residual buffer and the scaled output using adaptive tiling.
- detailed summary: The forward driver allocates `rsigma`, chooses a power-of-two tile size, decides between blocked or single-pass modes, and launches `_fused_add_rmsnorm_kernel` with one program per SM. Inside the kernel each program walks its assigned rows, adds `x` and `res_in` into `res_out`, accumulates sum-of-squares across BLOCK_SIZE tiles to form the RMS norm factor (`1/sqrt(mean_square+eps)`), stores it, and replays the stored tiles to multiply by the per-channel weights and norm factor. In the narrow case it processes the whole row in one pass while still caching the residual sum and writing masked tails.
