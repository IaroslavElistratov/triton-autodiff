- kernel family: attention (flash attention, variable-length sequences, FP8 QKV)
- concise summary: Converts ragged Q/K/V streams into FP8 per batch-head slice using prefix offsets, then calls the varlen flash-attention launcher that tiles over padded maxima while respecting the sequence boundaries and optional dropout/ALiBi features before trimming any padding.
- detailed summary: The forward helper `_cast_varlen_to_fp8` walks each batch range described by `cu_seqlens`, captures per-head maxima, and emits FP8 tiles alongside descale factors. `_flash_attn_forward` recognizes the varlen mode (cu_seqlens provided), builds strides for the jagged layout, zero-fills outputs and log-sum-exp buffers, seeds dropout RNG if enabled, and selects ROCm-tuned block sizes. Its `_attn_fwd` kernel uses remapped head IDs to balance XCDs, loads BLOCK_M chunks of queries across the ragged layout, streams compatible key/value tiles bounded by per-sequence limits derived from `cu_seqlens`, applies scaled q·k in float32 using the descale factors, injects causal masking and optional ALiBi offsets, maintains running softmax statistics, and fuses the value accumulation plus optional score materialization before the wrapper slices away the temporary head padding.
