- kernel family: normalization (fused residual add + layer norm)
- concise summary: For each row it fuses the residual addition into the layer-norm forward pass, computing statistics over the summed activations, normalizing them, and writing both the residual output and affine-normalized tensor.
- detailed summary: The wrapper preallocates per-row mean/inv-std buffers and chooses a power-of-two tile size capped by the 64 KB rule before launching `_fused_add_layernorm_kernel` with one program per row. Inside the kernel, each program streams BLOCK_SIZE tiles of `x` and `res_in`, accumulates the sum into `res_out`, builds the row mean and variance in float32, stores mean/rstd for autograd, and replays the stored tiles to normalize `(res_out - mean)*rstd`, apply the learned weight/bias, and commit the normalized output with masking for tail columns.
