- kernel family: normalization (layer norm with affine weights, Triton row kernel)
- concise summary: Launches a per-row Triton kernel that streams blocks of the feature dimension to compute mean/rstd in float32, then applies affine scaling with the provided weights and bias while caching the statistics.
- detailed summary: The forward wrapper allocates output along with per-row mean and inverse std buffers, chooses a power-of-two block size bounded by the 64 KB limit, and dispatches `_layernorm_kernel` with one program per row. Each program iterates over the feature columns in BLOCK_SIZE chunks: it first accumulates the sum to form the mean, reloads the blocks to accumulate variance, derives `rstd = 1/sqrt(var+eps)`, stores mean/rstd, and finally replays the column tiles to normalize `(x-mean)*rstd`, multiply by `weight`, add `bias`, and write the results using masks for tail columns.
