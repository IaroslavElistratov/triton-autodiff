- kernel family: attention (flash attention, dense heads with optional dropout/ALiBi)
- concise summary: Pads heads to multiples of eight, then feeds Q/K/V into a Triton flash-attention launcher that tiles over batches and heads, applies scaled dot products with optional causal masking, dropout, and ALiBi bias, and returns the de-padded output plus optional softmax diagnostics.
- detailed summary: The forward helper `_flash_attn_forward` prepares dense or jagged (cu_seqlens) memory strides, zero-initializes the output tensor, log-sum-exp buffers, and optionally score/dropout masks, and picks tile sizes from ROCm-specific configs. It launches `_attn_fwd` with a grid spanning `(batch × heads × cdiv(seq_q, BLOCK_M))`; each kernel instance remaps heads across compute dies, loads BLOCK_M queries, streams BLOCK_N keys/values, forms scaled q·k in float32, injects ALiBi offsets, enforces causal or window constraints, accumulates softmax normalization via running max/LSE, optionally materializes dropout masks, and fuses the value accumulation. After the kernel completes, the wrapper slices away any padding and decides whether to expose the per-row log-sum-exp or score tensor without touching the backward path.
