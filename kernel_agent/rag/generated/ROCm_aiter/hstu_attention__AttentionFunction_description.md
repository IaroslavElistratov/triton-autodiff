- kernel family: attention (HSTU jagged sequences with causal/multi-target masking)
- concise summary: Dispatches a Triton kernel that batches over sequences and heads, tiles the jagged Q/K/V layout, and performs silu-gated dot-product attention with rich masking for causal, contextual, and multi-target constraints.
- detailed summary: The launcher materializes optional length-sorted indices, caches metadata, and selects per-device configs before invoking `_hstu_attn_fwd` on a grid of (sequence tiles × heads). Each program maps to one (sequence, head) pair, derives the actual subsequence span from `seq_offsets`, constructs block pointers into Q/K/V, and streams BLOCK_M queries against BLOCK_N key/value tiles. Within `_hstu_attn_fwd_compute`, it accumulates float32 outputs by repeatedly calling `_hstu_attn_fwd_one_block`, which loads a K tile, forms q·k scaled by `alpha/MAX_SEQ_LEN`, applies silu activation, and zeroes contributions based on causal windows, contextual lengths, target counts, and optional max attention length before mixing with the corresponding V tile. The kernel writes the accumulated tiles back either to contiguous sequence storage or a delta-Q window without ever touching the backward path.
