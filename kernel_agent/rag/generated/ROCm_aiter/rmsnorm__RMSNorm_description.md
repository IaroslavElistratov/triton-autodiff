- kernel family: normalization (RMSNorm with adaptive tiling)
- concise summary: Picks tile sizes from hardware heuristics, then runs a Triton kernel that sweeps each row to accumulate the RMS statistic in float32 before scaling the row by its inverse root-mean-square and the learned weights.
- detailed summary: `_rmsnorm_forward` allocates the normalized output plus an `rsigma` buffer, computes a power-of-two block size bounded by 64 KB, toggles between blocked and single-pass modes based on feature width, and launches `_rms_norm_kernel` with up to one program per SM. In blocked mode, each program strides over its assigned rows, iterates across column tiles to accumulate sum of squares, derives `norm_factor = 1/sqrt(mean_square + eps)`, stores it, and streams the tiles again to multiply the original data by both `norm_factor` and the per-channel weight; in the narrow mode it loads the whole row, computes the RMS in one shot, and emits the scaled row with masked writes for tail elements.
