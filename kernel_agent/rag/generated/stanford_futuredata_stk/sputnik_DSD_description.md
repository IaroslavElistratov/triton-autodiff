- kernel family: sparse matmul (block-sparse × dense, Sputnik format)
- concise summary: Consumes a block-sparse left operand and a dense right operand, expanding nonzero blocks on the fly to produce dense output tiles.
- detailed summary: Programs cover `(BLOCK_M, BLOCK_N)` tiles of the result; for each active row block (tracked by `offsets`) they step through the nonzero BLOCK_SIZE×BLOCK_SIZE tiles, loading either the raw data tensor or its transposed view, and gather the matching dense slice from the right matrix (with optional stride swaps if RHS is effectively transposed). Each contribution performs a `tl.dot` in fp32, accumulates into the output register tile, and at the end casts/stores the BLOCK_M×BLOCK_N tile back to the requested dtype, mirroring the block-sparse metadata that came from the Sputnik layout.
