- kernel family: sparse matmul (dense × dense → block-sparse output, Sputnik format)
- concise summary: Tiles the dense operands, multiplies them in fp32, and writes only the block positions listed in the sparse metadata into the block-sparse output buffer.
- detailed summary: The `_sdd_kernel` launches one program per nonzero block; it reads the destination block’s `(row, column)` indices, computes the contiguous row/col ranges, and streams through the K dimension in BLOCK_K chunks to multiply the corresponding dense tiles from `lhs` and `rhs`. Partial sums accumulate in fp32 registers before being cast to the output dtype and stored at the block’s offset within the block-sparse storage (using `BLOCK_SIZE^2` strides), while the host wrapper picks strides based on whether either dense operand is effectively transposed.
