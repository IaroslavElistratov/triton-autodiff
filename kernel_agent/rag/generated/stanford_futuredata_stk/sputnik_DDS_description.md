- kernel family: sparse matmul (dense × dense-sparse hybrid, Sputnik block format)
- concise summary: Multiplies a dense left matrix with a block-sparse right matrix by iterating over the nonzero column blocks and accumulating BLOCK_M×BLOCK_N output tiles.
- detailed summary: The `_dds_kernel` assigns each program to a `(BLOCK_M, BLOCK_N)` tile of the dense output, walks the CSR-style `offsets` to find which BLOCK_SIZE×BLOCK_SIZE tiles of the right-hand operand contribute, and for every tile loads the matching slice from the left matrix (with optional transpose handling) plus the block-sparse data before `tl.dot` accumulating in fp32. Autotune fixes block sizes from `TritonConfig`, the launcher swaps strides when operands are logically transposed, and the final fp32 accumulator is cast back to the output dtype and stored dense.
