- kernel family: chunked gated delta-rule attention
- concise summary: Applies delta-rule attention with multiplicative gates by chunking the sequence, computing a gated lower-triangular kernel from keys, solving it to obtain WY factors, evolving a gated recurrent state, and mixing the gated values with the queries.
- detailed summary: The forward pass converts the gate tensor `g` into chunkwise cumulative sums, uses `chunk_scaled_dot_kkt_fwd` to assemble `A = beta·K·Kᵀ` with gate weighting, and inverts `(I + A)` via `solve_tril`. It then rebuilds the WY matrices `w` and `u` with `recompute_w_u_fwd`, launches `chunk_gated_delta_rule_fwd_h` to march through the tokens in 64-length blocks—multiplying the state by the exponentiated gate offsets, injecting the delta updates, and optionally capturing the terminal state—and finally calls `chunk_fwd_o` to combine the queries with the gated state/value stream and emit the output tensor. The saved context includes the gated cumulative sums, triangular factors, and WY buffers for backward reuse.
