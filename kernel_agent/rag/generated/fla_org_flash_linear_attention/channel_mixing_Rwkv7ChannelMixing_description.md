- kernel family: sequence mixing (RWKV v7 channel mixer with fused pointwise ops)
- concise summary: The forward path first applies the Triton `rwkv_seq_mix_kernel` to blend each token with either the previous token or a cached state using per-channel gains `x_k`, then projects through a key matrix, applies a fused ReLU² nonlinearity, and finally multiplies by the value matrix to produce the mixed activations.
- detailed summary: `rwkv_mix_fwd` prepares a flat launch over `batch·seq·hidden` positions; for each element the kernel loads the current activation, picks the preceding value (`x_prev` for the first timestep, otherwise the prior token), computes `(prev - current) * mix_k` in fp32, and writes `current + mixed` to `k1`. The wrapper reshapes as needed for batched or unbatched inputs. It next contracts `k1` with `key_weight`, then invokes `rwkv_channel_mixing_pow_and_relu`, whose single-pass kernel applies `ReLU` and squares the result tilewise. The nonlinearity output is finally multiplied by `value_weight`, yielding the channel-mixed tensor; intermediate tensors needed for backward (`x`, `x_prev`, `x_k`, `key_weight`, `value_weight`) are saved in the context.
