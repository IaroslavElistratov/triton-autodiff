- kernel family: recurrent gated RNN (HGRN chunked scan)
- concise summary: Computes the HGRN state update by scanning each chunk of the sequence, exponentiating the gate to decay the hidden state `h`, adding the new input, and then propagating the chunk boundary state forward so every timestep sees the accumulated history.
- detailed summary: The first Triton kernel tiles the `(B, T, D)` tensor into `BT×BD` blocks; within each block it iterates sequentially, loading `x` and `g`, updating the running state `h = exp(g)·h + x`, and recording both the state and the cumulative gate sum `gc`. A second kernel walks chunk boundaries, loading the last state of the previous block, reapplying the stored `exp(gc)` factors, and adding the carry to the current block’s outputs so the recurrence spans the entire sequence. The forward path optionally seeds `h` with `initial_state` for chunk 0 and, if requested, returns the final state after casting the accumulated output back to the input dtype.
