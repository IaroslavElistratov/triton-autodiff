- kernel family: loss (fused cross entropy with optional sharding)
- concise summary: Computes per-row cross entropy, z-loss, and optional label smoothing directly from logits, supporting column sharding and distributed splits without materializing full probabilities.
- detailed summary: cross_entropy_fwd_kernel tiles the vocabulary into BLOCK_SIZE slices so each launch handles one minibatch row and column block, applies the logit_scale, performs local log-sum-exp, and writes partial losses, lse, and z-loss while skipping ignore_index targets. fused_cross_entropy_forward orchestrates this across splits and process groups: it optionally all-gathers lse across ranks, sums partial losses, recomputes the z-loss term if needed, and zeroes ignored positions. The backward path is untouched, so the forward returns the loss tensors along with cached metadata for later reuse.
