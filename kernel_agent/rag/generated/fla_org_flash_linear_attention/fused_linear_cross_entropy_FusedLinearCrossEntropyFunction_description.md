- kernel family: loss (fused linear layer + cross entropy)
- concise summary: Fuses the final linear projection and cross-entropy loss into a single forward pass that normalizes logits, optionally applies label smoothing or L2 warp penalties, and materializes gradients immediately.
- detailed summary: The host splits the batch into manageable chunks, runs F.linear to produce logits, then calls logsumexp_fwd_kernel to get per-row normalization constants and cross_entropy_kernel to overwrite the logits buffer with ∂L/∂logits, adjusting for smoothing, ignore_index, and reduction mode. Optional L2 warp regularization adds head-specific penalties using torch.scatter. Accumulated weight/bias gradients are built by matrix-multiplying the stored gradients with the inputs, so later backward steps can reuse the buffered tensors without recomputing the expensive softmax.
