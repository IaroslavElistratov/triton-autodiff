- kernel family: normalization + projection (quantized layer norm followed by bitlinear matmul)
- concise summary: The forward pass performs a fused layer/RMS norm with optional residual caching, quantizes the normalized activations to int8 range, applies a per-tensor 1.58-bit quantization to the linear weights, and executes the dense projection (optionally returning the residual when used in prenorm mode).
- detailed summary: `layer_norm_fwd_kernel_quant` assigns one program per row, folds in an optional residual, computes the mean/variance (or RMS), and applies the affine parameters; before storing it scales the activations by a per-row max to map them to ±127, rounds/clamps, and rescales back so the subsequent matmul operates on quantized-friendly values. The wrapper reshapes the input to 2-D, selects whether residual accumulation stays in fp32, launches the kernel, and reshapes the normalized output. It then quantizes the linear weight tensor with `weight_quant`, casts to the current autocast dtype, and calls `F.linear` with the (optionally float) bias to produce the final activation. All intermediates—quantized residual buffer, norm stats, quantized weight—are cached in `ctx` so backward can reconstruct gradients while respecting the quantization scheme.
