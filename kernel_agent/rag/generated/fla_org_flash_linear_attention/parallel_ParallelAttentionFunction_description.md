- kernel family: attention (parallel chunked softmax with gating)
- concise summary: Implements causal attention in BT=128 chunks, maintaining log-sum-exp accumulators in base-2 for numerical stability and optionally incorporating cumulative gates g to bias scores.
- detailed summary: The host precomputes a chunked global cumsum of the gate stream and picks tile sizes (BS, BK, BV) based on architecture. parallel_attn_fwd_kernel operates on (value tile, chunk index, batch·HQ) programs: it loads a BT block of Q, streams over earlier blocks accumulating b_m/b_acc while adjusting scores by the difference in g_cumsum, then handles the in-block causal region by masking upper-triangular positions. Outputs are normalized by dividing the accumulated values by b_acc and writing lse = log₂(accum) for reuse, all without invoking backward work.
