- kernel family: attention approximation (chunked “based” kernel with quadratic Taylor expansion)
- concise summary: The forward Triton kernel iterates over 16-token chunks, keeps running zeroth/first/second-order statistics of past K/V tiles, and uses them to evaluate the quadratic Taylor approximation `1 + s + ½s²` for the current Q·K scores, producing both the accumulated output tiles and their normalizers.
- detailed summary: With grid `(V-block, K-block, batch·head)`, each program loads a scaled Q block, the matching K/V panels, and maintains three history tensors: `h0` (sums of V), `h1` (sums of K⊗V), and `h2` (sums of (K⊗K)⊗V) along with scalar counters `k0`, `k1`, `k2`. On every loop iteration it (1) contributes the historical terms to the current output (`b_o += h0 + q·h1 + ½(q⊗q)·h2`) and normalizer, (2) updates the running K statistics with the newly loaded tile, (3) evaluates `b_s = 1 + q·k + ½(q·k)²` under a causal mask, adds this to the normalizer and multiplies it with V for the streaming output, and (4) stores the tile results into staging tensors `o` and `z`. After writing, it updates `h0/h1/h2` with the fresh K/V contributions and advances the block pointers. The wrapper launches the kernel with fixed chunk sizes (`BT=16`) across all NK key splits and sums the partial results over NK before returning the fp32 output and normalization tensors, caching Q/K/V for backward.
