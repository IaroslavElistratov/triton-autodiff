- kernel family: chunked generalized IPLR delta-rule attention (interpolated low-rank)
- concise summary: Uses the interpolated low-rank (IPLR) delta-rule formulation—building WY factors from auxiliary bases `a`/`b`, evolving a recurrent state over chunked timesteps, and combining queries with both the carried state and chunk-local corrections to emit the output.
- detailed summary: The forward pass calls `prepare_wy_repr_fwd` to generate the WY representation (`w`, `u`) from `a`, `b`, `k`, and `v`. Next, `chunk_generalized_iplr_delta_rule_fwd_h` iterates through the sequence in 64-token blocks: for each sub-block it loads the current key slice, the auxiliary matrices `b`, accumulates `b·(dot(d, h) + u)` contributions, updates the state `h`, and writes an intermediate value stream `v_new`, all while honoring optional initial/final states and variable-length segments. Finally `chunk_generalized_iplr_delta_rule_fwd_o` processes each chunk again, contracting the queries with `h` and the triangular coefficients derived from `k` and `b`, and adds the `v_new` corrections scaled by `scale` to form the attention outputs, returning them along with the optional terminal state tensor.
