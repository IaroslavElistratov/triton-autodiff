- kernel family: loss (GRPO policy gradient objective)
- concise summary: Evaluates the GRPO objective per token by forming log-sum-exp over logits, subtracting the reference log-prob, and combining KL and advantage terms, respecting completion masks and optional KL saving.
- detailed summary: grpo_fwd_kernel assigns one row (batch, time) per program, iterates over the vocabulary tile-by-tile to compute the global lse and recover the target logit, then uses ref_logp, advantages, and beta to evaluate loss = β·KL(ref||π) - advantage (and optionally store KL). The forward wrapper preallocates loss/lse buffers, fills a default completion mask when absent, and launches the kernel with BLOCK_SIZE chosen from autotuned configs. No backward math is performed in this forward-only routine.
