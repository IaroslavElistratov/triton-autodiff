- kernel family: chunked log-linear attention (hierarchical time-dilated scheme)
- concise summary: Implements log-linear attention by chunking the sequence, building hierarchical key/value caches for each binary level inside a chunk, and using gated exponentials plus level-dependent scaling factors to accumulate the attention output, all while supporting warm-start states and optional final-state capture.
- detailed summary: The forward routine optionally merges a provided `initial_state` with the new sequence via `copy_input_kernel`, then applies `chunk_local_cumsum` to turn the gate tensor `g` into prefix-sum weights. A precomputed level lookup table feeds the main `chunkwise_fwd_kernel`, which iterates over chunks of size 64: it keeps per-level KV accumulators (`kv_0 … kv_11`), loads the relevant level coefficients from `level_scales`, multiplies query/key blocks with the gated exponentials `exp(g_i - g_j)`, and adds the resulting contributions to the chunk output buffer. Chunk boundaries update offsets and, if requested, the kernel records multi-level summary tensors `ht` so later calls can resume. Finally, if `output_final_state` is true, `copy_last_chunk_kernel` extracts the tail chunk to form a `LogLinearAttentionState`; otherwise the stacked chunk outputs are summed across the K/BK dimension and returned directly.
