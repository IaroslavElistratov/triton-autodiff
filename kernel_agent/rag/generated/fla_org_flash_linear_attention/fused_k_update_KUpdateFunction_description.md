- kernel family: recurrent update (RWKV7 key cache refresh)
- concise summary: Applies the elementwise update k_out = k * (1 + (a-1)*ka) over entire batches, choosing between a simple per-token kernel for short sequences and a chunked traversal for long or ragged sequences.
- detailed summary: When T ≤ 512, k_update_fwd_kernel_short launches over (N, T) to read contiguous blocks of K, A, and KA, uses an evict_last policy to reuse the per-dimension KA vector, and writes the updated keys. For longer or cu_seqlens-backed inputs, k_update_fwd_kernel_long chunkizes time into BT stripes, optionally uses prepare_chunk_indices to respect variable lengths, and lets each (feature chunk, time chunk, batch) program loop over BT timesteps applying the same formula. The forward returns the updated tensor along with mode flags so downstream code can mirror the launch parameters without touching the backward fields.
