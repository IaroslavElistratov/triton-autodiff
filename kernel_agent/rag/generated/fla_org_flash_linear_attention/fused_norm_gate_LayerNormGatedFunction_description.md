- kernel family: normalization (layer norm + learned gate)
- concise summary: Performs layer or RMS normalization over each token, adds optional residual input, and applies a learned activation gate (swish/silu/sigmoid) using a companion tensor g.
- detailed summary: Depending on hidden size, it launches either layer_norm_gated_fwd_kernel (tiling tokens into BT chunks with BD feature tiles) or the 1D layer_norm_gated_fwd_kernel1 to load X (plus residual), compute mean/variance or RMS, and write rstd/mean to temporary buffers. It then scales by weight/bias if provided, multiplies by the gate tensor, writes the normalized output, and optionally stores the residual sum in residual_out. All reductions remain per-block, and forward metadata (mean, rstd, gating choice) is cached for backward while no gradient work is performed here.
