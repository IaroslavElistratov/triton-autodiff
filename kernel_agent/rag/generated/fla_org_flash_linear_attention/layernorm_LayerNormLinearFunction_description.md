- kernel family: normalization (layer norm + linear projection)
- concise summary: Normalizes inputs exactly as the standalone layer norm, then reshapes back and applies a follow-up linear layer in the current autocast precision, with an optional prenorm branch that returns the original (pre-normalized) activations for residual routing.
- detailed summary: The forward flattens batch/time, delegates normalization to the shared kernels (layer_norm_fwd_kernel / _1), collects mean/rstd/residual stats, and reshapes the normalized activations to run `F.linear` with dtype-aligned weights/bias. When `prenorm=True` it bundles the linear output together with `res_out`, which is the pre-normalized tensor produced inside `layer_norm_fwd`; otherwise only the projected output is returned while the context retains the saved inputs/statistics for backward.
