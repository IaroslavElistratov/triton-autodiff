- kernel family: sequence mixing (chunked delta rule without extra low-rank branches)
- concise summary: The forward pass computes per-chunk beta-weighted key–key interactions, inverts the resulting lower-triangular system to obtain transformed key/value streams (`w`, `u`), feeds them through a gated delta-rule recurrence to update the hidden state (optionally returning the last state), and finally projects the queries against the updated values to produce the output.
- detailed summary: `prepare_wy_repr_fwd` first calls `chunk_scaled_dot_kkt_fwd` to accumulate a strictly lower-triangular matrix `A` representing beta-scaled dot products inside each 64-token chunk; `solve_tril` converts `(I + A)` into its inverse, and `recompute_w_u_fwd` multiplies this inverse by the original keys/values to produce the auxiliary streams `w` and `u`. `chunk_gated_delta_rule_fwd_h` then iterates across the sequence: for every block it applies the stored recurrence matrices to evolve an fp32 state tensor `h` (seeding from `initial_state` if provided) and writes the adjusted values `v_new`, capturing the final state when requested. `chunk_fwd_o` completes the forward pass by contracting the (optionally L2-normalized) queries with `k`, `v_new`, and `h` under the given scale, producing the chunked outputs. The wrapper keeps `q`, `k`, `v`, normalization factors, beta, and `A` on the context so backward can reconstruct the same steps.
