- kernel family: gated linear attention (parallel chunked simple GLA with optional gating and varlen support)
- concise summary: The forward path chunks queries into 128-step stripes, tiles key and value dimensions, and uses a Triton kernel to accumulate gated causal attention outputs while optionally materializing attention matrices; auxiliary kernels compute chunkwise prefix sums for the gating vector in either scalar or vector layouts.
- detailed summary: `parallel_simple_gla_fwd` picks tiling parameters from shared-memory budgets, builds chunk indices for variable-length batches, optionally runs `chunk_local_cumsum` to prefix-sum the gating tensor, and launches `parallel_simple_gla_fwd_kernel` on a grid over key/value tiles, query chunks, and batch-head combinations. Inside the kernel each program loads a BT×BK block of queries, scales it, preloads segment-wise gating, and streams over key/value stripes in both forward and backward directions using causal masks to form partial similarity scores, applies exponential gating offsets when present, and accumulates the resulting BT×BV outputs into a private buffer before writing per-tile results (and, if requested, storing the attention slice). The scalar and vector `chunk_local_cumsum_*` kernels traverse chunked sequences per head, performing inclusive scans (with optional reversal and scaling) via Triton block pointers, enabling the gating tensor to be reused efficiently by the main attention kernel.
