- kernel family: recurrent attention (time-mixed Triton chunked linear module)
- concise summary: Processes Time-Token Transform blocks in BT-sized chunks, blending Q/K/V with per-head affine parameters and optional recurrent state to emit normalized outputs and updated states.
- detailed summary: fused_chunk_ttt_linear_fwd_kernel runs with grid (N·H) so each program walks a variable-length sequence, loading BT rows of Q, K, V, η, weights, and biases, and keeps a local K×V matrix b_h plus a bias vector b_hb. Inside each chunk it forms Kᵀ·h, applies per-token layer norm (mean/var + rstd), applies the learned scale/bias, and mixes in the gate η to generate the output o = Q·h plus corrective terms. The kernel also updates the hidden state via the last η slice, respecting optional initial/final state buffers and cu_seqlens, so the entire recurrent linear transform stays on-chip during forward execution.
