- kernel family: attention (chunked gated linear attention with recurrent state)
- concise summary: The forward path normalizes the decay stream, rescales Q/K, and streams through the sequence in BT=16 chunks to produce attention outputs while maintaining an optional K×V state per head.
- detailed summary: It first calls chunk_local_cumsum to compute chunkwise prefix sums of the gating signal, then prepare_qg_kg to scale Q/K by the exponentiated gates. fused_chunk_gla_fwd_kernel launches with grid (NV, NK, B·H) so each program owns a tile of K×V channels, repeatedly loads Q/K/V blocks, updates a per-tile hidden matrix b_h = exp(g)·b_h + K@V, and emits Q·b_h while optionally seeding and storing recurrent state. Afterwards fwd_inner_chunk builds a lower-triangular score tensor A for intra-chunk interactions, multiplies it with reshaped V, and the result is accumulated into the output along with the streamed pass, keeping all reductions local to the tile without touching the backward path.
