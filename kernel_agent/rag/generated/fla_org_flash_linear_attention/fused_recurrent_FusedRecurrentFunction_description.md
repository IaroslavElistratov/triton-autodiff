- kernel family: recurrent attention (generic gated outer-product state)
- concise summary: Provides a configurable recurrent operator where the K×V hidden matrix is multiplied by combinations of scalar gates (g, g_gamma, gk, gv), receives the current K⊗V, and emits Q·hidden, supporting causal or reversed traversal.
- detailed summary: fused_recurrent_fwd_kernel tiles value and key dimensions (NV, NK, N·H), loads per-token Q/K/V, and conditionally multiplies the hidden state by exp of each gate tensor if supplied (scalar per head, per key, per value). After adding the new outer product, it computes the output tile by scaling Q and summing over features. The kernel works with cu_seqlens and optional initial/final states; since NK is limited to one tile the entire key dimension fits in registers/shared memory, keeping the forward recurrence self-contained.
