- kernel family: RWKV fused addcmul (elementwise recurrent update)
- concise summary: Applies the RWKV-7 fused addcmul update by chunking the time dimension, loading per-feature coefficients, and computing `hidden + delta * x_*` for each of the recurrent streams (r, w, k, v, a, and optional g) in a single Triton kernel launch.
- detailed summary: The forward loop processes up to 65,536 timesteps at a time to respect launch limits. For each chunk, `fused_addcmul_fwd_kernel` loads the current hidden slice and delta activations, broadcasts the learned vectors (`x_r`, `x_w`, `x_k`, `x_v`, `x_a`, and optionally `x_g`), and emits fused FMA results for every stream, writing them into preallocated output tensors (`oxr`, `oxw`, `oxk`, `oxv`, `oxa`, `oxg`). By keeping the operations in one kernel the routine minimizes memory traffic and ensures consistent scaling across all recurrent branches. The backward path later reuses the saved tensors, so the forward step only needs to stash the inputs and a flag indicating whether the gate stream was active.
