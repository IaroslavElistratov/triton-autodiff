- kernel family: gated linear attention (simplified chunked GLA without auxiliary scans)
- concise summary: The forward path optionally folds the gate tensor into chunked prefix sums, runs a tiled recurrence that multiplies each K/V slice by the gate factors to update the hidden state, and then applies the same chunked tiles to project queries against the gated values, yielding the output and (optionally) the final state.
- detailed summary: After choosing a chunk size (up to 64), the wrapper feeds `g` through `chunk_local_cumsum` when present, producing per-step gate accumulators. `chunk_fwd_h` launches Triton programs over `(K-block, V-block, batch·head)` that iterate across the sequence: for each BT-length tile they load K/V, rescale them by the gate factors (`g` or `g_gamma` ramps), and accumulate into an fp32 state buffer `h`, seeding from `initial_state` and storing boundary states `ht` if requested. `chunk_fwd_o` reuses the same chunking to load Q/K/V, applies the gate weights, contracts with the cached state slices, and writes the chunked outputs. The wrapper saves Q/K/V, gated prefixes, and state inputs so backward can replay the same recurrence.
