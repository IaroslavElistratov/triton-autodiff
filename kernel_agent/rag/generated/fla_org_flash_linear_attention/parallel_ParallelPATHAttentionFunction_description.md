- kernel family: attention (PATH factored attention with chunked Householder transforms)
- concise summary: Executes the PATH attention factorization by building chunkwise (I+A)⁻¹ factors from the w weights, transforming Q/K via small Householder systems, and then streaming chunk outputs with gated cumulative sums and cached key projections.
- detailed summary: The forward computes g_cumsum for gating, chooses chunk sizes (BS for intra-chunk, BT for inter-chunk), and calls chunk_scaled_dot_kkt_fwd + solve_tril to convert the learned Householder weights w and scaling beta into per-chunk triangular inverses A. intra_chunk_preprocess_fwd_fn then runs intra_chunk_preprocess_fwd_kernel to mix Q/K/V with A, w, and beta, generating transformed tensors (q_new, k_new, w2), partial outputs o, and normalization logs (L, M). Finally parallel_path_fwd_fn streams these chunks—reusing the chunked K cache and optional g_cumsum—to accumulate the full attention output while optionally materializing a cache via prepare_k_cache_fn; all steps are confined to the forward path with backward kernels never touched.
