- kernel family: rotary embedding (chunked Triton apply with optional variable-length and interleaved layouts)
- concise summary: Applies rotary position embeddings to a B×T×H×D tensor by tiling along sequence/time, mixing even–odd feature pairs with cached cos/sin tables, and handling optional in-place updates, interleaved storage, and per-sequence offsets.
- detailed summary: The launcher prepares chunk metadata from `cu_seqlens` when sequences are ragged, chooses feature and token tile sizes (`BD` as next pow2 of 2·R, `BT` from SM count), and dispatches a grid of (NT, B, H) so each kernel instance covers a time tile for one batch/head. Inside the kernel, varlen batches advance base pointers by prefix lengths, compute token indices `o_t`, and derive cos/sin lookup positions using either a scalar or tensor of offsets; guard masks clip tokens beyond the chunk or rotary table. Non-interleaved mode loads paired feature halves, converts to fp32, mixes them with cos/sin (optionally flipping the sine for conjugation), and writes the rotated values back while preserving untouched tail dimensions; interleaved mode reshuffles even/odd lanes to accomplish the same rotation for alternating layouts. This forward path reuses the same Triton kernel irrespective of inplace mode—the caller decides whether to materialize a new tensor or mutate in place before launch.
