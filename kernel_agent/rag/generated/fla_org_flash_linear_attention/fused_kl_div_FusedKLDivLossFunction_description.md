- kernel family: loss (fused KL divergence between logits)
- concise summary: Calculates KL(logits || target_logits) row-wise while simultaneously writing the gradient of the student logits, batching over linear projections to keep memory bounded.
- detailed summary: kl_div_kernel runs twice over each vocab block: the first pass collects log-sum-exp statistics for both student and teacher logits using numerically stable rolling maxima, and the second pass accumulates the KL value and stores the gradient ∂L/∂logits = p_student - p_teacher back in place. The host fused_kl_div_forward slices the batch into chunks so it can call F.linear to form logits, invokes the kernel, and aggregates the loss scalar while optionally building weight gradients. Only the forward quantities (loss, dx, dw) are produced; backward is handled elsewhere.
