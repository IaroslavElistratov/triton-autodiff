- kernel family: chunked attention (generic fused implementation with optional gating)
- concise summary: Provides a general-purpose chunked attention kernel that accumulates key/value state across blocks, supports optional per-token gates (`g`, `g_gamma`), and outputs both the attention result and an optional final state tensor.
- detailed summary: For each (batch, head) tile the `fused_chunk_fwd_kernel` walks the sequence in blocks of `BT`, loading query/key/value tiles, applying the dot-product plus scale, and—when gates are provided—multiplying by `exp(g)` factors or per-head `g_gamma`. It keeps a running state `b_h` that captures contributions from prior chunks, optionally seeded from `initial_state`, and writes the chunk’s output into an accumulation buffer (summing across key splits when `K > BK`). If `output_final_state` is enabled, the last `b_h` snapshot is stored for reuse. The driver handles gate prefix sums via `chunk_local_cumsum`, launches the kernel, reduces the split outputs as needed, and hands back the fused attention result (and final state) in the caller’s dtype.
