- kernel family: token shift / temporal differencing (varlen-aware with optional cache feedback)
- concise summary: Produces per-token deltas across a B×T×D activation stream by subtracting each token from its predecessor (or from an external cache for the first position), optionally emitting the last token to refresh a recurrent cache.
- detailed summary: The launcher chooses between two Triton kernels: a `short` variant that assigns each (sequence, timestep) pair to one program when T≤4096, and a `long` variant that tiles both features (`BD`) and chunked timesteps (`BT`) for longer or batched workloads. Variable-length batches use prefix-sum chunk indices to derive (`bos`,`eos`) windows, while dense batches compute offsets analytically; both modes map feature lanes via `tl.arange` with masks when D is not a power of two. In every step the kernel loads the current token, subtracts either the previous token in-place or an initialization cache for the first position, writes the delta to the output, and optionally snapshots the final token into `cache_out` to support streaming decode. The short kernel also detects decode-mode micro-batches (T==1) and short-circuits to a direct cache-minus-input update, whereas the long kernel iterates through the time chunk in-register so that each program handles sequential differences within its assigned tile.
