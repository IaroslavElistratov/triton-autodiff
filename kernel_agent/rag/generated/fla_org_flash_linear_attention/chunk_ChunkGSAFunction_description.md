- kernel family: chunked gated state attention (GSA)
- concise summary: Runs GSA in two stages—first computing chunk-wise logits and recurrent key states with a gated scan over the auxiliary stream `s`, then softmaxing to probabilities and invoking a GLA-style value pass to obtain the final outputs and optional terminal states.
- detailed summary: Forward execution starts by rolling the gate tensor `g` into chunked cumulative sums, then `chunk_gsa_fwd_k` propagates a recurrent state `h_k` over the `k`/`s` branch: `chunk_fwd_h` advances in `BT`-sized tiles, `chunk_gsa_fwd_k_kernel_inter` contracts queries with the stored states for inter-chunk contributions, and `chunk_gsa_fwd_k_kernel_intra` fills in the lower-triangular intra-block terms, yielding logits `ok` and the cached triangular tensor `A_k`. A softmax produces probabilities `p`, which are cast back to the model dtype and fed into `chunk_gsa_fwd_v`, a reuse of the chunked GLA pipeline that evolves a second state `h_v` and mixes the gated values `v` to deliver `ov`. The context retains the logits, softmax, intermediate states, and triangular blocks so backward can replay the gated-state attention mechanics.
