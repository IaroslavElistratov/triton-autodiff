- kernel family: sequence mixing (DPLR generalized delta rule with chunked low-rank factors)
- concise summary: The forward pipeline chunk-wises reweights the low-rank factors (q,k,a,b) by gate exponentials, accumulates blockwise interaction matrices, derives transformed representations (`w`,`u`) for the delta rule, runs a gated recurrence to update the state/value stream, and finally combines the updated state with the original values to emit the output (optionally returning the final recurrent state).
- detailed summary: With chunk size 16, `chunk_dplr_fwd_intra` drives `chunk_dplr_fwd_A_kernel_intra_sub_intra`, which for each `(batch, head, chunk)` computes lower-triangular tiles `A_qk`, `A_qb`, `A_ak`, `A_ab` while multiplying q/k/a/b by intra- (`gi`) and inter-chunk (`ge`) gate exponentials to obtain gated tensors `qg`, `kg`, `ag`, `bg`. `prepare_wy_repr_fwd` then multiplies these tiles with the beta-scaled values to produce the auxiliary streams `w` and `u`. The recurrent kernel `chunk_dplr_fwd_h` iterates over time using the gated keys `kg`, the gated bias branch `bg`, the value stream, and `w/u` to update an fp32 state tensor `h` (seeding from `initial_state` if supplied) and to generate a rescaled value stream `v_new`, keeping track of the final state when requested. Finally, `chunk_dplr_fwd_o` contracts the gated queries `qg`, the original values, the rescaled values, and the precomputed `A_qk/A_qb` with `h` to assemble each chunk’s output tile; these tensors plus configuration parameters (`chunk_size`, gate buffers) are cached on the context for backward.
