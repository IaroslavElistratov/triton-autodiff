- kernel family: gated linear attention (chunked prefix scan with recurrent state updates)
- concise summary: The forward path computes chunked cumulative gates, runs a tiled recurrence to maintain the GLA state tensor, assembles lower-triangular attention blocks from the gated Q/K pairs, and finally contracts those blocks with the values plus the running state to emit the chunk outputs, optionally recording the final state.
- detailed summary: `chunk_gla_fwd` starts by turning the gate logits `g` into cumulative sums via `chunk_local_cumsum`; these prefix factors drive `chunk_fwd_h`, whose Triton kernel traverses each `(batch, head)` stream in `BT`-length tiles, rescales K/V by the appropriate gate ratios, and updates an fp32 state tensor `h` (seeding from `initial_state` when provided, storing boundary states in `ht` if requested). Next, `chunk_gla_fwd_intra_gk` iterates through the same chunking scheme to build strictly lower-triangular blocks `A` that capture scaled Q·K interactions under the gate weights (handling large head dimensions by splitting/merging subblocks). Finally, `chunk_gla_fwd_o_gk` combines the gated queries, original values, the accumulated state `h`, and the `A` tiles to form each output block. The wrapper caches `q`, `k`, `v`, either the original gate tensor or its prefix-sum form, plus `A` and configuration metadata so backward can reproduce the same recurrence.
