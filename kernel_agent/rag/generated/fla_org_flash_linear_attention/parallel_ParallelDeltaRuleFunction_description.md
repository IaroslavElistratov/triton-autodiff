- kernel family: attention (parallel delta-rule decomposition)
- concise summary: Uses a two-stage pipeline to transform Q/K with chunk-local low-rank corrections and then stream through chunks subtracting previously explained mass while accumulating attention outputs (and optionally attention matrices).
- detailed summary: chunk_transform_qk_fwd_kernel processes each BT chunk, forming causal QK and KK Gram matrices, multiplying by the precomputed lower-triangular solver A, and writing transformed Q and K (q_new, k_new) plus optional intra-chunk attention for inspection. parallel_delta_rule_fwd_kernel then iterates backwards over off-diagonal blocks and forwards over the causal block, repeatedly computing scores, applying the beta-scaled corrections stored in k2, updating the running Q residual, and accumulating o_new. Optional save_intra_chunk_attn copies intra-block attention when required. The forward API returns the new outputs, transformed states, and any auxiliary tensors without touching gradients.
