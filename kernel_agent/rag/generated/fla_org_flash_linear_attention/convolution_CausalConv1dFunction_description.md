- kernel family: convolution (chunked causal 1D convolution with optional state carry)
- concise summary: The forward routine tiles the batch/time plane, loads each receptive field window, multiplies by the causal filter weights (optionally adding bias, residual, and swish activation), and writes the result while optionally computing the updated convolution state for streaming use.
- detailed summary: `causal_conv1d_fwd` flattens the input as needed, picks block sizes for tokens and filter width, and calls `causal_conv1d_fwd_kernel` with grid `(feature-block, chunk, batch)`. For each tile the kernel walks the causal window: when no initial state is provided it only reads valid in-range timesteps; otherwise it pulls missing prefix elements from the cached state to ensure continuity. Dot products against the weight tail are accumulated in fp32, bias and residual terms are fused, and an optional swish activation is applied before the result is stored. If `output_final_state=True`, the helper `causal_conv1d_update_states` scans the tail of each sequence (reusing the same chunk metadata) to assemble the final kernel state tensor. The wrapper returns the reshaped convolution output together with the updated state when requested, caching all relevant inputs for backward.
