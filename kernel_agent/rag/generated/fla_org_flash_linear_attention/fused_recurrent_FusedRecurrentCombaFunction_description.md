- kernel family: recurrent attention (Comba-style gated linear attention)
- concise summary: Streams through each sequence chunk keeping a K×V hidden matrix that is decayed by gated exponents, corrected by auxiliary projector p, modulated by head-specific beta, and then dotted with the current Q to produce outputs.
- detailed summary: fused_recurrent_comba_fwd_kernel launches with grid (NV, NK, N·HV); each program selects a tile of keys/values for one head-group, optionally reloads an initial state, and for every timestep loads Q/K/V along with decay g and projector p. It subtracts the projected contribution b_h·p, multiplies the state by exp(g), scales V by either per-value beta or a scalar, adds the outer product K⊗V to the hidden state, and finally writes Q·hidden to the output tensor while advancing block pointers. If requested it also writes the final hidden matrix per sequence, supporting variable-length sequences via cu_seqlens.
