- kernel family: MesaNet attention (chunked gated delta-rule with conjugate-gradient solve)
- concise summary: Forms chunked MesaNet states by integrating gated key/value updates, then runs a per-chunk conjugate-gradient solve to produce the transformed queries and final outputs, while preserving optional initial/final recurrent states.
- detailed summary: The forward routine first computes chunkwise gate prefix sums (`chunk_local_cumsum`) and invokes `chunk_mesa_fwd_h`, which iterates over the sequence in 64-token blocks, decays the stored state with the gate, updates the `K×V` matrices `h_kk` and `h_kv`, and optionally records terminal states. Those states feed `chunk_mesa_cg_fwd`: each chunk launches a Triton CG solver (`chunk_fwd_mesa_cg_dim64_kernel`) that solves the MesaNet linear system for `q_star` using the cached `h`, `h_kv`, gate weights, `beta`, and regularizer `lamb`, and simultaneously accumulates the chunk output `o`. The driver handles optional input whitening, returns the output tensor together with any requested final states, and saves all intermediate buffers needed for backward recomputation.
