- kernel family: recurrent attention (delta rule with DPLR parameterization)
- concise summary: Implements the diagonal-plus-low-rank delta rule recurrence, retaining a K×V state that is repeatedly shrunk by exp(gk), mixed by low-rank factors a and b, and updated with the latest K⊗V outer product before projecting with Q.
- detailed summary: fused_recurrent_dplr_delta_rule_fwd_kernel is launched per (value tile, sequence/head) and iterates forward or backward through time depending on the reverse flag. At each step it scales the hidden state by exp(gk), adds b[:,None] * (aᵀ·hidden) to implement the rank-one component, then injects the new key/value outer product. The kernel multiplies Q by scale, computes the dot with the fresh state, writes the activation, and moves block pointers respecting cu_seqlens. Optional initial/final states are handled entirely inside the program so the forward path provides both outputs and recurrent caches.
