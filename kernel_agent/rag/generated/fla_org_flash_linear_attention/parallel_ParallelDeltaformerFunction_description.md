- kernel family: attention (deltaformer sliding-window)
- concise summary: Processes a trailing context of length C per head by iterating over the full key sequence, maintaining log-sum-exp statistics, accumulating a normalized value buffer, and writing both softened weights and residual updates.
- detailed summary: parallel_deltaformer_fwd_kernel tiles the C context across BLOCK_C rows and BLOCK_T key stripes. For each stripe it updates per-row maxima and sums in base-2 exponent space, accumulating acc by multiplying the current probabilities with the stored update vectors u. After the scan it writes the log-sum-exp (lse) and computes a correction u = v - β·acc/rowsum, storing it back into the tail of u_ptr and emitting the probability tiles w_ptr for kv positions within the context. The host function handles batching/chunking when cu_seqlens is provided and returns the normalized weights plus log norms for reuse downstream.
