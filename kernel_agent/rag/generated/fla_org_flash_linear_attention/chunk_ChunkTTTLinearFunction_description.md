- kernel family: time-mixing (TTT linear recurrent block with learnable eta/w/b parameters)
- concise summary: The forward pass chunkwise updates two coupled state tensors (`h` for the main dynamics and `hb` for the bias branch) using the TTT recurrence, writing a gated/normalized value stream `v_new`, and then projects the queries against this updated state to produce the output while optionally returning both final states.
- detailed summary: With chunk size 16, `chunk_ttt_linear_fwd_h` launches a Triton kernel over `(K-block, V-block, batch·head)` that iterates through the sequence, loading K/V tiles plus per-head parameters (`eta`, `w`, `b`) and eps. At each timestep it applies the TTT update—computing outer products `k⊗v`, mixing them with the running state `h`, maintaining a bias accumulator `hb`, and writing the normalized value tile to `v_new`; optional initial states (`h0`, `hb0`) are injected and final states are saved when requested. `chunk_ttt_linear_fwd_o` then walks the same tile structure, combining gated Q/K/V with the stored `h` and `hb` (and the exponential of `eta`) to form the chunk outputs under the supplied scale. The wrapper orchestrates both kernels, returning the output along with the final recurrent state/bias tensors for downstream use.
