- kernel family: RWKV-style gated linear attention (chunked RWKV-6 recurrence with dual gate scans)
- concise summary: The forward pipeline scans the 4-D gate tensor to build inclusive/exclusive prefix sums, uses them to update a chunked hidden state with gated key/value tiles, constructs lower-triangular attention blocks from gated Q·K interactions (modulated by an auxiliary `u` stream), and finally combines those blocks with the running state to emit the chunk outputs while optionally returning the last state.
- detailed summary: For a chosen chunk size (≥32), `chunk_rwkv6_fwd_cumsum` launches a Triton kernel that produces `gi` (inclusive) and `ge` (exclusive) gate prefixes per head and channel. `chunk_fwd_h` then walks each `(batch, head)` stream tile-by-tile, rescales the loaded K/V slices by the appropriate gate ratios (`gi`) and accumulates them into an fp32 state buffer `h`, seeding from `initial_state` and caching the boundary state `ht` when requested. In parallel, `chunk_rwkv6_fwd_intra` builds a block-lower-triangular matrix `A`: it tiles Q/K pairs, weights them with both `gi` and `ge`, mixes in the auxiliary vector `u`, and stores the strictly causal chunks (handling wide heads by splitting/merging subblocks). Finally `chunk_gla_fwd_o_gk` reuses `ge` to gate the value stream, projects the gated queries through `A`, adds the state contribution from `h`, and writes the fused output tensor; the wrapper keeps `A`, `h`, and prefix buffers for backward.
