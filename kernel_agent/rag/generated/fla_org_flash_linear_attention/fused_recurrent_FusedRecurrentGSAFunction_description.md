- kernel family: recurrent attention (Gated State Attention)
- concise summary: Runs a two-phase recurrent attention where the first pass accumulates key-side state with value gates, converts it to a softmax distribution, and the second pass mixes gated values to produce outputs, with a fast inference shortcut for T=1.
- detailed summary: The forward first calls fused_recurrent_fwd_kernel with gv gating to build ok (pre-softmax logits) and optionally hkt, using chunked cu_seqlens-aware loops. The logits are normalized via softmax along the middle dimension to form qv, then a second invocation of the same kernel—this time treating qv as queries, s as keys, and g as key-gates—produces the final value stream ov and optionally hvt. For single-step inference it dispatches fused_recurrent_gsa_inference_kernel, which directly evolves the hidden matrices and writes outputs. All gating, normalization, and state handling occur on the forward path without touching the backward implementation.
