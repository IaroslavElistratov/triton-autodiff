- kernel family: attention (block-sparse neighborhood selective attention)
- concise summary: Computes attention where each query attends only to a set of registered key blocks, accumulating logits and outputs block-by-block while preserving causal masking and optional variable lengths.
- detailed summary: parallel_nsa_fwd_kernel runs over (time position, value tile, batch·head); it pulls the list of participating block indices (and optional counts) from block_indices, iterates through them, loads the corresponding K/V slices, computes scaled dot products, and keeps running base-e log-sum-exp scalars b_m/b_acc. Each step multiplies the accumulated value buffer by exp(prev-max - new-max) before adding the new contribution, and final outputs divide by b_acc and store the log normalizer. The wrapper chooses BK/BV tile sizes based on shared-memory availability, supports cu_seqlens via token_indices, and leaves backward untouched.
