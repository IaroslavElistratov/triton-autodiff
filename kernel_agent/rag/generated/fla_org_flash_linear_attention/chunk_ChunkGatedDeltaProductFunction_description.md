- kernel family: chunked gated delta-product attention (with Householder expansion)
- concise summary: Expands the gated delta-product formulation across the requested Householder copies, builds a chunked lower-triangular system from the gated keys, solves it to form WY update matrices, evolves a gated recurrent state, and mixes queries with the resulting values.
- detailed summary: The forward pipeline first interleaves the gate tensor when `num_householder > 1`, runs `chunk_local_cumsum` to obtain cumulative gates for both the original and expanded streams, and feeds them to `chunk_scaled_dot_kkt_fwd` to assemble the strictly lower-triangular matrix `A = beta·K·Kᵀ` (optionally gate-weighted). After inverting `(I + A)` via `solve_tril`, it recreates the WY factors `w` and `u` with either `gdn_recompute_w_u_fwd` (gated) or `dn_recompute_w_u_fwd`. The `chunk_gated_delta_product_fwd_h` kernel then marches through the sequence in 64-length chunks, applying the gate accumulators to update the `K×V` state `h` and caching the transformed values. Finally `chunk_gated_delta_product_fwd_o` contracts the queries against `h`, applies the appropriate gate rescaling, and produces the attention output, while saving the gating buffers, triangular factors, and optional final state for backward reuse.
