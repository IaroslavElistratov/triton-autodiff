- kernel family: attention-like sequence mixing (chunked ABC operator with hierarchical log-cumsum preprocessing)
- concise summary: The forward routine preprocesses the state tensor `s` with a log-cumsum-exp scan, builds chunk-level key/value summaries via `chunk_abc_fwd_kernel_h`, assembles blockwise attention logits (`ok0`, `ok1`) that are softmaxed to produce mixing weights, and then reuses the same hierarchical kernels to combine `v` into the final output while optionally threading recurrent states.
- detailed summary: With chunk length `BT=64`, the pipeline first calls `logcumsumexp_fwd_kernel` so each batch–head stream gets running log-normalizers `z` for the `M`-sized state channels. `fwd_inner` (backed by `chunk_abc_fwd_kernel_h`) streams over the sequence in tiles, using the precomputed `z` to accumulate cross-chunk summaries `h` (and storing or seeding recurrent state tensors when requested). The kernel `chunk_abc_fwd_kernel_K` then contracts the scaled queries with both `k` and `h`, writes the lower-triangular matrix `A`, and produces one slice of the chunked logits `ok1`, while `chunk_abc_fwd_kernel_intra_K` covers intra-chunk combinations to form `ok0`; the sum is softmaxed (in fp32) to yield `qv`. That probability tensor drives a second `fwd_inner` pass (now treating `s` as keys and `v` as values) to create hierarchical value summaries `hv`, which together with `A` feed `chunk_abc_fwd_kernel_V` and `chunk_abc_fwd_kernel_intra_V` to assemble the final output tiles `ov`. All intermediate tensors (`z`, `ok`, `p`, `hk`, `hv`, `Av`) plus configuration knobs (`BT`, tiling factors) are cached on the context for the backward sweep.
