It then processes the intra-block region with a causal mask m_s, repeats the same polynomial expansion, and finally stores the partial output and normalization z into tensors that are later summed across K tiles. The forward wrapper enforces NK=1, allocates output/normalizer tensors, and records the scaling factor for backward.
