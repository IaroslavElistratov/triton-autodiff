- kernel family: mean pooling (chunked BxTxHxD tensor with optional variable lengths)
- concise summary: Computes per-chunk means of an input sequence by slicing B×T×H×D blocks, summing across the chunk length, and writing normalized chunk averages into an output tensor of shape B×NT×H×D.
- detailed summary: Each Triton program instance indexes a feature tile (BD), a chunk index (BT), and a batch–head pair; for variable-length batches it looks up chunk offsets via cached prefix sums, otherwise it derives offsets from uniform T. The kernel constructs block pointers to a BT×BD tile of the input, accumulates along the temporal axis in fp32, divides by the effective chunk length (handling tail chunks), and stores the per-feature means into contiguous output tiles. The Python launcher allocates the chunked output, prepares cached chunk indices when `cu_seqlens` is provided, defines the grid as (ceil_div(D, BD), NT, B·H), and dispatches the kernel to cover all feature tiles without any reduction loops beyond the intra-kernel sum.
