- kernel family: attention-like sequence mixing (Comba chunk operator with triangular solves)
- concise summary: The forward routine builds chunked cumulative gates, forms a lower-triangular interaction matrix from auxiliary keys, inverts it, uses the result to recompute transformed key/value streams (`w`, `u`), runs a gated delta-rule recurrence to update the state, and finally projects queries against the new state to emit the chunk outputs (optionally returning the terminal state).
- detailed summary: `chunk_comba_fwd` drives the pipeline: (1) `chunk_comba_cumsum_scalar_fwd` scans the gate tensor `g` across 64-length chunks to obtain both the cumulative log-sums `g` and their shifted variant `g0`; (2) `chunk_scaled_dot_comba_pkt_fwd` contracts `beta`-weighted auxiliary keys `p` with the true keys `k`, storing a strictly lower-triangular matrix `A` per chunk, which is turned into `(I + A)^{-1}` via `solve_tril`; (3) `recompute_w_u_fwd` multiplies this inverse against chunked values/keys (scaled by `beta` and the gate exponentials) to produce `u` and `w`; (4) `chunk_gated_delta_rule_fwd_h` iterates over time, using `w`, `u`, the gate accumulators, and any provided initial state to evolve the recurrent state tensor and reweighted values `v_new`, capturing final states when requested; and (5) `chunk_fwd_o` applies the scaled queries to the updated key/value/state trio to generate the output tiles. The wrapper optionaly L2-normalizes `q`, `k`, and `p` before the pipeline, saves all intermediates (`g0`, `g`, `A`, states) plus normalization factors, and returns the mixed output along with the final state if requested.
