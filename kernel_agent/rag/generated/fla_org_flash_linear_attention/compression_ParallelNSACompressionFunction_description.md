- kernel family: attention compression (parallel normalized sparse attention shingling)
- concise summary: The forward kernel iterates over tokens and grouping heads, computing softmax-normalized scores across previously seen compression blocks and accumulating the weighted value tiles, while tracking log-sum-exp statistics that downstream stages can reuse.
- detailed summary: After optional sequence packing metadata is prepared, `parallel_nsa_compression_fwd_kernel` launches with grid `(T, V-blocks, batch·head)`. For each timestep it loads the corresponding grouped-query slice (scaled by `scale`), streams over completed block columns (`BC=BS=block_size`), and repeatedly loads K/V tiles from the cached chunk offsets. Inside the loop it forms dot products, applies causal masking by zeroing future blocks, updates the running max/denominator via exp-log compensation, and accumulates the weighted value contributions. When all eligible blocks have been processed it normalizes the accumulator, writes the compressed output tile to `o`, and—once per value block—stores the per-group log-sum-exp vector `lse`. The Python wrapper sets autotuned block sizes, allocates the output/lse tensors, and saves inputs plus token index tables so the backward pass can rebuild the same compression sweep.
