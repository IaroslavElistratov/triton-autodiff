- kernel family: Mixture-of-experts gather (scatter-to-scatter parallel linear)
- concise summary: The forward Triton kernel iterates over expert IDs per tile, gathers the relevant token activations, multiplies them by per-expert weight blocks, optionally adds biases, and scatters the results into the output ordering used by the MoE router.
- detailed summary: `_scatter2scatter` launches one program per `(BLOCK_M × BLOCK_N)` tile of the sorted expert–token list; it loads the expert indices and original token positions (`grouped_idx_ptr`), then loops only over the experts that appear in that tile. For each expert it forms masks identifying which rows belong to the expert, derives the input row indices (either the grouped index or the original token index depending on `x_grouped`), and calls `_compute_expert_block` to stream through the K dimension in BLOCK_K chunks, performing masked `tl.dot` accumulations into an FP32 accumulator (with optional TF32). After the expert loop it adds per-expert biases when provided and finally stores the tile back to the output layout controlled by `y_grouped`. The Python wrapper `scatter2scatter` validates shapes, allocates or reuses the output buffer, and dispatches the kernel via the custom OP entrypoint, while `_ParallelLinear_forward` wraps this operation, optionally combines the per-expert outputs with gate coefficients, and records the metadata needed for backward.
