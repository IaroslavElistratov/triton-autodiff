- kernel family: Flash attention (blockwise softmax attention with optional bias/causal masking)
- concise summary: The forward kernel tiles queries over BLOCK_M rows per (batch, head), streams through key/value tiles, incorporates vector or matrix bias plus causal masking, and maintains numerically stable running statistics to emit both the attention output and per-query log-sum-exp.
- detailed summary: `_fwd_kernel` launches a 2D grid where program_id(0) selects a BLOCK_M slice of query positions and program_id(1) selects the batch–head pair. Each instance loads its query tile (with masking when dimensions are uneven), then iterates over key/value tiles up to either `seqlen_k` or the causal diagonal. For each tile it loads K and optionally bias, forms the QK scores, applies `softmax_scale`, fuses causal or ragged masking, and uses vectorized exponentials to update running maxima (`m_i`) and log-sum-exp accumulators (`lse_i`) stored in FP32. A scratch buffer `TMP` holds scaling factors so the accumulated output tile `acc_o` can be renormalized between iterations before multiplying the current probabilities with the V tile and accumulating in FP32. After exhausting keys the kernel rescales the result using the final `lse_i`, writes the log-sum-exp values into the rounded storage, and stores the BLOCK_M×headdim output with tail masking as needed. `_flash_attn_forward` validates layouts, expands bias into the expected shape, allocates the temporary LSE/scratch tensors, chooses BLOCK=128 with warp count conditioned on head dimension, and dispatches the kernel with bias-type dependent strides.
