- kernel family: attention (FlashAttention-style with optional bias and causal masking)
- concise summary: The Triton forward kernel tiles queries and keys/values, performs log-sum-exp stabilized softmax with optional per-head bias, and accumulates the weighted values into the output while recording log-sum-exp scalars for reuse.
- detailed summary: For each `(batch, head, query-block)` program, `_fwd_kernel` loads a BLOCK_M×head_dim tile of Q, streams over BLOCK_N key/value tiles, computes q·kᵀ, applies vector or matrix bias when supplied, enforces causal masking if requested, and updates running maxima/sums (`m_i`, `lse_i`) to maintain numerical stability. Temporary buffers store scaling factors so accumulated outputs can be rescaled between iterations before the final normalization and writeback; the kernel writes both the attention result and per-head log-sum-exp rows. The Python driver normalizes shapes, expands bias to the right layout, sets autotuned block sizes/warps based on head dimension, and dispatches the kernel with cached sequence-length keys to enable reuse.
